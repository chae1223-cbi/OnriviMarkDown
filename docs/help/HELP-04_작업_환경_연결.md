# 작업장·로컬 폴더·웹드라이브 연결

작업장 폴더는 원고를 탐색하고 저장할 기준 위치입니다. 공통 리소스 폴더는 이미지·서식·프롬프트 등 부속 자료의 위치입니다. 두 폴더는 역할이 다르며 같은 이름의 파일이 있어도 실제 위치가 다를 수 있습니다.

## 로컬 작업장

1. 파일 메뉴의 작업장 열기로 폴더를 선택합니다.
2. 브라우저나 운영체제가 요청하는 폴더 접근 권한을 허용합니다.
3. 왼쪽 탐색기에서 문서를 엽니다.
4. 환경설정에서 공통 리소스 폴더의 연결 상태를 확인합니다.

웹에서는 브라우저의 폴더 접근 기능과 권한 유지 정책에 영향을 받습니다. 재접속 뒤 파일이 보이지 않으면 삭제로 단정하지 말고 같은 폴더를 다시 연결합니다.

## 개인 웹드라이브

파일 메뉴에서 개인 웹드라이브 연결을 선택하고 계정 인증을 진행합니다. 연결 계정과 작업 폴더를 확인한 뒤 문서를 엽니다. 로컬 작업장과 웹드라이브는 저장·이미지 접근 방식이 다르므로 경로를 임의로 섞지 마세요.

## 다른 PC로 이동

원고뿐 아니라 이미지와 사용자 자료도 옮깁니다. 새 환경에서 공통 리소스 폴더를 연결하고 AI 연결 상태를 다시 확인합니다. 다른 기기나 계정의 키가 자동으로 사용된다고 가정하지 마세요.

폴더 연결 해제는 원본 폴더 삭제와 다릅니다. 파일 탐색기의 삭제 작업은 별도이며, 삭제 전에 대상 경로를 확인하세요.
