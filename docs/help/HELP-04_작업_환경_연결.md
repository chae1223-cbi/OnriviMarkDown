# 작업장·로컬 폴더·웹드라이브 연결

온리비 어서는 사용자의 문서를 특정 플랫폼 서버에 강제 종속시키지 않고, 내 컴퓨터의 로컬 폴더나 개인 웹드라이브(구글 드라이브 등)에 안전하게 보관하는 **사용자 주권 파일 구조**를 기본 원칙으로 합니다.

본 가이드에서는 원고를 체계적으로 관리하기 위한 작업장(Workspace) 지정과 공통 리소스 폴더 연결, 그리고 클라우드 드라이브 활용법을 안내합니다.

![[그림 4] 공통 리소스 폴더 및 작업 환경 설정](./assets/fig4_resource_folder.png)

## 1. 작업장(Workspace)과 공통 리소스 폴더의 명확한 구분

온리비 어서의 작업 공간은 두 개의 핵심 디렉토리로 구성됩니다:

1. **작업장 폴더 (Workspace - `onrivi_workspace_path`)**:
   - 순수 마크다운 원고 파일(`.md`)과 프로젝트 폴더들이 모여 있는 곳입니다.
   - 좌측 사이드바의 파일 탐색기에 표시되며, 새 문서를 만들면 이곳에 파일이 생성됩니다.
2. **공통 리소스 폴더 (Resource Folder - `media/`)**:
   - 원고 본문에 첨부되는 사진, 일러스트, 동영상 썸네일, 커스텀 CSS 서식, 워터마크 이미지, AI 설정 등이 보관되는 공유 창고입니다.
   - [환경설정(⚙️)] ➔ [일반 설정] ➔ [공통 자원 관리]에서 로컬 폴더를 지정합니다.

---

## 2. 작업장 폴더 연결 방법

- **Electron 데스크톱 앱에서**:
  - 상단 메뉴의 [파일] ➔ [작업장 열기]를 클릭하면 Windows 탐색기나 Mac Finder 창이 뜹니다.
  - 내 문서나 D드라이브 등 원하는 작업 폴더를 선택하고 [폴더 선택]을 누르면 즉시 연결됩니다.
- **웹 브라우저 환경에서**:
  - Chrome이나 Edge 브라우저의 File System Access API를 통해 로컬 폴더 읽기/쓰기 권한을 부여받아 연결합니다.
  - 브라우저 상단에 "파일 수정 권한을 허용하시겠습니까?"라는 팝업이 뜨면 [허용]을 눌러주셔야 저장이 가능합니다.

---

## 3. 클라우드 웹드라이브(Google Drive, OneDrive, Dropbox) 연동

외출 중이나 다른 PC와 문서를 동기화하고 싶다면 로컬 동기화 방식의 클라우드 스토리지를 연결하여 사용할 수 있습니다:

- **올바른 연동 방식**:
  - Google Drive 데스크톱 앱이나 Microsoft OneDrive가 내 PC에 마운트한 **로컬 가상 드라이브 폴더(예: `G:\내 드라이브\OnriviWorkspace`)**를 온리비 어서의 작업장으로 지정합니다.
  - 온리비 어서에서 `Ctrl + S`로 저장하면 해당 로컬 폴더에 기록되고, 클라우드 동기화 프로그램이 이를 백그라운드에서 자동으로 서버에 업로드합니다.
- **주의해야 할 점**:
  - 클라우드 프로그램이 파일을 동기화(잠금) 중일 때 동시에 덮어쓰기를 시도하면 "파일이 다른 프로세스에서 사용 중"이라는 일시적 오류가 발생할 수 있습니다. 이 경우 잠시 후 다시 `Ctrl + S`를 누르시면 정상 저장됩니다.

---

## 4. 데이터 안전 수칙 및 임의 폴백 원천 차단

- 온리비 어서는 개발 규칙에 따라 작업장 경로가 설정되어 있지 않을 때 임의로 C드라이브 루트나 프로그램 설치 폴더에 더미 폴더를 함부로 생성하지 않습니다.
- 작업장 폴더가 지정되지 않은 상태에서 저장을 시도하면 시스템이 명확한 안내 창을 띄워 사용자가 직접 원하는 폴더를 선택하도록 안내합니다.
- 다른 PC로 프로젝트를 이전하실 때는 **작업장 폴더**와 **공통 리소스 폴더** 두 곳을 모두 외장 드라이브로 복사해 주셔야 완벽한 저작 환경이 유지됩니다.
