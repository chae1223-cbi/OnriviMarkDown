## 1. 자동 렌더링

코드블록을 만들고 상단 **코드 블록 언어** 입력칸을 `mermaid`로 지정합니다. 코드 내용을 입력하거나 수정하면 문서보기에서 다이어그램을 자동 갱신합니다. 기존 내용이 있는 Mermaid 블록은 코드를 접고 다이어그램을 보여줍니다.

```mermaid
flowchart LR
  A[원고 작성] --> B[서식 선택]
  B --> C[내보내기]
```

## 2. 코드 수정과 그래프만 보기

**코드 편집**을 눌러 원문을 펼치고 수정합니다. **편집 완료**를 누르면 코드를 접습니다. 다이어그램 카드의 새 창 확대는 그래프를 별도 창에서 보는 기능입니다.

순서도에는 둥근 모서리·밝은 파랑 노드·회색 연결선과 ELK 자동 배치를 사용합니다. 같은 연결이라도 방향, 노드 이름, 렌더러와 화면 폭에 따라 배치가 달라질 수 있습니다. 참고 이미지의 좌표를 그대로 재현하는 기능은 아닙니다.

## 3. 작업 버튼

다이어그램에 마우스를 올리거나 포커스를 두면 상단 작업 버튼이 표시됩니다.

| 버튼 | 내용 |
| --- | --- |
| 코드 복사 | Mermaid 코드블록 원문 복사 |
| 새 창으로 확대 | 다이어그램 별도 창 보기 |
| 이미지 복사 | 렌더링된 다이어그램 이미지 복사 |
| 저장 | PNG 등 제공되는 이미지 저장 |

일반 CODE 헤더의 복사는 코드 내용만 복사합니다. Mermaid 카드의 코드 복사는 `mermaid` 코드블록 표시를 함께 포함합니다.

## 4. 오류가 뜨면

`-->`, 괄호·따옴표, 다이어그램 종류의 문법을 점검합니다. 유효한 코드도 렌더러 오류가 날 수 있습니다. 앱을 새로고침하고 콘솔 오류와 재현 코드를 확인하세요. 순환 참조 관련 ELK 로그 오류는 번들에서 수정되어 있으므로 설치판은 수정된 자산이 포함된 버전인지 확인합니다.

코드와 Mermaid 원문은 리소스 이미지 파일이 아니라 마크다운 본문에 저장됩니다.
