# 코드 블록 입력·편집·복사

개발 가이드, 기술 블로그, IT 교재, 소프트웨어 설명서를 작성할 때 소스코드는 가장 핵심적인 콘텐츠입니다. 온리비 어서는 전 세계 주요 프로그래밍 언어의 **고해상도 문법 강조(Syntax Highlighting)**와 **원클릭 코드 복사 도구**를 완벽 지원합니다.

---

## 1. 코드 블록 기본 입력 문법

키보드 숫자 1번 왼쪽에 있는 백틱(`` ` ``) 3개를 연속으로 입력하고, 한 칸 띄우지 않고 언어 식별자를 적습니다:

````markdown
```typescript
function calculateDiscount(price: number, rate: number): number {
  if (rate < 0 || rate > 1) {
    throw new Error("할인율은 0과 1 사이여야 합니다.");
  }
  return price * (1 - rate);
}
```
````

- **자동 닫기**: 백틱 3개를 입력하고 `Enter`를 누르면 닫는 백틱 3개가 자동으로 생성되어 커서가 블록 안쪽에 위치합니다.
- **슬래시 빠른 명령어 (`/code`)**: 빈 줄에서 `/code`를 입력하고 `Enter`를 누르면 언어를 선택할 수 있는 코드 블록이 즉시 생성됩니다.

---

## 2. 지원하는 주요 프로그래밍 언어 목록

온리비 어서는 30여 개 이상의 주요 언어 문법을 감지하여 알록달록한 전용 컬러 테마로 렌더링합니다:

- **웹 및 앱 개발**: `javascript`, `typescript`, `html`, `css`, `jsx`, `tsx`, `json`
- **백엔드 및 시스템**: `python`, `java`, `cpp` (C++), `csharp` (C#), `go`, `rust`, `php`
- **데이터 및 인프라**: `sql`, `yaml`, `dockerfile`, `bash`, `powershell`, `markdown`

---

## 3. 독자를 배려한 원클릭 [코드 복사] 버튼

- 우측 미리보기 및 블로그 HTML 복사 시 코드 블록 우측 상단에 단정한 **[복사 (Copy)]** 버튼이 자동으로 부착됩니다.
- 책이나 기술 문서를 읽는 독자가 마우스로 길게 드래그할 필요 없이, 버튼 클릭 한 번으로 들여쓰기 공백 손상 없이 완벽한 원본 코드를 클립보드로 복사할 수 있습니다.
- 코드 블록 내부에서 `Tab` 키를 누르면 다음 필드로 튕기지 않고 코드 인덴트(들여쓰기 2칸 또는 4칸)가 매끄럽게 동작합니다.
