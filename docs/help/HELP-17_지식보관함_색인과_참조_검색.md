> "지난달에 작성했던 회사 내규, 작년에 정리해 둔 학술 논문 요약, 책 1권에 썼던 세계관 설정을 AI가 완벽히 기억하고 새 글에 자연스럽게 인용해 준다면 어떨까요?  
> 온리비 어서의 **지식보관함(Knowledge Vault)**은 내 컴퓨터에 쌓인 방대한 마크다운 문서들을 개인형 AI 데이터베이스로 변환하여, 지어낸 거짓말(환각) 없는 정확한 팩트와 출처를 갖춘 글쓰기를 실현합니다."

## 1. 지식보관함(Knowledge Vault)의 핵심 개념과 개인형 RAG

일반적인 대화형 AI는 세상의 일반 상식은 잘 알지만, **'내 개인 원고나 회사의 기밀 업무 매뉴얼'**은 알지 못합니다. 또한 모르는 내용을 그럴싸하게 날조하는 환각(Hallucination) 현상이 발생하기도 합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 개인형 RAG (검색 증강 생성) 메커니즘           │
│                                                                        │
│  [사용자 질문] ➔ "우리 회사 이번 분기 재택근무 규정을 요약해줘"           │
│         │                                                              │
│         ▼                                                              │
│  [1단계: 지식 검색] 내 PC의 onrivi_knowledge.db에서 관련 규정 청크 검색  │
│         │          (SQLite FTS5 전문 색인으로 0.01초 만에 발췌)        │
│         ▼                                                              │
│  [2단계: 맥락 주입] 검색된 규정 원문 + 라인 번호(L12~L45)를 AI에 주입    │
│         │                                                              │
│         ▼                                                              │
│  [3단계: 정확한 집필] 내 원고의 실제 사실을 근거로 본문 작성            │
│                      + 문장 끝에 [출처 1: 취업규칙] 각주 자동 결합     │
└────────────────────────────────────────────────────────────────────────┘
```

온리비 어서는 **RAG(Retrieval-Augmented Generation, 검색 증강 생성)** 기술을 소프트웨어 내부에 완벽히 구현하여, 인터넷에 내 문서를 업로드하지 않고도 내 컴퓨터 안에서 안전하게 똑똑한 비서를 구축합니다.

## 2. 지식보관함 관리자(`KnowledgeManagerModal`) 진입 방법

지식보관함에 등록된 문서 목록을 확인하고, 문서를 일괄 색인하거나 관리하는 화면은 두 가지 방법으로 진입할 수 있습니다:

- **단축키**: `Ctrl + Shift + K` (Mac: `Cmd + Shift + K`)
- **상단 메뉴바**: [도구] ➔ **[지식 보관함 관리자]**
- **우측 툴바**: 우측 사이드바 툴바의 **[🏛️ 지식 베이스]** 버튼 클릭

![지식 보관함 관리 화면](media/fig4_resource_folder.png)

화면 좌측 상단의 뷰 모드 토글을 통해 대량 문서를 한눈에 보는 **[테이블 리스트 뷰]**와 문서 요약 카드가 시원하게 보이는 **[카드 뷰]**를 자유롭게 전환할 수 있습니다.

## 3. 스마트 자동 색인(Auto-Indexing) 원리

온리비 어서는 사용자가 복잡한 데이터베이스 명령을 몰라도 원고를 작성하기만 하면 백그라운드에서 스스로 지식을 분할하고 적재합니다.

### ① 의미 단위 지능형 분할 (Semantic Chunking)
에디터에서 문서를 저장(`Ctrl + S`)하거나 지식보관함에 문서를 등록하면, 온리비 파서(`chunkMarkdownIntoSections`)가 문서를 다음과 같이 구조적으로 쪼갭니다:
- **헤딩 계층 인식**: `# 대주제 > ## 중주제 > ### 소주제` 형태의 논리적 헤딩 경로를 자동 추적합니다.
- **줄 번호 매핑**: 각 청크가 원본 파일의 몇 번째 줄부터 몇 번째 줄까지(`startLine ~ endLine`)인지 정확한 앵커 위치를 기록합니다.
- **표와 리스트 보존**: 복잡한 데이터 표나 할 일 체크리스트가 중간에 뚝 끊어지지 않도록 의미 단락 단위로 보존합니다.

### ② 데스크톱 네이티브 SQLite FTS5 초고속 전문 색인
- **저장 위치**: 내 공통 리소스 폴더 하위의 `db/onrivi_knowledge.db` 파일에 단일 데이터베이스로 영구 저장됩니다.
- **SQLite FTS5(Full-Text Search 5)**: 수만 페이지에 달하는 방대한 서적 원고도 **0.01초(10밀리초)** 만에 키워드 및 의미 문맥을 번개처럼 찾아냅니다.
- **원트랜잭션 무결성**: 색인 도중 정전이나 앱 종료가 발생해도 데이터가 꼬이지 않도록 올-오어-너씽(All-or-Nothing) 트랜잭션으로 안전하게 보호됩니다.
- **웹(SaaS) 호환**: 웹 브라우저 환경에서도 `sql.js`(WASM SQLite) 엔진이 구동되어 데스크톱과 동일한 색인 능력을 제공합니다.

## 4. AI 원고 작성 시 지식 참조 연동 (실전 활용)

AI 글쓰기 창(`AIDraftModal`)에서 내 지식을 바탕으로 글을 쓰는 과정은 놀라울 정도로 직관적입니다:

```
[1단계] 에디터에서 Ctrl + Shift + A를 눌러 AI 글쓰기 창 열기
[2단계] 하단의 [🧠 내 지식보관함 자동 참조 (Auto-RAG)] 스위치 켜기 (ON)
[3단계] [📚 출처 각주 포함] 스위치 켜기 (ON)
[4단계] 프롬프트 입력창에 작성하고 싶은 내용 질의
        ➔ "지식보관함의 지난 세미나 발표 자료를 참조해서, 참가자 감사 안내 메일을 써줘."
[5단계] [✨ AI 생성 실행] 클릭
```

### 🔗 본문 인라인 출처 태그와 클릭 이동 앵커
생성이 완료되면 온리비 어서의 단일 진실 공급원(SSOT) 결합 엔진이 다음과 같이 출처를 완벽하게 연결해 줍니다:

```markdown
이번 세미나에서는 인공지능 윤리와 저작권 가이드라인이 중점적으로 다루어졌으며 [출처 1: AI_세미나_발표록], 
참석자 만족도 조사에서 94%의 긍정 응답을 기록했습니다 [출처 2: 2026_상반기_성과보고서].
```

## 5. 자주 묻는 질문 (FAQ)

### Q1. 지식보관함의 문서를 수정하면 데이터베이스에도 바로 반영되나요?
**A.** 네! 에디터에서 해당 마크다운 문서를 수정하고 저장(`Ctrl + S`)하면, 백그라운드에서 파일 변경 해시(Hash)를 감지하여 수정된 청크만 0.1초 만에 스마트 재색인(Re-index)합니다.

### Q2. 컴퓨터를 포맷하거나 다른 PC로 옮길 때 지식 베이스를 백업하려면 어떻게 하나요?
**A.** 공통 리소스 폴더 하위의 `db/onrivi_knowledge.db` 파일 하나만 외장하드나 클라우드에 백업해 두시면 됩니다. 새 컴퓨터에서 공통 리소스 폴더를 연결하기만 하면 모든 색인 데이터가 즉시 100% 복원됩니다.
