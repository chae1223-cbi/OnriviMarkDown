## 1. 지식보관함의 역할

작업 문서를 색인하여 검색하고 AI 작업에 관련 내용을 참조하는 기능입니다. 지식 관리 화면에서 문서 목록·작업 진행·실패 항목·검색·설정을 확인할 수 있습니다.

## 2. 등록과 색인

1. 지식 관리 도구를 엽니다.
2. 가져오기 안내에서 대상 자료를 선택하고 스캔 결과를 확인합니다.
3. 가져오기 설정을 확인한 뒤 색인을 실행합니다.
4. 작업 진행과 실패 항목을 확인합니다.
5. 검색으로 실제 본문이 찾아지는지 확인합니다.

색인한 자료와 원본 파일은 별개입니다. 파일을 수정했거나 이동했으면 갱신·경로 상태를 확인하세요. 등록 문서의 저장 후 자동 갱신 처리도 있지만 실패한 작업은 다시 확인해야 합니다.

## 3. 저장 위치와 환경

데스크톱은 리소스 `db/onrivi_knowledge.db`를 사용하는 로컬 저장 경로가 있습니다. 브라우저·웹의 저장 방식과 제공되는 관리 기능은 데스크톱과 다를 수 있습니다. 로컬 DB 하나를 모든 환경에서 그대로 쓴다고 가정하지 마세요.

## 4. AI 참조와 출처

검색 결과 또는 선택한 지식 자료를 AI 작업에서 참조할 수 있습니다. 원본·근거 화면과 출처를 확인하세요. 색인이 완료되었다고 모든 질문의 정답이나 특정 검색 시간을 보장하지는 않습니다.
