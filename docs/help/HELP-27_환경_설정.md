# 환경설정과 문서 서식의 차이

환경설정은 편집 환경과 계정 등을 관리합니다. 서식 관리는 현재 문서의 표현과 출력 설정을 관리합니다. 화면 원문 글자를 크게 바꾸고 싶은지, 책의 본문 글자를 크게 바꾸고 싶은지를 먼저 구분하세요.

## 1. 일반 설정

- 자동 줄바꿈: 원문 편집창 너비에 맞춰 표시합니다. 원문에 실제 줄바꿈을 삽입하는 기능은 아닙니다.
- 괄호 자동 완성: 여는 괄호와 짝을 이루는 기호 입력을 돕습니다.
- 자동 저장: 저장 주기를 설정합니다. 경로·권한·연결 오류가 있으면 완료되지 않을 수 있습니다.
- 자동 맞춤법 밑줄: 브라우저 기본 검사를 표시하며 글을 자동 교체하지 않습니다.
- 탭 간격: 일반 문단의 Tab 공백 간격을 정합니다.
- 원문 글꼴 크기·굵기·고대비: 편집 화면의 가독성 설정입니다.

## 2. 자료와 출력 설정

공통 리소스 폴더 연결 위치를 확인합니다. 폴더 변경은 사용자 서식·프롬프트·이미지·AI 연결 상태에 영향을 줄 수 있습니다. 워터마크 기본값은 문서별 설정이 없는 경우의 출력 기준이며, 내보내기 화면에서 최종 상태를 확인합니다.

## 3. 단축키와 계정

단축키 탭에서 실제 도구 할당을 확인합니다. 계정 탭에서는 로그인 정보와 표시 이름 등 화면에서 제공하는 항목을 관리합니다. 라이선스 권한과 구독 상태는 계정 화면의 현재 결과를 기준으로 확인하세요.

설정 창에서 API 키 입력을 마쳤더라도 모델 호출 성공까지 보장되는 것은 아닙니다. 연결·모델 선택·실행 오류를 구분합니다.
