> 시각 자료와 멀티미디어가 결합된 문서는 독자에게 훨씬 강력한 몰입감을 선사합니다. 하지만 일반적인 마크다운 편집기에서는 이미지를 복사해 넣으면 경로가 깨지거나 어디 저장되는지 몰라 애를 먹곤 합니다. 온리비 어서는 **클립보드 붙여넣기 0초 저장**과 **상대 경로 표준화 아키텍처**로 완벽한 미디어 관리 환경을 제공합니다.

---

## 1. 이미지 붙여넣기(`Ctrl + V`)와 드래그 앤 드롭

복잡한 파일 업로드 창을 열 필요가 없습니다. 온리비 어서에서는 평소 웹 서핑이나 캡처 도구를 사용하듯 자연스럽게 이미지를 삽입할 수 있습니다.

```
┌──────────────────────────────────────────────┐
│ [1] 화면 캡처 (Win + Shift + S)              │
│ [2] 웹 브라우저 이미지 복사 (Ctrl + C)       │
│ [3] 내 컴퓨터 탐색기 파일 드래그 (Drag & Drop)│
└───────────────────────┬──────────────────────┘
                        │ 에디터에 Ctrl + V
┌───────────────────────▼──────────────────────┐
│    온리비 공통 리소스 폴더 (Resource Folder)  │
│    └── media/                                │
│        └── img_a1b2c3d4e5f6.png              │
│            (해시 기반 고유 파일명 자동 저장)  │
└───────────────────────┬──────────────────────┘
                        │ 본문에 마크다운 자동 생성
┌───────────────────────▼──────────────────────┐
│       ![](media/img_a1b2c3d4e5f6.png)        │
└──────────────────────────────────────────────┘
```

### ① 캡처 도구 클립보드 직결 붙여넣기
1. Windows 캡처 도구 단축키 **`Win + Shift + S`**로 화면의 원하는 부분을 캡처합니다 (또는 웹 브라우저에서 마우스 우클릭 ➔ `이미지 복사`).
2. 온리비 어서 본문 커서 위치에서 **`Ctrl + V`**를 누릅니다.
3. 찰나의 순간에 이미지가 리소스 폴더의 `media/` 하위에 자동 저장되고, 본문에는 마크다운 이미지 태그가 즉시 생성됩니다!

### ② 마우스 드래그 앤 드롭 (Drag & Drop)
- 내 컴퓨터 탐색기에서 이미지 파일(`.png`, `.jpg`, `.webp`, `.gif`)을 마우스로 잡고 온리비 어서 편집기 안으로 끌어다 놓으세요.
- 단일 파일뿐 아니라 여러 장의 이미지를 한 번에 끌어다 놓아도 순서대로 깔끔하게 삽입됩니다.

## 2. 왜 상대 경로(`media/`) 표준화가 중요한가?

일반 편집기는 이미지를 삽입하면 `C:\Users\홍길동\Pictures\스샷.png`처럼 사용자의 컴퓨터 절대 경로로 기록하곤 합니다. 이 경우 문서를 다른 사람에게 이메일로 보내거나 다른 PC에서 열었을 때 이미지가 전부 엑박(Broken Image)으로 깨져 버립니다.

온리비 어서는 이 문제를 원천 차단하기 위해 **상대 경로 표준화 규격**을 강제합니다:

```markdown
![](media/img_a1b2c3d4e5f6.png)
```

1. **완벽한 이동성 (Portability)**:  
   문서가 있는 폴더와 공통 리소스 폴더만 함께 보관하면, 맥북, 윈도우 PC, 구글 드라이브, 외장 하드 어디서 열어도 이미지가 깨지지 않고 영구 보존됩니다.
2. **해시 기반 고유 파일명 (SHA Collision-free)**:  
   이미지 내용의 바이너리 해시를 기반으로 파일명을 자동 부여(`img_xxxx.png`)하므로, 우연히 같은 이름의 사진을 여러 번 붙여넣더라도 원본 파일이 덮어씌워져 유실되는 일이 0%입니다.
3. **Google Drive 클라우드 자동 동기화**:  
   구글 드라이브 작업장에서 이미지를 붙여넣으면, 사용자의 구글 드라이브 `OnriviAuthor/참조파일/media/` 폴더로 무인 백그라운드 자동 업로드됩니다.

> [!중요]
> **공통 리소스 폴더를 먼저 지정해 주세요!**  
> 공통 리소스 폴더가 설정되지 않은 상태에서는 이미지를 안전하게 저장할 디스크 위치를 알 수 없어 경고 배너(`⚠️ [리소스 폴더 미지정]`)가 표시됩니다. 시작 전 메뉴의 `도구 ➔ 환경 설정 ➔ 일반 설정 ➔ 자원 관리`에서 리소스 폴더를 꼭 한 번 지정해 두세요.

## 3. 온리비 전용 이미지 크기 및 정렬 파라미터 🌟

마크다운 기본 문법만으로는 이미지의 크기를 줄이거나 가운데 정렬하기 어렵습니다. 온리비 어서는 마크다운 URL 끝에 **직관적인 쿼리스트링 파라미터**를 붙여 이미지의 조판을 자유자재로 다룰 수 있습니다:

```markdown
![설명 문구](media/img_sample.png?align=center&width=600)
```

### ① 지원 파라미터 일람
| 파라미터 | 단축 표현 | 설정 가능 값 | 기능 설명 |
| :--- | :--- | :--- | :--- |
| **`align`** | `a` | `center`, `left`, `right` | 이미지 가로 정렬 (가운데, 좌측, 우측) |
| **`width`** | `w` | `600`, `80%`, `400px` | 이미지 너비 (가로 크기 조절) |
| **`height`** | `h` | `300`, `250px` | 이미지 높이 (세로 크기 고정) |

### ② 실전 활용 예시
- **너비 500px 가운데 정렬**:
  ```markdown
  ![](media/my_chart.png?align=center&width=500)
  ```
- **너비 80% 좌측 정렬**:
  ```markdown
  ![](media/banner.png?align=left&width=80%)
  ```

> [!팁]
> **출판용 자동 그림 캡션(Figcaption)**  
> 대괄호 안에 이미지 설명을 적어두면(`![시스템 구조도](...)`), 온리비 어서 출판 서식 프로필에 따라 이미지 하단에 `[그림 1] 시스템 구조도` 형식의 세련된 출판용 캡션이 자동으로 번호 매겨져 렌더링됩니다.

## 4. YouTube 동영상 및 인터랙티브 지도 삽입

문서에 움직이는 미디어나 위치 정보를 담아 전자책이나 웹 리포트의 완성도를 높여보세요.

### ① 유튜브 동영상 삽입 (`YoutubeModal`)
1. 상단 서식 툴바의 **`동영상삽입(FilmReel 아이콘)`**을 클릭하거나 슬래시 명령어 `/video`를 입력합니다.
2. 팝업 창에 YouTube 동영상 URL(예: `https://www.youtube.com/watch?v=xxxx` 또는 단축 링크 `youtu.be/xxxx`)을 붙여넣습니다.
3. 원하는 크기와 정렬을 확인한 후 삽입을 누릅니다.
4. 본문에 16:9 비율의 반응형 비디오 카드가 삽입되어, 미리보기 창에서 영상을 즉시 재생해 볼 수 있습니다.

### ② 인터랙티브 지도 삽입 (`MapModal`)
1. 서식 툴바의 **`지도 삽입(MapTrifold 아이콘)`**을 클릭하거나 슬래시 명령어 `/map`을 입력합니다.
2. 지도 모달의 검색창에 찾고자 하는 주소나 건물명(예: `서울시청`, `세종대로 110`)을 입력하고 검색을 누릅니다.
3. 마우스 휠로 줌 배율(Zoom Level)을 조절하고 너비와 정렬을 선택한 뒤 삽입을 누릅니다.
4. Google Maps 기반의 확대/축소가 가능한 실제 인터랙티브 지도 iframe 블록이 본문에 깔끔하게 조판됩니다.

## 5. 자주 묻는 질문 (FAQ)

### Q1. 인터넷에 있는 웹 이미지 주소(`https://...`)를 그대로 넣어도 보이나요?
**A.** 네, 물론입니다! 일반 웹 이미지 URL(`https://example.com/photo.jpg`)도 표준 마크다운 문법으로 완벽하게 노출됩니다. 단, 외부 웹사이트가 사진을 삭제하면 엑박이 될 수 있으므로, 영구 보존이 중요한 원고라면 이미지를 복사하여 내 PC의 `media/` 폴더에 `Ctrl+V`로 저장해 두시기를 강력히 권장합니다.

### Q2. 이미지를 PDF로 인쇄하거나 Word(.docx)로 내보낼 때 해상도가 흐려지지 않나요?
**A.** 전혀 흐려지지 않습니다! 온리비 어서는 원본 이미지의 픽셀 밀도(DPI)와 종횡비를 100% 손실 없이 보존하여 인쇄 엔진으로 전달하므로, 4K 고해상도 다이어그램이나 사진도 인쇄 시 선명하게 출력됩니다.
