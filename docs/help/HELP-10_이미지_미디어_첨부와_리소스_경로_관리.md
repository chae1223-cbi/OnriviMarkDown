# 이미지·동영상·지도와 리소스 관리

## 이미지 넣기

이미지 도구에서 파일 찾기, 경로 입력 또는 클립보드 붙여넣기를 사용합니다. 실제 파일을 읽어 미리보기가 표시되는지 확인한 뒤 삽입합니다. 클립보드에 이미지 주소만 있는 경우와 이미지 데이터가 있는 경우는 처리 방식이 다릅니다.

## 크기와 정렬

- 가로에 `%`를 선택하면 본문 너비에 대한 비율로 지정할 수 있습니다. `50%`는 원본 이미지 픽셀의 절반과 같은 뜻이 아닙니다.
- 세로를 비우거나 `auto`로 두면 원래 비율을 유지하는 데 도움이 됩니다. 가로·세로를 모두 고정하면 그림이 찌그러질 수 있습니다.
- 왼쪽·가운데·오른쪽 정렬과 미리보기를 확인합니다.
- 이미지 자체를 재가공하는 것과 문서에서 표시 크기만 바꾸는 것은 다릅니다.

## 설명·제목·대체 텍스트

이미지 제목과 번호, 설명 위치·표현 형식, Alt를 구분해 확인합니다. 현재 삽입 창은 설명 관련 입력과 크기 입력을 제공합니다. 서식의 캡션 설정에 따라 표시 위치가 달라질 수 있으므로 삽입 결과도 확인하세요.

## 동영상과 지도

전용 도구에서 주소와 크기·정렬·설명을 설정합니다. 문서 안 링크·임베드가 웹에서 동작하더라도 PDF에서는 같은 방식으로 재생되지 않습니다. EPUB 리더도 외부 콘텐츠·스크립트 지원에 차이가 있습니다.

## 이미지가 사라질 때

원문 경로와 실제 파일, 리소스 폴더, 드라이브 인증을 확인합니다. 문서를 옮길 때 이미지도 함께 이동하세요. 잠시 보이는 노란 이미지 배경·주황 테두리는 위치 안내 강조일 수 있습니다.
