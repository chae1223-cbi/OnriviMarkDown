## 1. 계정과 라이선스

라이선스 등록 또는 환경설정의 계정 관련 기능에서 로그인·인증 상태, 요금제와 사용 가능 상태를 확인합니다. 실제 사용 권한은 서버가 반환한 현재 라이선스 상태에 따라 달라집니다.

요금제 이름·가격·기기 수를 도움말에 고정하지 않습니다. 현재 계정 화면과 공식 대시보드에서 확인하세요.

## 2. 같은 계정의 여러 화면

동일 브라우저의 중복 탭 감지와 기기·세션 확인으로 동시에 편집하는 상태를 제한할 수 있습니다. 제한된 화면에는 읽기 전용 안내가 나타납니다.

표시되는 **이 화면에서 편집 시작하기** 등의 제어권 인수 버튼으로 현재 화면의 편집을 요청할 수 있습니다. 기존 화면과 신규 화면의 상태를 확인하고 작업 내용을 저장하세요.

## 3. 읽기 전용

읽기 전용에서는 문서를 볼 수 있지만 편집·저장 등의 명령은 차단됩니다. 내보내기나 서식 변경을 포함한 모든 작업이 항상 허용되는 것은 아닙니다. 현재 활성화된 메뉴와 안내를 따르세요.

## 4. 연결이 끊겼거나 인증에 실패하면

계정·기기·세션 상태와 네트워크를 확인하고 다시 인증합니다. 저장된 인증 정보가 있더라도 만료·권한 변경·검증 조건에 따라 제한될 수 있습니다. 오프라인 영구 권한을 보장하는 것으로 해석하지 마세요.

오류를 제보할 때 이메일·비밀번호·토큰·API 키는 가리고 오류 메시지와 상태만 전달합니다.
