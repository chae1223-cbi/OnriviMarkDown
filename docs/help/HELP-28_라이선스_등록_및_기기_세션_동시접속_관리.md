# 라이선스·로그인·동시 접속 상태

로그인과 라이선스 상태는 편집·저장·AI·내보내기 등 작업 가능 여부에 영향을 줄 수 있습니다. 요금·기간·기기 제한은 변경될 수 있으므로 이 도움말의 고정 수치보다 현재 계정·라이선스 화면 안내를 확인하세요.

## 1. 기능이 비활성화될 때

1. 문서가 열려 있는지 확인합니다.
2. 도움말 같은 읽기 전용 문서인지 확인합니다.
3. 로그인과 인증 상태를 확인합니다.
4. 만료·제한 사용자·중복 실행·동시 접속 안내가 있는지 확인합니다.
5. 네트워크 연결을 확인한 뒤 상태를 다시 불러옵니다.

동일 계정을 여러 환경에서 사용할 때 세션이 제한되거나 다른 세션에서 해제될 수 있습니다. 현재 창의 원고를 먼저 보관하고 안내에 따라 로그인·세션 상태를 정리하세요.

## 2. 다른 계정으로 전환

현재 파일을 저장한 뒤 계정을 전환합니다. 계정별 브라우저 저장 상태와 리소스 폴더 자료가 모두 같은 범위로 공유되는 것은 아닙니다. 다른 계정의 작업 목록·초안·AI 연결이 그대로 보일 것이라고 가정하지 마세요.

## 3. API와 구분

온리비 라이선스와 외부 AI 제공사의 API 잔액·권한은 별개입니다. 온리비에서 편집이 가능하더라도 API 결제 오류로 AI가 실패할 수 있습니다. 반대로 API 키가 정상이어도 현재 문서의 편집 권한이 제한되면 일부 작업은 실행할 수 없습니다.
