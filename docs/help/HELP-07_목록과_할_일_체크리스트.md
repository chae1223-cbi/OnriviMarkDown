# 숫자 목록·글머리기호·체크리스트

## 1. 목록 만들기

문단 앞에서 `- `, `* `, `+ `를 입력하면 글머리 목록을 만들 수 있습니다. `1. `은 숫자 목록입니다. 툴바의 숫자 목록·글머리기호 버튼을 사용해도 됩니다.

```markdown
1. 준비하기
   1. 자료 모으기
   2. 내용 확인하기
2. 작성하기

- [ ] 초안 작성
- [x] 자료 확인
```

## 2. 인터랙티브 체크리스트

`- [ ]`와 `- [x]`로 작성된 체크리스트는 온리비 어서만의 양방향 실시간 동기화를 지원합니다:
- **미리보기 화면에서 마우스로 체크박스를 직접 클릭**하면 에디터 원본 마크다운의 `[ ]`와 `[x]`가 실시간으로 자동 토글됩니다.
- 반대로 에디터에서 `[x]`로 수정하면 미리보기 체크박스가 즉시 체크 상태로 반영됩니다.

## 3. 단계와 이어 쓰기

목록 안에서 `Enter`로 다음 항목을 만들고, `Tab`으로 하위 단계, `Shift+Tab`으로 상위 단계로 이동합니다. 일반 문단의 Tab은 목록 단계 변경과 다릅니다. 빈 항목에서 Enter나 Backspace를 사용할 때는 현재 목록 구조를 확인하세요.

## 4. 서식 관리의 목록 설정

숫자 목록의 마커·간격·들여쓰기를 설정할 수 있습니다. 보고서 번호 옵션은 중첩된 목록을 `Ⅰ. → 1. → 가. → 1) → 가)`로 표시합니다. 이 기능의 원문은 일반 숫자 목록 구조이며, 제목 자동 번호와는 별도 기능입니다.

## 5. 제목 번호와 혼동하지 않기

`# Ⅰ. 개요`는 제목이고 `1. 준비`는 목록입니다. 책의 장·절 번호는 제목 설정에서, 절차나 나열은 목록 설정에서 관리하세요. 제목에 설정한 글머리기호도 제목 내용으로 저장되며 일반 불릿 목록으로 바뀌지는 않습니다.
