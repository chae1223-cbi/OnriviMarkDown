# 목록과 할 일 체크리스트

온리비 어서는 글의 구조를 정돈하고 업무나 작업 항목을 관리할 수 있도록 **순서 없는 글머리기호**, **순서 있는 숫자 목록**, 그리고 **인터랙티브 체크리스트(작업 목록)**를 지원합니다.

---

## 1. 순서 없는 목록 (글머리기호 목록)

항목 간의 위계나 순서가 중요하지 않은 나열형 문장에 사용합니다:

```markdown
- 첫 번째 핵심 특징
- 두 번째 주요 기능
  - 하위 세부 설명 1 (Tab 키로 들여쓰기)
  - 하위 세부 설명 2
- 세 번째 장점
```

- **입력 방법**: 줄 맨 앞에서 하이픈(`-`), 별표(`*`), 더하기(`+`) 중 하나를 입력하고 스페이스를 한 번 누르면 글머리기호로 자동 변환됩니다.
- **연속 입력**: 항목을 작성하고 `Enter`를 누르면 다음 줄에 글머리기호가 자동으로 생성됩니다. 목록을 끝내고 일반 문단으로 돌아가려면 내용이 없는 상태에서 `Enter`를 한 번 더 누르면 됩니다.

---

## 2. 순서 있는 목록 (숫자 목록)

단계별 절차, 순위, 요리법 등 순서가 중요한 내용을 작성할 때 사용합니다:

```markdown
1. 작업장 폴더를 연결합니다.
2. 새 문서를 생성합니다.
   1. 제목을 정하고 본문을 작성합니다. (Tab 키로 들여쓰기)
   2. 원하는 출판 서식을 선택합니다.
3. 내보내기 메뉴에서 PDF로 변환합니다.
```

- **자동 번호 매김**: 줄 시작 부분에 `1. `을 입력하고 내용을 작성한 후 `Enter`를 누르면 다음 줄에 `2. `, `3. ` 등 연속된 번호가 자동으로 부여됩니다.

- 중간에 새 항목을 추가하거나 삭제해도 온리비 어서 조판 엔진이 최종 렌더링 시 번호를 올바른 순서대로 자동 정렬해 줍니다.

---

## 3. 들여쓰기(Tab)와 내어쓰기(Shift + Tab)

목록을 작성하는 도중 계층 구조(하위 목록)를 표현할 때 사용합니다:

- **하위 항목으로 들어가기**: 줄 맨 앞에서 **`Tab`** 키를 누르면 오른쪽으로 2칸 또는 4칸 들여쓰기되어 하위 항목으로 바뀝니다.
- **상위 항목으로 빠져나오기**: **`Shift + Tab`** 키를 누르면 왼쪽으로 내어쓰기되어 상위 계층으로 복귀합니다.

---

## 4. 인터랙티브 할 일 체크리스트 (Task List)

할 일 목록이나 일정, 원고 집필 점검표를 만들 때 매우 유용한 기능입니다:

```markdown
- [x] 목차 및 챕터 기획 완료
- [x] 1장 및 2장 초안 작성
- [ ] 3장 이미지 첨부 및 표 편집
- [ ] 최종 PDF 출판 조판 검토
```

- **입력 방법**: 줄 시작 부분에 `- [ ] ` (하이픈 + 공백 + 대괄호 열기 + 공백 + 대괄호 닫기 + 공백)을 입력합니다. 체크된 상태로 시작하려면 대문자 또는 소문자 x를 넣어 `- [x] `로 입력합니다.
- **원클릭 마우스 토글**: 온리비 어서의 **문서보기**와 **우측 미리보기**에서는 네모난 체크박스를 마우스로 직접 클릭하면 체크 표시가 토글되며, 마크다운 원문의 `[ ]`와 `[x]`가 실시간으로 자동 갱신됩니다.
