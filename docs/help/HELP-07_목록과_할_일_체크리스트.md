## 1. 목록 만들기와 변경

문장들을 선택하고 플로팅 툴바에서 **숫자 목록·글머리 기호·체크리스트**를 선택합니다. 여러 항목을 선택하면 선택한 항목 모두에 적용합니다. 태그 취소는 선택한 목록을 일반 줄로 바꿉니다.

```markdown
1. 첫 번째
2. 두 번째

- 일반 목록
- [ ] 할 일
- [x] 완료한 일
```

새로 생성하는 일반 목록은 `*` 대신 `-`를 사용합니다. 외부에서 가져온 기존 원문의 표시는 편집하지 않은 부분에서 유지될 수 있습니다.

## 2. 키보드로 계층 편집

| 키 | 목록에서 하는 일 |
| --- | --- |
| Enter | 다음 목록 항목 추가 |
| Tab | 현재 항목을 하위 목록으로 들여쓰기 |
| Shift+Tab | 상위 목록으로 내어쓰기 |

목록 문장 중간에 Tab을 누르면 본문 공백을 넣습니다. 항목의 끝에서 계층 이동을 사용하세요. 부모가 될 항목이 없는 첫 항목은 하위 목록으로 이동하지 않을 수 있습니다. 앞에 부모 항목을 만든 뒤 계층을 조정하세요.

## 3. 체크리스트

체크박스를 클릭하면 완료 상태가 마크다운의 `[ ]`와 `[x]`에 반영됩니다. 체크 항목에서 Enter로 새 항목을 만들면 새 체크박스는 미완료 상태입니다.

항목 사이에 불필요한 마크다운 빈 줄을 만들지 않도록 목록을 생성합니다. 서로 다른 목록 블록 사이 여백은 문서 화면에서 유지합니다. 목록을 취소할 때도 각 줄 사이에 빈 문단을 추가하지 않습니다.

일반 문단의 Tab은 목록 계층 변경이 아니라 설정된 수의 공백 입력입니다.
