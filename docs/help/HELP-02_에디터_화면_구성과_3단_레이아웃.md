> 온리비 어서(Onrivi Author)는 한눈에 들어오는 **3단 분할 레이아웃(좌측 사이드바 - 중앙 편집기 - 우측 실시간 미리보기)**을 통해 글쓰기와 조판 검토를 동시에 해결합니다. 화면 구성을 완벽히 이해하면 작업 속도가 2배 이상 빨라집니다.

## 1. 한눈에 보는 에디터 3단 레이아웃 개요

온리비 어서의 작업 화면은 시선의 흐름과 작업 동선을 고려하여 크게 세 가지 구역으로 나뉩니다.

```
┌─────────────────┬──────────────────────────┬──────────────────────────┬───┐
│                 │   상단 메뉴바 (MenuBar)   &   서식 툴바 (Formatting)   │   │
├─────────────────┼──────────────────────────┼──────────────────────────┤ 우│
│ [좌측 사이드바] │     [중앙 편집기]        │    [우측 실시간 미리보기] │ 측│
│                 │                          │                          │   │
│ • 탐색기(트리)  │ • Monaco Editor          │ • 출판 규격 Safe-zone    │ 툴│
│ • 개요(TOC)     │ • D2Coding / Pretendard  │ • 1:1 실시간 렌더링      │ 바│
│ • 전역 검색     │ • 단축키 및 자동완성     │ • 양방향 스크롤 동기화   │   │
│                 │ • 마우스 플로팅 툴바     │ • 인쇄/PDF 최종 결과물   │   │
└─────────────────┴──────────────────────────┴──────────────────────────┴───┘
```

1. **좌측 LNB 사이드바 (LeftSidebar)**: 내 컴퓨터 폴더와 Google Drive 서재를 오가며 파일을 탐색하고, 문서의 목차(TOC)와 키워드를 즉각 검색하는 지식 관제탑입니다.
2. **중앙 Monaco 편집기 (Editor)**: 키보드 타이핑에만 몰입할 수 있는 메인 집필 구역입니다. 시각적 피로를 줄여주는 고대비 커서와 정밀한 문법 하이라이팅을 제공합니다.
3. **우측 실시간 렌더링 미리보기 (Preview)**: A4 및 출판 판형의 안전구역(Safe-zone) 안에서 내 글이 실제 책으로 인쇄되었을 때의 완성본을 실시간으로 확인하는 조판 뷰어입니다.
4. **우측 세로 툴바 (Toolbar)**: 이모지 보관함, 플로팅 서식 툴바 토글, 지식 베이스 전환, 서식 관리 갤러리 등 핵심 생산성 도구를 원클릭으로 호출하는 퀵 컨트롤러입니다.

## 2. 상단 네비게이션: 메뉴바와 서식 툴바

화면 최상단에는 앱의 전체 기능을 제어하는 **메뉴바(MenuBar)**와 자주 쓰는 서식을 모아둔 **서식 툴바(FormattingToolbar)**가 자리합니다.

### ① 상단 메뉴바 (MenuBar)
전통적인 데스크톱 메뉴 구조로 직관적인 단축키와 기능을 제공합니다.

* **파일(F)**:
  * `파일 열기` (`Ctrl + O`): 단일 마크다운 파일을 선택하여 엽니다.
  * `작업장 폴더 열기` (`Ctrl + Shift + O`): 내 PC의 프로젝트 폴더 전체를 서재로 불러옵니다.
  * `내 구글 드라이브 연결 / 구글 드라이브 연결 해제`: 원클릭으로 클라우드 서재를 바인딩하거나 해제합니다.
  * `저장` (`Ctrl + S`) / `다른 이름으로 저장` (`Ctrl + Shift + S`): 문서를 디스크나 드라이브에 안전하게 물리적으로 씁니다.
  * `타문서 변환` (`Ctrl + Alt + O`): 외부 Word, HTML, 텍스트 파일을 마크다운으로 변환하여 가져옵니다.
  * `내보내기 (미리보기 모드 전용)`: `인쇄/PDF`, `Word 문서 (.docx)`, `한글 문서 (.hwpx)`, `HTML 파일 (.html)`, `EPUB 전자책 (.epub)`, `PNG 이미지 (.png)` 사출.
* **편집(E)**:
  * `실행 취소` (`Ctrl + Z`) / `다시 실행` (`Ctrl + Y`): 이전 편집 작업 복원.
  * `이모지 보관함` (`Ctrl + Shift + E`): 감성적인 이모지 및 특수문자 입력 패널 토글.
  * `찾기` (`Ctrl + F`) / `바꾸기` (`Ctrl + H`): 단어 일괄 검색 및 치환.
  * `확대` / `축소`: 편집기 글자 크기 확대/축소.
* **도구(T)**:
  * `사이드바 표시/숨김` / `툴바 표시/숨김`: 넓은 작업 공간 확보를 위한 패널 토글.
  * `화면 보기 모드`: `편집 전용`, `분할 화면`, `미리보기` 3가지 뷰 전환.
  * `지식 보관함 관리자` (`Ctrl + Shift + K`, 데스크톱 전용): 내 PC 지식 문서 데이터베이스 관리.
  * `서식 정의 (갤러리)`: 온리비 전용 CSS 출판 서식 관리 센터 오픈.
  * `전역 검색` (`Ctrl + Shift + F`), `마크다운 복사`, `문서 병합`, `각주 정리`, `환경 설정`.
* **도움말(H)**:
  * `사용 설명서`: 공식 사용자 도움말 센터 열기.
  * `라이선스 등록`: 제품 정품 인증 및 구독 정보 확인.
* **우측 상단 상태 칩**:
  * `[⚠️ 리소스 폴더 미설정]`: 공통 자원 폴더가 지정되지 않았을 때 깜빡이는 알림 칩으로, 클릭 시 즉시 폴더 지정 창이 뜹니다.
  * `사용자 별명 칩`: 현재 로그인된 사용자명과 요금제 상태(`전체사용자` / `제한사용자`)를 보여주며 클릭 시 계정 관리 탭으로 이동합니다.

### ② 2열 서식 툴바 (FormattingToolbar)
편집기 바로 위에 위치하여 마우스 클릭만으로 마크다운 문법을 즉시 적용합니다.

* **AI 글쓰기**: `AI 프롬프트 (✨)` (Gemini API 키 등록 시 활성화).
* **기본 텍스트 서식**: `B` (굵게, `Ctrl+B`), `I` (기울임, `Ctrl+I`), 인라인 코드(`Ctrl+E`), `U` (밑줄, `Ctrl+U`), `S` (취소선, `Ctrl+Shift+X`).
* **제목 스핀 버튼**: `▲` (크기 키우기) - `H1~H6` (제목 레벨 적용) - `▼` (크기 줄이기).
* **문서 구조**: 구분선(`—`, `Ctrl+Alt+-`), 숫자 목록(`Ctrl+Shift+7`), 글머리 기호(`Ctrl+Shift+8`), 인용구 드롭다운(`Ctrl+Q` 및 Note/Tip/Important/Warning/Caution Alert 콤보), 체크리스트(`Ctrl+Shift+C`), 태그 취소(지우개, `Ctrl+Shift+X`), 문서 서식 일괄 정리(마법봉, `Ctrl+Shift+L`).
* **링크 및 미디어**: 링크(`Ctrl+K`), 문서 연결, 인용(참조문헌, `Ctrl+Alt+C`), 각주(`fn`, `Ctrl+Alt+F`), 이미지, 동영상(YouTube), 현재 날짜/시간, 서명/발신인(우측 정렬, `Ctrl+Alt+R`).
* **고급 도구**: 지도 삽입, 표 생성(`Ctrl+T`), 코드 블록(`Ctrl+Shift+E`), 수식(LaTeX, `Ctrl+M`).

## 3. 좌측 LNB 사이드바 (LeftSidebar) 3대 탭

좌측 사이드바는 세 가지 강력한 탭을 통해 방대한 프로젝트를 손쉽게 통제합니다.

### ① 탐색기 (Explorer) 탭
* **작업장 실폴더 바**: 현재 연결된 작업장 폴더명이 상단에 표시되며, 클릭하여 언제든 다른 프로젝트 폴더로 변경할 수 있습니다. Google Drive 연결 시 우측에 빨간색 `[🔌 해제]` 버튼이 제공됩니다.
* **파일 트리 조작**:
  * 폴더와 파일을 마우스 드래그 앤 드롭으로 자유롭게 다른 폴더로 이동시킬 수 있습니다.
  * 빈 영역이나 폴더 우클릭 시 풍부한 컨텍스트 메뉴가 나타납니다:
    * `새 파일` (`Alt + N`), `새 폴더`, `복사하기` (`Ctrl + C`), `잘라내기` (`Ctrl + X`), `붙여넣기` (`Ctrl + V`), `새로고침` (`Ctrl + F5`), `타문서 변환` (`Ctrl + Alt + O`), `파일 탐색기/Finder에서 보기`.
    * 실수를 방지하기 위한 `잘라내기 취소`(`Esc`) 및 `이동/삭제 되돌리기`(`Ctrl + Z`)가 지원됩니다.

### ② 개요 (TOC, Table of Contents) 탭
* 문서 안의 제목 태그(`# 제목 1` ~ `###### 제목 6`)를 실시간으로 파싱하여 계층형 트리 목차를 자동으로 그려줍니다.
* **원클릭 위치 이동**: 목차의 특정 항목을 클릭하면 에디터와 우측 미리보기가 해당 단락으로 부드럽게 스크롤되고 시각적 하이라이트 효과가 적용됩니다.
* **Auto-scroll Follow**: 미리보기 본문을 읽으며 스크롤을 내리면, 좌측 개요 탭도 현재 읽고 있는 헤딩 위치를 지능적으로 추적하여 자동으로 파란색 포커스를 맞춰줍니다.

### ③ 검색 (Search) 탭
* 현재 열린 작업장 안의 모든 마크다운 문서를 대상으로 텍스트를 고속 전역 검색(Global Search)합니다.
* 검색 결과 목록에서 특정 줄을 클릭하면 해당 파일이 새 탭으로 즉시 열리며, 검색된 단어에 브라우저 최신 **CSS Custom Highlight**가 적용되어 노란색 인라인 마킹으로 강조됩니다.

## 4. 중앙 Monaco 편집기와 우측 실시간 미리보기

### ① 중앙 Monaco 편집기: 몰입형 글쓰기 환경
* **타이포그래피 최적화**: 한글은 가독성과 원문자 표기가 완벽한 `Pretendard Variable`, 영문 및 코드는 가독성 높은 `D2Coding` 고정폭 폰트가 자동 적용됩니다.
* **고대비 커서 (Cursor)**: 커서 두께를 4px(일반의 2배)로 확대하고 코발트 블루(#1d4ed8) 색상을 적용하여 넓은 화면에서도 커서 위치를 놓치지 않습니다.
* **스크롤바 안전 여백**: 볼드(**) 강조 기호 등으로 글자 폭이 늘어나도 오른쪽 끝 글자가 스크롤바에 가려지지 않도록 안전 패딩이 확보되어 있습니다.

### ② 우측 실시간 미리보기: 인쇄 출판 안전구역 (Safe-Zone)
* **1:1 조판 렌더링**: 화면 너비에 따라 줄바꿈이 무한정 늘어나는 일반 에디터와 달리, A4 용지 규격의 상하 18mm, 좌우 12mm 표준 여백을 시각화합니다.
* **양방향 스크롤 동기화 (Bi-directional Sync)**:
  * 에디터에서 타이핑하거나 스크롤하면 우측 미리보기가 1:1로 정확하게 같은 위치를 유지합니다.
  * 미리보기에서 마우스 휠을 굴려 읽을 때도 에디터 커서가 조화롭게 동기화되며, 빠른 스크롤 시 발생할 수 있는 떨림(Jitter)을 방지하는 동기화 락킹이 내장되어 있습니다.

### ③ 화면 보기 모드 3종 전환
상단 메뉴 `도구(T) ➔ 화면 보기 모드`를 통해 언제든 원하는 작업 모드로 전환할 수 있습니다:
1. **편집 전용 모드 (`edit`)**: 오직 글쓰기에만 집중하고 싶을 때 미리보기를 숨기고 에디터를 전체 화면으로 확장합니다.
2. **분할 화면 모드 (`both`)**: 좌측 에디터와 우측 미리보기를 반반씩 띄워 실시간 결과를 검토하며 집필하는 가장 권장되는 기본 모드입니다.
3. **미리보기 전용 모드 (`preview`)**: 작성된 문서를 최종 점검하거나 인쇄/내보내기를 진행할 때 방해 요소 없이 완성된 책 형태로 열람합니다.

## 5. 우측 세로 툴바와 마우스 플로팅 툴바

### ① 우측 세로 툴바 (Toolbar)
에디터 우측 가장자리에 위치하여 화면을 차지하지 않으면서도 필수 도구를 제공합니다.
* `이모지 보관함 (Smile)`: 단축키 `Ctrl + Shift + E`로 이모지 패널을 우측에 플로팅 오버레이로 띄웁니다.
* `플로팅 서식 툴바 켜기/끄기 (CubeFocus)`: 텍스트 드래그 시 플로팅 툴바의 노출 여부를 토글합니다.
* `슬래시(/) 빠른 명령어 호출 (TerminalWindow)`: 현재 커서 위치에 명령어 팝오버를 호출합니다.
* `홈으로 이동` / `대시보드 이동`: 온리비 어서 공식 홈페이지 및 라이선스 관리 대시보드로 이동합니다.
* `지식 베이스 화면 전환 (HeadCircuit)`: 데스크톱 전용 지식 관리 허브로 화면을 전환합니다 (`Ctrl + Shift + K`).
* `서식관리 (Palette)`: 서식 관리 센터 및 갤러리를 호출합니다.
* `참조 파일 관리 (NewspaperClipping)`: 참고문헌 및 참조 파일을 관리합니다.
* `환경 설정 (Settings)`: 에디터 테마, 글꼴, 단축키 설정 모달을 엽니다.

### ② 마우스 플로팅 서식 툴바 (Floating Toolbar)
에디터 안에서 마우스로 텍스트를 드래그하여 블록을 지정하는 순간, 마우스 커서 바로 위에 직관적인 미니 서식 바가 떠오릅니다. 마우스를 상단 툴바까지 길게 움직일 필요 없이 그 자리에서 즉시 글자를 굵게(`B`) 하거나, 제목(`H`)으로 바꾸거나, 인용구 박스를 적용할 수 있습니다.

> 좌측 사이드바와 중앙 에디터 경계선, 그리고 에디터와 미리보기 사이의 경계선에 마우스를 올리면 마우스 커서가 양방향 화살표 모양으로 바뀝니다. 마우스를 드래그하여 각 영역의 폭을 자유롭게 조절할 수 있습니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 화면이 좁은 노트북에서는 분할 화면이 답답한데 어떻게 하나요?
**A.** 상단 메뉴바의 `도구(T) ➔ 화면 보기 모드 ➔ 편집 전용`을 선택하거나, `사이드바 표시/숨김`을 눌러 좌측 탐색기를 접어두세요. 중앙 편집기만 넓게 펼쳐져 쾌적하게 집필에 몰입할 수 있습니다.

### Q2. 미리보기에서 체크리스트 박스를 클릭하면 본문도 바뀌나요?
**A.** 네, 맞습니다! 우측 미리보기 화면에 렌더링된 체크리스트(`[ ]` 또는 `[x]`)를 마우스로 직접 클릭하면, 중앙 에디터의 마크다운 원본 텍스트도 실시간으로 `[x]` 또는 `[ ]`로 함께 자동 수정됩니다.

### Q3. 상단 메뉴바 우측의 [리소스 폴더 미설정]은 무엇인가요?
**A.** 온리비 어서의 핵심 기능인 공통 이미지 저장, 출판 서식(CSS 프로필), AI 프롬프트를 온전히 사용하기 위해 내 컴퓨터나 구글 드라이브에 전용 폴더를 지정하라는 친절한 안내입니다. 클릭하여 폴더를 한 번만 지정해 두면 다시 나타나지 않습니다.
