# 화면 구성과 보기 모드

> **<u>상단에는 파일·편집·도구·도움말 메뉴와 문서 탭이 있습니다. 왼쪽은 작업장 탐색·개요·검색, 가운데는 편집 영역, 오른쪽은 도구와 AI 패널, 아래는 상태바입니다. 사이드바와 툴바는 접어 작업 공간을 넓힐 수 있습니다.</u>**

## 1. 보기 선택

| 보기 | 용도 | 입력 위치 |
| :--- | :--- | :--- |
| 문서보기 | 서식이 적용된 위지윅(WYSIWYG) 본문 직접 편집 | 문서보기 편집 본문 |
| 나란히 보기 | 마크다운 원문과 실시간 조판 결과 비교 | 문서보기의 편집 가능 영역 |
| 마크다운 | 태그·경로·메타데이터 원문 직접 편집 | Monaco 마크다운 편집 창 |

나란히 보기의 좌측 마크다운 창에는 읽기 전용 가드가 적용되어 우측 위지윅 편집 결과를 안전하게 실시간 동기화합니다. 글을 직접 마크다운으로 수정하려면 단독 '마크다운' 보기로 전환하세요. 그림책은 일반 본문 대신 장면별 편집을 사용합니다.

## 2. 위치 이동과 Safe Zone 동기화

왼쪽 개요의 제목을 누르면 해당 위치로 부드럽게 이동합니다. 에디터와 미리보기는 상단 40px, 하단 140px의 커서 안전구역(Safe Zone)을 유지하며 양방향 위치를 실시간 동기화하여 커서 가림을 방지합니다.

에디터 글꼴은 Pretendard 및 고정폭 D2Coding을 지원하며, 고대비 커서가 적용되어 있습니다. 화면 확대·축소는 화면 열람 배율을 조절하는 기능이며 서식 관리의 출력 글자 크기와 구분됩니다.

## 3. 편집이 안 될 때

문서를 정상적으로 열었는지, 도움말 전용 읽기 모드인지, 제한 사용자 상태인지 먼저 확인합니다. 찾기/바꾸기 또는 모달 창이 열려 있을 때는 해당 창을 닫아야 에디터 편집이 복귀됩니다.
