# 문서 가져오기와 Word·HWPX 내보내기

## 가져오기 지원 형식

현재 파일 변환 목록은 DOCX·HWP·PDF·EPUB·TXT·MD·MARKDOWN·HTML·HTM입니다. XLSX·PPTX·HWPX는 같은 가져오기 목록에 포함되어 있지 않습니다. 내보내기 지원과 가져오기 지원은 별개입니다.

파일 메뉴에서 로컬 또는 웹드라이브 가져오기를 선택하고 파일을 읽습니다. 변환된 원고를 저장하기 전에 제목·문단·표·이미지·각주가 제대로 전달되었는지 확인하세요.

## 형식별 제한

- PDF: 텍스트를 추출합니다. 이미지로만 된 스캔 PDF는 현재 가져오기에서 OCR을 지원하지 않으므로 텍스트 PDF나 원본 문서를 준비합니다.
- HWP: 일반 HWP 호환 형식을 읽는 경로가 있습니다. 모든 한글 문서 버전·보호 문서·고유 객체를 동일하게 변환한다고 보장하지 않습니다.
- DOCX·HTML·EPUB: 원문의 내용과 지원되는 구조를 변환하며 원본 프로그램의 배치가 완전히 복제되지는 않습니다.

## 편집 가능한 파일로 출력

일반 문서는 내보내기에서 Word 문서(DOCX) 또는 한글 문서(HWPX)를 선택합니다. 대상 프로그램에서 열어 표 폭·글꼴·제목 번호·이미지를 확인합니다. 표시되는 글꼴이 설치되어 있지 않으면 대체 글꼴이 사용될 수 있습니다.

그림책에는 DOCX·HWPX 내보내기 항목이 제공되지 않습니다. 인쇄/PDF·EPUB 등 그림책에서 표시되는 형식을 사용하세요. 다른 프로그램과의 완벽한 서식 일치를 전제로 재편집하지 마세요.
