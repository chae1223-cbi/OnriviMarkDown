## 1. 다른 문서 가져오기

파일 메뉴의 타문서 변환/가져오기에서 파일을 선택합니다. 현재 가져오기 선택기는 다음 확장자를 지원합니다.

| 유형 | 확장자 |
| --- | --- |
| Word | `.docx` |
| 한글 | `.hwp` |
| PDF | `.pdf` |
| 전자책 | `.epub` |
| 텍스트·마크다운 | `.txt`, `.md`, `.markdown` |
| HTML | `.html`, `.htm` |

현재 가져오기 목록에 `.hwpx`는 없습니다. HWPX 내보내기 지원과 HWPX 가져오기 지원을 혼동하지 마세요.

## 2. 변환 결과 확인

변환은 마크다운 구조로 내용을 옮기는 작업입니다. 복잡한 셀 병합, 다단, 부유 그림, 원본 전용 서식은 달라질 수 있습니다. PDF가 스캔 이미지뿐이면 텍스트를 읽을 수 없을 수 있습니다. 원본을 보관하고 제목·목록·표·이미지를 비교하세요.

## 3. DOCX·HWPX 내보내기

일반 문서의 내보내기에서 **Word 문서(.docx)** 또는 **한글 문서(.hwpx)**를 선택합니다. 렌더링된 문서 구조와 서식·이미지를 기반으로 생성합니다. 결과는 Word·한컴에서 직접 열어 확인하세요.

그림책은 현재 DOCX·HWPX 형식을 제외합니다. 그림책은 인쇄/PDF·HTML·PNG·EPUB 등 제공되는 형식을 사용합니다.

마크다운 원고 저장과 오피스 파일 내보내기는 별도입니다. 내보낸 파일을 수정해도 현재 원고에 자동 반영되지 않습니다.
