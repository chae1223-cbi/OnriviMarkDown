온리비 어서는 문서 화면에서 글을 작성하고, 마크다운 파일과 서식 프로필을 함께 사용해 출판물을 만드는 저작 도구입니다.

## 1. 처음 시작하는 순서

1. 왼쪽 탐색기에서 작업장 폴더를 연결하거나 Google Drive에 연결합니다.
2. 환경설정에서 현재 작업 환경의 리소스 폴더를 확인합니다. 사진과 서식 등 공통 자료가 여기에 저장됩니다.
3. **새 문서작성** 또는 파일 메뉴의 새 문서 기능으로 문서를 만듭니다.
4. **문서 보기** 본문을 클릭해 입력합니다. 앱 시작과 일반 파일 열기는 문서보기가 기본입니다. 새 문서 생성 절차에 따라 나란히 보기로 열리면 하단의 문서 보기 버튼을 누르세요.
5. `Ctrl+S`로 저장하고 저장 상태를 확인합니다.

![초기 설정 안내](/help/assets/fig1_setup_steps.png)

## 2. 글쓰기 → 서식 선택 → 내보내기

- **글쓰기:** 문서보기에서 직접 입력하고 제목·목록·표·인용문을 적용합니다.
- **원문 확인:** 하단 **나란히 보기**를 선택하면 왼쪽 문서와 오른쪽 마크다운 원문을 함께 봅니다.
- **서식:** 하단 서식 이름 또는 우측 서식관리 도구로 문서 글꼴·여백·표 디자인을 선택합니다.
- **내보내기:** 파일 메뉴의 내보내기에서 필요한 형식을 선택합니다. 그림책과 일반 문서의 지원 형식은 다릅니다.

## 3. 저장되는 내용

원고는 `.md` 파일입니다. 제목·목록·표·Mermaid 원문은 본문에 저장됩니다. 서식 연결 정보는 문서 맨 위 메타영역에 기록되며 문서 화면에서는 숨겨집니다. 이미지와 로컬 동영상은 리소스 폴더의 `media`에 저장합니다.

다른 컴퓨터로 옮길 때는 원고뿐 아니라 참조하는 미디어와 사용자 서식도 함께 옮기세요. 사용자 서식 ID만으로 다른 기기에 없는 서식 파일이 자동 생성되지는 않습니다.
