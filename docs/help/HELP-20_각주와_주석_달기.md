## 1. 각주 만들기

각주 도구, `/각주`, `Ctrl+Alt+F`를 사용합니다. 원문에서는 본문 참조와 각주 정의가 짝을 이룹니다.

```markdown
이 문장에는 보충 설명이 있습니다.[^1]

[^1]: 각주 내용입니다.
```

문서의 각주 번호와 돌아가기 링크로 본문·설명을 이동합니다. 번호를 정리하는 기능을 사용할 때는 실행 전 문서를 저장하고 결과를 확인하세요. 문서보기에서 직접 처리되지 않는 정의 블록은 제공되는 개별 원문 편집창을 사용합니다.

## 2. 참고문헌과 인용

각주와 참고문헌 인용은 다른 기능입니다. 참조관리 도구(`/참조관리`)로 문헌을 관리하고 인용 도구(`/인용문헌`, `Ctrl+Alt+C`)를 사용합니다.

```markdown
관련 자료를 인용합니다.[@reference-key]
```

참고문헌 자료는 리소스 `bible/references.bib`를 사용합니다. 인용 키가 자료에 있는지 확인하세요. 문서를 옮길 때 참고문헌 자료도 함께 준비합니다.

## 3. 출력 확인

각주와 문헌의 번호·링크·내용이 PDF·EPUB·Word 결과에서 필요한 형태로 표시되는지 확인합니다. 출력 형식마다 이동 링크와 배치가 다를 수 있습니다.
