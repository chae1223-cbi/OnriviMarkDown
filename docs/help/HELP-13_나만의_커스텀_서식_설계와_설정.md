# 사용자 서식과 제목 자동 번호

## 1. 사용자 서식 만들기

기본 제공 서식을 복제하거나 새 사용자 서식을 만듭니다. 이름을 정하고 용지·본문·제목·목록·표·미디어 설정을 조절한 뒤 적용합니다. 시스템 서식을 수정하려고 하지 말고 사용자 사본에서 작업하세요.

## 2. 제목 1~6의 번호 형식

서식 관리의 제목 위계 스타일 → 제목 번호 형식에서 단계마다 번호 없음·로마자·숫자·가나다·괄호 번호·사용자 지정을 선택합니다. 보고서 번호 적용은 `Ⅰ. → 1. → 가. → 1) → 가)`를 지정하며 제목 6에는 번호를 붙이지 않습니다.

같은 단계는 순서대로 증가하고 상위 제목이 바뀌면 하위 번호가 다시 시작됩니다. 제목 삽입·붙여넣기·서식 변경 시 번호를 계산합니다. 실제 번호는 `# Ⅰ. 개요`처럼 마크다운에도 기록하므로 다른 도구에서도 읽을 수 있습니다. 기존 제목 앞 번호는 선택한 형식으로 갱신될 수 있습니다.

## 3. 사용자 지정

앞 문구·표시 종류·뒤 문구를 조합합니다.

| 설정 | 결과 예시 |
| --- | --- |
| 앞 `제` + 숫자 + 뒤 `장` | 제1장, 제2장 |
| 앞 `(` + 가나다 + 뒤 `)` | (가), (나) |
| 글머리기호 `◆` | 제목마다 ◆ |

글머리기호는 숫자가 증가하지 않습니다. 입력 아래 미리보기를 확인하세요. 번호 설정을 해제하면 적용 중이던 앞 표시를 제거하는 경로가 있습니다. 제목 자체의 중요한 문구를 번호처럼 작성한 경우 원문도 확인합니다.

숫자 목록의 번호 형식은 별도 설정입니다. 제목 번호와 목록 마커를 혼동하지 마세요.
