# 사용자 서식과 제목 자동 번호

## 1. 사용자 서식 만들기

기본 제공 서식을 복제하거나 새 사용자 서식을 만듭니다. 이름을 정하고 용지·본문·제목·목록·표·미디어 설정을 조절한 뒤 적용합니다. 시스템 서식을 직접 수정하려고 하지 말고 사용자 사본에서 작업하세요.

## 2. 제목 1~6의 번호 형식

서식 관리의 제목 위계 스타일 → 제목 번호 형식에서 단계마다 다음 형식을 지정할 수 있습니다:
- **번호 없음 (`none`)**
- **로마자 (`roman`)**: `Ⅰ.`, `Ⅱ.`
- **아라비아 숫자 (`decimal`)**: `1.`, `2.`
- **계층형 십진 분류 (`decimal-outline`)**: `1.` ➔ `1.1` ➔ `1.1.1` (상위 제목 번호를 계층적으로 연결)
- **한글 자모 (`hangul`)**: `가.`, `나.`
- **괄호 숫자 (`decimal-paren`)**: `(1)`, `(2)`
- **괄호 한글 (`hangul-paren`)**: `(가)`, `(나)`
- **사용자 지정 (`custom`)**: 접두사/접미사 및 도형 글머리기호(`□`, `○`, `-`, `ㆍ`)

같은 단계는 순서대로 증가하고 상위 제목이 바뀌면 하위 번호가 다시 시작됩니다. 실제 번호는 `# 1.1 개요`처럼 마크다운에도 기록하므로 다른 도구에서도 읽을 수 있습니다.
에디터에서 `# ` 입력 후 스페이스를 한 번 더 누르면(`## ` + Space) 현재 단계에 맞는 번호가 자동 삽입됩니다.

## 3. 사용자 지정 기호

앞 문구·표시 종류·뒤 문구를 조합합니다:

| 설정 | 결과 예시 |
| --- | --- |
| 앞 `제` + 숫자 + 뒤 `장` | 제1장, 제2장 |
| 앞 `(` + 가나다 + 뒤 `)` | (가), (나) |
| 글머리기호 `□`, `○`, `◆` | 도형 불릿 위계 |

글머리기호는 숫자가 증가하지 않습니다. 입력 아래 미리보기를 확인하세요. 번호 설정을 해제하면 적용 중이던 앞 표시를 제거하는 경로가 있습니다. 제목 자체의 중요한 문구를 번호처럼 작성한 경우 원문도 확인합니다.

## 4. 미디어 캡션 독립 설정 (`kindOverrides`)

표, 그림, 동영상, 지도별로 캡션 위치(상단/하단)와 라벨(`표`, `그림`), 번호 형식, 구분자(`-`, `.`)를 독립적으로 설정할 수 있습니다. 예를 들어 기술표준 규격처럼 표는 상단(`표 1 -`), 그림은 하단(`그림 1 -`)으로 분리 배치할 수 있습니다.
