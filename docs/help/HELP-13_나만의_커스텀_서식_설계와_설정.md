# 사용자 서식과 제목 자동 번호

온리비 어서는 시스템이 제공하는 4대 기본 서식 외에도, 작가나 기업이 자신만의 브랜드 스타일을 살릴 수 있는 **사용자 정의 커스텀 서식(Custom CSS Profile)** 제작과 **계층형 십진 분류 자동 번호** 엔진을 지원합니다.

---

## 1. 나만의 커스텀 서식 만들기

1. 에디터 우측 상단의 **[서식 관리]** 버튼을 클릭하여 서식 관리 센터를 엽니다.
2. 상단의 **[+ 새 서식 만들기]** 버튼을 누릅니다.
3. 서식 명칭, 기본 글꼴, 본문 글씨 크기(pt), 줄간격, 여백, 제목 색상(Primary/Secondary)을 시각적 UI 폼에서 손쉽게 지정합니다.
4. 고급 사용자는 하단의 [CSS 직접 편집] 영역에서 원하는 CSS 규칙을 직접 작성하여 세밀한 디자인을 완성할 수 있습니다.
5. [저장]을 누르면 내 컴퓨터의 공통 리소스 폴더에 서식 파일이 안전하게 기록되며 즉시 적용됩니다.

---

## 2. 계층형 십진 분류 자동 번호 (`decimal-outline`)

공학 보고서, 학술 논문, 법률 문서, 회사 규정집에서는 제목마다 체계적인 번호를 붙이는 작업이 매우 번거롭습니다. 온리비 어서는 이를 전자동으로 해결합니다:

- **십진 분류 번호 체계**:
  ```markdown
  # 1. 서론 (대제목)
  ## 1.1 연구 배경 (중제목)
  ### 1.1.1 국내외 기술 동향 (소제목)
  ## 1.2 연구 목적
  # 2. 본론
  ```
- **원문 양방향 실시간 동기화**:
  - 서식 설정에서 제목 번호 매김을 활성화하면, 에디터에서 `# 제목`을 입력할 때마다 `1. `, `1.1 `, `1.1.1 ` 번호가 자동으로 계산되어 부여됩니다.
  - 마크다운 원문에도 번호가 실시간 기록되므로, 외부 다른 마크다운 뷰어나 Git 저장소에 문서를 올려도 번호 구조가 그대로 유지됩니다.

---

## 3. 미디어 캡션 독립 제어 (`kindOverrides`)

출판 조판의 완성도를 결정하는 세밀한 캡션 위치 제어 기능입니다:

- **표(Table) 캡션**: 일반적으로 표는 데이터를 읽기 전에 표의 제목을 먼저 인지해야 하므로 **표 상단 배치**가 출판 원칙입니다.
- **그림(Figure) 캡션**: 사진이나 차트는 이미지를 먼저 본 뒤 부연 설명을 읽으므로 **그림 하단 배치**가 출판 원칙입니다.
- 온리비 어서의 서식 관리 센터는 `kindOverrides` 옵션을 통해 표는 캡션을 상단에, 그림은 하단에 배치하도록 클릭 한 번으로 독립 제어할 수 있습니다.
