## 1. 사용자 서식 만들기

서식관리에서 기준 서식을 선택하고 새 서식을 만듭니다. 이름을 정한 뒤 문서 전체의 글꼴·글자 크기·행간·용지 여백을 먼저 조정하세요. 시스템 서식 원본은 보호됩니다.

## 2. 요소별 설정

| 요소 | 조절하는 내용 |
| --- | --- |
| 본문·제목 | 글꼴, 크기, 색, 행간, 문단 여백 |
| 목록·체크리스트 | 목록 배치와 체크 표시 |
| 인용구 | 바깥 간격, 안쪽 여백, 선·배경 |
| 표 | 헤더·본문 색, 셀 여백, 외곽·행·열 선 |
| 코드·미디어 | 코드 색과 행간, 이미지 표시 |
| 용지 | 크기·방향·여백 |

문서보기의 헤더 중앙 정렬, 셀 내부 문단 여백 제거, 인용문 내 줄 간격, 코드 가로 스크롤에는 편집용 규칙이 적용됩니다. 일반 문단의 여백만 조절해서 셀 간격을 바꾸려고 하지 마세요.

## 3. 그림책 배치

문서 배치에서 **그림책 — 그림과 본문**을 선택하면 장면 단위 화면을 사용합니다. 일반 문서와 작성 구조가 다릅니다. 자세한 작성법은 HELP-31을 참고하세요.

## 4. 저장과 이동

서식 변경을 저장하고 해당 문서에도 선택한 프로필을 연결합니다. 다른 환경에 원고를 옮길 때 사용자 서식 JSON도 내보내거나 대상 환경에 가져오세요. 별도의 사용자 CSS를 적용했다면 문서 화면과 출력 결과를 모두 확인하세요.
