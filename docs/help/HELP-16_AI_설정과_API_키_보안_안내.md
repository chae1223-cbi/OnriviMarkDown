## 1. API 키와 모델 설정

환경설정의 AI 항목에서 키를 입력하고 제공되는 모델 목록·연결 확인 기능을 사용합니다. 모델 목록은 앱의 후보와 API 조회 결과에 영향을 받습니다. 목록에 이름이 있어도 해당 프로젝트에서 실제 호출 가능한지는 연결 확인으로 검사하세요.

도움말에 특정 모델을 영구적인 최신·공식 지원 모델로 고정하지 않습니다. `404`가 나오면 모델이 현재 API와 계정에서 사용 가능한지 확인하세요.

## 2. 저장과 전송

앱은 API 키를 로컬 저장소에 암호화 형태로 저장하는 처리를 사용합니다. 이 처리는 공유 PC나 유출된 브라우저 프로필에서 키가 절대 안전하다는 보장이 아닙니다. 키를 문서·스크린샷·오류 제보에 포함하지 마세요.

AI 요청에 사용할 본문과 지식 자료는 선택한 AI 서비스로 전송됩니다. 프롬프트의 참조 범위를 확인하고 필요한 내용만 포함하세요. Google Drive 로그인 권한과 AI API 키는 별개입니다.

## 3. 오류별 조치

| 표시 | 확인할 것 |
| --- | --- |
| 401·403 | API 키, 프로젝트 권한 |
| 404 | 선택한 모델의 제공 여부 |
| 429 | 프로젝트 호출 한도·할당량 |
| 500·503·504 | 서비스 상태, 잠시 후 재시도 |
| 시간 초과 | 네트워크, 입력 분량 |

실패한 요청은 완료된 원고 생성으로 처리되지 않습니다. 응답 내용을 확인한 후 직접 적용합니다.
