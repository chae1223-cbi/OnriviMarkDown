> 온리비 어서(Onrivi Author)는 **'내 데이터는 내 컴퓨터에만 머문다'**는 프라이버시 제일주의 철학을 엄격히 고수합니다. 중앙 중계 서버를 일체 거치지 않고 오직 사용자 PC에서 Google AI 엔드포인트로 직접 암호화 통신하는 가장 안전한 아키텍처를 소개합니다."

## 1. 온리비 어서 공식 지원 AI 모델 라인업

온리비 어서는 구글 딥마인드(Google DeepMind)의 최신 세대 대규모 언어 모델(LLM)을 완벽하게 통합 지원합니다:

```
┌────────────────────────────────────────────────────────────────────────┐
│  👑 Gemini 3.8 Flash (최신 플래그십 / 기본 추천)                         │
│     ➔ 온리비 어서의 기본 모델. 초고속 응답과 뛰어난 한국어 문맥 이해력   │
├────────────────────────────────────────────────────────────────────────┤
│  ⚡ Gemini 3.7 Flash (차세대 고성능 모델)                               │
│     ➔ 방대한 원고의 정밀 분석과 복잡한 논리 구조 조판에 최적화          │
├────────────────────────────────────────────────────────────────────────┤
│  🛡️ Gemini 3.6 Flash / 💡 Gemini 3.5 Flash (안정화 모델)              │
│     ➔ 서버 트래픽이 몰리는 시간대에도 변함없는 안정성을 제공            │
├────────────────────────────────────────────────────────────────────────┤
│  💎 Gemma 4 31B IT / 26B A4B IT (오픈 모델)                            │
│     ➔ Google DeepMind의 256K 대규모 컨텍스트를 지원하는 오픈 가중치 모델│
└────────────────────────────────────────────────────────────────────────┘
```

> [!팁]
> **실시간 동적 모델 탐색 (`fetchGoogleAIStudioModels`)**  
> Google에서 새로운 Gemini 모델을 출시하면, 프로그램을 재설치하거나 업데이트하지 않아도 온리비 어서가 등록된 API 키를 통해 최신 모델 목록을 실시간으로 자동 감지하여 목록에 띄워줍니다.

## 2. Google Gemini API 키 무료 발급 가이드 (Step-by-Step)

구글 계정(Gmail)만 있다면 누구나 **비용 부담 없이 평생 무료**로 매일 수만 자의 원고를 AI로 작성할 수 있는 개인 API 키를 발급받을 수 있습니다:

```
[1단계] 구글 AI 스튜디오 접속
  ➔ 브라우저를 열고 https://aistudio.google.com/ 에 접속합니다.
  ➔ 기존에 사용하시던 Google 계정으로 로그인합니다.

[2단계] API 키 발급 메뉴 이동
  ➔ 좌측 상단의 파란색 [Get API key] 버튼을 클릭합니다.

[3단계] 키 생성
  ➔ [Create API key] 버튼을 누르고, 프로젝트를 선택(또는 기본 프로젝트 생성)합니다.
  ➔ 화면에 "AIzaSy..." 로 시작하는 39자리의 고유 키 문자열이 나타납니다.

[4단계] 키 복사
  ➔ 키 옆의 [Copy] 버튼을 눌러 클립보드에 복사합니다.
```

## 3. 온리비 어서에 API 키 등록 및 연동 테스트

복사한 키를 온리비 어서에 등록하는 방법은 매우 간단합니다:

```
[1단계] 상단 메뉴 [도구] ➔ [환경 설정] (단축키 Ctrl + ,) 클릭
[2단계] 환경설정 창에서 [AI 어시스턴트] 그룹으로 스크롤 이동
[3단계] [Google Gemini API Key] 입력창에 복사한 키 붙여넣기 (Ctrl + V)
[4단계] 우측의 [연동 테스트] 버튼 클릭 ➔ "API 연동에 성공했습니다! 🎉" 확인
[5단계] 하단의 [설정 저장] 버튼을 누르면 즉시 모든 AI 기능이 활성화됩니다.
```

## 4. 철저한 3중 보안 & 프라이버시 보호 구조

온리비 어서는 일반적인 웹 기반 AI 서비스들과 근본적으로 다릅니다. 사용자의 데이터 주권을 지키기 위해 다음과 같은 엄격한 보안 원칙을 아키텍처에 구현했습니다:

```
[사용자 PC]                                    [온리비 중앙 서버]
┌────────────────────────────────┐            ┌─────────────────┐
│ 1. API 키 로컬 AES-256 암호화   │            │                 │
│ 2. 로컬 브라우저에만 보관      │            │  ★ 접근 불가!   │
└──────────────┬─────────────────┘            │  어떠한 키나 본문│
               │                              │  데이터도 중앙  │
               │ (직접 HTTPS 보안 터널)        │  서버로 가지    │
               │ Direct Client-to-API         │  않습니다.      │
               ▼                              └─────────────────┘
┌────────────────────────────────┐
│ Google AI Studio 공식 엔드포인트│
│ (https://generativelanguage...)│
└────────────────────────────────┘
```

### ① 로컬 스토리지 AES-256 군사 표준 암호화 (`saveSecureData`)
- 입력하신 API 키는 브라우저 로컬 저장소에 그냥 저장되지 않습니다.
- 온리비의 보안 엔진이 **AES-256 알고리즘**을 사용하여 강력한 암호문(`U2FsdGVkX1...`)으로 변환한 뒤 사용자 PC에만 저장합니다.
- 악성 스크립트나 외부 도구가 사용자의 브라우저 저장소를 훔쳐보더라도 평문 키를 알아낼 수 없습니다.

### ② 온리비 중앙 서버 경유 제로 (Direct Client-to-API)
- 온리비(Onrivi) 개발사나 운영진은 **사용자의 API 키를 절대 열람하거나 보관할 수 없습니다.**
- AI 질의 및 원고 작성 요청은 사용자 PC에서 구글 공식 API 서버(`generativelanguage.googleapis.com`)로 직접 TLS 1.3 암호화 통신을 수행합니다.
- 어떠한 중간 프록시나 중계 서버도 없으므로 제3자 정보 유출 위험이 0%입니다.

### ③ 3초 주기 3회 자동 재시도 및 친절한 한글 오류 진단
- 인터넷 회선이 불안정하거나 구글 서버에 일시적 트래픽 폭증(503 과부하)이 발생하면, 프로그램이 멈추지 않고 **3초 간격으로 최대 3회까지 자동 재시도**를 수행합니다.
- 만약 할당량이 소진(429)되었거나 키가 잘못된 경우(400), 난해한 영문 에러 코드 대신 *"구글 AI 서버 일시 과부하입니다. 잠시 후 다시 시도해 주세요"*와 같은 명확한 한국어 진단 메시지를 표출합니다.

## 5. 자주 묻는 질문 (FAQ)

### Q1. 무료 API 키를 쓰면 요금이 청구되지 않나요?
**A.** 네, Google AI Studio의 무료 등급(Free Tier)은 신용카드를 등록하지 않아도 발급되며, 분당 15회 질의(15 RPM) 한도 내에서 완전 무료로 제공됩니다. 개인 작가나 실무자가 하루 종일 원고를 작성하기에 충분히 넉넉한 분량입니다.

### Q2. 여러 컴퓨터에서 온리비 어서를 쓸 때는 키를 어떻게 하나요?
**A.** 온리비 어서는 보안을 위해 키를 클라우드로 자동 전송하지 않습니다. 새 컴퓨터나 노트북에 설치하셨다면 해당 기기에서 키를 최초 1회만 등록해 주시면 됩니다.
