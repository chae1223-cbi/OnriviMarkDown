# AI 질문·문서 정리·문구 수정

온리비 어서의 AI 어시스턴트는 작가의 창작권을 존중하며 집필의 번거로움을 덜어주는 믿음직한 페어 라이터(Pair Writer)입니다.

사용자의 원고가 무분별하게 외부로 유출되지 않도록 **3가지 목적별 독립 작업 모드**를 철저히 분리하여 제공합니다.

---

## 1. 3대 핵심 AI 집필 작업 모드

```
┌────────────────────────────────────────────────────────────────────────┐
│                        온리비 어서 AI 3대 모드                         │
├───────────────────┬────────────────────────────┬───────────────────────┤
│    1. 질문 모드   │      2. 문서 정리 모드      │    3. 문구 수정 모드  │
│ ───────────────── │ ────────────────────────── │ ───────────────────── │
│ • 문서 미전송     │ • 열린 원고 전체 전송      │ • 선택 문장만 전송    │
│ • 순수 단일 질의  │ • 전체 요약 및 목차 추출   │ • 11가지 전문 프리셋  │
│ • 최고 수준 보안  │ • 챕터 구조 재배치 제안    │ • 윤문/맞춤법 원클릭  │
└───────────────────┴────────────────────────────┴───────────────────────┘
```

1. **질문 모드 (Ask Mode - 프라이버시 최우선)**:
   - 현재 열려 있는 문서의 본문을 외부 AI로 자동 전송하지 않습니다.
   - 사용자가 대화창에 직접 입력한 질문이나 메모만 주고받으므로, 기밀 원고나 미발표 소설의 내용이 외부에 새어 나갈 위험이 전혀 없습니다.
2. **문서 정리 모드 (Document Structuring Mode)**:
   - 현재 에디터에 열려 있는 문서 전체를 AI에게 컨텍스트로 전달합니다.
   - 긴 원고의 핵심 3줄 요약, 장/절 계층 목차 자동 추출, 논리적 모순이나 누락된 설명 보강 제안 등을 요청할 때 최적입니다.
   - **안전장치**: AI가 답변을 제시하더라도 사용자가 직접 확인하고 [본문에 반영] 버튼을 누르기 전까지는 원본 글이 임의로 덮어써지지 않습니다.
3. **문구 수정 모드 (Polishing & Rewriting Mode)**:
   - 본문에서 다듬고 싶은 특정 문장이나 단락을 마우스로 드래그하여 선택한 뒤 호출합니다.
   - 11가지 전문 프리셋 버튼을 통해 단 한 번의 클릭으로 문맥에 맞는 완벽한 윤문이 이루어집니다.

## 2. 문구 수정의 11가지 전문 프리셋

선택한 문장에 대해 작가의 의도에 맞추어 즉시 적용할 수 있는 11가지 원클릭 기능입니다:

- **맞춤법 및 띄어쓰기 교정**: 국립국어원 표준어 규정에 맞추어 오탈자와 어색한 띄어쓰기를 바로잡습니다.
- **문장 다듬기 (윤문)**: 어색한 번역투나 중복 표현을 매끄럽고 유려한 문맥으로 리라이팅합니다.
- **간결하게 줄이기**: 군더더기 수식어를 걷어내고 핵심 메시지만 명쾌하게 압축합니다.
- **풍부하게 늘리기**: 서술이 부족한 부분에 구체적인 묘사나 논리적 설명을 살을 붙여 확장합니다.
- **격식 있는 비즈니스체**: 공문서, 보고서, 이메일에 적합한 정중하고 명확한 문체로 변환합니다.
- **친근하고 다정한 대화체**: 블로그, 에세이, 소셜 미디어에 어울리는 따뜻한 어투로 변환합니다.
- **전문 학술/기술 논문체**: 객관적인 3인칭 관점의 학술 논문 스타일로 톤앤매너를 일괄 전환합니다.
- **외국어 번역**: 한국어 원고를 자연스러운 영어, 일본어, 중국어로 즉시 번역합니다.

## 3. 그림책 모드에서의 AI 지원 범위

- 그림책(Picturebook) 모드에서는 일반적인 문서 정리 대신, 각 **장면(Scene) 단위의 대사와 나레이션 지문 다듬기**에 특화된 AI 보조가 제공됩니다.
- 한 장면의 글자 수가 너무 길어 그림을 가리지 않도록 2~3줄 이내로 간결하게 압축해 주는 그림책 전용 문구 정리가 작동합니다.
