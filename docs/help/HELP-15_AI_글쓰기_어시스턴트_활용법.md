## 1. AI 글쓰기 열기

AI 도구 또는 `/인공지능`을 사용합니다. 먼저 환경설정에 사용할 API 키와 모델을 설정하세요.

AI 창에서는 프롬프트를 입력하고 전체 문서 참조, 선택 영역만 참조 또는 기존 본문을 참조하지 않는 작성 방식을 선택할 수 있습니다. 선택 영역을 다룰 때는 창을 열기 전에 본문에서 범위를 지정하세요.

![AI 도구 안내](/help/assets/fig5_ai_integration.png)

## 2. 실행과 반영

1. 초안 작성·교정·요약 등 원하는 작업을 설명합니다.
2. 참조 범위와 모델을 확인하고 실행합니다.
3. 결과 미리보기를 읽습니다.
4. 선택 영역 교체 또는 삽입 등 제공되는 적용 버튼으로 원고에 반영합니다.
5. 결과를 확인하고 문서를 저장합니다. 잘못 반영했으면 실행 취소를 사용합니다.

AI 실행 결과가 표시되는 것과 원고에 적용되는 것은 다릅니다. 생성 중 표시만 보고 적용이 완료되었다고 판단하지 마세요.

## 3. 프롬프트와 지식 자료

프롬프트 라이브러리·프리셋을 재사용할 수 있으며 관련 자료는 리소스 `prompt`에서 관리합니다. 지식보관함을 참조하는 작업에서는 색인 상태와 출처도 확인하세요.

## 4. 실패한 경우

인증 오류, 모델 없음, 호출 한도, 네트워크 오류, 응답 시간 초과를 구분해서 표시합니다. 500·503·504 같은 일시적 서버 응답에는 제한된 재시도가 적용됩니다. 문서 분량을 줄이거나 오류 안내에 따라 설정을 확인하세요.
