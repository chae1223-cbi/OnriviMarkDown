# 🎨 서식 정의 및 서식 관리 센터 가이드

온리비 어서(Onrivi Author)의 **CSS 서식 프로필 시스템**은 마크다운 문서를 출판물, 학술 논문, 공공 보고서, 기술 명세서 등 최고급 디자인 수준의 문서로 실시간 조판할 수 있는 강력한 스타일 엔진입니다.

---

## 🏛️ 1. 서식 관리 센터 (Style Manager Hub)

에디터 상단 메뉴의 **[서식] ➔ [🎨 서식 관리]**를 클릭하면 열리는 통합 서식 제어 센터입니다.

### ① 기본 서식으로 새로 만들기 (원클릭 자동 복제)
- 좌측 사이드바 상단의 **`[+ 기본 서식으로 새로 만들기]`** 버튼을 누르면 온리비 어서의 공식 표준 규격(`DEFAULT_PROFILE`)을 100% 딥 클론(Deep Clone)하여 안전한 새 프로필을 즉시 생성합니다.
- 복제 즉시 서식 명칭 편집 모드로 진입하며, 원하는 이름을 입력하고 엔터(Enter)를 누르면 바로 저장됩니다.
- 구버전 서식 생성 시 발생하던 속성 누락이나 깨짐 없이, 모든 7대 쇼케이스 태그와 최신 표/구분선/체크박스 구조체가 포함된 완전체로 시작할 수 있습니다.

### ② 서식 가져오기 & 붙여넣기 (Import Hub)
- **파일 불러오기 (.json)**: 외부에 보관 중인 서식 파일이나 팀원이 공유해준 `.json` 테마 파일을 드래그 앤 드롭 또는 클릭하여 즉시 등록합니다.
- **JSON 직접 붙여넣기**: 메신저나 웹에서 복사한 JSON 텍스트를 입력창에 붙여넣고 `[서식 등록하기]`를 누르면 즉시 테마가 생성되고 적용됩니다.
- **자동 정규화 & 살균 (Auto-normalization)**: 구버전 서식 파일이나 불완전한 JSON이라도 최신 Onrivi 규격(표 구조체, 표준 여백, 7대 쇼케이스 태그)으로 100% 자동 복원 및 정규화됩니다.

### ③ 서식 내보내기 & 공유 (Export Hub)
- **파일로 내보내기 (.json)**: 현재 선택된 서식을 온리비 완전체 규격의 JSON 파일로 다운로드합니다.
- **클립보드로 JSON 복사**: 클릭 한 번으로 서식 전체 JSON 코드가 클립보드에 복사되어 메신저나 문서로 간편하게 공유할 수 있습니다.

### ④ 프롬프트로 서식 만들기 (AI 서식 제너레이터)
- 원하는 문서의 스타일을 일상 언어로 입력하면 AI(Gemini 3.8 Flash)가 온리비 맞춤 서식을 즉시 설계해 줍니다.
- **추천 프롬프트 예시**:
  - `🏛️ 공공기관 보고서`: KoPubBatang 바탕체, 정갈한 화이트 배경, 줄간격 1.8, 네이비 헤딩, 표준 여백(상하 18mm/좌우 12mm), 논문형 표 스타일(외곽 2px 굵은선, 행 1px, 열 0px 세로선 없음), 왼쪽 띠형 인용구
  - `💻 GitHub 기술 명세서`: Pretendard 고딕체, 15px, 표준 여백(상하 18mm/좌우 12mm), 깔끔한 엑셀 격자형 표(외곽 1px, 행 1px, 열 1px), 다크 계열 코드블록, 텍스트 하단 옅은 밑줄 구분선
  - `📖 감성 출판 에세이`: Noto Serif KR 명조체, 따뜻한 아이보리 미색 배경(#FAF6ED), 넓은 줄간격 1.85, 표준 여백(상하 18mm/좌우 12mm), 미니멀 표 서식(외곽 0px, 행 1px, 열 0px), 감성적인 박스형 인용구

## 📐 2. 문서 표준 여백 규격 (A4 세로 기준)

온리비 어서는 **화면 가독성(Screen Ergonomics)**과 **A4 출력/PDF 인쇄 안전성**을 완벽하게 절충한 표준 여백(Onrivi 기본서식 기준)을 기본 제공합니다.

| 여백 항목 | 표준 기본값 | 권장 범위 | 시각적 특징 및 설명 |
| :--- | :---: | :---: | :--- |
| **위 여백 (Top)** | **22mm** | 15 ~ 25mm | 인쇄 시 상단 헤더 공간을 확보하며 첫 문단과의 안정적인 간격 유지 |
| **아래 여백 (Bottom)** | **22mm** | 15 ~ 25mm | 페이지 번호 및 하단 툴바 가림 없는 깔끔한 마감 |
| **왼쪽 여백 (Left)** | **19mm** | 10 ~ 22mm | 화면에서 본문 텍스트가 시원하게 확장되며 리스트 들여쓰기 중첩 시에도 답답하지 않음 |
| **오른쪽 여백 (Right)** | **20mm** | 10 ~ 22mm | 코드블록 및 대형 표가 가로로 넉넉하게 펼쳐짐 |

> 💡 **여백 설정 팁**:
> - 화면 분할 모드(에디터 + 미리보기)에서 글이 너무 좁게 보일 때는 좌우 여백을 **10~12mm**로 설정하면 화면 공간을 가장 알차게 쓸 수 있습니다.
> - 책이나 링바인더로 제본할 계획이 있다면 좌측(또는 철하는 쪽) 여백을 **25~30mm**로 늘려주세요.

## 📊 3. 표(Table) 테두리 세부 분리 설정 (`tableStructure`)

표는 문서의 가독성과 전문성을 결정하는 가장 중요한 요소입니다. 온리비 어서는 표 테두리를 **3가지 독립 요소**로 완벽히 분리 제어합니다.

### 3대 테두리 두께 구성
1. **외곽 테두리 두께 (`outerBorderWidth`)**: 표 전체 바깥쪽을 둘러싸는 외곽선 (예: `1px`, `2px`, 미니멀형 `0px`)
2. **행(가로선) 두께 (`rowBorderWidth`)**: 행과 행 사이를 구분하는 가로선 (예: `1px`, 헤더 강조 `2px`)
3. **열(세로선) 두께 (`colBorderWidth`)**: 열과 열 사이를 구분하는 세로선 (격자형 `1px`, 논문/보고서형 `0px`)

### 표 서식 대표 프리셋
- **격자형 (Grid Standard)**: 외곽 `1px`, 행 `1px`, 열 `1px` — 엑셀처럼 모든 셀의 경계가 명확한 표준 서식
- **가로선 강조형 (Academic/Report)**: 외곽 `2px`, 행 `1px`, 열 `0px` — 세로선을 없애고 행의 흐름을 강조하는 학술 논문 및 공공 보고서 표준
- **미니멀형 (Clean Minimal)**: 외곽 `0px`, 행 `1px`, 열 `0px` — 외곽선 없이 텍스트 중심의 현대적이고 세련된 서식

## 🎴 4. 7대 서식 쇼케이스 제어

서식 설정 모달 좌측의 슬라이더를 통해 코딩 없이 마우스 조작만으로 실시간 반영됩니다:

1. **타이포그래피 (Typography)**:
   - 본문 서체(KoPub, Pretendard, D2Coding 등), 글자 크기(14~18px), 줄간격(1.3~2.0배), 자간(-0.05~0.05em), 문서 배경색
2. **제목 위계 (Headings h1~h6)**:
   - H1부터 H6까지 단계별 글자 크기 배율, 글자색, 볼드 굵기, 상하 여백, 하단 구분선
3. **본문 단락 (Paragraph)**:
   - 양끝 정렬, 첫 줄 들여쓰기, 단락 상하 여백, 문장 사이 간격(sentence-gap)
4. **목록 및 체크리스트 (List & TaskList)**:
   - 글머리 기호(원형, 사각형, 숫자 등), 들여쓰기 폭, 체크박스 크기 및 체크 시 딤/취소선 효과
5. **표 (Table)**:
   - 3종 테두리 두께, 헤더 배경색, 본문 지브라 패턴, 셀 내부 패딩
6. **인용구 (Blockquote)**:
   - 왼쪽 띠형, 박스형, 따옴표형, 슬림형 프리셋 및 Alert 태그([!NOTE], [!TIP], [!중요] 등) 자동 연동
7. **미디어, 수식, 구분선 (Media & Math & HR)**:
   - 이미지/비디오/지도의 가로폭, 상하여백, 좌/중/우 정렬
   - KaTeX 수식(math) 단일 글자 크기 및 상하여백 슬라이더
   - 수평선(HR) 두께, 스타일(실선/점선/이중선), 길이(%) 및 상하여백
   - 각주(Footnote) 전용 글자 크기 및 상하여백
