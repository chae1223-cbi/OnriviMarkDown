## 1. 슬래시 메뉴 사용

문서보기에서 `/`를 입력하고 명령어 또는 한글 이름을 검색합니다. 한글 별칭과 환경설정에서 지정한 명령어가 같은 기능을 실행합니다.

| 입력 예 | 기능 |
| --- | --- |
| `/h3`, `/제목3` | 제목 3 |
| `/ul`, `/글머리목록` | 일반 목록 |
| `/check`, `/체크리스트` | 할 일 목록 |
| `/tip`, `/팁` | TIP 인용문 |
| `/table`, `/표` | 표 생성 |
| `/code`, `/코드블록` | 코드블록 |
| `/image`, `/사진` | 이미지 |
| `/now`, `/날짜`, `/달력` | 달력과 날짜 삽입 |

방향키로 선택하고 `Enter` 또는 `Tab`으로 실행합니다. `Esc`로 닫습니다. 한글 조합이 진행 중이면 먼저 조합을 마친 뒤 실행하세요.

## 2. 플로팅 서식 툴바

텍스트를 선택한 뒤 `Ctrl+Space` 또는 오른쪽 도구 버튼으로 엽니다. 마우스 선택만으로 자동 표시되지 않습니다. 선택한 여러 목록 항목에 숫자·일반·체크 목록을 적용할 수 있습니다.

`Ctrl+Space`는 플로팅 서식 툴바 호출입니다. 무조건 슬래시 자동완성 창을 여는 키로 안내하지 않습니다. 슬래시 메뉴는 `/` 입력이나 오른쪽 명령어 도구를 사용합니다.

## 3. 사용자 정의

환경설정 **단축키 / 명령어**에서 각 기능의 단축키와 `/명령어`를 바꿉니다. 설정한 짧은 코드나 한글 이름을 명령어로 사용할 수 있습니다. 공백과 특수문자가 많은 이름보다는 구분하기 쉬운 짧은 이름을 사용하세요.

표 셀 이동과 코드 입력 같은 문맥 동작은 메뉴 명령 실행과 별개입니다. 명령창이 열렸을 때 Tab은 명령 선택을 우선합니다.
