> "원고를 빠르게 집필하다가 서식을 적용하기 위해 마우스로 손을 옮겨 상단 툴바를 클릭하고 다시 키보드로 돌아오는 과정은 작가의 집중력과 글의 흐름(Flow)을 끊어놓는 가장 큰 방해 요인입니다.  
> 온리비 어서(Onrivi Author)는 키보드에서 손을 떼지 않고 빈 줄에서 슬래시(`/`)만 누르면 필요한 모든 조판 도구를 즉시 호출하는 **슬래시 명령어 자동완성 엔진**과, 텍스트를 마우스로 드래그하는 순간 커서 바로 위에 우아하게 떠오르는 **스마트 플로팅 미니 툴바(Floating Toolbar)**를 제공합니다.  
> 특히 표(Table) 내부를 지능적으로 감지하여 열 정렬 버튼을 동적으로 띄워주는 온리비만의 컨텍스트 인식 UX를 함께 살펴보겠습니다."

## 1. 마우스 없는 논스톱 글쓰기: 슬래시(`/`) 명령어의 가치

슬래시 명령어는 노션(Notion)이나 슬랙(Slack)을 사용하듯, 에디터 본문에서 슬래시 기호 하나로 온리비 어서의 모든 조판 및 서식 기능을 1초 만에 불러오는 지능형 자동완성 시스템입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 어서 슬래시(/) 명령어 호출 화면                │
│                                                                        │
│  /t|                                                                   │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ 📋 Table (표)               기본 표 삽입                         │  │
│  │ 💡 quoteTip (인용구 팁)     팁(Tip) 유용한 정보 상자             │  │
│  │ 🧹 clear (태그 취소)        서식 마크다운 태그 취소              │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│                                                                        │
│  ➔ 방향키(↑/↓)로 이동 후 Enter를 누르면 서식이 즉각 삽입됩니다.       │
└────────────────────────────────────────────────────────────────────────┘
```

### 기본 동작 원리
1. **호출 방법**: 에디터 본문의 빈 줄 또는 단어 시작 지점에서 키보드의 **`/`** 키를 누릅니다.
2. **필터링 검색**: 슬래시 뒤에 원하는 기능의 영문 또는 한글 키워드를 타이핑하면 실시간으로 목록이 압축됩니다 (예: `/h1`, `/표`, `/인용`, `/코드`, `/사인`).
3. **선택 및 삽입**: 키보드 방향키(`↑` / `↓`)로 항목을 선택하고 **`Enter`** 또는 **`Tab`**을 누르면 마크다운 서식 템플릿이 커서 위치에 즉시 삽입됩니다.
4. **목록 닫기**: `Escape` 키를 누르면 슬래시 명령어 창이 닫힙니다.

> [!팁]
> **자동완성 목록이 닫혔을 때**:  
> 슬래시(`/`)를 입력한 후 실수로 팝업을 닫았거나 다른 곳을 클릭했다면, 커서가 위치한 상태에서 **`Ctrl + Space`**를 누르면 언제든 슬래시 자동완성 목록이 다시 열립니다.

## 2. 공식 슬래시 명령어 전체 카탈로그

## 3. 스마트 플로팅 미니 툴바 (Floating Toolbar)

원고를 작성하다가 특정 단어나 문장을 마우스로 드래그 선택하면, 커서 바로 위쪽 공중에 **초소형 플로팅 서식 미니 툴바**가 부드럽게 나타납니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 스마트 플로팅 미니 툴바 구조                  │
│                                                                        │
│   [ B  I  Password  U  S ] | [ ▲ H3 ▼ ] | [ —  1.  •  ❝▼  ☑  🧹 ] ...  │
│   ┌──────────────────────────────────────────────────────────────┐     │
│   │ 온리비 어서는 개인형 RAG 기술을 탑재하여... (마우스 드래그 영역) │     │
│   └──────────────────────────────────────────────────────────────┘     │
└────────────────────────────────────────────────────────────────────────┘
```

### 플로팅 툴바의 4대 프리미엄 UX 특징
1. **초고속 서식 원클릭 적용**:  
   마우스를 상단 화면 끝까지 올릴 필요 없이, 드래그한 위치에서 바로 `B`(굵게), `I`(기울임), `U`(밑줄), 인라인 코드(`Password.png`), 취소선(`S`)을 1클릭으로 적용할 수 있습니다.
2. **드래그 이동(Drag & Drop) 지원**:  
   툴바 가장자리나 빈 공간을 마우스로 잡고 원하는 위치로 자유롭게 끌어다 놓을 수 있어 본문 시야를 가리지 않습니다.
3. **키보드 접근성 네비게이션**:  
   플로팅 툴바가 열린 상태에서 키보드 방향키(`←`, `→`, `↑`, `↓`)를 누르면 버튼 사이를 자유롭게 포커스 이동할 수 있으며, `Escape` 키를 누르면 즉시 닫히고 에디터 커서로 복귀합니다.
4. **표(Table) 내부 지능형 위치 감지 (컨텍스트 인식)**:  
   커서가 표 안에 위치해 있을 때(`curLine`이 `|`로 시작) 플로팅 툴바가 이를 감지하여 **열 정렬 3종 버튼**을 동적으로 사출합니다!
   - **`⇤` 현재 열 왼쪽 정렬**: `Alt+Shift+L`
   - **`↔` 현재 열 가운데 정렬**: `Alt+Shift+C`
   - **`⇥` 현재 열 오른쪽 정렬**: `Alt+Shift+R`

## 4. 상단 서식 툴바와의 완벽한 시너지

플로팅 툴바와 함께 상단에 고정된 **메인 서식 툴바(`FormattingToolbar.tsx`)** 역시 고대비 커스텀 아이콘과 원클릭 편의 기능을 갖추고 있습니다:

```
┌────────────────────────────────────────────────────────────────────────┐
│  [✨ AI 프롬프트] | [B I 코드 U S] | [▲ H3 ▼] | [— 1. • ❝▼ ☑ 🧹 🪄] | ...  │
└────────────────────────────────────────────────────────────────────────┘
```

- **✨ AI 프롬프트 버튼**: API 키가 등록되어 있을 때 활성화되며, 선택한 문장의 윤문/교정/초안 작성 모달(`OPEN_AI_WRITER`)을 즉시 호출합니다.
- **❝▼ 인용구 콤보 드롭다운**: 단순 인용구뿐만 아니라 GitHub 5대 Alert 태그([!참고], [!팁], [!중요], [!주의], [!경고])를 한눈에 보고 고를 수 있습니다.
- **🧹 태그 취소 지우개 (`Ctrl+Shift+X`)**: 제목 기호(`#`)나 목록 기호(`-`)가 적용된 줄에서 클릭하면 기호만 말끔히 제거하여 일반 본문으로 되돌립니다.
- **🪄 문서 서식 일괄 정리 (`Ctrl+Shift+L`)**: 불필요한 연속 빈 줄 제거, 공백 정규화, 표 파이프 줄 맞춤을 한 번에 실행합니다.
- **도장 서명/발신인 버튼 (`Ctrl+Alt+R`)**: 공문서나 편지 하단에 품격 있는 붉은색 원형 인감도장(`<span style="color:#dc2626...">인</span>`)과 우측 정렬 발신인을 사출합니다.

## 5. 단계별 실전 따라 하기 (Step-by-Step)

슬래시 명령어와 플로팅 툴바를 결합하여 마우스 손 움직임을 90% 줄이는 3단계 고속 집필 루틴을 실습해 봅니다.

### 1단계: 슬래시 명령어로 구조 잡기
1. 빈 줄에서 `/h2` 입력 후 Enter ➔ `## 새로운 시작` 작성
2. 다음 줄에서 `/quoteTip` 입력 후 Enter ➔ 유용한 팁 상자가 즉시 생성됩니다.
3. 다음 줄에서 `/table` 입력 후 Enter ➔ 깔끔한 표 템플릿이 안착됩니다.

### 2단계: 텍스트 드래그 후 플로팅 툴바로 강조하기
1. 방금 작성한 본문 중 핵심 단어를 마우스로 드래그합니다.
2. 머리 위에 나타난 플로팅 툴바에서 `B`를 누르면 `**핵심 단어**`로 굵게 처리됩니다.
3. 표 안의 셀을 드래그하면 툴바에 나타나는 `↔` 버튼을 눌러 열 정렬을 즉시 가운데로 맞춥니다.

### 3단계: 단축키로 신속 마무리
- 글의 끝머리에서 단축키 **`Ctrl+Alt+R`**을 누르면 정갈한 우측 정렬 서명과 붉은색 인감도장이 자동으로 삽입됩니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 슬래시 명령어를 내가 원하는 단어로 바꿀 수 있나요?
**A.** 네! 상단 메뉴 [도구] ➔ [환경설정] ➔ **[단축키 / 명령어]** 탭에 들어가시면, 각 기능별 슬래시 명령어를 자유롭게 수정할 수 있습니다 (예: `/codeblock` 대신 `/코드`, `/c` 등으로 커스텀 가능).

### Q2. 텍스트를 드래그할 때 플로팅 툴바가 자꾸 본문을 가려요. 어떻게 치우나요?
**A.** 툴바의 빈 영역을 마우스로 잡고 옆으로 드래그하시면 원하는 위치로 쉽게 이동할 수 있습니다. 또는 키보드의 `Escape` 키를 누르면 선택 영역은 그대로 유지된 채 플로팅 툴바만 즉시 사라집니다.

### Q3. 한글 입력 중에 슬래시(`/`)를 누르면 가끔 자동완성이 안 뜰 때가 있어요.
**A.** 윈도우 한글 IME 조합 상태(글자 밑에 밑줄이 그어진 상태)에서는 슬래시 키가 조합 문자로 인식될 수 있습니다. `Space`나 `Enter`를 가볍게 눌러 글자 조합을 끝낸 후 `/`를 입력하시거나, 단축키 **`Ctrl + Space`**를 누르시면 100% 즉시 열립니다.
