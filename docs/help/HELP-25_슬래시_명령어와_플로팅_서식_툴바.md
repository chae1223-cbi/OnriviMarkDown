# 슬래시 명령과 플로팅 서식 툴바

## 슬래시 명령

편집 가능한 본문에서 `/`를 입력하면 명령 목록을 검색할 수 있습니다. 명령이나 별칭을 입력하고 방향키로 선택한 뒤 Enter로 실행합니다. Escape는 목록을 닫습니다. 코드와 특수 블록에서는 일반 본문과 다르게 처리될 수 있습니다.

| 명령 예 | 작업 |
| --- | --- |
| `/h1`~`/h6` | 제목 단계 |
| `/ul`, `/ol`, `/check` | 목록·체크리스트 |
| `/quote`, `/note`, `/warning` | 인용구·콜아웃 |
| `/table`, `/image`, `/video`, `/map` | 표·미디어 |
| `/code`, `/math` | 코드·수식 |
| `/pagebreak` | 수동 페이지 나누기 |
| `/style`, `/now`, `/sign` | 서식·날짜·서명 |

명령은 환경설정에서 변경할 수 있으므로 기본 이름이 동작하지 않으면 현재 설정을 확인하세요.

## 플로팅 툴바

`Ctrl+Space`로 플로팅 서식 도구를 사용합니다. 선택 영역에는 굵게·기울임·링크 등 필요한 서식을 적용합니다. 툴바를 클릭해도 작업 대상을 유지하도록 처리하지만, 다른 문서로 이동하거나 글을 바꾸면 선택을 다시 확인해야 합니다.

## AI 버튼과 구분

오른쪽 AI 런처는 플로팅 서식 툴바와 별도입니다. 위쪽은 패널 열기·숨기기, 아래 모델 이름은 모델 목록입니다. 도구가 열려 있을 때 Enter·Escape의 대상은 현재 포커스에 따라 달라집니다.
