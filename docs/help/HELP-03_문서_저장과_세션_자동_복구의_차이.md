# 저장·자동 저장·세션 복구

온리비 어서는 소중한 원고가 불의의 사고로 유실되지 않도록 **수동 영구 저장**, **주기적 자동 저장**, 그리고 **비상 세션 복구**라는 3중 데이터 안전망을 운영하고 있습니다.

이 세 가지 기능의 차이를 명확히 이해하시면 어떤 상황에서도 안심하고 집필에 몰입하실 수 있습니다.

---

## 1. 3대 저장 체계의 역할과 차이점

| 구분 | 작동 방식 | 저장 위치 | 데이터 신뢰도 | 권장 사용법 |
| :--- | :--- | :--- | :---: | :--- |
| **수동 영구 저장 (`Ctrl + S`)** | 사용자가 단축키를 누르는 즉시 실행 | 내 컴퓨터 디스크 실제 파일(`.md`) | **최상 (100% 영구 보존)** | 중요한 문단을 작성한 직후 수시로 실행 |
| **주기적 자동 저장 (Auto-Save)** | 설정한 시간 주기(예: 30초)마다 자동 실행 | 내 컴퓨터 디스크 실제 파일(`.md`) | **상 (주기별 동기화)** | 환경설정에서 본인의 집필 속도에 맞게 활성화 |
| **비상 세션 복구 (Session Restore)** | 타이핑 중 백그라운드 캐시 보관 | 브라우저/앱 로컬 캐시 (IndexedDB) | **임시 안전망 (비상용)** | PC 강제 종료 시 재실행 후 나타나는 모달에서 복구 |

---

## 2. 수동 영구 저장 (`Ctrl + S`)

가장 확실하고 안전한 원본 저장 방법입니다.

- 에디터 상단 탭에 파일명 옆에 점(•)이나 별표(*)가 표시되어 있다면, 마지막 저장 이후 내용이 수정되었음을 뜻합니다.
- `Ctrl + S`(Mac은 `Cmd + S`)를 누르면 하단 상태바에 "저장 완료" 알림이 뜨며 디스크 파일에 즉각 기록됩니다.
- 데스크톱 앱에서는 지연 시간 없이 파일 시스템에 직접 쓰이며, 웹 브라우저에서는 파일 권한이 유지되는 동안 안전하게 동기화됩니다.

---

## 3. 주기적 자동 저장 (Auto-Save) 설정

자동 저장은 사용자가 저장을 깜빡하더라도 일정 시간마다 원본 파일에 변경 사항을 자동으로 덮어써 주는 기능입니다.

1. 상단 메뉴의 [설정] 또는 우측 상단 톱니바퀴(⚙️) 아이콘을 클릭하여 **[환경설정]** 모달을 엽니다.
2. [일반 설정] 탭의 **'자동 저장 주기'** 항목을 확인합니다.
3. 비활성화(끄기), 10초, 30초, 60초 등 원하는 주기를 선택할 수 있습니다.
4. **주의사항**: 파일이 읽기 전용 상태이거나 네트워크 드라이브의 연결이 끊긴 경우 자동 저장이 일시 실패할 수 있으므로, 하단 상태바의 저장 메시지를 확인하세요.

---

## 4. 비상 세션 자동 복구 (정전 및 강제 종료 방어)

컴퓨터가 갑자기 꺼지거나, 실수로 창을 닫았거나, 프로그램이 강제 종료되었을 때 작동하는 비상 복구 시스템입니다.

- 온리비 어서는 입력이 발생할 때마다 변경된 원고를 안전한 로컬 캐시 저장소(IndexedDB / LocalStorage)에 실시간으로 임시 기록(`onrivi_draft_*`)해 둡니다.
- 프로그램을 다시 실행하고 해당 문서를 열면 시스템이 캐시 내용과 디스크 원본 파일의 수정 시점을 자동으로 비교합니다.
- 만약 캐시에 저장되지 않은 최신 작업 내용이 남아 있다면 다음과 같은 알림창이 나타납니다:
  > **"저장되지 않은 세션 복구 데이터가 있습니다. 복구하시겠습니까?"**
- **[복구하기]**를 누르면 종료 직전까지 작성했던 내용이 마법처럼 그대로 복원됩니다. 복원 후 반드시 `Ctrl + S`를 눌러 디스크 파일에 영구 저장해 주세요.

> [!WARNING]
> 세션 복구 기능이 존재하더라도 브라우저 쿠키/캐시를 완전히 청소하거나 시크릿 창(InPrivate)을 닫으면 임시 캐시가 지워질 수 있습니다. 정기적인 `Ctrl + S`와 외장 백업을 절대 게을리하지 마세요.
