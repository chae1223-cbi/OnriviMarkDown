## 1. 문서 저장과 세션 복구는 다릅니다

| 기능 | 목적 | 확인할 것 |
| --- | --- | --- |
| 저장 (`Ctrl+S`) | 현재 문서를 선택한 파일·Drive 파일에 기록 | 저장 완료 상태와 저장 위치 |
| 다른 이름으로 저장 (`Ctrl+Shift+S`) | 새 이름·위치의 파일로 기록 | 파일명과 대상 환경 |
| 자동 저장 | 입력이 멈춘 뒤 설정된 시간에 파일 기록 | 환경설정의 간격, 파일 연결, 편집 권한 |
| 세션 복구 | 다시 실행할 때 탭과 작업 내용을 복원 | 복구 후 실제 파일에 저장했는지 |

자동 저장이 항상 5초인 것은 아닙니다. 환경설정에서 선택한 초 단위 간격을 사용합니다. 새 문서의 저장 위치가 정해지지 않았거나 읽기 전용이면 자동 저장에 의존하지 마세요.

## 2. 안전하게 저장하기

1. 연결한 작업장이 로컬인지 Google Drive인지 확인합니다.
2. `Ctrl+S`를 누릅니다. 처음 저장하면 이름과 위치를 선택하는 절차가 나올 수 있습니다.
3. 저장 실패 또는 미저장 표시가 남아 있으면 연결·권한을 확인하고 다시 저장합니다.

Drive 연결이 끊긴 경우 임시 초안 복구가 사용될 수 있으나, 임시 초안은 Drive 파일에 저장이 완료되었다는 뜻이 아닙니다. 재연결 후 저장 상태를 확인하세요.

## 3. 다시 열었을 때

복구된 탭의 최신 내용을 확인한 뒤 저장하세요. 브라우저 데이터 삭제, 저장소 장애, 저장 이전의 강제 종료에서는 복구가 제한될 수 있습니다. 중요한 원고는 별도 파일 백업을 유지하세요.

문서 열기·저장 시 현재 편집 화면과 선택 위치를 유지하도록 처리하지만, 다른 파일을 열면 그 문서의 상태로 전환됩니다.
