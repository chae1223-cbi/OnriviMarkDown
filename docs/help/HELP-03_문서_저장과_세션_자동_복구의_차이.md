# 저장·자동 저장·세션 복구

## 세 가지 기능의 차이

| 기능 | 의미 | 확인할 사항 |
| --- | --- | --- |
| 저장 | 현재 문서를 선택한 파일 위치에 기록 | 파일명, 작업장, 저장 완료 안내 |
| 자동 저장 | 환경설정의 주기로 저장 시도 | 저장 가능한 경로와 권한, 주기 설정 |
| 세션·초안 복구 | 이전 작업 상태나 임시 원고를 다시 표시 | 실제 파일에도 저장되었는지 확인 |

## 저장 순서

1. `Ctrl+S` 또는 저장 버튼을 누릅니다.
2. 새 문서라면 이름과 위치를 지정합니다.
3. 문서 탭의 수정 표시와 오류 알림을 확인합니다.
4. 중요한 작업은 저장한 파일을 다시 열어 제목·표·이미지가 있는지 확인합니다.

다른 이름으로 저장은 `Ctrl+Shift+S`입니다. 메뉴에서 로컬 저장과 개인 웹드라이브 저장을 구분합니다. 복사본을 만들었다면 이후 어느 파일을 편집하고 있는지도 확인하세요.

## 자동 저장 사용

환경설정의 자동 저장 주기를 선택합니다. 원고를 저장할 위치가 없거나 드라이브 연결이 끊긴 상태에서는 주기가 설정되어 있어도 저장이 완료되지 않을 수 있습니다. 자동 저장은 모든 시점의 변경 이력을 보관하는 버전 관리 기능이 아닙니다.

## 복구한 원고 다루기

복구된 내용이 실제 파일보다 최신인지 확인한 뒤 저장합니다. 로컬 파일과 초안이 다를 때 내용을 확인하지 않고 한쪽으로 덮어쓰지 마세요. 파일 백업에는 원고 외에 참조 이미지·서식·참고문헌도 포함하는 것이 좋습니다.
