## 1. 기본 단축키

아래는 기본값입니다. 변경한 설정이 있으면 환경설정의 표시값을 따릅니다.

| 기능 | 기본 키 |
| --- | --- |
| 저장 / 다른 이름으로 저장 | Ctrl+S / Ctrl+Shift+S |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 플로팅 서식 툴바 | Ctrl+Space |
| 굵게 / 기울임 / 밑줄 | Ctrl+B / Ctrl+I / Ctrl+U |
| 인라인 코드 / 취소선 | Ctrl+E / Ctrl+Shift+X |
| 제목 1~6 | Ctrl+1~6 |
| 숫자 / 일반 / 체크 목록 | Ctrl+Shift+7 / Ctrl+Shift+8 / Ctrl+Shift+C |
| 기본 인용구 | Ctrl+Q |
| NOTE / TIP / IMPORTANT / WARNING / CAUTION | Ctrl+Shift+1~5 |
| 태그 취소 | Ctrl+Shift+0 |
| 링크 / 표 / 수식 | Ctrl+K / Ctrl+T / Ctrl+M |
| 코드블록 | Ctrl+Shift+E |
| 각주 / 문헌 인용 | Ctrl+Alt+F / Ctrl+Alt+C |
| 서명 | Ctrl+Alt+R |
| 문서 서식 정리 | Ctrl+Shift+L |

코드블록 키 `Ctrl+Shift+E`는 일부 기존 이모지 메뉴 표시와 겹칠 수 있습니다. 이모지는 오른쪽 버튼을 사용하고 사용자 단축키를 확인하세요.

## 2. 문맥별 키

- 목록 끝의 Tab·Shift+Tab은 계층 이동입니다.
- 문장 중간 Tab은 설정된 수의 스페이스를 넣습니다.
- 표 Tab·Shift+Tab은 셀 이동과 대상 셀 글 전체 선택입니다.
- 표·코드·인용문에서 Ctrl+Enter는 아래 본문으로 나갑니다.
- Esc는 이모지 패널·플로팅 도구·슬래시 메뉴 등을 닫습니다.

## 3. 변경 방법

환경설정 → **단축키 / 명령어**에서 키 조합과 슬래시 명령어를 지정합니다. 충돌 안내가 나오면 다른 조합을 사용하세요. 복사하기로 현재 설정을 텍스트로 확인하고 초기화로 기본값을 복원할 수 있습니다.

문서보기의 사용자 정의 단축키는 Windows의 Ctrl 또는 macOS의 해당 Ctrl/Command 처리를 사용합니다. 브라우저·OS가 먼저 사용하는 키는 환경에 따라 실행이 제한될 수 있습니다.
