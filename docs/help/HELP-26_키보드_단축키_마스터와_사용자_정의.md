# 기본 단축키와 사용자 지정

온리비 어서는 집필의 속도와 리듬을 극대화할 수 있도록 풍부한 키보드 단축키를 제공하며, 사용자의 익숙한 손맛에 맞추어 단축키를 자유롭게 재정의할 수 있는 **단축키 매핑 시스템**을 지원합니다.

---

## 1. 필수 핵심 단축키 치트시트

| 단축키 (Windows/Linux) | 단축키 (macOS) | 기능 설명 |
| :--- | :--- | :--- |
| **`Ctrl + S`** | `Cmd + S` | **수동 영구 저장 (가장 중요)** |
| **`Ctrl + N`** | `Cmd + N` | 새 문서 생성 |
| **`Ctrl + O`** | `Cmd + O` | 기존 문서 파일 열기 |
| **`Ctrl + P`** | `Cmd + P` | 인쇄 및 출판용 PDF 내보내기 |
| **`Ctrl + B`** | `Cmd + B` | 텍스트 **굵게 (Bold)** |
| **`Ctrl + I`** | `Cmd + I` | 텍스트 *기울임 (Italic)* |
| **`Ctrl + U`** | `Cmd + U` | 텍스트 <u>밑줄 (Underline)</u> |
| **`Ctrl + K`** | `Cmd + K` | 하이퍼링크 삽입 |
| **`Ctrl + Space`** | `Cmd + Space` | **플로팅 서식 도구함 열기** |
| **`Ctrl + Shift + C`** | `Cmd + Shift + C` | **블로그 포스팅용 HTML 서식 복사** |
| **`Ctrl + Z`** | `Cmd + Z` | 실행 취소 (Undo) |
| **`Ctrl + Y`** | `Cmd + Shift + Z` | 다시 실행 (Redo) |
| **`Ctrl + F`** | `Cmd + F` | 본문 단어 찾기 |
| **`Ctrl + H`** | `Cmd + H` | 본문 단어 찾아 바꾸기 |

---

## 2. 단축키 사용자 정의 (커스텀 키 설정)

기존에 쓰던 다른 에디터의 단축키가 익숙하시다면 원하는 키 조합으로 자유롭게 변경할 수 있습니다:

1. 상단 톱니바퀴(⚙️) 아이콘을 눌러 **[환경설정]** 모달을 엽니다.
2. 좌측 탭에서 **[단축키 & 슬래시 명령어]** 탭을 클릭합니다.
3. 변경하고 싶은 명령 항목 옆의 키 입력 상자를 클릭합니다.
4. 키보드에서 원하는 조합(예: `Alt + S`, `Ctrl + Shift + F` 등)을 직접 누르면 즉시 감지되어 입력됩니다.
5. 시스템이 Windows와 Mac 환경을 자동으로 판별하여 OS별 특수 키(Meta, Win, Cmd) 충돌을 지능적으로 방지합니다.
6. 하단의 **[저장]**을 누르면 나만의 커스텀 단축키가 즉시 활성화됩니다.
7. 언제든지 **[기본값 복원]** 버튼을 누르면 초기 공장 출하 단축키로 안전하게 리셋할 수 있습니다.
