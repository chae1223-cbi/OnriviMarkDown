## 1. 웹 링크와 문서 연결

**링크** 또는 `Ctrl+K`로 표시할 글과 URL을 입력합니다. 선택한 글이 있으면 링크 글로 사용합니다. 문서보기의 외부 링크는 브라우저로 열고, 문서 안 앵커는 해당 위치로 이동합니다.

**문서 연결** 또는 `/문서연결`은 문서 선택창을 열어 현재 커서 위치에 다른 문서 링크를 삽입합니다. 연결한 마크다운 링크를 클릭하면 대상 문서를 엽니다. 상대경로 링크는 대상 파일이 같은 위치에 있어야 합니다.

```markdown
[웹사이트](https://onrivi.com)
[다음 문서](<다음 문서.md>)
```

## 2. 달력과 날짜 삽입

`/날짜`, `/달력`, `/캘린더`, `/시간` 또는 날짜 도구를 사용합니다. 달력에서 날짜를 고르고 표시 서식을 선택합니다.

- ISO 날짜: `2026-10-14`
- 한글 날짜: `2026년 10월 14일`
- 점 표기, 요일 약칭, 상세 요일 서식
- 현재 시·분 포함 및 초 포함 옵션

삽입 미리보기를 확인하고 적용하면 현재 커서 위치에 일반 텍스트로 들어갑니다. 삽입한 날짜는 시계처럼 자동 갱신되지 않습니다.

## 3. 이모지

오른쪽 이모지 도구로 패널을 열고 원하는 이모지를 선택합니다. 문서보기의 현재 삽입 위치에 문자를 넣고 마크다운에도 반영합니다. **Esc**로 패널을 숨깁니다.

이모지는 이미지 리소스 파일이 아니라 문자입니다. OS·글꼴에 따라 모양과 색이 달라질 수 있습니다. 코드블록 기본 단축키와 겹치는 기존 이모지 메뉴 표시는 환경설정에서 확인하고 오른쪽 도구를 사용하세요.
