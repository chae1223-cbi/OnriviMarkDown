# 표 만들기·편집·제목과 정렬

데이터나 비교 항목을 일목요연하게 전달할 때 표(Table)는 필수적입니다. 온리비 어서는 표준 마크다운 파이프 표 문법과 함께 직관적인 **표 마법사 도구**와 **텍스트 정렬 컨트롤**, 그리고 **표 상단 캡션 자동 배치**를 지원합니다.

---

## 1. 마크다운 표 기본 문법

마크다운에서는 파이프(`|`) 기호와 하이픈(`-`)을 사용하여 표를 작성합니다:

```markdown
| 기능명 | 지원 여부 | 단축키 | 상세 설명 |
| :--- | :---: | :---: | :--- |
| 수동 영구 저장 | 지원 | Ctrl + S | 디스크 실제 파일에 즉각 기록 |
| 주기적 자동 저장 | 지원 | 환경설정 연동 | 10초~60초 주기 자동 저장 |
| 비상 세션 복구 | 지원 | 자동 팝업 | 정전 및 강제 종료 시 복구 모달 |
```

- 첫 번째 줄은 **헤더(제목 행)**가 됩니다.
- 두 번째 줄은 **구분선**이며, 이곳에 콜론(`:`)을 넣어 각 열의 텍스트 정렬 방향을 지정합니다.
- 세 번째 줄부터는 실제 데이터 행이 됩니다.

---

## 2. 텍스트 정렬 (좌측, 중앙, 우측)

구분선의 콜론(`:`) 위치에 따라 열 단위로 텍스트 정렬을 지정할 수 있습니다:

- **좌측 정렬 (`:---`)**: 일반적인 텍스트, 설명문, 제목에 권장합니다.
- **중앙 정렬 (`:---:`)**: 날짜, 상태 코드, 단축키, '예/아니오' 여부에 권장합니다.
- **우측 정렬 (`---:`)**: 금액, 수량, 백분율, 페이지 번호 등 숫자에 권장합니다.

---

## 3. 표 삽입 도구와 슬래시 명령어

마크다운 파이프 기호를 일일이 타이핑하기 번거롭다면 다음의 편리한 도구를 활용하세요:

1. **슬래시 빠른 명령어 (`/table`)**:
   - 빈 줄에서 `/table`을 입력하고 `Enter`를 누르면 기본 3행 3열 표가 즉시 생성됩니다.
2. **상단 툴바의 [표 삽입] 버튼**:
   - 툴바의 표 아이콘을 클릭하면 행 수와 열 수를 직접 지정하여 원하는 크기의 표를 단숨에 생성할 수 있는 마법사 모달이 열립니다.
3. **엑셀(Excel) 복사 붙여넣기**:
   - 엑셀이나 스프레드시트에서 표 영역을 복사(`Ctrl + C`)한 뒤 에디터에 붙여넣기(`Ctrl + V`)하면 마크다운 파이프 표로 자동 변환됩니다.

---

## 4. 표 캡션(제목) 위치와 출판 조판 규칙

출판학 및 표준 공문서 규격(KS / ISO)에서 **표(Table)의 캡션(제목)은 표 상단에 위치하는 것이 원칙**입니다.

- 온리비 어서의 서식 관리 센터는 미디어 캡션 독립 제어(`kindOverrides`) 기능을 통해, 표의 캡션은 자동으로 상단에 배치하고 그림의 캡션은 하단에 배치하도록 정밀하게 통제합니다.
- 표 위에 `*[표 1] 온리비 어서 기능 비교표*`와 같이 이탤릭 텍스트로 적어두시면 출판 조판 시 아름다운 캡션 스타일로 자동 승격되어 렌더링됩니다.
