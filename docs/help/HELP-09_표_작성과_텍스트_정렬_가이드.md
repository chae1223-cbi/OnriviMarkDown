## 1. 표 만들기

`Ctrl+T`, `/표`, 표 버튼으로 생성창을 엽니다. 원하는 행·열 수를 선택하고 삽입합니다. 새 표의 헤더는 문서보기에서 중앙 정렬됩니다.

```markdown
| 이름 | 수량 | 금액 |
| :--- | :---: | ---: |
| 사과 | 2 | 3000 |
```

## 2. 표 편집 도구 위치

문서보기에서 **표 셀 안을 클릭**하면 문서 영역 상단에 **표 편집 도구**가 나타납니다. 화면 전체의 메뉴바가 아니라 현재 문서 영역 위에 붙는 도구입니다.

| 버튼 | 기능 |
| --- | --- |
| 행 추가·행 삭제 | 현재 행을 기준으로 편집 |
| 열 추가·열 삭제 | 현재 열을 기준으로 편집 |
| 본문 왼쪽·중앙·오른쪽 | 클릭한 열의 본문 정렬 변경 |
| 표 아래 본문 | 표 밖으로 이동 |
| 표 삭제 | 표 전체 삭제 |
| 복사 | 현재 표 전체를 마크다운 형식으로 복사 |

헤더 행이나 마지막 남은 열은 개별 삭제가 제한됩니다. 전체를 없애려면 표 삭제를 사용합니다.

## 3. 셀 입력과 이동

- 마우스로 셀을 클릭하면 클릭 위치에 커서를 놓습니다. 셀 내용을 자동으로 전체 선택하지 않습니다.
- **Tab / Shift+Tab:** 다음·이전 셀로 이동하고 이동한 셀의 글을 전체 선택합니다.
- 마지막 셀의 Tab은 새 행을 추가합니다.
- **Enter:** 셀 안 줄바꿈입니다. 마크다운에는 `<br>`로 저장합니다.
- **Ctrl+Enter:** 표 밖의 다음 본문으로 이동합니다.

## 4. 여백과 복사

표 셀의 문단 여백은 제거하고 셀 안쪽 여백을 사용합니다. Onrivi 기본서식의 셀 안쪽 여백은 상하 5px·좌우 8px입니다. 표끼리의 바깥 간격과 셀 내부 간격은 서로 다른 설정입니다.

복사 버튼은 표 정렬·강조·셀 줄바꿈을 포함한 마크다운을 복사합니다. 이미지 형태의 복사나 Excel 셀 데이터 형식 복사를 의미하지 않습니다. 문서보기의 Excel/TSV 붙여넣기 자동 변환은 별도로 보장하지 않으므로 표 생성 도구를 사용하세요.
