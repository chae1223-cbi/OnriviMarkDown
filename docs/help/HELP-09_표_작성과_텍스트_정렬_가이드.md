# 표 만들기·편집·제목과 정렬

## 1. 표 삽입과 캡션 규칙

1. 표 도구 또는 `Ctrl+T`를 실행합니다.
2. 행·열과 정렬 방식을 정합니다.
3. 필요한 경우 표 제목과 번호를 입력합니다.
4. 설명 위치와 표현 형식을 확인한 뒤 삽입합니다.

서식 관리의 미디어 캡션 설정에 따라 표 캡션의 위치(상단/하단)와 번호 형식을 조절할 수 있습니다. 시스템 제공 4대 표준 서식의 표 캡션 규칙은 다음과 같습니다:
- **KS / ISO 기술표준**: 표 상단 (`표 1 - 제목`)
- **대기업 전략기획서**: 표 상단 (`표 1. 제목`)
- **학술·정책 연구보고서 (KDI)**: 표 상단 (`<표 1> 제목`)
- **글로벌 테크 6-Pager**: 표 상단 (`표 1. 제목`)

## 2. 기본 마크다운 표

```markdown
**표 1. 추진 일정**

| 작업 | 일정 | 상태 |
| :--- | :---: | ---: |
| 자료 수집 | 10월 | 완료 |
| 초안 작성 | 11월 | 진행 |
```

문서보기에서는 셀을 클릭해 입력하고 표 편집 도구로 행·열과 정렬을 조절합니다. 셀 안 줄바꿈과 표 밖으로 나가는 동작은 일반 본문과 다릅니다. 표 아래 본문이 필요하면 블록 나가기 도구를 사용합니다.

## 3. 보존과 호환성

단순 마크다운 표는 복잡한 셀 병합을 표현하지 못합니다. 다른 프로그램의 복잡한 표를 붙여넣거나 가져온 뒤에는 데이터 누락·순서·병합 상태를 확인하세요. 모든 스프레드시트 붙여넣기가 자동으로 동일한 표가 된다고 보장하지 않습니다.

문서 서식 일괄 정리는 표 문법과 간격을 정돈합니다. PDF·EPUB·DOCX·HWPX는 서로 다른 출력 방식이므로 표 폭·글꼴·페이지 분할을 결과 파일에서 확인합니다.
