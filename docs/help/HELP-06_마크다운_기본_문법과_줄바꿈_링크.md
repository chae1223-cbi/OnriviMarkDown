# 마크다운 기본 문법·제목·줄바꿈·링크

## 1. 자주 쓰는 문법

| 입력 | 의미 |
| --- | --- |
| `# 제목`~`###### 제목` | 제목 1~6 |
| `**강조**` | 굵게 |
| `*기울임*` | 기울임 |
| `~~삭제~~` | 취소선 |
| `` `코드` `` | 인라인 코드 |
| `[표시 글](https://example.com)` | 웹 링크 |
| `![설명](media/photo.png)` | 이미지 참조 |

해시와 제목 사이에는 공백이 필요합니다. 문서보기에서는 스페이스 입력 시 제목 태그가 실제 제목 서식으로 바뀝니다. 태그를 일반 글자로 보여주려면 코드 표시를 사용하세요.

## 2. 제목 번호와 제목 태그

`## 1. 준비 사항`에서 `##`는 제목 단계, `1.`은 제목 내용에 포함된 번호입니다. 서식 관리에서 자동 번호를 켜면 제목 단계에 따라 번호를 계산하여 원문에 기록합니다. 번호를 직접 중복 입력할 필요가 없습니다.

## 3. 문단과 줄바꿈

문단 사이는 빈 줄로 구분합니다. 같은 문단에서 강제로 줄을 바꾸는 마크다운은 줄 끝 공백 두 칸 또는 필요한 위치의 `<br>`입니다. 일반 Enter로 빈 줄을 많이 넣는 방법은 인쇄 페이지 배치를 고정하는 수단이 아닙니다.

## 4. 경로에 공백이 있을 때

문서 연결 도구를 사용하면 경로 형식을 직접 맞추는 부담을 줄일 수 있습니다. 수동 작성 예시는 `[다음 장](<다음 장.md>)`입니다. 다른 PC에서 열 때는 링크 대상과 이미지가 같은 상대 위치에 있는지 확인합니다.
