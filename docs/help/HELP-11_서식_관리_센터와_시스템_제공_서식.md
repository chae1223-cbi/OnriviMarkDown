> 온리비 어서는 원고 본문과 시각적 스타일을 완전히 분리하여, 단 한 번 작성한 마크다운 원고를 전자책, 기술 백서, 블로그 포스팅, 고급 출판물로 자유자재로 변신시킬 수 있습니다.

## 1. 내용(Markdown)과 디자인(CSS Profile)의 완벽한 분리 철학

일반적인 워드 프로세서(MS Word, 한글 등)에서는 글을 쓰면서 동시에 글자 크기를 키우고, 색상을 바꾸고, 표 테두리를 일일이 칠해야 합니다. 이 방식은 작성자의 집중을 흐트러뜨릴 뿐 아니라, 나중에 문서를 블로그나 전자책 등 다른 규격으로 옮길 때 서식이 뒤엉켜 수많은 시간을 낭비하게 만듭니다.

온리비 어서는 **"내용과 디자인의 완벽한 분리(Content & Style Separation)"** 철학을 고수합니다:

```
┌────────────────────────────────────────────────────────┐
│  마크다운 원고 본문 (Markdown Content)                  │
│  - 순수한 텍스트, 제목(#), 목록(-), 표(|) 내용만 기록  │
└──────────────────────────┬─────────────────────────────┘
                           │ + (실시간 결합)
┌──────────────────────────▼─────────────────────────────┐
│  온리비 CSS 서식 프로필 (CSS Profile Engine)           │
│  - 글꼴, 행간, 여백, 컬러 팔레트, 표 선 두께, 장식선  │
└──────────────────────────┬─────────────────────────────┘
                           │ = (원클릭 맞춤 렌더링)
      ┌────────────────────┼────────────────────┐
      ▼                    ▼                    ▼
[ Onrivi 기본서식 ]   [ 기술 표준 백서 ]   [ 편안한 전자책 ]
   정갈한 보고서         GitHub 스타일        시니어 20px 큰글자
```

- **집중력 극대화**: 본문을 집필할 때는 서식 고민 없이 생각의 흐름대로 타이핑하세요.
- **원소스 멀티유즈(OSMU)**: 본문 내용은 단 1글자도 고치지 않고, 서식 테마만 클릭 한 번으로 바꾸어 여러 매체에 최적화된 출판물을 사출할 수 있습니다.
- **스타일 일관성 보장**: 수백 페이지에 달하는 긴 책이나 여러 편의 연재물도 동일한 서식 프로필을 적용하면 완벽하게 통일된 조판 품질이 유지됩니다.

## 2. 문서 Frontmatter `css_profile` 지정 원리와 글로벌 이동성

온리비 어서 문서의 맨 위를 보면 다음과 같이 `---`로 둘러싸인 **메타데이터 영역(YAML Frontmatter)**이 있습니다:

```markdown
---
title: "내 첫 번째 전자책 원고"
css_profile: "system-1"
css_profile_name: "Onrivi 기본서식"
---

# 1장. 시작하며
여기에 본문 내용을 작성합니다...
```

### ① Frontmatter 한 줄로 작동하는 마법
문서 상단에 `css_profile: <프로필ID>`를 적어두면, 온리비 어서가 문서를 여는 순간 해당 서식을 즉시 인식하여 미리보기 화면과 인쇄 엔진에 자동으로 적용합니다.
- 만약 프로필을 다른 서식으로 바꾸면 문서의 Frontmatter도 자동으로 갱신됩니다.
- 서식이 지정되지 않은 외부 마크다운 문서를 열더라도 온리비 어서가 기본값인 **`Onrivi 기본서식(system-1)`**으로 안전하게 자동 보호 렌더링해 줍니다.

### ② 전 세계 어디서든 똑같이 열리는 글로벌 이동성
문서 파일(`.md`)을 이메일로 다른 사람에게 전달하거나 다른 컴퓨터, Google Drive에서 열더라도 걱정하지 마세요. Frontmatter에 명시된 고유 서식 ID를 기준으로 전 세계 어디서든 동일하고 아름다운 출판 조판이 1초 만에 복원됩니다.

> [!팁]
> **Frontmatter가 화면에 보이지 않나요?**  
> 모나코 편집기에서는 메타데이터 코드가 그대로 보이지만, 우측 미리보기 창과 인쇄/내보내기 결과물에서는 Frontmatter가 자동으로 깔끔하게 숨겨지므로 독자에게 노출되지 않습니다.

## 3. 서식 관리 센터(CssStyleModal) 열기와 화면 구성

서식 정의 창을 여는 방법은 매우 간단합니다:

```
[방법 1] 우측 사이드바 툴바 ➔ 팔레트 아이콘(🎨) 클릭
[방법 2] 상단 메뉴 ➔ [도구(T)] ➔ [서식 정의 (갤러리)] 선택
```

![서식 관리 창 호출](media/img_style_menu.png)

서식 관리 창(`CssStyleModal`)이 열리면 다음과 같은 직관적인 2단 레이아웃이 펼쳐집니다:

1. **상단 컨트롤 바**:
   - 현재 적용된 서식 이름 확인 및 이름 변경(✏️)
   - **서식 드롭다운 & 갤러리**: 클릭하여 다른 서식으로 원클릭 전환
   - **[⚙ 서식 관리] 버튼**: 새 서식 추가, JSON 파일 가져오기/내보내기, AI 맞춤 서식 생성 센터로 이동
   - **[📖 서식 설정 가이드] 버튼**: 서식 상세 규격 설명서 열람
2. **좌측 설정 패널 (7대 아코디언)**:
   - 타이포그래피, 용지 여백, 제목, 목록, 구분선, 표, 미디어 등 모든 조판 요소를 슬라이더와 컬러 피커로 실시간 튜닝
3. **우측 실시간 미리보기 (WYSIWYG Showcase)**:
   - **[🎴 서식별 모아보기]**: 글꼴, 제목, 표, 인용구 등 요소별 샘플 카드를 1:1로 확인
   - **[📝 현재 편집 문서]**: 내가 지금 실제로 작성 중인 원고 전체가 실시간으로 어떻게 바뀌는지 확인

## 4. 온리비 어서 8대 시스템 제공 서식 둘러보기

온리비 어서에는 전문가들이 정밀하게 튜닝한 **8종의 공식 시스템 서식(System Profiles)**이 기본 탑재되어 있습니다. 시스템 서식은 실수로 삭제되거나 변형되지 않도록 안전하게 보호(`🏛️` 아이콘 표시)되어 있습니다.

| 서식명 | 고유 ID | 주요 글꼴 & 여백 | 추천 용도 |
| :--- | :--- | :--- | :--- |
| **Onrivi 기본서식** | `system-1` | Times New Roman + Noto Sans KR (상하 18mm, 좌우 12mm) | 표준 보고서, 일반 원고, 에세이 |
| **Onrivi 기술 표준 서식** | `github-readme-style` | 시스템 고딕 (-apple-system), 1.5배 컴팩트 행간 | 개발 문서, API 명세, GitHub README |
| **Onrivi 법률·계약서 A4** | `legal-contract-a4` | 전통 명조체, 정밀한 관보선(이중선), 1.75배 행간 | 계약서, 법률 의견서, 규정집, 공문 |
| **Onrivi 네이버 블로그 감성** | `naver-blog-style` | 부드러운 고딕, 파스텔 컬러, 넓은 줄간격 | 감성 포스팅, 리뷰, SNS 칼럼 |
| **Onrivi 일반 기술서적 표준** | `profile-tech-book-2026` | 기술 출판용 서적 폰트, 여유로운 단행본 마진 | IT 단행본 서적 출판, 튜토리얼 북 |
| **Onrivi 공식 행사 및 가정통신문** | `profile-official-notice-letter` | 단정한 공문서 서체, 상단 와이드 타이틀 | 기관 안내장, 학교 가정통신문, 행사 공지 |
| **Onrivi 한컴 테크 블로그** | `hancom-tech-blog` | 모던 테크니컬 디자인, 오렌지 포인트 컬러 | 테크 블로그 포스팅, 기획서, 신제품 소개서 |
| **편안한 전자책 서식** | `profile-1791514218283` | KoPub/Pretendard, **20px 대형 활자**, **미색(#FCFBF7) 배경** | **시니어 도서, 자서전, 수필, 시집, 전자책** |

### ① Onrivi 기본서식 (`system-1`)
- **특징**: 온리비 어서의 기준이 되는 대표 표준 테마입니다.
- **조판 규격**: 영문은 품격 있는 세리프(Times New Roman, Georgia), 한글은 가독성 높은 시스템 고딕(Noto Sans KR)의 조화를 이룹니다.
- **인쇄 최적화**: A4 용지 기준 상하 18mm, 좌우 12mm 표준 마진과 가로선 중심의 정갈한 표 스타일이 적용되어 있어 보고서나 과제 제출용으로 가장 무난합니다.

### ② Onrivi 기술 표준 서식 (`github-readme-style`)
- **특징**: 전 세계 개발자들에게 익숙한 GitHub Flavored Markdown의 콘텐츠 표현을 완벽히 재현했습니다.
- **조판 규격**: H1과 H2 제목 하단에 은은한 회색 밑줄(`1px solid #d0d7de`)이 자동으로 그어지며, 1.5배 컴팩트한 줄 간격과 깔끔한 박스형 코드블록이 적용됩니다.
- **추천 용도**: 프로그램 사용 설명서, 개발 프로젝트 README, 오픈소스 기술 백서.

### ③ Onrivi 법률·계약서 A4 공식 문서 (`legal-contract-a4`)
- **특징**: 오탈자나 왜곡이 없어야 하는 엄격한 법률 문서와 비즈니스 계약서를 위한 서식입니다.
- **조판 규격**: 공문서의 품격을 나타내는 관보선(3px Double 이중선)과 조항별 번호 위계가 선명하게 조판되며, 인쇄 시 정밀한 A4 여백을 보장합니다.

### ④ Onrivi 한컴 테크 블로그 서식 (`hancom-tech-blog`)
- **특징**: 한컴(HANCOM) 공식 테크 블로그의 모던하고 세련된 감각을 그대로 담아냈습니다.
- **조판 규격**: H2 제목 하단의 세련된 오렌지 포인트 라인, H3 제목 좌측의 감각적인 컬러 인디케이터 바, 1.8배 여유로운 본문 줄 간격과 8px 문장 사이 간격이 독자의 시선을 사로잡습니다.

### ⑤ 편안한 전자책 서식 (`profile-1791514218283`) 🌟
- **특징**: 컴퓨터 화면이나 태블릿을 오래 보면 눈이 시리고 피로한 시니어 독자와 작가를 위해 특별히 설계된 온리비 어서 전용 프리미엄 테마입니다.
- **조판 규격**:
  - **20px 대형 본문 활자**: 돋보기 없이도 편안하게 읽을 수 있는 큼직한 글자 크기
  - **1.85 여유로운 줄 간격**: 다음 줄로 넘어갈 때 줄을 잃어버리지 않는 황금 비율
  - **눈부심 없는 소프트 미색 배경(`#FCFBF7`)**: 순백색 모니터의 강한 빛 반사를 차단하여 장시간 독서에도 눈이 피로하지 않습니다.
  - **대형 20px 체크박스 & 굵직한 인용구 테두리**: 시각적 요소를 또렷하게 강조합니다.

> [!중요]
> **시스템 제공 서식은 수정할 수 없나요?**  
> 시스템 서식 자체는 원본 보존을 위해 잠겨 있지만, 마음에 드는 시스템 서식을 바탕으로 **[새 서식 추가]**를 누르면 모든 설정을 내 마음대로 편집할 수 있는 커스텀 서식이 1초 만에 복제 생성됩니다! (자세한 방법은 HELP-13 챕터를 참조하세요.)

## 5. 자주 묻는 질문 (FAQ)

### Q1. 서식을 변경하면 제가 작성한 마크다운 본문 글씨나 이미지가 사라지나요?
**A.** 전혀 그렇지 않습니다! 온리비 어서에서 서식을 변경하는 것은 '문서에 옷을 갈아입히는 것'과 같습니다. 원고의 본문 내용, 표의 수치, 첨부한 이미지 경로는 단 1바이트도 손상되지 않으며, 화면에 보이는 디자인 스타일만 실시간으로 즉시 바뀝니다.

### Q2. 새 문서를 만들 때 항상 적용되는 기본 서식을 바꿀 수 있나요?
**A.** 새 문서를 작성하면 온리비의 표준 규격인 `Onrivi 기본서식`이 기본 적용됩니다. 다른 서식을 기본으로 쓰고 싶다면 문서 첫머리의 Frontmatter에서 `css_profile: "원하는서식ID"`로 변경해 주시면 즉시 반영됩니다.
