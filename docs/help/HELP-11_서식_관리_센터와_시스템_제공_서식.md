# 서식 관리와 제공 서식 선택

> **<u>서식 관리는 원고의 글꼴·제목·문단·표·미디어·용지 설정을 함께 관리하는 기능입니다.</u>** 화면 확대와 원문 편집기의 글자 크기는 문서 출력용 서식 설정과 다릅니다.

## 1. 적용 순서

1. 서식 관리 또는 상태바의 현재 서식 이름을 누릅니다.
2. 제공 서식과 사용자 서식을 살펴봅니다.
3. 사용할 서식을 선택하고 현재 문서의 제목·본문·표를 확인합니다.
4. 필요한 경우 사용자 서식으로 복제해 조절합니다.
5. 마크다운을 저장하고 내보내기 결과를 확인합니다.

기본 제공 서식은 직접 수정이 제한됩니다. 사용자 서식을 만들어 관리하세요. 문서의 메타데이터에는 적용할 서식 식별 정보가 들어갈 수 있으며, 사용자 서식 파일까지 원고 안에 모두 포함되는 것은 아닙니다.

## 2. 4대 표준 규격 서식

온리비 어서는 표준 조판 규격을 준수하는 4대 표준 서식 프로필을 기본 탑재하고 있습니다:

| 표준 규격 | 항목 위계 체계 | 표 / 그림 캡션 규칙 | 문체 및 조판 특징 |
| --- | --- | --- | --- |
| **KS / ISO 기술표준** | 1. ➔ 1.1 ➔ 1.1.1 (십진 분류) | 표 상단 (`표 1 -`), 그림 하단 (`그림 1 -`) | SI 국제 단위계, 객관적 기술식 서술, Pretendard 15.5px |
| **대기업 전략기획서 (삼성/현대)** | □ ➔ ○ ➔ - ➔ ㆍ (도형 기호) | 표 상단 (`표 1.`) | 상단 핵심 요약 헤드라인, 개조식 종결어(~추진함), 15px 고밀도 |
| **학술·정책 연구보고서 (KDI 표준)** | 제1장 ➔ 제1절 ➔ 1. ➔ 가. | 표 상단 (`<표 1>`), 그림 하단 (`[그림 1]`) | 학술 서술식, 각주(`[^1]`) 및 출처 명시, KoPub 바탕 16px |
| **글로벌 테크 / 아마존 6-Pager** | H1(#) ~ H4(####) 시맨틱 헤딩 | 표 상단 (`표 1.`) | 6페이지 내러티브 줄글, 콜아웃 박스, Inter 15.5px |

이 외에도 온리비 기본, 학술 논문, 출판 소설, 시니어 맞춤 큰 글자 등 다양한 목적의 서식이 제공됩니다. 정부 공식 인증이나 모든 기관의 단일 법적 의무 규격이 아니므로 제출 기관의 지침에 맞게 사용자 서식으로 복제해 활용하세요.

## 3. 도움말 전용 서식

기본 제공 서식의 **온리비 도움말**은 설명서에 맞춘 파란 제목, 읽기 편한 본문, 표·코드 예제 서식입니다. 도움말 문서와 도움말 창에는 이 서식을 사용합니다. 제목 1은 문서 제목으로 번호 없이 표시하고, 제목 2~6에는 각각 숫자·가나다·숫자 괄호·가나다 괄호·글머리기호를 사용합니다. 다른 용도로 조절하려면 사용자 서식으로 복제하세요.

## 4. 확인할 항목

제목 번호를 켠 서식은 마크다운 제목 앞 번호도 갱신합니다. 미디어 설명의 위·아래 위치와 형식도 확인하세요. 서식을 바꾸기 전 중요한 원고는 저장하고, 사용자 지정 CSS를 사용했다면 기본 설정보다 우선되는 규칙이 있는지 확인합니다.
