# 페이지 나누기와 인쇄·PDF 출력

온리비 어서는 일반적인 웹 브라우저의 조잡한 인쇄 기능과 달리, 실제 종이 책과 보고서 인쇄에 최적화된 **A4 실시간 조판 분할 엔진**과 **고품질 PDF 출력 시스템**을 탑재하고 있습니다.

---

## 1. 실시간 페이지 경계선과 수동 페이지 나누기

- **실시간 페이지 분할선 (Page Break Line)**:
  - 우측 미리보기 창에는 A4 인쇄 규격(가로 210mm x 세로 297mm)에 맞춘 점선 형태의 페이지 경계선이 실시간으로 표시됩니다.
  - 내가 타이핑한 글과 표가 몇 번째 페이지 어디쯤 걸치는지 쓰면서 바로 확인할 수 있습니다.
- **수동 페이지 나누기 (강제 페이지 넘김)**:
  - 새로운 챕터가 시작되거나 중요한 표를 새 페이지 맨 위에서 시작하고 싶을 때 사용하는 방법입니다:
    1. 인쇄 버튼에서 쪽 윤곽 미리보기를 열고 페이지 나누기 조정을 선택합니다.
    2. 원하는 위치의 `+`로 지정하고 `×`로 해제합니다. 원본 본문은 분리되지 않으며, 문서에 적용 후 저장하면 출력 설정이 보관됩니다.

---

## 2. 인쇄용 고품질 PDF 출력 설정

상단 메뉴의 [파일] ➔ [내보내기] ➔ [PDF 인쇄]를 선택하면 인쇄 조판 모달이 열립니다:

- **용지 및 여백 설정**: A4 용지 표준 여백(상하좌우 20mm~25mm)을 지정할 수 있습니다.
- **머리글 / 바닥글 (Header & Footer)**:
  - 페이지 상단에 문서 제목이나 장 제목을 작고 단정하게 표기합니다.
  - 페이지 하단 중앙 또는 우측에 `- 1 -`, `Page 1 of 12` 형식의 쪽 번호를 자동으로 매깁니다.
- **표지(첫 페이지) 제외 옵션**: 보고서나 책의 표지에는 머리글과 쪽 번호가 찍히지 않도록 깔끔하게 숨겨줍니다.

---

## 3. 기본 워터마크(Watermark) 조판 컨트롤 (2026-10-19 신설)

사내 대외비 문서나 저작권 보호가 필요한 원고를 위해 문서 전체에 배경 워터마크를 자동으로 합성해 줍니다:

- **텍스트 워터마크**: '대외비 (CONFIDENTIAL)', '초안 (DRAFT)', 회사명, 작가명 등의 문구를 지정하고 폰트 크기, 대각선 회전 각도(-45도), 투명도(진하기 10%~30%)를 조절합니다.
- **로고 이미지 워터마크**: 기업 로고나 작가 인장 이미지를 등록하여 페이지 중앙에 은은하게 합성합니다.
- [환경설정(⚙️)] ➔ [일반 설정]에서 기본 워터마크를 저장해 두면 매번 번거롭게 설정할 필요 없이 모든 PDF 출력 시 일괄 적용됩니다.
