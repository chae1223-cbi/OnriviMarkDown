## 1. 인쇄·PDF 만들기

1. 문서보기에서 서식과 이미지·수식·다이어그램을 확인합니다.
2. 파일 메뉴의 인쇄/PDF 또는 내보내기에서 인쇄를 선택합니다.
3. 인쇄창에서 PDF 저장 또는 프린터를 선택합니다.
4. 용지·방향·배율·머리말/꼬리말 옵션을 확인하고 저장합니다.

브라우저와 데스크톱의 인쇄창·저장 위치 선택은 다를 수 있습니다. 출력 전 처리에서는 입력 내용을 반영하고 편집 도구를 제외합니다.

## 2. 여백과 페이지 나눔

문서 전체 용지 여백은 서식관리에서 조절합니다. 제목 기준 페이지 나눔 등 제공되는 인쇄 설정을 확인하세요. 페이지 수는 글꼴·크기·그림·표의 높이에 따라 달라집니다.

긴 다이어그램과 이미지는 인쇄 페이지에 맞추는 처리가 있지만, 매우 긴 표·문장이나 외부 영상은 별도 점검이 필요합니다.

## 3. 그림책

그림책은 장면을 페이지로 출력하는 규칙을 사용합니다. 넘침 경고를 해결하고 설정한 용지 방향을 확인하세요. 화면 편집 중 내부 스크롤이 보인다고 인쇄물에서도 그 아래 내용이 모두 보이는 것은 아닙니다.

## 4. 저장 후 점검

실제 PDF를 열어 빈 페이지, 잘린 표, 마지막 줄, 그림 비율, 각주를 확인하세요. 벡터 텍스트와 비트맵 이미지가 섞일 수 있으며 특정 DPI나 완전 무손실을 일괄 보장하지 않습니다.
