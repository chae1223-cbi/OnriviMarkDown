# 페이지 나누기와 인쇄·PDF 출력

## 세 가지 구분

| 항목 | 의미 |
| --- | --- |
| 예상 페이지 경계 | 현재 용지·서식으로 계산한 화면 안내 |
| 수동 페이지 나누기 | 사용자가 원문에 넣은 명시적 구분 |
| 실제 출력 페이지 | 인쇄용 배치와 운영체제 설정을 적용한 결과 |

예상 점선에 글이 걸린다고 Enter로 빈 줄을 반복하지 마세요. 다음 쪽에서 시작할 문단 앞에 커서를 놓고 페이지 나누기를 사용합니다. 원문에는 `<!-- onrivi:page-break -->`가 들어갑니다. 빈 줄과 수동 구분이 겹치면 불필요한 빈 페이지가 생기는지 확인하세요.

## 출력 순서

1. 서식 관리에서 용지 크기·방향·여백을 정합니다.
2. 상태바의 예상 페이지 경계로 문서 흐름을 확인합니다. 이 표시를 끄면 수동선 안내도 숨기지만 원문 구분을 삭제하지는 않습니다.
3. 내보내기의 인쇄 / PDF 출력을 선택합니다.
4. 운영체제 인쇄 화면에서 용지·배율·머리말·꼬리말 설정을 확인합니다.
5. PDF 저장 또는 프린터를 선택하고 결과를 엽니다.

## 점검할 것

그림·표·글꼴 로딩이 끝났는지 확인합니다. 인쇄 화면의 배율이나 용지가 문서 설정과 다르면 쪽 위치도 달라질 수 있습니다. 조판 가드는 화면 조작 보조이며 모든 인쇄 엔진의 배치를 고정하는 기능은 아닙니다.

워터마크는 환경설정의 기본값과 문서별 설정을 구분합니다. 문구·이미지·투명도·위치·첫 페이지 제외 등을 확인합니다. 저장 창을 닫은 뒤 원문이 달라 보이면 먼저 실제 수동 구분 표시와 보기 상태를 확인하세요.
