# 서식 가져오기·백업과 AI 서식 생성

## 사용자 서식 보관

사용자 서식은 원고와 별도 자료입니다. 리소스 폴더를 옮기거나 다른 PC에서 작업하기 전 서식 자료도 백업합니다. 같은 이름이라고 같은 설정인 것은 아니므로 적용 후 용지·제목·표를 확인하세요.

## 가져오기

서식 관리의 가져오기 기능으로 서식 JSON을 불러오거나 붙여넣습니다. 코드 블록이나 설명문이 섞인 입력을 정제하는 경로가 있지만, 모든 임의 문서를 서식으로 변환하는 기능은 아닙니다. 오류가 나면 서식 객체와 값 형식을 확인합니다.

가져온 사용자 서식은 기본 제공 서식과 구분하여 관리합니다. 제목 번호의 사용자 지정, 미디어 설명, 용지 방향처럼 새로 추가된 항목은 다른 버전에서 처리 방식이 다를 수 있습니다.

## AI로 서식 만들기

AI 서식 생성 도구에는 문서 용도, 독자, 책 크기, 본문과 제목의 분위기를 구체적으로 적습니다. AI 연결이 필요하며 일반 질문의 모델 선택과 모든 생성 기능이 동일한 제공사를 지원한다고 가정하지 마세요. 화면의 연결 안내를 따릅니다.

생성된 서식은 초안입니다. 글자 대비, 표 잘림, 과도한 장식, 잘못된 CSS와 용지 값을 확인하고 사용자 서식으로 저장합니다. AI가 만든 서식이 정부 규정·인쇄소 규격·접근성 인증을 충족한다고 자동 보장하지 않습니다.

서식의 내보내기는 원고의 PDF·EPUB 내보내기와 다른 작업입니다. 공유할 때는 원고와 사용자 서식 중 무엇을 전달하는지 구분하세요.
