## 1. 서식 백업

서식관리의 관리 기능에서 사용자 서식을 JSON으로 내보내거나 복사합니다. 문서의 `css_profile`은 서식 ID이므로 원고 파일만으로 사용자 서식 전체를 백업할 수 없습니다.

현재 환경의 사용자 서식 저장 위치는 리소스 `profiles/userCssProfiles.json`입니다. 로컬과 Google Drive는 각각의 환경 설정을 사용합니다.

## 2. 가져오기

1. 서식관리에서 JSON 가져오기를 실행합니다.
2. 파일 또는 제공된 입력 방식으로 서식 정보를 가져옵니다.
3. 목록에 추가된 서식을 선택합니다.
4. 글꼴·용지·표·인용구를 문서보기에서 확인하고 저장합니다.

다른 기기에서는 글꼴과 리소스 접근 조건에 따라 표시가 달라질 수 있습니다. 가져오기 전에 현재 사용자 서식을 백업하세요.

## 3. AI 맞춤 서식

AI 키와 모델을 설정한 뒤 서식관리의 AI 생성 기능에 원하는 용도와 디자인 조건을 입력합니다. 생성 결과는 앱의 서식 구조로 처리됩니다. 결과를 검토하고 사용자 서식으로 저장하세요.

AI 응답 오류나 올바르지 않은 구조가 나오면 조건을 단순화해 다시 시도합니다. AI가 만든 글꼴·색·여백이 원하는 출판 결과를 보장하지는 않습니다.
