> "마크다운 에디터에서 정성껏 작성한 아름다운 글을 네이버 블로그나 티스토리에 붙여넣었더니, 예쁜 글씨체와 표 테두리, 콜아웃 알림 상자가 온데간데없이 사라지고 밋밋한 검은 글자만 남아 허탈했던 적이 있으신가요?  
> 그 이유는 대다수 블로그 플랫폼들이 보안 및 시스템 충돌 방지를 위해 외부 CSS 스타일시트를 강제로 삭제(스트리핑)해 버리기 때문입니다.  
> 온리비 어서(Onrivi Author)는 모든 디자인과 서식을 HTML 각 태그 내부에 직접 밀봉하는 **CSS 인라인화(Inlining) 특화 엔진**을 탑재하여, 블로그 에디터에 `Ctrl+V`로 붙여넣기만 해도 에디터에서 보던 감각적인 조판과 색상이 100% 완벽하게 재현됩니다."

## 1. 네이버 블로그 & 티스토리 호환의 비밀 (CSS 인라인화)

일반 마크다운 변환기와 온리비 어서의 결정적인 기술적 차이는 바로 **CSS 인라인화(Inline Styles Injection)**에 있습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   일반 변환 vs 온리비 CSS 인라인화 비교                │
│                                                                        │
│  [일반 마크다운 에디터]                                                │
│  <p class="callout-tip">온리비 꿀팁입니다.</p>                          │
│        └── 블로그 플랫폼이 외부 CSS(.callout-tip)를 강제 삭제!          │
│        └── [결과]: 서식, 배경색, 테두리가 모두 날아가고 밋밋한 텍스트  │
│                                                                        │
│  ───────────────────────────────────────────────────────────────────  │
│                                                                        │
│  [온리비 어서 인라인화 엔진 (applyExportInlineStyles)]                  │
│  <div style="background-color: #eff6ff; border-left: 4px solid #1d4ed8;│
│              border-radius: 8px; padding: 12px 16px; color: #1e3a8a;"> │
│    <p style="margin: 0; font-weight: bold;">온리비 꿀팁입니다.</p>     │
│  </div>                                                                │
│        └── 외부 CSS가 없어도 태그 자체에 스타일이 영구 박제!          │
│        └── [결과]: 네이버/티스토리 어디서나 100% 동일한 서식 완벽 재현  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **외부 스타일시트 의존성 0%**:  
   `<link rel="stylesheet">`나 별도 `.css` 파일이 전혀 필요하지 않습니다.
2. **모든 스타일 속성 인라인 주입**:  
   활자 크기, 글꼴 색상, 행간, 배경색, 둥근 모서리(`border-radius`), 상하좌우 안쪽 여백(`padding`)이 모든 태그의 `style="..."` 속성에 하나하나 정밀하게 주입됩니다.
3. **블로그 보안 필터링 방어**:  
   네이버 스마트에디터 ONE과 티스토리의 보안 필터를 안전하게 통과하는 표준 인라인 속성만을 엄선하여 사용합니다.

## 2. 화면 위치와 HTML 생성 메뉴

블로그에 게시할 HTML 코드를 추출하거나 클립보드에 담는 방법입니다.

```
[상단 메뉴바]
  └── 파일(F)
        └── 내보내기 (미리보기 모드 전용)
              ├── 인쇄/PDF
              ├── Word 문서 (.docx)
              ├── 한글 문서 (.hwpx)
              ├── HTML 파일 (.html)  <── [클릭]
              ├── EPUB 전자책 (.epub)
              └── PNG 이미지 (.png)
```

1. **미리보기 모드 전환**:  
   - 에디터 우측 상단 플로팅 툴바 또는 상단 메뉴 [도구] ➔ [화면 보기 모드]에서 **미리보기** 전용 모드로 전환합니다.
2. **HTML 파일 내보내기 실행**:  
   - 상단 메뉴 [파일(F)] ➔ [내보내기] ➔ **[HTML 파일 (.html)]**을 클릭합니다.
   - 내 컴퓨터에 완성된 독립형 `.html` 파일이 다운로드됩니다.
3. **코드 열람 및 복사**:  
   - 해당 파일을 메모장이나 VS Code, 브라우저 소스 보기로 열어 내부의 본문 코드를 복사(`Ctrl+C`)합니다.

> [!팁]
> **브라우저 드래그 복사(WYSIWYG) 초간편 지원**:  
> 복잡한 HTML 코드를 다루기 번거롭다면, 온리비 어서의 [미리보기] 화면에서 본문 전체를 마우스로 드래그(또는 `Ctrl+A`)한 뒤 복사(`Ctrl+C`)하여 네이버 블로그 에디터 일반 본문 창에 바로 `Ctrl+V`로 붙여넣어도 인라인 서식이 아름답게 복사됩니다!

## 3. 플랫폼별 원클릭 발행 워크플로우

### ① 네이버 블로그 (스마트에디터 ONE) 발행법
네이버 블로그는 대한민국에서 가장 널리 쓰이는 플랫폼이지만 외부 서식 제약이 까다롭습니다. 온리비 어서 원고를 가장 깔끔하게 올리는 방법입니다:

```
[네이버 블로그 발행 단계]
  [1단계] 온리비 [미리보기] 화면에서 전체 복사 (Ctrl+A ➔ Ctrl+C)
    │
    ▼
  [2단계] 네이버 블로그 글쓰기(스마트에디터 ONE) 창 열기
    │
    ▼
  [3단계] 본문 영역에 마우스 클릭 후 붙여넣기 (Ctrl+V)
    │
    ▼
  [4단계] 인라인 서식이 적용된 표, 콜아웃 상자, 강조 텍스트 확인 후 [발행]
```

- **팁 상자/콜아웃 완벽 유지**:  
  온리비의 5종 Alert 콜아웃([!참고], [!팁], [!중요], [!주의], [!경고])이 네이버 블로그 고유의 인용구 상자보다 훨씬 모던하고 세련된 박스로 그대로 들어갑니다.
- **표(Table) 테두리 보존**:  
  네이버 에디터에서 깨지기 쉬운 표의 테두리 선과 헤더 배경색이 단정하게 유지됩니다.

### ② 티스토리 (Tistory) 발행법
티스토리는 전문 개발 블로그와 테크 블로거들이 애용하는 플랫폼으로, 강력한 HTML 모드를 지원합니다:

```
[티스토리 발행 단계]
  [1단계] 온리비 [내보내기] ➔ [HTML 파일] 저장 후 파일 내용 복사
    │
    ▼
  [2단계] 티스토리 글쓰기 우측 상단 모드 선택에서 [HTML] 모드로 전환
    │
    ▼
  [3단계] 본문 입력창에 복사한 HTML 코드 붙여넣기 (Ctrl+V)
    │
    ▼
  [4단계] 다시 [기본모드]로 전환하여 렌더링 상태 확인 후 [완료/발행]
```

- HTML 모드로 붙여넣으면 온리비 어서가 생성한 정밀 인라인 스타일이 1픽셀의 오차도 없이 100% 동일하게 렌더링됩니다.

## 4. 이미지 경로와 콜아웃 상자의 블로그 최적화 노하우

블로그 포스팅에서 흔히 발생하는 이미지 엑스박스(깨짐) 현상과 코드블록 스크롤 문제를 방지하는 실전 노하우입니다.

### ① 로컬 이미지의 Base64 Data URI 자동 임베딩
내 컴퓨터 로컬 폴더(`C:\Users\...`)에 있는 이미지를 마크다운에 넣은 채 HTML로 추출하면, 외부 블로그 독자들은 그 이미지를 볼 수 없습니다.  
온리비 어서는 HTML 내보내기 시 **`inlineLocalImages` 파이프라인**을 가동하여 로컬 이미지 파일을 순수 텍스트 데이터 형태인 **Base64 Data URI (`data:image/png;base64,...`)**로 인라인 변환하여 HTML 내부에 직접 내장합니다. 따라서 별도의 외부 이미지 호스팅 서버 없이도 이미지가 어디서나 정상 표시됩니다.

> [!참고]
> 대형 고용량 이미지가 많은 포스팅의 경우, 네이버 블로그의 [사진] 버튼을 이용해 이미지만 따로 업로드하거나 온리비 어서 클립보드 붙여넣기를 활용하시면 블로그 로딩 속도를 최적화할 수 있습니다.

### ② 5대 Alert 콜아웃 상자 인라인화
온리비 어서의 5대 콜아웃 상자는 각 타입별 고유 색상이 인라인 스타일로 자동 매핑됩니다:
- **`[!참고]` (Note)**: 차분한 블루 테두리와 연한 파랑 배경
- **`[!팁]` (Tip)**: 싱그러운 그린 테두리와 에메랄드 배경
- **`[!중요]` (Important)**: 품격 있는 퍼플 테두리와 바이올렛 배경
- **`[!주의]` (Warning)**: 눈에 띄는 앰버 오렌지 테두리와 연주황 배경
- **`[!경고]` (Caution)**: 명확한 레드 테두리와 연분홍 배경

### ③ 코드블록 다크 테마와 자동 줄바꿈
- 모바일 블로그 앱에서 소스코드를 볼 때 가로 스크롤바가 생겨 본문이 옆으로 잘리는 답답함을 해소하기 위해, 온리비 어서는 코드블록에 **`white-space: pre-wrap !important;`** 및 **`word-break: break-all !important;`**를 기본 주입합니다.
- 어두운 배경색과 세련된 행간(1.35배)이 그대로 유지되어 테크 블로그의 전문성이 돋보입니다.

## 5. 단계별 실전 따라 하기 (Step-by-Step)

온리비 어서에서 작성한 글을 네이버 블로그에 포스팅하는 3분 워크플로우를 따라 해 보세요.

### 1단계: 원고 작성 및 서식 꾸미기
제목, 콜아웃 상자, 표, 굵은 글씨를 활용해 글을 풍성하게 작성합니다.
```markdown
# 2026년 최신 마크다운 글쓰기 가이드

마크다운은 생산성을 극대화하는 최고의 도구입니다.

> [!팁]
> 단축키를 익히면 글쓰기 속도가 2배 빨라집니다!

| 기능 | 단축키 | 설명 |
| :--- | :---: | :--- |
| 굵게 | Ctrl+B | 핵심 강조 |
| 기울임 | Ctrl+I | 어조 변화 |
```

### 2단계: 미리보기 화면에서 전체 선택 복사
1. 에디터를 [미리보기] 모드로 전환합니다.
2. 마우스로 본문 전체를 드래그하거나 본문 클릭 후 `Ctrl+A` ➔ `Ctrl+C`를 누릅니다.

### 3단계: 네이버 블로그 스마트에디터에 붙여넣기
1. 네이버 블로그 글쓰기 페이지를 엽니다.
2. 본문 영역을 클릭하고 `Ctrl+V`를 누릅니다.
3. 온리비 어서에서 보던 표와 녹색 팁 상자가 그대로 들어간 것을 확인합니다.

### 4단계: 발행 완료!
제목을 확인하고 [발행] 버튼을 누르면 완성됩니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 붙여넣었는데 줄 간격이 너무 넓게 벌어져요. 어떻게 하나요?
**A.** 네이버 블로그 스마트에디터의 기본 문단 줄간격 설정 때문입니다. 온리비 어서 우측 **서식관리(🎨)**에서 [문단 간격]을 콤팩트하게 조정한 후 복사하시거나, 네이버 에디터 상단 서식바에서 줄간격을 `160%` 또는 `180%`로 한 번 지정해 주시면 가장 편안한 가독성을 얻을 수 있습니다.

### Q2. 수식(KaTeX)도 블로그에 그대로 복사되나요?
**A.** 네이버 블로그는 KaTeX 스크립트를 지원하지 않으므로, 수학 수식이나 복잡한 다이어그램은 온리비 어서에서 [미리보기] 화면을 캡처하거나 [PNG 이미지로 내보내기] 기능을 이용해 이미지로 첨부하시는 방법을 적극 추천합니다.

### Q3. 복사한 내용이 모바일 화면에서도 깨지지 않고 잘 보이나요?
**A.** 네! 온리비 어서의 인라인화 엔진은 고정된 픽셀 폭(`width: 800px`) 대신 유연한 백분율(`width: 100%`, `max-width: 100%`, `box-sizing: border-box`)을 주입하므로, 독자가 스마트폰 네이버 블로그 앱으로 접속해도 화면 폭에 맞춰 본문과 표가 자연스럽게 반응형으로 리사이징됩니다.
