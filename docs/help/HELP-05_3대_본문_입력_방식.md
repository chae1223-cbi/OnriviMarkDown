# 본문 입력과 붙여넣기

온리비 어서는 작가의 집필 스타일에 맞추어 자유롭게 선택할 수 있는 **3대 본문 입력 및 편집 방식**을 완벽히 지원합니다.

워드프로세서에 익숙하신 분부터 마크다운 소스 코드를 꼼꼼히 대조하는 전문가, 그리고 외부 원고를 가져와 가공하는 분까지 모두 최고의 집필 경험을 누리실 수 있습니다.

---

## 1. 방식 1: 문서보기 (Visual Document Editor - 위지윅 방식)

마크다운 기호가 눈에 거슬리거나, 서식이 적용된 결과를 보면서 일반 워드프로세서처럼 편안하게 글을 쓰고 싶을 때 사용하는 모드입니다.

- **자연스러운 타이핑**: `#` 기호를 쓰고 한 칸 띄우면(스페이스) 그 자리에서 즉시 큼직한 제목 스타일로 변환됩니다.
- **직관적인 서식 조작**: 텍스트를 마우스로 드래그하면 커서 바로 위에 미니 서식 바가 떠서 굵게, 기울임, 색상, 링크를 바로 지정할 수 있습니다.
- **인터랙티브 컴포넌트**: 표의 셀을 마우스 클릭하여 바로 입력하고, 체크리스트를 클릭하여 바로 체크/해제할 수 있습니다.

---

## 2. 방식 2: 나란히 보기 (실시간 마크다운 원문 대조 모드)

좌측에서 위지윅으로 문서를 작성하면서, 우측에서 실제 마크다운 소스 코드가 어떻게 구성되는지 실시간으로 대조·확인하고 싶을 때 사용하는 모드입니다.

- **실시간 소스 코드 동기화**: 좌측 문서보기에서 글을 타이핑하거나 서식을 적용하면, 우측 마크다운 창에 표준 마크다운 태그가 지연 없이 즉각 반영되어 출력됩니다.
- **부드러운 행 추종 및 하이라이트**: 좌측에서 커서를 이동하거나 스크롤하면 우측 마크다운 뷰어의 해당 행으로 스크롤이 매끄럽게 동기화되며 현재 작업 행이 하이라이트됩니다.
- **무결성 보장을 위한 읽기 전용 보호**: 두 에디터 간의 동시 편집으로 인한 서식 충돌, 커서 튐, 한글 조합(IME) 깨짐을 원천 방지하기 위해 우측 마크다운 창은 안전한 **읽기 전용(Read-Only) 대조 뷰어**로 보호됩니다. (모든 직접 입력 및 서식 수정은 좌측 문서보기에서 단일하게 수행됩니다.)

---

## 3. 방식 3: 외부 원고 스마트 붙여넣기 파이프라인

기존에 MS Word, 한글(HWP), 노션(Notion), 벨로그, 또는 웹 브라우저에서 작성했던 원고를 복사하여 에디터에 붙여넣을 때 작동하는 지능형 변환 기능입니다:

- **HTML 서식의 마크다운 자동 정제**: 웹페이지나 워드에서 복사한 복잡한 HTML 스타일 태그를 온리비 어서가 스스로 분석하여, 군더더기 스타일을 제거하고 표준 마크다운(제목, 목록, 표, 굵게 등)으로 깔끔하게 변환하여 붙여넣습니다.
- **표(Table) 구조 완벽 보존**: 엑셀(Excel)이나 워드 문서의 표를 복사해 붙여넣으면 마크다운 파이프(`|`) 표 형식으로 깨짐 없이 자동 변환됩니다.
- **이미지 자동 다운로드 및 로컬화**: 웹페이지의 이미지를 복사해 붙여넣으면, 외부 링크가 언젠가 삭제되는 위험을 방어하기 위해 내 PC의 공통 리소스 폴더(`./media/`)로 이미지를 자동 저장하고 로컬 상대경로로 치환합니다.

---

## 4. 입력 시 유용한 타이핑 꿀팁

- **제목 빠른 생성**: 줄 맨 앞에서 `# `을 입력하면 제목 1, `## `는 제목 2, `### `는 제목 3이 됩니다.
- **슬래시 빠른 명령**: 빈 줄에서 `/`를 입력하면 제목, 표, 목록, 체크리스트, 수식, 코드블록 등 모든 서식을 방향키로 선택하여 바로 삽입할 수 있습니다.
- **플로팅 도구함 호출**: 언제든지 `Ctrl + Space`를 누르면 커서 바로 옆에 서식 도구 모음이 열립니다.
