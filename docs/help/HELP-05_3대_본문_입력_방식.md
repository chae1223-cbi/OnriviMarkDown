# 본문 입력과 붙여넣기

## 문서보기에서 입력

편집 가능한 일반 문서의 본문을 클릭하고 씁니다. `Enter`는 새 문단, `Shift+Enter`는 문단 안 줄바꿈에 사용합니다. 표·코드·인용문 등에서는 키 동작이 달라질 수 있습니다. 일반 본문에서의 Tab 간격은 환경설정으로 조절합니다.

## 마크다운과 도구 사용

태그를 직접 쓰거나 툴바·슬래시 명령으로 서식을 적용할 수 있습니다. 문서보기에서 `#`~`######`를 입력한 뒤 스페이스를 누르면 제목 1~6으로 즉시 바뀝니다. 스페이스 전까지 해시는 일반 문자로 남습니다.

## 붙여넣기

- 마크다운 텍스트는 문서 구조로 붙여넣습니다. 클립보드에 문법 강조용 HTML이 함께 있어도 원문 마크다운 경로를 우선하는 조건이 있습니다.
- 제목 번호가 설정된 서식을 사용하면 붙여넣은 제목을 기존 제목 순서에 맞춰 다시 계산합니다. 번호와 글머리기호는 원문에도 기록됩니다.
- 이미지 붙여넣기는 파일 저장과 삽입이 함께 필요합니다. 저장 오류가 나면 리소스 폴더를 확인합니다.
- 코드 블록 안에서는 텍스트를 코드로 취급합니다. 코드 예시 속 `# 제목`이 실제 문서 제목으로 바뀌어서는 안 됩니다.

## 서식 일괄 정리

도구의 문서 서식 일괄 정리 또는 `Ctrl+Shift+L`로 제목 공백·표·불필요한 빈 줄 등을 정돈합니다. 선택 영역이 있으면 원문 편집 경로에서는 그 부분만 처리할 수 있습니다. 정리 후 제목 번호와 내용이 맞는지 확인합니다.
