> 글쓰기는 사람마다 저마다의 호흡이 있습니다. 마우스로 블록을 긁어 직관적으로 꾸미는 분, 타이핑 흐름을 깨지 않고 키보드만으로 글을 써 내려가는 분 모두를 위해 온리비 어서는 **3가지 최적화된 입력 패러다임**을 제공합니다.

---

## 1. 취향과 집필 스타일에 맞춘 3대 입력 방식

온리비 어서는 사용자의 작업 습관에 맞추어 자유롭게 선택할 수 있는 3가지 본문 서식 입력 도구를 지원합니다:

```
┌─────────────────────────────────────────────────────────────┐
│                 온리비 어서 3대 서식 입력 패러다임              │
├─────────────────┬─────────────────────────┬─────────────────┤
│  ① 플로팅 툴바   │      ② 슬래시 명령어     │   ③ 키보드 단축키│
│   (마우스형)     │        (타이핑형)       │    (단축키형)    │
│                 │                         │                 │
│ 텍스트를 드래그  │ 빈 줄이나 본문에서      │ 마우스 손 뗄    │
│ 하면 마우스 옆에 │ '/' 입력 시 빠른 자동    │ 필요 없이 외운   │
│ 즉각 서식 팔레트 │ 완성 팝업 메뉴 노출     │ 키로 0초 컷 적용│
└─────────────────┴─────────────────────────┴─────────────────┘
```

1. **플로팅 툴바 (마우스형)**: 문장을 마우스로 드래그하면 커서 바로 위에 미니 서식 도구 모음이 부드럽게 나타납니다. 마우스 중심 작업에 가장 편안합니다.
2. **슬래시 명령어 (타이핑형)**: 키보드에서 `/`를 누르면 제목, 표, 인용구, 이미지 등 모든 마크다운 블록을 키보드 화살표와 엔터로 손쉽게 삽입할 수 있습니다.
3. **키보드 단축키 (키보드형)**: `Ctrl + B`(굵게), `Ctrl + K`(링크), `Ctrl + T`(표)처럼 손에 익은 조합키로 멈춤 없는 고속 집필이 가능합니다.

## 2. 플로팅 툴바 (Floating Toolbar) 완벽 활용

본문에서 특정 단어나 문장을 마우스로 드래그(선택)해 보세요. 선택된 영역 바로 위로 깔끔한 플로팅 서식 툴바가 즉시 나타납니다.

### ① 플로팅 툴바가 제공하는 핵심 기능
- **텍스트 서식**: `B`(굵게), `I`(기울임), `U`(밑줄), `S`(취소선), `Password`(인라인 코드)
- **제목 변경**: `▲`/`▼` 버튼으로 H1부터 H6까지 제목 레벨을 즉시 변경
- **목록 및 인용**: 숫자 목록, 글머리 기호, 체크리스트, 인용구(일반 및 5종 콜아웃 드롭다운)
- **정리 도구**: 태그 취소(서식 벗겨내기), 문서 서식 일괄 정리(`🧹`)
- **미디어 및 확장**: 하이퍼링크, 문서 연결, 각주, 이미지, 동영상, 지도, 표, 코드블록, LaTeX 수식, 현재 날짜/시간
- **서명/발신인 도구 (`✍️`)**: 공문서나 편지글의 우측 정렬 서명과 붉은색 인감도장 태그를 원클릭 삽입

> [!팁]
> **플로팅 툴바 켜기/끄기 (CubeFocus 버튼)**  
> 텍스트를 드래그할 때 툴바가 뜨는 것이 번거롭다면, 우측 사이드바 도구 모음의 **`CubeFocus(큐브 모양 아이콘)`** 버튼을 누르세요. 원클릭으로 플로팅 툴바를 끄거나 다시 켤 수 있습니다.

### ② 화면 경계 이탈 방지 (Boundary Clamp)
화면 우측 끝이나 창 모서리에서 텍스트를 드래그해도 걱정하지 마세요. 온리비 어서의 플로팅 툴바는 화면 밖으로 버튼이 잘려 나가지 않도록 뷰포트 너비를 실시간 계산하여 화면 안쪽으로 자동 정렬(Boundary Clamping)됩니다.

## 3. 슬래시 명령어 (Slash Commands) 활용법

타이핑하는 도중 마우스로 손을 옮길 필요가 없습니다. 빈 줄이나 문장 끝에서 슬래시(`/`)를 입력해 보세요.

### ① 슬래시 명령어 사용 절차
1. 에디터에서 `/`를 입력합니다.
2. 즉시 하단에 자동완성 팝업 창이 뜨며 사용 가능한 마크다운 명령 목록이 나타납니다.
3. 원하는 기능의 영문 또는 한글 이름을 타이핑합니다 (예: `/표`, `/인용`, `/팁`, `/code`).
4. 키보드 방향키(`↑`/`↓`)로 항목을 선택하고 `Enter`를 누르면 즉시 해당 서식이나 템플릿이 삽입됩니다.

### ② 대표 슬래시 명령어 일람
| 명령어 | 기능 | 삽입되는 서식 / 동작 |
| :--- | :--- | :--- |
| **`/h1` ~ `/h6`** | 제목 1 ~ 6 | `# ` ~ `###### ` 제목 헤딩 태그 |
| **`/ul`**, **`/목록`** | 글머리 기호 | `- ` 순서 없는 글머리 기호 |
| **`/ol`**, **`/숫자`** | 숫자 목록 | `1. ` 순서 있는 번호 목록 |
| **`/quote`**, **`/인용`** | 인용구 | `> ` 기본 인용문 |
| **`/note`**, **`/참고`** | 참고 콜아웃 | `> [!NOTE]` 블루 안내 상자 |
| **`/tip`**, **`/팁`** | 팁 콜아웃 | `> [!TIP]` 그린 꿀팁 상자 |
| **`/important`**, **`/중요`** | 중요 콜아웃 | `> [!IMPORTANT]` 퍼플 중요 상자 |
| **`/warning`**, **`/주의`** | 주의 콜아웃 | `> [!WARNING]` 오렌지 주의 상자 |
| **`/caution`**, **`/경고`** | 경고 콜아웃 | `> [!CAUTION]` 레드 위험 상자 |
| **`/check`**, **`/체크`** | 체크리스트 | `- [ ] ` 양방향 연동 할 일 체크박스 |
| **`/table`**, **`/표`** | 표 생성 | 10×10 표 생성 마법사 모달 오픈 |
| **`/code`**, **`/코드`** | 코드 블록 | ` ```markdown ` 3중 백틱 코드 영역 |
| **`/math`**, **`/수식`** | LaTeX 수식 | `$$수식$$` 카텍스 수식 입력 |
| **`/link`**, **`/링크`** | 링크 삽입 | `[홈페이지명](https://)` 링크 템플릿 |
| **`/sign`**, **`/사인`** | 서명/발신인 | 우측 정렬 날짜·작성자 및 인감도장 태그 |

> [!중요]
> **스마트 플레이스홀더 자동 선택!**  
> `/link` 명령어를 입력하면 `[홈페이지명](https://)`이 본문에 삽입됨과 동시에 `홈페이지명` 단어가 자동으로 블록 지정됩니다. 바로 원하는 사이트 이름을 타이핑하면 되므로 백스페이스를 누를 필요가 없습니다.

## 4. 키보드 단축키 (Keyboard Shortcuts) 치트시트

마우스를 완전히 잊고 오직 키보드만으로 글을 쓸 수 있는 핵심 단축키 모음입니다.

### 1) 텍스트 스타일링 단축키
- `Ctrl + B`: **굵게** (`**텍스트**`)
- `Ctrl + I`: *기울임* (`*텍스트*`)
- `Ctrl + U`: <u>밑줄</u> (`<u>텍스트</u>`)
- `Ctrl + Shift + X`: ~~취소선~~ (`~~텍스트~~`)
- `Ctrl + E`: `인라인 코드` (`` `텍스트` ``)
- `Ctrl + Alt + R`: 서명/발신인 (우측 정렬 `<div align="right">`)

### 2) 문단 및 목록 단축키
- `Ctrl + 1` ~ `Ctrl + 6`: H1 ~ H6 제목 적용
- `Ctrl + Shift + 7`: 숫자 목록 (`1. `)
- `Ctrl + Shift + 8`: 글머리 기호 목록 (`- `)
- `Ctrl + Shift + C`: 체크리스트 (`- [ ] `)
- `Ctrl + Q`: 인용구 (`> `)
- `Ctrl + Shift + 1` ~ `5`: 콜아웃 5종 (참고, 팁, 중요, 주의, 경고)
- `Ctrl + Shift + 0`: 태그 취소 (현재 줄의 마크다운 접두사 제거)
- `Ctrl + Shift + L`: 문서 서식 일괄 정리 (`🧹`)
- `Ctrl + Alt + -`: 수평 구분선 (`---`)

### 3) 고급 개체 및 미디어 단축키
- `Ctrl + K`: 링크 삽입 (`[링크명](URL)`)
- `Ctrl + T`: 표 생성 마법사 모달 열기
- `Ctrl + Shift + E`: 코드 블록 삽입 또는 이모지 보관함 열기
- `Ctrl + M`: 수식(LaTeX) 편집 모달
- `Ctrl + Alt + F`: 각주(Footnote) 삽입

### 4) 파일 및 화면 제어 단축키
- `Ctrl + S`: 문서 디스크 저장
- `Ctrl + Shift + S`: 다른 이름으로 저장
- `Ctrl + Shift + O`: 로컬 작업장 폴더 열기
- `Ctrl + Shift + M`: 화면 뷰 모드 전환 (편집 / 분할 / 미리보기)
- `Ctrl + Shift + B`: 좌측 탐색기 사이드바 열기/닫기
- `Ctrl + F`: 에디터 본문 찾기
- `Ctrl + H`: 에디터 본문 바꾸기
- `Ctrl + Shift + F`: 전체 작업장 문서 통합 검색

## 5. 나만의 단축키와 슬래시 명령어 커스텀하기

손에 익지 않은 단축키나 외우기 어려운 슬래시 명령어가 있다면 환경설정에서 마음대로 변경할 수 있습니다.

![환경설정 단축키 탭](./assets/fig2_settings_modal.png)
* [그림] 환경설정 ➔ 단축키/명령어 매핑 관리 화면

1. 상단 메뉴바의 `도구(T) ➔ 환경 설정`을 열거나 `Ctrl + ,`를 누릅니다.
2. 좌측 탭에서 **`[단축키 / 명령어]`**를 선택합니다.
3. 목록에서 원하는 기능의 **단축키 입력칸을 마우스로 클릭**한 뒤, 키보드로 원하는 키 조합(예: `Ctrl + Shift + D`)을 누르면 즉시 감지되어 저장됩니다.
4. **슬래시 명령어 입력칸**에는 원하는 호출 단어(예: `표`, `b`, `note`)를 자유롭게 입력합니다.
5. 상단의 **`[복사하기]`** 버튼을 누르면 현재 설정된 전체 단축키 표가 클립보드에 복사되어 개인 노트에 보관할 수 있습니다.
6. 기본 상태로 되돌리고 싶다면 **`[초기화]`** 버튼을 누르면 언제든 온리비 공인 기본값으로 복원됩니다.

> [!주의]
> **단축키 중복 방지 시스템**  
> 이미 다른 기능에 할당된 단축키를 누르면 `"⚠️ 이미 [기능명]에 할당된 단축키입니다"` 안내 토스트가 뜨며 충돌을 사전에 안전하게 차단합니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 슬래시(/)를 마크다운 문장 안에서 일반 글자로 입력하고 싶을 땐 어떻게 하나요?
**A.** `/`를 입력한 뒤 바로 한글이나 영문을 타이핑하여 문장을 이어가거나 `ESC` 키를 누르면 자동완성 팝업이 즉시 닫히고 일반 슬래시 문자로 남습니다.

### Q2. 플로팅 툴바를 실수로 꺼버렸는데 어디서 다시 켜나요?
**A.** 화면 우측 사이드바 툴바의 **`CubeFocus(큐브 모양 아이콘)`**을 클릭하시면 즉시 플로팅 툴바가 다시 활성화됩니다.
