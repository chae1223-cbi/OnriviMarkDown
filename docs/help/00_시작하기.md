# 온리비 어서 도움말

## 처음 사용할 때

1. 작업장과 리소스 폴더를 연결합니다.
2. 문서보기에서 글을 입력하고 저장합니다.
3. 서식을 선택하고 출력 형식에 맞게 결과를 확인합니다.

기본 단축키와 사용자 지정값이 다르면 환경설정의 **단축키 / 명령어**를 따릅니다. 세션 복구는 실제 파일 저장과 다르므로 저장 완료 상태를 확인하세요.
