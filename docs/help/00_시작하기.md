# 온리비 어서 도움말 — 현재 기능 안내

이 도움말은 2026년 10월 22일 작업 소스를 기준으로 작성했습니다. 문서보기 입력, 마크다운, 서식, AI, 그림책과 내보내기를 안내합니다. 웹·데스크톱·권한·연결 상태에 따라 화면의 작업 가능 여부가 달라집니다.

## 처음 사용하는 순서

1. 작업장과 공통 리소스 폴더를 확인합니다.
2. 새 문서를 만들거나 기존 원고를 엽니다.
3. 문서보기에서 입력하고 필요한 경우 원문을 확인합니다.
4. 서식 관리에서 제목·본문·용지와 번호를 정합니다.
5. 저장한 뒤 내보내기 결과물을 확인합니다.

## 이번 도움말의 주요 내용

- `#`~`######` 다음 스페이스 입력으로 제목 서식 즉시 적용.
- 제목별 번호·사용자 지정·글머리기호를 마크다운 원문에도 저장.
- AI의 질문 / 문서 정리 / 문구 수정과 복수 작업 프롬프트 자동 생성.
- 그림책의 장면 편집과 AI 사용 범위, 일반 문서와 다른 출력 방식.
- 예상 페이지 경계와 수동 페이지 나누기, 실제 PDF·EPUB의 차이.

## 빠른 문제 해결

- 입력이 안 되면 현재 보기·편집 가능 상태·문서 권한을 확인합니다.
- AI 점검에 열린 문서를 사용하려면 문서 정리 탭을 사용합니다.
- 이미지가 사라지면 원고 경로와 리소스 폴더를 확인합니다.
- PDF 페이지가 다르면 용지·배율·수동 구분을 확인합니다.
- 저장과 복구는 다릅니다. 중요한 원고와 부속 자료는 별도로 백업합니다.

도움말에 나오는 출판·조판 제안은 공식 인증이나 법령 준수 판정을 뜻하지 않습니다. 외부 AI·출판사·서점의 조건은 해당 서비스에서 확인하세요.
