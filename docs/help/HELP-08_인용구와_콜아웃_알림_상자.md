## 1. 인용문과 알림 상자 만들기

인용구 도구 또는 `/인용`을 사용합니다. 유형을 선택하면 알림 상자를 만들 수 있습니다.

| 유형 | 한글 검색 | 표시 배경 |
| --- | --- | --- |
| NOTE | 참고·노트 | 연한 파랑 |
| TIP | 팁 | 연한 초록 |
| IMPORTANT | 중요 | 연한 보라 |
| WARNING | 주의 | 연한 주황 |
| CAUTION | 경고 | 연한 분홍 |

문서보기에는 `[!TIP]` 원문 표시 대신 **TIP** 같은 제목이 나타납니다. 유형별 색상은 인용문 배경과 왼쪽 선에 적용합니다.

```markdown
> [!TIP]
> 첫 번째 안내
> 다음 줄 안내
```

한국어 유형 표기도 읽을 수 있습니다. 새로 삽입하는 유형은 영문 태그를 사용합니다.

## 2. 줄을 이어 입력하고 나가기

- **Enter:** 인용문 안의 바로 다음 줄로 이동합니다. 마지막 줄에서도 인용문을 유지합니다.
- **Ctrl+Enter:** 인용문 밖의 다음 본문으로 이동합니다.
- **태그 취소:** 선택한 인용문 서식을 해제할 때 사용합니다.

인용문 안의 문단 여백은 줄 입력을 방해하지 않도록 줄였습니다. 인용문 전체의 바깥 여백은 서식관리의 인용구 설정과 관련됩니다.

인용문 다음에 있는 빈 제목을 Backspace로 일반 문단으로 바꿀 때에는 앞 인용문으로 합쳐지지 않도록 처리합니다.
