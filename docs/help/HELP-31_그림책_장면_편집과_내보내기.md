## 1. 그림책 서식 선택

사용자 서식의 문서 배치에서 **그림책 — 그림과 본문**을 선택합니다. 일반 문서와 달리 그림과 본문을 장면 단위로 배치합니다. 용지 크기·방향, 그림 비율, 그림 맞춤 방식, 간격과 페이지 번호를 확인하세요.

## 2. 장면 구조

```markdown
:::scene {cover}
![표지](media/cover.png)

# 나의 그림책
:::

:::scene
![첫 장면](media/scene.png)

첫 장면의 이야기를 입력합니다.
:::
```

표지는 첫 장면에 둡니다. 각 장면을 `:::`로 닫고 그림 참조를 넣습니다. 장면 밖에 일반 본문이 있거나 닫는 표시·그림이 없으면 안내가 표시됩니다. 예시 이미지 파일은 직접 준비해야 합니다.

## 3. 장면 편집

- **본문 편집:** 해당 장면의 문서 편집기를 엽니다. 한 번에 선택한 장면을 편집합니다.
- **편집 완료:** 장면 본문 편집을 닫습니다.
- **사진 편집·복사:** 해당 장면 그림 변경 또는 마크다운 참조 복사입니다.
- **장면 추가·복제·위/아래 이동·삭제:** 그림책 장면 편집 도구에서 수행합니다. 표지 이동은 제한됩니다.

장면 본문 수정은 해당 장면에 반영하며 다른 장면·그림 참조를 유지합니다. 표지를 복제한 장면은 일반 장면으로 만듭니다.

## 4. 넘침과 내보내기

본문이 페이지를 넘으면 안내를 확인하고 내용·글자 크기·그림 비율을 조정하거나 장면을 추가하세요. 입력할 때 자동으로 후속 장면을 만드는 기능은 사용하지 않습니다.

현재 그림책은 인쇄/PDF·HTML·PNG·EPUB 출력 경로를 사용합니다. DOCX·HWPX는 그림책에서 제외합니다. EPUB은 고정 배치 처리를 사용하며 실제 리더에서 페이지 방향·그림 잘림·텍스트 넘침을 확인하세요.
