# 전자책 EPUB 제작과 제출 전 점검 사항

온리비 어서는 내가 작성한 마크다운 원고를 교보문고, 예스24, 알라딘, 리디북스 등 주요 서점에 바로 등록하여 판매할 수 있는 **국제 표준 ePub 3.0 전자책**으로 원클릭 변환해 줍니다.

---

## 1. ePub 3.0 전자책 제작 단계

1. **원고 완성 및 서식 검토**: 마크다운 본문과 챕터 제목(H1~H3)이 위계에 맞게 구성되었는지 확인합니다.
2. **내보내기 창 열기**: 상단 메뉴의 [파일] ➔ [내보내기] (\`Ctrl + Shift + E\`)를 선택하고 [EPUB 전자책] 탭을 클릭합니다.
3. **출판 메타데이터 입력**:
   - **도서 제목**: 서점에 등록될 정식 책 제목
   - **저자(글/그림)**: 작가 활동명 또는 본명
   - **출판사명 / 발행처**: 1인 출판사 또는 개인 브랜드명
   - **언어(Language)**: 한국어(ko) 또는 영어(en)
   - **ISBN 번호**: 국립중앙도서관에서 발급받은 정식 ISBN(선택 사항)
4. **표지 이미지(Cover) 등록**: 권장 규격(1600x2400px 또는 3:4 비율)의 고해상도 표지 사진(`.jpg` 또는 `.png`)을 선택합니다.
5. **[EPUB 생성] 클릭**: 클릭 즉시 표준 패키징(`.epub`) 파일이 내 컴퓨터에 저장됩니다.

---

## 2. 유통사 서점 등록 전 필수 점검 체크리스트

전자책 파일을 서점에 제출하여 유통사 검수에서 반려되지 않도록 다음 4가지를 꼭 점검하세요:

- [ ] **표지 이미지 누락 여부**: 표지가 없으면 서점 진열 시 기본 회색 박스로 보여 독자의 구매율이 떨어집니다.
- [ ] **목차(NCX / Nav) 링크 정상 작동**: 각 챕터 제목(H1~H2)이 ePub 내부 내비게이션 파일에 누락 없이 수록되었는지 확인합니다.
- [ ] **외부 이미지 링크 차단**: 인터넷 웹 URL로 걸린 이미지는 독자가 오프라인(비행기 모드 등)에서 전자책을 읽을 때 엑스박스로 뜹니다. 반드시 내 로컬 리소스 폴더(`./media/`)에 저장된 이미지를 사용하세요.
- [ ] **EPUB 유효성 검사 (EpubCheck)**: 온리비 어서가 생성하는 ePub 3.0 파일은 국제 디지털 출판 포럼(IDPF)의 W3C EpubCheck 유효성 검증을 100% 통과하도록 설계되어 있습니다.
