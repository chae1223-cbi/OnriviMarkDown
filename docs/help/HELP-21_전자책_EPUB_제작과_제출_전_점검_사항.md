## 1. EPUB 내보내기

문서보기에서 제목·본문·이미지를 확인하고 파일 메뉴의 내보내기에서 EPUB을 선택합니다. 출력에 사용할 문서·서식을 확인하고 파일을 저장합니다.

일반 문서는 읽기 화면에 맞춰 흐르는 전자책으로 변환합니다. 그림책 배치는 고정 배치 EPUB 처리가 적용됩니다. 두 종류는 같은 파일에서도 리더의 표시 방식이 다를 수 있습니다.

## 2. 준비할 원고

- 제목 계층을 정리합니다. 장과 절에 맞는 제목을 사용하세요.
- 문서 제목과 관련 메타 정보를 확인합니다.
- 로컬·Drive 이미지가 문서에서 실제로 열리는지 확인합니다.
- 수식·Mermaid 렌더링이 완료된 뒤 내보냅니다.
- 미디어 조작 버튼이나 편집 도구는 독자용 본문에 포함되지 않도록 출력 처리합니다.

## 3. 결과 확인

EPUB을 실제 리더에서 열고 목차, 장 이동, 한글 글꼴, 표의 폭, 이미지, 각주를 확인합니다. 그림책은 페이지 방향·크기와 그림 잘림도 확인합니다.

전자책 서점마다 제출 요구가 다릅니다. 내보내기 성공은 서점 등록이나 모든 리더 호환을 보장하지 않습니다. 제출처의 검증 도구와 요구 형식으로 점검하세요.
