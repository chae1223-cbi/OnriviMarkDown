## 1. 테스트 전 준비

가능하면 실행 전에 계정 로그인과 뷰어 설치를 끝냅니다. 0~5분은 준비 확인 시간입니다. 준비가 끝나지 않아도 60분을 넘기지 말고 의존 항목을 BLOCKED로 기록하세요.

1. 기본 환경을 **웹+로컬 / 웹+Google Drive / 데스크톱+로컬 / 데스크톱+Google Drive** 중 하나로 정합니다. 해당 환경을 CSV에 기록합니다. 모든 환경을 한 시간 안에 검증한 것으로 처리하지 않습니다.
2. 테스트 전용 작업장 `Onrivi-QA-YYYYMMDD`와 전용 리소스 폴더를 준비합니다. 기존 원고·기존 media 폴더에서 덮어쓰기 시험을 하지 않습니다.
3. `fixtures`의 `.md` 파일을 전용 작업장에 복사합니다. 원본 fixtures는 보존합니다.
4. `assets/original`과 `assets/replacement`를 선택하기 쉽게 준비합니다. Drive 시험은 두 폴더를 미리 각각 업로드하여 같은 이름의 V1·V2 파일을 구별합니다. 실제 삽입은 앱의 찾아보기로 합니다.
5. 탭 간격·자동 저장·슬래시 명령·현재 서식·기존 리소스 위치를 기록합니다. 시험 중 변경한 설정은 끝에 복원합니다.
6. PDF 뷰어, Word 또는 한컴, EPUB 리더 중 필요한 뷰어를 준비합니다. 뷰어가 없으면 해당 내용 확인을 BLOCKED로 기록합니다.
7. 콘솔을 열어 새 오류를 확인합니다. React DevTools 권장 메시지는 실패가 아닙니다. 순환 참조, 예외, 저장 실패, 이미지 로드 실패 등은 기록합니다.

## 3. 예제에 필요한 리소스

06 미디어 문서에서 앱의 삽입 도구로 `qa-photo.png`, `qa-video.webm`을 저장합니다. 07 그림책·09 출력 문서는 그 리소스의 `media/qa-photo.png`를 참조합니다. 현재 환경이 저장한 참조에 Drive ID나 다른 경로가 붙으면 미디어 복사 기능으로 해당 문서의 이미지 참조를 교체하세요.

그림책 시험은 사용자 서식 복사본에서 **문서 배치 → 그림책 — 그림과 본문**을 설정합니다. 07 원고의 기본 메타는 일반 서식이므로 그것만 열어서 그림책이 자동 적용되었다고 판단하지 않습니다.

05 Mermaid 오류 예제는 의도적으로 잘못된 코드입니다. 최초 오류 표시는 정상이며 **올바른 코드로 수정한 후 복구**되는지가 판정 대상입니다.

## 4. 결과와 종료 판정

- **PASS:** 절차를 수행했고 모든 기대 결과와 실제 저장/출력 결과를 확인했습니다.
- **FAIL:** 수행 가능했지만 기대 결과와 다릅니다. 파일 유실·다른 위치 입력·잘못된 덮어쓰기·재현되는 예외는 즉시 실패입니다.
- **BLOCKED:** 계정·권한·인터넷·뷰어·리소스 같은 선행 조건이 없어 판정할 수 없습니다.
- **NOT RUN:** 시간 부족 또는 해당 환경 범위 밖으로 수행하지 않았습니다.

**판정:** P0가 모두 실행되어 PASS일 때 기본 흐름 통과로 기록합니다. P0 FAIL은 통합 실패, P0 BLOCKED/NOT RUN은 판정 불가입니다. P1 실패와 미실행은 별도 목록으로 남깁니다. 단순히 오류 메시지가 없거나 파일이 생성된 것만으로 저장·출력 검증을 통과시키지 않습니다.

현재 확인된 **서식 변경 후 문단 DOM 유지 회귀**는 T21에서 집중 확인합니다. 내부 DOM 재사용 여부만으로 수동 판정하지 않고 커서·스크롤·입력 안정성과 내용을 확인합니다.

## 5. 범위와 후속 실행

이 한 시간은 사용자 편집과 저장·출판의 기본 통합 흐름입니다. 실제 서버 계정·결제·라이선스 만료·장시간 토큰 만료·대용량 미디어·AI/지식 색인·각 브라우저 조합·전체 가져오기 형식 검증은 별도 실행이 필요합니다. AI 키나 계정 토큰을 예제에 넣지 않습니다.

다른 환경을 확인하려면 CSV 복사본을 만들고 같은 60분 세트를 다시 수행하세요. 파일 가져오기(DOCX/HWP/PDF 등)는 이번 출력 결과를 보존해 후속 시험 자료로 사용할 수 있습니다.

## 6. 자동 확인 명령(60분 수동 실행과 별도)

저장소 루트에서 실행합니다.

```powershell
node scripts/check-integration-fixtures.cjs
node frontend/node_modules/typescript/bin/tsc --noEmit --project frontend/tsconfig.json
node scripts/check-visual-editor.cjs --visual --help
```

첫 명령은 시간표·예제·미디어 파일을 검사하며 제품 기능을 실행하지 않습니다. `--help` 브라우저 검사는 일부 편집 동작과 도움말 원문 렌더링을 확인하는 제한된 자동 검사입니다. 실제 로그인한 앱의 전체 통합 시험을 대신하지 않습니다.
