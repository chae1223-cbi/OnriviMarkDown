## 파일 교체용 자산

| 원본 | 교체본 | 차이 |
| --- | --- | --- |
| assets/original/qa-photo.png | assets/replacement/qa-photo.png | 파랑 1 → 주황 2, 각각 640×360 |
| assets/original/qa-video.webm | assets/replacement/qa-video.webm | 파랑 QA VIDEO V1 → 주황 QA VIDEO V2, 약 2초 |

같은 파일명을 의도적으로 사용합니다. 선택 순서 V1→V2에 따라 리소스 파일 내용이 갱신되는지 확인합니다. 수정 날짜 비교를 통한 최신 파일 자동 선택 시험이 아닙니다. 다른 사용 문서도 같은 파일명을 참조하면 표시가 바뀔 수 있으므로 전용 리소스 폴더를 사용합니다.

07·09의 그림 참조는 앱이 저장한 실제 리소스 참조에 맞게 교체할 수 있습니다. 표 예제 `<br>`은 셀 안 줄바꿈이며 HTML 누출 오류가 아닙니다. 일반 문장 Tab은 설정값 수의 ASCII 스페이스여야 합니다.

생성 재현 명령:

```powershell
python scripts/generate-integration-fixtures.py
node scripts/generate-integration-video.cjs
node scripts/check-integration-fixtures.cjs
```

예제 생성기는 기존 결과기록 CSV를 덮어쓰지 않습니다. 새로운 실행에는 원래 NOT RUN 템플릿을 다른 이름으로 복사해 사용하세요. 생성기를 다시 실행하면 예제 원문과 자산은 다시 만들어지므로 편집한 작업 파일은 별도 작업장에 보관합니다.
