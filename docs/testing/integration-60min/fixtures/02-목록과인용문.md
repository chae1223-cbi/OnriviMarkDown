# QA 목록·인용문

## 목록 변환 대상

회의 안건을 작성합니다.
담당자를 지정합니다.
결과를 저장합니다.

## 숫자 목록

1. 부모 항목 A
2. 하위 항목으로 바꿀 B
3. 원래 레벨로 돌아올 C

## 일반 목록

- 부모 항목
- 들여쓰기 할 항목
- 내어쓰기 할 항목

## 체크리스트

- [ ] 첫 번째 할 일
- [ ] 두 번째 할 일
- [x] 완료한 할 일

## 다섯 가지 콜아웃

> [!NOTE]
> 파란 배경 NOTE

> [!TIP]
> 초록 배경 TIP
> 여기서 Enter로 다음 줄을 입력하세요.

> [!IMPORTANT]
> 보라 배경 IMPORTANT

> [!WARNING]
> 주황 배경 WARNING

> [!CAUTION]
> 분홍 배경 CAUTION
