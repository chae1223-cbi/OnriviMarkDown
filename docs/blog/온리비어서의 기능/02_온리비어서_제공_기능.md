## [문서의 품격] 글쓰기 속도와 퀄리티를 2배로 올려주는 핵심 기능 9가지

안녕하세요! 평소에 블로그 글이나 업무 보고서를 작성할 때 단순히 글자만 줄줄이 적다 보면, 왠지 글이 밋밋해 보이거나 중요한 내용이 한눈에 들어오지 않아 고민한 적 있으신가요?

오늘은 복잡한 마우스 클릭 없이 키보드 하나로 글의 시각적 완성도와 가독성을 전문가 수준으로 끌어올릴 수 있는 **마크다운 필수 저작 기능 9가지**를 소개해 드립니다.

글 작성 흐름을 끊지 않고 1초 만에 깔끔하게 정돈하는 팁들을 지금 확인해 보세요!

---

### 1. 태그 취소: 잘못 입힌 서식을 클릭 한 번으로 벗겨내는 기능

* **어떤 기능인가요?**:
단어나 문장에 복잡하게 얽힌 마크다운 기호(`**`, `*`, `~~`, `<u>`, `<code>` 등)를 일일이 백스페이스로 지울 필요 없이, 선택한 영역의 서식 기호만 깔끔하게 제거하여 순수 텍스트(Plain Text)로 되돌려주는 기능입니다.

---

#### 📌 [예시 1] 여러 서식이 복합 적용된 텍스트 원상복구

* **태그 취소 적용 전 (서식이 과하게 꼬인 상태)**:
```markdown
이번 주말에는 **_~~<u>반드시 완료해야 할 작업</u>~~_** 목록을 정리합니다.

```

*(굵고, 기울어지고, 취소선에 밑줄까지 겹쳐서 가독성이 떨어진 상태)*
* **[태그 취소] 실행 후 (순수 텍스트만 남김)**:
```markdown
이번 주말에는 반드시 완료해야 할 작업 목록을 정리합니다.

```

---

> [!팁]
> **왜 유용한가요?**
> 외부 웹사이트나 기존 메모 앱, 스프레드시트에서 복사해 온 글에 원치 않는 볼드(`**`), 기울임(`*`), 또는 엉뚱한 백틱(```)이 섞여 있을 때, 글자 내용을 지우지 않고 서식 기호만 한 번에 싹 걷어낼 수 있어 교정 작업이 훨씬 간편해집니다.

---

### 2. 문서 서식 일괄 정리: 꼬이고 깨진 마크다운을 클릭 한 번으로 자동 교정

* **어떤 기능인가요?**:
외부 웹사이트, 메모 앱, 또는 다양한 생성형 AI(LLM)가 작성한 마크다운을 복사해 올 때 발생하는 **비표준 문법, 깨진 줄바꿈, 어긋난 표 구조, 불필요한 들여쓰기 공백**을 감지하여 에디터 렌더러와 출력 규격에 맞게 일괄적으로 자동 보정해 주는 기능입니다.

---

#### 📌 [예시 1] 생성형 AI가 출력한 깨진 표(Table) 자동 정렬

생성형 AI 모델에 따라 표의 열 구분선(`|`) 개수가 안 맞거나 정렬 하이픈(`---`) 행이 생략되어 표로 인식되지 않는 문제를 바로잡습니다.

* **일괄 정리 전 (문법이 깨져 표로 렌더링되지 않는 상태)**:
```text
| 구분 | 작업 내용 | 담당자
| 기획 온보딩 가이드 작성 온리비
| 개발 | D2Coding 폰트 최적화 | 개발팀 |

```


* **[문서 서식 일괄 정리] 실행 후 (표준 마크다운 표로 복원)**:
```markdown
| 구분 | 작업 내용 | 담당자 |
| :--- | :--- | :--- |
| 기획 | 온보딩 가이드 작성 | 온리비 |
| 개발 | D2Coding 폰트 최적화 | 개발팀 |

```



---

#### 📌 [예시 2] 붙여넣기 시 꼬여버린 공백과 불규칙한 줄바꿈 교정

웹 브라우저나 외부 도구에서 서식 문서를 긁어올 때 흔히 발생하는 과도한 빈 줄, 어중간한 들여쓰기 탭을 말끔하게 정돈합니다.

* **일괄 정리 전**:
```markdown
# 주요 공지사항



  - 첫 번째 항목입니다.
      - 하위 항목의 들여쓰기가 과도하게 들어감



본문 문단 사이에 불필요한 빈 줄이 서너 개씩 포함되어 레이아웃이 벌어진 상태

```


* **[문서 서식 일괄 정리] 실행 후**:
```markdown
# 주요 공지사항

- 첫 번째 항목입니다.
  - 하위 항목의 들여쓰기 규격 자동 보정

본문 문단 간격이 표준 여백(1줄 개행)으로 정갈하게 압축 정돈됨

```

#### 📌 [예시 3] 비표준 마크다운 기호 및 인용 상자 오류 보정

일부 챗봇이나 도구가 임의로 만들어낸 비표준 콜아웃 태그나 제목(#) 뒤 띄어쓰기 누락을 정상 문법으로 치환합니다.

### 3. 문서 연결: 로컬 문서를 거미줄처럼 엮어주는 스마트 내부 링크

* **어떤 기능인가요?**:
단순히 외부 웹페이지 URL을 여는 것에 그치지 않고, **현재 열려 있는 내 작업 폴더 내 다른 마크다운 문서나 특정 챕터(제목 태그)를 직접 연결하여 즉시 넘나들며 참조할 수 있는 로컬 링크 기능**입니다.

* **작성법**:
대괄호 `[]` 안에 화면에 보여줄 텍스트를 넣고, 소괄호 `()` 안에 대상 문서의 **상대 경로**를 입력합니다. 이때 파일 경로에 한글이나 공백(스페이스)이 포함되어 링크가 끊어지는 현상을 방지하기 위해 경로 전체를 꺾쇠괄호 `< >`로 감싸줍니다.

```markdown
[표시할 텍스트](<상대경로/파일명.md#이동할-제목-태그>)

```

---

#### 📌 [예시 1] 상위 폴더의 다른 가이드 문서 특정 소제목으로 이동

현재 작성 중인 문서의 상위 또는 도움말 폴더에 있는 문서의 세부 챕터(`### 사전 준비 지식`)를 정확히 타깃팅하여 연결합니다.

* **마크다운 작성**:
```markdown
본 실습을 진행하기 전에 [사전 준비 지식](<../../help/00_시작하기.md#사전 준비 지식>) 항목을 먼저 확인해 주세요.

```

* **동작 결과**:
링크 클릭 시 `00_시작하기.md` 문서가 열리면서 문서 최상단이 아닌 `#사전 준비 지식` 위치로 스크롤이 즉시 이동합니다.

---

#### 📌 [예시 2] 같은 폴더 내 관련 템플릿 문서 전체 연결
동일한 프로젝트 폴더 안에 있는 서식 템플릿이나 일일 업무일지 양식을 본문에 참조 링크로 삽입합니다.

* **마크다운 작성**:
```markdown
일일 실적 작성이 필요하신 분은 [표준 업무일지 양식](<./daily_report_template.md>)을 복사하여 작성하세요.

```


* **동작 결과**:
클릭 한 번으로 같은 작업 디렉터리에 있는 `daily_report_template.md` 문서로 즉시 전환됩니다.

#### 📌 [예시 3] 공백이 포함된 한글 파일 및 하위 폴더 참조

파일명이나 폴더명에 띄어쓰기가 있어도 `< >`로 감싸주면 경로가 깨지지 않고 안전하게 인식됩니다.

* **마크다운 작성**:
```markdown
상세한 서식 프로필 규격은 [온리비 서식 가이드](<../docs/서식 가이드/CSS 프로필 명세서.md#Card 1. 본문 및 기본 타이포그래피>)를 참조하세요.

```

> [!팁]
> **왜 유용한가요?**

### 6. 동영상 삽입: 16:9 와이드 영상으로 생동감 더하기

* **어떤 기능인가요?**:
텍스트나 사진만으로는 다 담기 어려운 프로그램 시연 영상, 튜토리얼, 제품 소개 클립을 문서 한가운데에 깔끔하게 배치하는 기능입니다.
* **작성법**:
HTML5 표준 `<video>` 태그를 활용하여 로컬 미디어 저장 경로(`/media/`)와 컨트롤러 속성, 중앙 정렬 속성(`data-align="center"`)을 지정합니다.


```html
<video src="/media/00_Onrivi_Author_소개글.mp4" title="00_Onrivi_Author_소개글.mp4" controls style="width:600px; height:340px;" data-align="center"></video>

```

* **출력 및 렌더링 특징**:
* **반응형 16:9 비율 유지**: 지정된 너비와 높이(`600px / 340px`)를 기준으로, 서식 프로필 설정에 따라 본문 전체 폭(100%)에 맞춰 모바일과 PC 화면 어디서든 잘림 없이 시원하게 자동 조판됩니다.

* **편리한 재생 제어**: `controls` 속성이 기본 적용되어 방문자가 바로 재생·일시정지, 볼륨 조절, 전체화면 보기를 손쉽게 조작할 수 있습니다.
* **로컬 파일 안전 연동**: 외부 동영상 플랫폼에 업로드하지 않고도 내 작업 공간 안의 동영상 파일(`/media/...`)을 직접 불러와 안전하게 재생합니다.

---

#### 📌 [예시 1] 프로그램 기능 시연 클립 삽입

기능 설명 문서 중간에 짤막한 MP4 조작 영상을 넣어 이해도를 높입니다.

```html
<video src="/media/markdown_shortcuts_demo.mp4" title="마크다운 단축키 시연" controls style="width:600px; height:340px;" data-align="center"></video>

```

#### 📌 [예시 2] 제품 튜토리얼 및 소개 영상 배치

온리비 어서 시작 가이드 문서에 공식 소개 영상을 중앙 배치합니다.

```html
<video src="/media/00_Onrivi_Author_소개글.mp4" title="00_Onrivi_Author_소개글.mp4" controls style="width:600px; height:340px;" data-align="center"></video>

```

---

> [!Tip]
> **왜 유용한가요?**
> 외부 동영상 공유 사이트에 영상을 일일이 올리고 링크를 따오는 번거로움 없이, 로컬 미디어 폴더에 담긴 MP4 영상을 태그 한 줄로 문서에 바로 얹을 수 있습니다. 특히 중앙 정렬(`data-align="center"`)과 16:9 와이드 비율이 기본 유지되어 본문 텍스트와 시각적 균형을 완벽하게 맞출 수 있습니다.
> 
>

### 8. 대화형 지도: 찾아오는 길을 한눈에 보여주는 임베드 지도

* **어떤 기능인가요?**:
단순한 약도 캡처 이미지 대신, 방문자가 마우스나 터치로 확대·축소하고 위치를 직접 둘러볼 수 있는 인터랙티브 지도 위젯을 본문 중앙에 배치하는 기능입니다.
* **작성법**:
표준 `<iframe>` 태그를 사용하여 위도/경도 좌표(`q=위도,경도`)와 줌 레벨(`z=15`), 중앙 정렬 속성(`data-align="center"`), 지연 로딩(`loading="lazy"`)을 함께 지정합니다.

```html
<iframe src="https://maps.google.com/maps?q=37.5665,126.9780&z=15&output=embed" style="width:600px; height:350px; border:0;" allowfullscreen loading="lazy" data-align="center"></iframe>

```

* **출력 및 렌더링 특징**:
* **중앙 정렬 조판**: `data-align="center"` 속성으로 문서 가운데에 단정하게 배치되어 텍스트와의 시각적 밸런스를 맞춥니다.
* **쾌적한 로딩 속도**: `loading="lazy"` 속성이 적용되어 독자가 지도가 있는 위치까지 스크롤을 내릴 때 지도를 불러오므로 전체 문서 로딩이 빨라집니다.
* **완전한 상호작용**: 방문자가 문서 안에서 직접 지도를 드래그해 주변 지하철역, 버스 정류장, 주차장 위치를 실시간으로 탐색할 수 있습니다.

### 9. 수식 렌더링: 복잡한 수학 공식도 벡터 그래픽처럼 깔끔하게

* **어떤 기능인가요?**:
분수, 루트, 미적분, 그리스 문자, 행렬 등 복잡한 학술 수식을 이미지 캡처 대신 텍스트 코드로 입력하여, 확대해도 깨짐 없는 초고해상도 벡터 타이포그래피(KaTeX)로 실시간 렌더링하는 기능입니다.

* **작성법**:
문장 흐름 속에 자연스럽게 녹여내는 **인라인 수식**은 달러 기호 1개(`$`)로 감싸고, 화면 중앙에 독립된 단락으로 돋보이게 배치하는 **블록 수식**은 달러 기호 2개(`$$`)로 위아래를 감쌉니다.

```latex
<!-- 1. 문장 속에 넣는 인라인 수식 -->
아인슈타인의 질량-에너지 등가 원리는 $E = mc^2$ 로 표현됩니다.

<!-- 2. 단독 문단으로 배치하는 블록 수식 -->
$$f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi)\,e^{2 \pi i \xi x}\,d\xi$$

```

* **출력 및 렌더링 특징**:
* **무한 확대 벡터 렌더링**: 비트맵(PNG/JPG) 이미지가 아니므로 스마트폰 작은 화면부터 4K 고해상도 모니터, 종이 A4 인쇄물까지 글자가 흐려지지 않고 칼같이 선명하게 출력됩니다.
* **텍스트 복사 및 검색 가능**: 수식 안의 변수나 수치도 일반 텍스트처럼 검색되거나 복사할 수 있어 문서의 데이터 가치를 유지합니다.
* **실시간 조판**: 복잡한 TeX 수식 편집기를 따로 켜지 않아도 타이핑과 동시에 에디터 미리보기에 즉각 결과가 반영됩니다.

#### 📌 [예시 1] 교재 및 강의 노트용 기본 수식 (근의 공식 & 피타고라스)

* **인라인 수식**:
피타고라스 정리에 따르면 직각삼각형의 빗변은 $c = \sqrt{a^2 + b^2}$ 가 성립합니다.
* **블록 수식**:
이차방정식 $ax^2 + bx + c = 0$ 의 근의 공식은 다음과 같습니다.
```latex
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

```
