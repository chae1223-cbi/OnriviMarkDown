# [마크다운 기초] 5분 만에 끝내는 마크다운 필수 기본 문법 총정리

> [!참조]블로그 방문자가 보고 바로 따라 할 수 있도록 가장 자주 쓰이는 **마크다운(Markdown) 필수 기본 문법 7가지**를 정리한 포스팅 본문 초안입니다. 블로그에 바로 복사해 게시할 수 있는 구성입니다.

---

글을 쓸 때 마우스로 글자 크기를 바꾸고 볼드 버튼을 누르느라 타이핑 흐름이 끊긴 적 있으신가요?

마크다운(Markdown)은 키보드에서 손을 떼지 않고 특수기호 몇 개만으로 서식을 완성하는 가장 가볍고 직관적인 문서 작성법입니다.

자주 쓰는 핵심 문법 7가지만 알아두면  온리비(Onrivi), 노션, 옵시디언, 깃허브 등 어디서든 깔끔한 글을 빠르게 작성할 수 있습니다.

![](/media/img_8d8241202309.png?align=center)

### 1. 제목 위계 (Heading)

`#` 기호의 개수로 글의 목차와 뼈대를 잡습니다. `#` 뒤에는 반드시 한 칸 공백을 둡니다.

> [!Tip]
> **작성 팁**: 한 문서에서 `#` 1개(H1)는 보통 최상단 대표 제목으로 1번만 사용하고, 본문 소주제는 
>  `##`(H2)와 `###`(H3) 위주로 구성하는 것이 가독성과 검색 노출(SEO)에 유리합니다.

```markdown
# 1단계 대제목 (문서 제목)
## 2단계 중제목 (주요 소주제)
### 3단계 소제목 (세부 항목)
#### 4단계 소주제
##### 5단계 대항목
###### 6단계 중항모
```

> ### **[예시]**
> # 제목1 : 온리비 소개
> ## 제목 2: 온리비를 사용해야하는 사람
> ### 제목 3 : 초·중·고 학생
> #### 제목 4 : 학습일지
> ##### 제목 5 : 과학
> ###### 제목 6 : 지구의 자전 

---

### 2. 글자 강조 (Bold, Italic, 취소선)

단어 앞뒤를 기호로 감싸 텍스트를 강조합니다.

```markdown
**굵은 글씨(Bold)**: 중요한 단어 강조
*기울임(Italic)*: 부가 설명이나 뉘앙스 표현
~~취소선(Strikethrough)~~: 수정되거나 삭제된 내용
<u>밑줄(Underline)</u>: HTML 태그 활용

```

> * **예시**
> * **굵은 글씨(Bold)**
> * *기울임(Italic)*
> * ~~취소선(Strikethrough)~~
> * 밑줄(Underline)

---

### 3. 목록 만들기 (List)

순서가 없는 항목은 `-`, `*`, `+`를 사용하고, 순서가 있는 항목은 숫자와 마침표를 씁니다. 체크리스트는 `- [ ] , -[X]`를 사용해서 선택안함, 선택을 표시한다.

```markdown
- 사과
- 바나나
  - 미니 바나나 (스페이스 2번 또는 Tab으로 들여쓰기)
- 오렌지

1. 첫 번째 순서
2. 두 번째 순서
3. 세 번째 순서

- [ ] 예
- [X] 아니오
```

> **예시**
> 
> **[글머리 리스트]**
> - 사과
> - 바나나
> - 파인애플
> - 오렌지
> - 감
    > - 홍시
    > - 단감
    > - 곶감
> ---
> **[숫자 리스트]**
> 1. 첫 번째 순서
> 2. 두 번째 순서
> 3. 세 번째 순서
> ---
> **[체크 리스트]**
> **당신은 성별이 어떠헤 됩니까?**
> - [X] 여자
> - [ ] 남자
---

### 4. 인용구 및 안내 상자 (Blockquote)

문장 맨 앞에 `>`를 넣으면 인용구 상자가 만들어집니다. 참고 사항이나 중요한 문구를 강조할 때 유용합니다. 머리에 태그(참고, 팁, 중요, 주의, 경고) 에 따라 색이 달르게 적용됨 

```markdown
> [!Note]
> "단순함이 궁극의 정교함이다." - 레오나르도 다빈치
>
> > `>`를 두 개 겹쳐 쓰면 인용구 안에 또 다른 인용 상자를 중첩할 수 있습니다.

```


> [!참고]
> **[예시]**
> "단순함이 궁극의 정교함이다." - 레오나르도 다빈치
> > `>`를 두 개 겹쳐 쓰면 인용구 안에 또 다른 인용 상자를 중첩할 수 있습니다.

> [!팁]
> **[예시]**
> **안양은 관악역에서 삼성천으로 가서 `안양예술공원`으로 가서 계곡이 보이는 커피전문점에서 커피를 마시면 좋습니다.**

> [!중요]
> **[예시]**
**오늘은 마감되었습니다. 다음 시간은 2시간후부터 진행합니다.. 늦지마세요**

> [!주의]
> **[예시]**
> **여기하는 초등학교 앞이라 시속 30km 이하로 운전하셔야 합니다.**

> [!경고]
> **[예시]**
> **여기부터는 수영금지 구역입니다.**

### 5. 링크와 이미지 삽입 (Link & Image)

마크다운에서 가장 헷갈리기 쉬운 부분이지만 규칙만 알면 간단합니다. 대괄호 `[]` 뒤에 소괄호 `()`가 옵니다.

```markdown
<!-- 1. 외부 링크 연결 -->
[온리비 공식 웹사이트](https://onrivi.com)

<!-- 2. 이미지 삽입 (링크 문법 맨 앞에 느낌표 '!' 추가) -->
![대체 텍스트](https://example.com/image.png)

```
> [!Note]
> **[예시]**
> [온리비](https://onrivi.com)
> [온리비(https://onrivi.com)](https://onrivi.com)
> 
> ![](/media/img_3a14418bf67d.png?align=center)

### 6. 코드 블록 및 인라인 코드 (Code)

키보드 숫자 1 왼쪽에 있는 백틱(```) 기호를 사용합니다.

* **인라인 코드**: 문장 중간에 단어 하나만 감쌀 때 백틱 1개를 사용합니다.
```markdown
설치 명령어로 `npm install`을 입력하세요.

```

> **[예시]**
> 설치 명령어로 `npm install`을 입력하세요.
> 한국은 **4계절**이 뚜렸합니다. `봄, 여름, 가을, 겨울` 사계절이 있습니다.

* **코드 블록**: 여러 줄의 코드나 데이터를 묶을 때 백틱 3개(```)로 위아래를 감쌉니다.
```markdown
```python
def say_hello():
    print("Hello, Markdown!")
```
```

### 7. 표 만들기 (Table)

파이프 기호(`|`)와 하이픈(`-`)을 사용해 표를 그립니다.

```markdown
| 기능 | 단축키 / 기호 | 설명 |
| :--- | :---: | ---: |
| 굵게 | `**텍스트**` | 좌측 정렬 |
| 기울임 | `*텍스트*` | 가운데 정렬 (`:---:`) |
| 취소선 | `~~텍스트~~` | 우측 정렬 (`---:`) |

```


| 기능 | 단축키 / 기호 | 설명 |
| :--- | :--- | :--- |
| 굵게 | `**텍스트**` | 좌측정렬 |
| 기울임 | `**텍스트**` | 가운데 정렬(`:---:`) |
| 취소선 |`~~텍스트~~` | 우측 정렬 (`---:`) |

### 마무리

마크다운은 복잡한 단축키나 마우스 클릭 없이 오직 글쓰기 본연의 흐름에 집중할 수 있게 도와줍니다. 오늘 정리한 7가지 문법만 손에 익혀두셔도 블로그 포스팅, 개발 일지, 사내 문서 작성 속도가 훨씬 빨라질 것입니다.
