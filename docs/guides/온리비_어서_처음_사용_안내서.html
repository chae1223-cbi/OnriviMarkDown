온리비 어서 처음 사용 안내서

글 한 편에서 나만의 이야기책까지

컴퓨터에 익숙하지 않아도 괜찮습니다. 아래 순서대로 한 단계씩 따라 해 보세요.

오늘 할 일: 홈페이지 열기 → 무료 회원가입 → 글 또는 이야기책 만들기 → 저장 → 출력

이 안내서는 컴퓨터에서 사용하는 화면을 기준으로 설명합니다.

1. 홈페이지에 들어가기

  1. 컴퓨터에서 인터넷을 여는 프로그램을 실행합니다. 예를 들어 크롬(Chrome) 또는 **엣지(Edge)**를 엽니다.

  2. 화면 맨 위의 긴 주소 입력 칸을 한 번 누릅니다.

  3. 아래 주소를 입력합니다.

    https://onrivi.com

  4. 키보드의 Enter를 누릅니다.

  5. 온리비 홈페이지가 보이는지 확인합니다.

지금 읽는 문서에서 바로 열려면: 온리비 홈페이지 열기

주소 입력 칸은 인터넷 화면 맨 위에 있습니다. 검색 결과 목록에서 홈페이지를 찾지 않아도 됩니다.

2. 무료로 회원가입하기

먼저 알아두세요

회원가입은 무료입니다. 무료 체험 기간과 체험 이후 이용 조건은 가입 화면에서 확인해 주세요. 현재 가입 화면에는 14일 무료 체험이 안내되어 있습니다.

방법 A. 구글 계정으로 가입하기

구글 계정이 있다면 이 방법으로 시작할 수 있습니다.

  1. 홈페이지에서 무료로 시작하기를 누릅니다.
  2. 가입 화면에서 이용약관과 개인정보처리방침을 읽습니다.
  3. 내용에 동의하면 동의 칸에 표시합니다.
  4. **활동명(별명)**을 입력합니다. 예: 봄날의 작가
  5. Google 계정으로 빠른 가입을 누릅니다.
  6. 사용할 구글 계정을 선택합니다.
  7. 화면의 안내에 따라 가입을 마칩니다.

가입 화면 바로 열기: 무료 회원가입

방법 B. 이메일로 가입하기

  1. 가입 화면에서 약관 동의와 **활동명(별명)**을 입력합니다.
  2. 본인이 사용하는 이메일 주소를 입력합니다.
  3. 사용할 비밀번호를 입력합니다.
  4. 비밀번호 확인 칸에 같은 비밀번호를 한 번 더 입력합니다.
  5. 가입 버튼을 누릅니다.
  6. 화면에 이메일 확인 안내가 나오면 받은 편지함을 확인합니다.

비밀번호는 화면의 조건에 맞춰 만듭니다. 현재 조건은 8~20자이며 영문 소문자·숫자·특수문자를 포함하는 것입니다.

비밀번호는 다른 사람에게 알려주지 마세요. 이메일 주소와 활동명도 함께 적어 두면 다음에 로그인할 때 도움이 됩니다.

가입한 뒤 글쓰기 화면 열기

  1. 로그인이 필요하면 로그인 화면에서 로그인합니다.
  2. 홈페이지 위쪽의 에디터를 누릅니다.
  3. 글을 작성하는 화면이 열리는지 확인합니다.

글쓰기 화면 바로 열기: 온리비 에디터

홈페이지 로그인과 구글 드라이브 연결은 서로 다릅니다. 구글 드라이브에 글을 보관하려면 글쓰기 화면에서 드라이브를 별도로 연결합니다.

3. 일반문서 작성하기

일기, 편지, 수필, 회고록처럼 글이 중심인 문서부터 연습해 보세요.

3-1. 글을 보관할 곳 정하기

작업장은 내가 쓰는 글을 보관하는 폴더입니다.

보관 장소 뜻
내 PC(로컬) 지금 사용하는 컴퓨터의 폴더
웹드라이브 인터넷에 연결된 구글 드라이브의 폴더

컴퓨터에 보관하려면

  1. 위쪽 파일 메뉴를 누릅니다.
  2. 작업장 폴더 열기를 누릅니다.
  3. 글을 보관할 컴퓨터 폴더를 선택합니다.
  4. 폴더 접근을 허용할지 물으면 내용을 확인한 뒤 허용합니다.

구글 드라이브에 보관하려면

  1. 위쪽 파일 메뉴를 누릅니다.
  2. 개인 웹드라이브 연결을 누릅니다.
  3. 사용할 구글 계정으로 연결합니다.
  4. 화면에 폴더 선택 창이 나오면 글을 보관할 폴더를 선택합니다.

이미 작업장이 열려 있다면 그대로 사용해도 됩니다. 연결 후 왼쪽 탐색기에 폴더와 파일 목록이 보이는지 확인하세요.

3-2. 새 문서 만들기

  1. 파일 → 새문서를 누릅니다.
  2. 저장할 폴더를 확인합니다.
  3. 문서 이름을 입력합니다. 예: 나의 첫 일기
  4. 새 문서 만들기를 누릅니다.

문서 이름 뒤에 .md가 붙을 수 있습니다. 온리비에서 다시 열어 고칠 수 있는 원고 파일이라는 뜻입니다.

3-3. 글 입력하기

  1. 화면의 문서보기를 선택합니다. 편집 중인 글이 종이에 쓰는 모습처럼 보이는 화면입니다.
  2. 본문 안을 한 번 누릅니다.
  3. 아래 연습 글을 입력합니다.

오늘의 기록

오늘은 온리비에서 처음으로 글을 써 보았습니다.

오래 기억하고 싶은 순간을 한 줄씩 적어 보려고 합니다.

  1. 다음 문단으로 내려가려면 Enter를 누릅니다.
  2. 글의 모양을 바꾸고 싶으면 글자를 마우스로 선택한 뒤 서식 도구를 사용합니다.

특별한 기호나 마크다운 문법을 외우지 않아도 문서보기에서 본문을 입력할 수 있습니다.

3-4. 실수한 내용 고치기

  • 방금 한 작업을 취소하려면 편집 → 실행 취소를 누릅니다.
  • 취소한 작업을 다시 적용하려면 편집 → 다시 실행을 누릅니다.
  • 특정 낱말을 찾으려면 편집 → 찾기를 누릅니다.
  • 낱말을 다른 말로 바꾸려면 편집 → 바꾸기를 누릅니다.

3-5. 원고 저장하기

  1. 파일 → 저장을 누릅니다.
  2. 저장 완료 안내를 확인합니다.

다른 장소에도 한 부 보관하려면 파일 → 다른 이름으로 저장을 사용합니다.

  • 내PC(로컬)로 저장: 컴퓨터에 사본을 저장합니다.
  • 개인웹드라이브 저장: 계정·드라이브·폴더·파일명을 선택하여 사본을 저장합니다.

다른 곳에 사본을 저장해도 현재 작업장이 자동으로 바뀌지는 않습니다.

잠시 자리를 비우거나 프로그램을 닫기 전에는 한 번 더 저장을 눌러 주세요.

4. 이야기책 작성하기

이야기책은 표지와 여러 장면을 차례로 이어 만드는 책입니다. 화면에서는 그림책이라는 이름도 사용합니다.

처음에는 표지 1장과 이야기 장면 2개로 짧게 만들어 보세요.

4-1. 이야기책용 새 문서 만들기

  1. 파일 → 새문서를 누릅니다.
  2. 문서 이름을 입력합니다. 예: 숲속 친구들의 하루
  3. 새 문서 만들기를 누릅니다.

4-2. 책 모양 선택하기

서식은 글과 그림이 놓이는 모양입니다.

  1. **도구 → 서식 관리(갤러리)**를 엽니다.
  2. 이름에 Story Book이 들어간 서식을 찾습니다.
  3. 표지에 그림이 크게 나오는 서식이나 오른쪽에 그림이 놓이는 서식을 선택합니다.
  4. 이 서식 적용하기를 누릅니다.
  5. 서식 창을 닫아 작성 중인 문서로 돌아갑니다.

4-3. 표지와 첫 장면 준비하기

  1. 문서에 표지·본문 예시 추가 버튼이 보이면 누릅니다.
  2. 그림책 장면 편집을 눌러 장면 목록을 펼칩니다.
  3. 표지와 본문 장면이 준비되었는지 확인합니다.

예시의 사진 경로는 견본입니다. 사진을 찾을 수 없다는 안내가 나오면 아래 방법으로 실제 사진을 넣어 주세요.

4-4. 표지 글 바꾸기

  1. 표지의 본문 편집을 누릅니다.
  2. 책 제목을 입력합니다. 예: 숲속 친구들의 하루
  3. 저자 이름을 입력합니다. 예: 글·그림: 봄날의 작가
  4. 편집 완료를 누릅니다.

4-5. 장면에 글과 그림 넣기

  1. 작성할 장면으로 이동합니다.
  2. 본문 편집을 누릅니다.
  3. 장면의 이야기를 입력합니다.

아침 햇살이 숲속으로 들어왔습니다. 다람쥐는 친구들을 만나러 작은 길을 걸어갔습니다.

  1. 편집 완료를 누릅니다.
  2. 그림 영역의 편집 버튼을 누릅니다. 글을 고치는 본문 편집 버튼과 구분하세요.
  3. 사진 선택 창에서 사용할 그림을 선택합니다.
  4. 사진 선택을 마친 뒤 장면에 그림이 나타나는지 확인합니다.

그림을 새로 준비한다면 가로 3 : 세로 4 비율의 세로 그림을 권합니다. 화면에서 그림이 잘리거나 중요한 부분이 가려지지 않는지도 확인하세요.

4-6. 다음 장면 추가하기

  1. 현재 장면 아래의 ＋ 다음 장면 추가를 누릅니다.
  2. 새 장면에서 본문 편집을 누릅니다.
  3. 이어지는 이야기를 입력합니다.
  4. 새 장면의 그림도 선택합니다.
  5. 필요한 만큼 장면을 추가합니다.

장면 목록으로 돌아가려면 ↑ 장면 목록으로를 누릅니다. 장면 순서를 바꾸려면 장면 목록의 위로 / 아래로를 사용합니다.

4-7. 이야기책 확인하고 저장하기

  1. 표지부터 마지막 장면까지 천천히 읽습니다.
  2. 그림이 빠진 곳이 없는지 확인합니다.
  3. 글이 그림이나 페이지 밖으로 넘어가지 않는지 확인합니다.
  4. 파일 → 저장을 누릅니다.

“장면 밖 본문이 있습니다”라는 안내가 나오면, 어느 장면에도 들어가지 않은 글이 있다는 뜻입니다. 안내의 문제 본문을 확인하고 해당 장면의 본문에 옮겨 주세요.

5. 종이로 인쇄하거나 PDF로 보관하기

먼저, 저장과 출력의 차이

할 일 사용할 기능 언제 사용하나요?
원고를 계속 고칠 수 있게 보관 파일 → 저장 다음에 이어서 작성할 때
종이로 뽑거나 완성본 만들기 파일 → 내보내기 → 인쇄/PDF 읽거나 다른 사람에게 보여 줄 때

5-1. 출력 전 확인하기

  1. 파일 → 저장을 누릅니다.
  2. 문서보기에서 제목과 본문을 확인합니다.
  3. 이야기책은 장면 순서와 그림을 확인합니다.
  4. 파일 → 내보내기 → 인쇄/PDF를 누릅니다.

5-2. 종이로 인쇄하기

인쇄 창이 열리면 다음 순서로 진행합니다.

  1. 사용할 프린터를 선택합니다.
  2. 필요한 인쇄 매수를 확인합니다.
  3. 오른쪽 또는 왼쪽의 인쇄 미리보기를 확인합니다.
  4. 인쇄를 누릅니다.

그림이나 배경색이 빠져 보이면 인쇄 창의 배경 그래픽 또는 비슷한 이름의 항목을 확인합니다. 컴퓨터와 프린터에 따라 설정 이름이 다를 수 있습니다.

5-3. PDF 파일로 보관하기

PDF는 다른 사람에게 보낼 때 문서 모양을 유지하기 좋은 완성본 파일입니다.

  1. 인쇄 창의 대상 또는 프린터에서 PDF로 저장을 선택합니다.
  2. 저장을 누릅니다.
  3. 저장할 컴퓨터 폴더를 선택합니다.
  4. 파일 이름을 확인합니다. 예: 숲속 친구들의 하루.pdf
  5. 저장한 PDF를 열어 글과 그림을 확인합니다.

PDF 저장 창이 곧바로 열리는 환경에서는 저장 위치와 파일 이름을 정해 저장하면 됩니다.

원고(.md)와 완성본(.pdf)을 둘 다 보관하세요. 글을 고칠 때는 원고를 열고, 가족이나 지인에게 보여 줄 때는 PDF를 보내면 편리합니다.

막힐 때 확인하세요

글자가 너무 작아요

문서보기에서 글을 크게 보려면 Ctrl 키를 누른 채 + 키를 누릅니다. 원래 보기 크기로 돌아오려면 Ctrl+0을 누릅니다. 문서의 실제 인쇄 글자 크기는 서식 설정에서 조절합니다.

구글 로그인 창이 열리지 않아요

주소 입력 칸 근처에 팝업 차단 표시가 있는지 확인합니다. 온리비의 팝업을 허용한 뒤 다시 연결합니다.

그림 대신 오류 안내가 보여요

해당 장면의 그림 편집을 눌러 실제 그림을 다시 선택합니다. 웹드라이브 그림이라면 드라이브 연결 상태도 확인합니다.

어디에 저장했는지 모르겠어요

왼쪽 탐색기의 작업장 이름과 폴더 목록을 확인합니다. 처음에는 온리비 글모음처럼 알아보기 쉬운 폴더 한 곳을 정해 사용해 보세요.

파일을 다시 열고 싶어요

작업장에 저장한 .md 파일은 왼쪽 탐색기에서 파일 이름을 누르면 열립니다.

다른 문서를 가져오려면 파일 → 파일 열기에서 로컬 또는 웹드라이브를 선택합니다. 파일을 가져온 뒤 저장할 폴더와 이름을 확인합니다. 가져온 문서는 .md 원고로 변환하여 저장됩니다.

마치기 전 다섯 가지 확인

  • 내가 만든 문서의 이름을 확인했습니다.
  • 원고를 저장했습니다.
