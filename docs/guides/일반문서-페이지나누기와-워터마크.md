# 일반 문서 페이지 나누기와 워터마크

## 용지 설정

서식관리에서 용지 크기, 세로·가로 방향, 상하좌우 여백을 정합니다. 쪽 윤곽과 PDF는 이 설정을 함께 사용합니다.

## 페이지 나누기

1. 문서보기에서 다음 페이지를 시작할 위치에 커서를 둡니다.
2. **페이지 나누기** 버튼 또는 `/페이지나누기` 명령을 사용합니다.
3. 경계 아래에 계속 입력합니다.

경계를 선택하고 Delete를 누르면 제거됩니다. 실행 취소도 가능합니다. Ctrl+Enter의 기존 블록 탈출 기능은 유지합니다.

수동 나누기는 마크다운에 `<!-- onrivi:page-break -->`로 저장됩니다. 일반 구분선 `---`와는 다릅니다. 표·목록 바깥의 본문에 삽입하세요.

## 페이지 확인과 PDF 출력

- **예상 페이지 경계 켜기**: 편집 화면에 분량을 가늠할 점선을 표시합니다. 표·이미지·문단 분할과 서식 차이로 실제 출력과 다를 수 있습니다.
- **인쇄 / 쪽 윤곽**: 실제 출력에 사용할 종이 단위 배치와 전체 페이지 수를 확인합니다. 내용이 늘어나면 페이지도 자동으로 늘어납니다.

쪽 윤곽은 읽기 전용입니다. 본문은 문서보기에서 고치세요. 동일한 내용과 설정의 쪽 윤곽 결과를 출력에 재사용합니다.

브라우저 인쇄 창에서는 **여백 없음**, **배율 100%**, **서식관리와 같은 용지·방향**, **배경 그래픽 켜기**, **머리글/바닥글 끄기**를 사용하세요. 앱의 여백은 이미 페이지 안에 반영되어 있으므로 브라우저에서 여백을 추가하면 출력 배치가 달라질 수 있습니다.

## 기본 워터마크 관리

1. **환경설정 → 일반 설정 → 기본 워터마크**를 엽니다.
2. 워터마크 사용 여부와 문자·이미지 종류를 정합니다.
3. 문구, 위치, 진하기, 각도, 너비, 글자 크기와 첫 페이지 제외를 설정합니다.
4. **저장**을 누릅니다.
5. 인쇄 / 쪽 윤곽에서 확인합니다. 출력 창에는 설정 요약과 환경설정으로 이동하는 버튼이 표시됩니다.

저장한 기본 설정을 여러 문서에 공통 적용합니다. 아직 기본 설정을 저장하지 않은 경우 기존 문서의 워터마크 설정을 읽어 호환합니다.

## 이미지 워터마크와 리소스 폴더

- 연결된 **리소스 폴더의 media**에서 이미지를 선택하거나 새 파일을 추가합니다.
- PNG·JPG·WebP, 10MB 이하를 지원합니다. 투명 배경 PNG를 권합니다.
- 새 파일은 리소스 폴더에 저장하고 설정에는 파일 참조를 보관합니다. 기본 엠블럼도 활성화한 뒤 설정을 저장하면 리소스 파일로 보관합니다.
- 리소스 폴더를 바꾸면 그 폴더의 이미지로 다시 선택하세요. 기존 파일은 자동 삭제하지 않습니다.
- 다른 환경에서 출력하려면 같은 리소스 파일에 접근할 수 있어야 합니다. 읽을 수 없는 경우 오류를 알립니다.

이미지는 원고 본문에 삽입되지 않습니다. 진하기 0%일 때는 진하기를 올리거나 워터마크를 끄세요.

## 적용 안내

웹은 새 코드 배포 후, 설치된 데스크톱 앱은 새 빌드 설치 후 사용할 수 있습니다. 위 페이지 설명은 일반 문서 인쇄/PDF 기준입니다. EPUB은 읽기 프로그램에 따라 페이지 배치가 달라집니다.

워터마크는 작성자와 검토 상태를 표시하는 기능이며 복제·변조를 막는 보안 기능은 아닙니다.
