# 문서보기 AI 사용 안내

작성일: 2026-10-20

## 빠르게 사용하기

- AI를 처음 열면 질문 입력란에 커서가 놓입니다. 문서 선택 없이 질문을 입력하고 Enter로 보냅니다. Shift+Enter는 줄바꿈입니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 상단의 **질문 / 문서 요약 / 문서 수정** 버튼으로 작업을 바로 바꿉니다.
- **문서 요약**은 현재 문서의 처리 가능한 본문 텍스트를 한 번에 참고해 하나의 요약을 보여줍니다. 요청을 비워 두고 보내면 기본 핵심 요약을 생성합니다. 원문은 바꾸지 않습니다.
- **문서 수정**은 기본적으로 현재 문단을 대상으로 하며, ‘수정 범위’를 펼쳐 선택한 글·문서 전체로 바꿀 수 있습니다.
- 파일 첨부와 프롬프트 템플릿은 접힌 메뉴에서 필요할 때 펼칩니다. 모델 선택은 하단 버튼의 목록을 사용합니다.

## 1. AI 연결

환경설정 → 일반 → **AI 연결 관리**에서 Google(Gemini/Gemma), OpenAI, Claude의 연결 카드를 각각 사용합니다. 세 제공사를 동시에 등록할 수 있으며 각 카드에서 API 키·모델·연결 해제를 별도로 관리합니다.

1. 제공자에서 발급받은 API 키를 입력합니다.
2. **연결 · 모델 목록 확인**을 누릅니다. 이 동작은 모델 목록을 조회하며 글 생성을 요청하지 않습니다.
3. 문서 화면의 AI 버튼 아래쪽을 눌러 사용할 모델을 선택합니다.

API 사용은 각 제공자의 요금·할당량·권한을 따릅니다. 모델 목록에 표시돼도 실제 생성 접근 권한이 없을 수 있습니다. ChatGPT·Claude·Gemini 웹 구독과 API 연결은 별도로 확인하세요.

- 웹에서 새로 등록한 키는 현재 페이지 메모리에만 유지됩니다. 새로고침하면 다시 연결해야 합니다. 로그인 후 온리비의 같은 출처 API 서버를 통해 호출합니다.
- 데스크톱은 세션 연결 또는 **이 PC의 암호화 저장소에 보관**을 선택할 수 있습니다. OS 암호화 기능을 사용할 수 없으면 영구 보관을 진행하지 않습니다.
- 기존 Gemini 연결은 호환용으로 이용할 수 있습니다. 새 연결의 키를 원고·템플릿에 기록하지 않습니다. 환경설정 아래의 중복된 기존 AI 어시스턴트 입력 화면은 제거했습니다. 기존 키 데이터는 삭제하지 않으며, 새 연결은 제공사별로 독립 관리합니다.

## 2. 두 줄 AI 버튼

- **위쪽 온리비 AI**: 요청 입력란을 엽니다.
- **아래쪽 모델명**: 제공자와 모델을 바꾸는 메뉴를 엽니다.
- 제공사별 추천 모델 선택, 목록 새로고침, 연결 설정 이동을 지원합니다.
- 모델을 바꿔도 프롬프트와 첨부 목록은 유지합니다. 생성 중에는 모델 변경을 잠급니다.
- 하루 이상 지난 모델 목록은 연결이 있으면 메뉴를 열 때 재조회합니다. 새 모델로 자동 전환하지 않습니다.

## 3. 문장 수정

1. 문서보기에서 고칠 글을 선택하거나 일반 문단에 커서를 둡니다.
2. AI 버튼 위쪽을 누릅니다.
3. 교정·다듬기·요약·쉽게 설명·문체 변경·번역을 고르거나 요청을 직접 입력합니다.
4. 실행한 뒤 원문과 수정안을 비교합니다. 수정안은 적용 전에 직접 고칠 수도 있습니다.
5. **선택한 글 바꾸기** 또는 **문단 아래에 추가**를 누릅니다. 추가 결과는 일반 문단으로 들어갑니다.

적용 전에는 원문이 바뀌지 않습니다. 적용 후 Ctrl+Z 한 번으로 복원할 수 있습니다. 생성 중지나 연결 오류가 발생한 불완전한 결과는 적용할 수 없습니다.

대상 앞에서 다른 내용을 편집해도 위치를 추적합니다. 대상 자체를 고치거나 지우면 다시 선택하도록 안내합니다. 탭을 바꾸면 진행 중 요청과 대상을 해제합니다.

초기 지원은 한 문단 안의 텍스트, 제목 텍스트, 목록 항목의 본문입니다. 여러 블록 전체·혼합 서식·표·코드·수식·이미지 자체의 AI 수정은 제한합니다. 선택 없이 빈 문단에서 새 글을 작성할 수 있습니다. 마크다운 편집기에서도 선택 영역 또는 현재 줄을 대상으로 사용할 수 있습니다.

## 4. 첨부파일

입력란의 **파일 첨부** 또는 파일 끌어놓기를 사용합니다.

- 텍스트: UTF-8 TXT, MD, CSV, JSON
- 문서: 텍스트를 추출할 수 있는 PDF, DOCX
- 이미지: PNG, JPG, WebP. 선택 모델의 이미지 입력 지원이 필요합니다.
- 제한: 최대 5개, 파일당 10MB, 합계 20MB. 추출 텍스트는 파일당 80,000자, 요청 전체 텍스트는 100,000자 이하입니다. PDF는 최대 100쪽입니다.

첨부 후 ‘준비됨’을 확인하고 실행하세요. 파일별 제거가 가능합니다. 파일 선택만으로 AI에 전송하지 않으며 실행 시 선택한 제공자에게 전달합니다. 파일 자체를 원고나 프롬프트 템플릿에 자동으로 저장하지 않습니다.

스캔 PDF의 OCR, HWP/HWPX·엑셀·PPT·음성·영상 첨부는 이번 범위에 포함하지 않습니다. ‘문서 가져오기’의 지원 형식과 AI 첨부 형식은 다를 수 있습니다.

## 5. 템플릿 저장과 재사용

입력란의 **프롬프트 템플릿 저장 · 불러오기**를 펼칩니다.

1. **기존 라이브러리 불러오기 · 새로고침**으로 기존 사용자·도메인 템플릿을 확인합니다.
2. 템플릿을 선택하면 요청 입력란에 채워집니다. 즉시 생성하지 않습니다.
3. 요청을 작성하고 이름과 분류를 입력한 뒤 **새 템플릿 저장 · 복제**를 누릅니다.
4. 기존 사용자 항목을 수정하려면 선택 후 **선택 템플릿 수정**을 누릅니다. 이름과 분류도 이때 변경할 수 있습니다.
5. `{{대상독자}}`, `{{문체}}`처럼 변수를 넣으면 재사용할 때 값을 입력할 수 있습니다.

저장 위치는 연결한 리소스 폴더의 **prompt/ai_presets.json**입니다. 기존 추가 필드를 보존합니다. 저장 전 이전 파일은 **ai_presets.backup.json**으로 백업합니다. 다른 창에서 파일이 변경되면 목록을 다시 불러온 뒤 저장하세요. Drive 저장 전 변경 검사는 하지만 동시 저장의 모든 경합을 원자적으로 막는 분산 잠금 기능은 포함하지 않습니다.

선택한 본문, 첨부파일 바이트, API 키, 생성 결과는 템플릿에 자동으로 포함하지 않습니다. 사용자가 프롬프트 칸에 직접 적은 내용은 저장되므로 개인 정보는 입력 전에 확인하세요.

## 6. 적용 및 검증 범위

- 웹 개발 서버: `/api/ai/request` 개발 라우트를 제공합니다.
- 웹 배포: 화면과 함께 Cloudflare Pages Functions의 `functions/api/ai/request.js`를 배포해야 합니다. API 함수의 환경변수에 `NEXT_PUBLIC_SUPABASE_URL`과 `NEXT_PUBLIC_SUPABASE_ANON_KEY`(또는 `SUPABASE_ANON_KEY`)가 필요합니다. 서비스 역할 비밀키를 브라우저에 넣지 마세요.
- 설치형 앱: 새 Electron 브리지와 메인 프로세스 코드가 포함된 새 빌드가 필요합니다. 화면 파일만 갱신한 구버전 앱에는 업데이트 안내를 표시합니다.
- 공급사 통신은 공통 공식 REST 어댑터를 사용합니다. Google generateContent 스트리밍, OpenAI Responses, Claude Messages를 각각 처리합니다. 모델 목록은 동적으로 조회하며 SDK 자동 업데이트나 모델의 무단 대체는 하지 않습니다.

자동 검증은 공급사 응답을 모의하여 요청 형식·중지·실패·본문 보호를 확인합니다. 실제 API 키를 이용한 유료 호출, 운영 서버 배포, 설치 패키지 빌드와 설치는 별도입니다.

## 수정 범위 선택

오른쪽 AI 패널에서 **문서 수정 → 수정 범위**를 선택합니다.

- **선택한 글**: 한 문단 안에서 드래그한 글만 수정합니다.
- **현재 문단**: 커서가 있는 문단을 수정합니다. 위치를 바꿨으면 ‘현재 위치에서 범위 다시 지정’을 누릅니다.
- **문서 전체**: 문서보기의 편집을 켜고 실행합니다. 최대 200문단·100,000자의 본문을 문단별로 처리합니다. 수정안을 확인한 뒤 체크된 문단만 적용하거나 전체 선택 후 적용할 수 있습니다. 적용한 변경은 Ctrl+Z 한 번으로 되돌립니다.

문서 전체 수정에서는 이미지·코드·삽입 요소가 섞인 문단을 제외하고 텍스트를 처리합니다. 제목·목록·표의 구조, 이미지, 메타정보, 페이지 나누기는 유지합니다. 수정되는 글 안의 서식은 변경 범위의 공통 서식을 사용하며, 변경되지 않은 앞뒤의 서식은 유지합니다. 문단마다 요청하지 않고 약 5,000자·최대 40문단씩 묶어 요청합니다. 짧은 문서는 한 번에 처리하고, 변경된 문단만 답변받아 반복 입력과 출력량을 줄입니다. 실행 전 예상 요청 횟수를 표시합니다. 첨부와 요청문은 각 묶음에 포함되며 실제 토큰과 비용은 모델 및 답변 길이에 따라 달라집니다. 도중에 문서를 편집하거나 생성이 중단되면 적용할 수 없습니다.

## 간소화한 모델 목록 (2026-10-20)

제공사별 최신 문서 작업용 추천 3개씩 표시합니다. Gemini: 3.8 Flash, 4 Argon, 3.5 Flash-Lite / GPT: 6.1 Sol, 6 Luna, 6 Astra / Claude: Sonnet 5.5, Opus 5.5, Haiku 5.5. Gemma 4는 31B IT, 26B A4B IT 두 종류로 유지합니다. 총 11개를 그룹으로 구분합니다. 공식 사용량 순위가 아닌 문서 작업 추천 순서이며, API 조회 목록에 있는 모델만 선택할 수 있습니다. 기존 선택은 자동으로 바꾸지 않습니다.

### 하단 버튼에서 모델 선택

AI 버튼 아래의 모델명을 누르면 버튼 위에 작은 목록이 열립니다. 현재 API 키가 등록되어 있고 조회 목록에 포함된 추천 모델만 표시합니다. 연결 해제된 제공사는 숨깁니다. 선택하면 목록만 닫히며, 작성 중인 오른쪽 AI 패널의 요청은 유지합니다. 바깥을 누르거나 Esc를 누르면 목록을 닫습니다. 목록 조회 확인은 실제 생성 권한·잔액을 보장하지 않습니다.

### 선택한 글에 대해 질문하기

문서에서 질문할 글을 드래그한 뒤 오른쪽 질문 입력란을 클릭합니다. 제목과 여러 목록·문단을 함께 선택해도 참고할 수 있습니다. 선택 영역은 보라색으로 남고, 패널에 ‘선택한 글 참고’와 발췌문이 표시됩니다. 질문을 보내면 이 발췌문과 직접 첨부한 파일만 참고 자료로 전달합니다. ‘선택 해제’로 자료를 제외할 수 있습니다. 선택한 원문이 변경되면 다시 선택해야 하며, 문서를 바꾸거나 패널을 닫으면 참고 선택도 해제됩니다. 질문은 원문을 수정하지 않습니다.
