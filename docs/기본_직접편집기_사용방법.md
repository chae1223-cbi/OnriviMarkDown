# 기본 직접 편집기

적용일: 2026-10-12. 첫 단계 구현이며 그림책과 고급 블록의 직접 편집은 후속 작업이다.

## 사용 방법

1. 일반 Markdown 문서를 열고 하단 **문서 보기** 또는 **나란히 보기**를 선택한다.
2. 오른쪽 화면의 **직접 편집**을 선택한다. 처음에는 직접 편집이 활성화되어 있다.
3. 문서 본문을 클릭해 입력한다. 플로팅 서식 도구는 Ctrl+Space 또는 오른쪽 툴바에서 연다.
4. `/`를 입력하면 본문·제목·목록·인용문·코드 블록·구분선을 선택할 수 있다.
5. **문서 저장** 또는 `Ctrl+S`로 기존 저장 위치에 저장한다. 기존 자동 저장 설정도 적용된다. Mac에서는 `⌘S`를 사용한다.
6. 원문은 **마크다운 보기**에서 수정한다. **미리보기**를 누르면 기존 읽기 전용 조판 화면을 확인할 수 있다.
7. 내보내기를 선택하면 읽기 전용 미리보기로 전환한 뒤 기존 내보내기 기능을 실행한다.

저장 위치를 지정하지 않은 문서는 기존 새 문서작성·저장 흐름을 통해 위치를 지정해야 한다. 직접 편집기가 임의로 저장 폴더를 생성하지 않는다.

## 현재 지원

- 본문, 제목, 굵게, 기울임, 인라인 코드, 링크.
- Markdown 입력: 줄 앞의 `## `는 제목, `- `는 목록, `1. `는 번호 목록, `> `는 인용문으로 바뀐다. `**굵게**`, `*기울임*`, 인라인 코드도 자동 적용된다. 기본 Markdown 원고를 붙여넣을 때도 서식을 적용한다.
- `---` 메타데이터가 포함된 MD 원고 전체를 붙여넣으면 본문은 Markdown으로 해석하고 메타데이터는 문서 맨 앞의 한 영역에 합친다. 클립보드에 문법 색상용 HTML이 함께 들어 있어도 원본 Markdown을 우선한다. 메타데이터의 변경도 실행 취소·다시 실행에 포함된다.
- 글머리 목록, 번호 목록, 인용문, 코드 블록, 구분선.
- 문단 서식 메뉴, 기본 슬래시 메뉴, 선택 영역 플로팅 툴바.
- 실행 취소·다시 실행. 목록의 Enter 및 Tab/Shift+Tab 들여쓰기.
- `Ctrl+Space`로 플로팅 툴바를 열고 닫는다. `/` 명령 입력 중에는 슬래시 메뉴를 다시 연다. Mac에서는 `⌘Space`로 연결되지만 OS 단축키와 겹칠 수 있으므로 글 선택 또는 `/` 입력으로도 사용할 수 있다.
- 기존 탭의 내용·수정 표시·저장·자동 저장 연결.
- 같은 문서의 직접 편집 ↔ 미리보기 전환 시 직접 편집 실행 취소 기록 보관. 최근 20개 문서까지 메모리에서 유지한다.
- 제한 사용자와 도움말의 기존 읽기 전용 정책 유지.

## 이번 단계의 범위

- 그림책은 기존 장면 편집 및 미리보기를 사용한다.
- 독립 이미지 문단은 직접 삽입·교체할 수 있다. 수식, Mermaid, 각주, 체크리스트, HTML 등 복합 구문은 원문 보존 블록으로 처리한다. 일반 표와 태그 인용문은 직접 편집하며, 그 밖의 복합 블록은 **마크다운 보기**에서 수정한다.
- 메타데이터는 그대로 보관하며 본문 직접 편집 영역에는 표시하지 않는다.
- 수정하지 않은 블록은 원래 문자열을 보존한다. 수정한 기본 블록만 Markdown으로 변환한다.
- 기존 Markdown 편집기와 직접 편집기의 실행 취소 기록을 하나로 합치는 것은 후속 단계다. 원문이 변경되면 직접 편집기의 이전 기록을 초기화하여 다른 버전으로 되돌리는 것을 방지한다.
- 기존 사용자에게 저장된 보기 설정은 유지한다. 저장된 설정이 없는 경우 문서 보기를 기본으로 사용한다.
- Ctrl+Space는 기존 아이콘형 플로팅 툴바 자체를 문서보기에서도 재사용한다. 제목·인용구 선택과 기존 버튼 순서를 유지한다. 슬래시 메뉴는 기존 명령 정의를 사용해 아이콘·`/명령어`·기능 이름·설명이 한 줄씩 나오는 세로 목록으로 표시한다. 사용자 정의 이름과 방향키·Enter·Tab 선택도 지원한다.
- 기본 명령과 사진 넣기는 문서 보기에서 실행한다. 수식·AI 등 기존 편집기를 사용하는 명령은 선택 영역을 원문 위치로 변환한 뒤 **나란히 보기**에서 기존 기능을 호출한다. 고급 블록 자체의 시각적 편집은 후속 단계다.
- 제목 안의 `1.`·`-`는 제목의 내용으로 유지한다. 문단용 목록 자동 변환은 일반 본문 문단에서만 실행한다.
- 강조·기울임·코드의 닫는 기호 뒤 입력은 일반 글로 이어진다. 상단 `plain`/`bold`/`italic`/`inlinecode` 표시로 현재 입력 서식을 확인하고, `clear`로 현재 서식을 해제할 수 있다.

## 확인 결과

- 원문 보존 테스트: 메타데이터, CRLF, 표, 이미지 경로, 각주, 그림책, Mermaid, 수식, 체크리스트.
- Edge 자동 점검: 본문 입력, 한글 문자열 입력, 실행 취소·다시 실행, 보기 전환, 선택 서식, 슬래시 제목 추가, 외부 원문 변경, 읽기 전용.
- 전체 원고 검증: `HELP-01_온리비_어서_소개와_시작하기.md`를 실제 클립보드 붙여넣기 이벤트로 삽입한 뒤 원본과 문자열 전체가 일치하는지 확인한다. 메타데이터 중복, HTML 서식 혼입, 제목·링크·표·코드·알림 표시, 붙여넣기 실행 취소·다시 실행을 함께 확인한다.
- 코드 블록: 기본 코드 편집은 구문 강조 작업 없이 직접 DOM으로 표시한다. 코드에서는 맞춤법 검사를 끄고 가로 스크롤로 줄 정렬을 유지한다. 입력한 부분만 원문 모델에 반영하며, 본문 입력으로 문서 서식 CSS를 다시 만들지 않는다. HELP-02 코드 입력 및 큰 코드 원문에 대한 최소 변경 전달을 확인했다. 독립 편집기 검사 수치는 앱 전체의 초기 로딩 시간 측정과는 구분한다.
- 실제 한글 IME 조합과 실제 Google Drive 저장은 사용자 환경에서 추가 확인이 필요하다.
- TypeScript 검사, 수정 파일 ESLint, 데스크톱 정적 빌드 확인.

데스크톱은 최신 정적 빌드가 필요하다. 개발 저장소에서 `npm run electron:prod`로 실행하는 경우 앱을 종료하고 다시 실행한다. 배포된 설치 앱은 새 패키지 배포가 별도로 필요하다.


## 단축키와 슬래시 명령 설정

환경설정 → 단축키에서 설정한 키 조합과 /명령어를 문서 보기와 Markdown 보기에서 사용합니다. 예를 들어 굵게 명령을 `b`로 설정하면 `/b`로 실행합니다. 고정 단축 코드를 별도로 추가하지 않습니다. 한글 이름 검색도 지원하며, 명령이나 단축키를 비우면 해당 설정을 사용하지 않습니다.


## 문서 보기에서 사진 넣기와 교체

- 빠른 작업의 사진 넣기, 툴바의 이미지 버튼, 설정한 이미지 슬래시 명령을 사용합니다.
- 기존 사진 넣기 모달에서 파일·주소·클립보드를 선택하고 크기, 정렬, 설명을 지정합니다.
- 문서 본문에서 이미지 붙여넣기와 파일 드래그도 가능합니다. 데스크톱에서는 네이티브 클립보드를 사용합니다.
- 사진 위에 마우스를 올리면 편집 버튼이 나타납니다. 사진을 클릭하기만 해서는 모달이 열리지 않습니다.
- 파일은 기존 환경설정의 로컬 또는 Google Drive 리소스 저장 경로를 사용하며 MD에는 참조 경로를 기록합니다.
- 사진 삽입·교체는 실행 취소와 다시 실행을 지원합니다. 참조 파일 자체는 실행 취소로 삭제하지 않습니다.
- 현재 단계에서는 독립적인 이미지 문단을 직접 편집합니다. 문장 속 이미지, 표 안 이미지, 그림책 장면은 기존 처리 방식을 사용합니다.


## 이미지·동영상·지도 편집과 복사

- 문서 보기와 일반 미리보기의 미디어에 마우스를 올리면 편집·복사 버튼을 사용할 수 있습니다.
- 편집은 기존 사진·동영상·지도 모달을 열고 해당 항목을 교체합니다. 같은 미디어가 여러 곳에 있으면 가까운 원본 위치를 선택하며, 코드 예시 속 미디어는 수정하지 않습니다.
- 복사는 Markdown 이미지 참조 또는 동영상·지도 HTML을 클립보드에 넣습니다. 문서 보기에 붙여넣어 재사용할 수 있습니다. 이미지의 기존 픽셀 복사 기능도 유지됩니다.
- 사진·동영상의 찾아보기, 붙여넣기, 로컬 절대 경로 또는 Google Drive 파일 주소 입력은 현재 환경설정의 리소스 폴더 아래 media에 저장합니다.
- 원래 파일명을 유지하고 같은 이름은 선택한 파일 내용으로 덮어씁니다. Drive는 기존 파일 ID를 유지하여 다른 문서의 참조가 이어집니다.
- 일반 웹 이미지 주소와 YouTube·지도 임베드는 주소를 참조합니다. 지도에는 복사할 로컬 파일이 없습니다.
- 덮어쓴 파일의 표시 캐시를 갱신합니다. 실행 취소는 원고 변경에 적용되며 이미 덮어쓴 리소스 파일 내용은 이전 버전으로 되돌리지 않습니다.

검증: scripts/check-media.cjs(실제 저장 구현의 로컬 파일 덮어쓰기, 브라우저 저장, 모의 Drive 전송) 및 scripts/check-visual-editor.cjs --visual(미디어 삽입·교체·복사·실행 취소·문서 전환).


### 사진·동영상 찾아보기 시작 위치

현재 문서 연결이 Google Drive이면 cloud 환경설정의 리소스 폴더부터 Drive 탐색기를 엽니다. 로컬 연결에서는 local 환경설정의 리소스 폴더를 OS 파일 선택 창의 시작 위치로 지정합니다. 브라우저 로컬 모드는 연결된 폴더 핸들을 startIn으로 사용하며, 해당 API가 없는 경우 리소스 폴더 내부 탐색기를 사용합니다. 사진·동영상 확장자를 구분하고, 선택한 파일은 현재 리소스 저장 기능으로 복사합니다. 데스크톱의 새 찾아보기 IPC는 앱 전체 재시작 후 사용합니다.


### 표 헤더 정렬

표 헤더는 문서 보기와 미리보기에서 중앙 정렬됩니다. 표 삽입의 열 정렬 프리셋은 본문 셀에 적용됩니다. Markdown의 구분선과 원문은 유지되며, 렌더링된 헤더에는 중앙 정렬을 기록하여 내보내기에서도 같은 정렬을 전달합니다.


## 표·취소선·태그 인용문 직접 편집

- 표 넣기 버튼, 슬래시 명령, 환경설정의 표 단축키로 표 생성 모달을 엽니다.
- 기존 일반 Markdown 표도 셀을 클릭하여 수정할 수 있습니다. 헤더는 중앙 정렬하며 본문 열 정렬은 유지합니다.
- 셀에 들어가면 행·열 추가/삭제, 본문 열 정렬, 표 아래 본문, 표 삭제 도구가 나타납니다.
- Tab/Shift+Tab은 셀 이동입니다. 마지막 셀에서 Tab을 누르면 새 행이 생깁니다. Enter도 다음 셀로 이동합니다.
- 표 아래 본문으로 이동하여 표 뒤에 글을 이어 쓸 수 있습니다. 헤더 행과 마지막 열은 삭제하지 않으며, 표 전체 삭제는 별도 버튼을 사용합니다.
- 취소선 버튼, 설정된 단축키/슬래시 명령 또는 `~~텍스트~~` 입력을 지원합니다.
- 인용문 태그는 NOTE/TIP/IMPORTANT/WARNING/CAUTION 명령으로 작성·변경할 수 있습니다. 기존 `[!참고]` 같은 태그도 원문을 보존하여 읽습니다.
- 표·태그·취소선 수정은 Markdown 저장 및 실행 취소/다시 실행에 연결됩니다.
- 셀 병합, 셀 안 미디어·수식 등 복합 구문은 기존 원문 편집 방식을 사용합니다.

## 그림책 장면 직접 편집 (2026-10-13)

1. 그림책 서식이 적용된 문서에서 ‘문서 보기’를 선택한다.
2. 원하는 페이지 글 영역의 ‘본문 편집’을 누른다.
3. 제목·문단을 직접 입력하고 편집기 기본 서식 및 /명령어를 사용한다.
4. ‘편집 완료’를 누르면 조판 화면으로 돌아간다. 내용 변경은 기존 저장 흐름으로 반영된다.
5. ‘그림책 장면 편집’을 펼치면 추가·복제·위로·아래로·삭제를 사용할 수 있다.

한 번에 한 장면만 편집한다. 글이 넘치면 글 영역을 스크롤해 수정할 수 있으며, 자동으로 다음 페이지를 만들지 않는다. 넘침 안내를 확인하고 원고를 줄이거나 장면을 직접 추가한다. 현재 그림책의 우측 툴바·이모지 공통 연결은 후속 단계다.
