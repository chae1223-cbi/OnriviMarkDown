# 글꼴 내보내기와 Google Drive OAuth 점검

## 2026-10-04 적용

- PDF·HTML·EPUB에 문서에서 사용하는 웹 글꼴의 파일 데이터를 포함한다.
- PNG의 KaTeX 전용 글꼴 추출을 문서 글꼴 전체 추출로 교체한다.
- 글꼴 URL은 해당 CSS 파일을 기준으로 해석한다. 로컬 절대 경로 `/fonts/...`도 내보낸 결과에는 data URL로 포함한다.
- Unicode 범위가 있는 분할 글꼴은 문서에 있는 문자 범위를 포함한다.
- 비어 있는 파일, HTTP 실패, 글꼴 대신 반환된 HTML/JSON은 오류로 표시한다.
- 사용하지 않는 폴백 글꼴이나 글꼴 굵기의 과거 실패가 문서 전체 내보내기를 차단하지 않도록 검사한다.
- globals.css의 로컬 글꼴 경로 19개는 모두 public에 실제 파일이 존재한다.
- Google 로그인 팝업 지원을 위해 배포 _headers에 COOP same-origin-allow-popups를 설정한다.
- OAuth 응답의 오류 코드와 접근 거부/출처 불일치 안내를 표시한다.

## 적용 범위와 남은 확인

- 글꼴 선택창에서 Local Font Access로 읽은 사용자 글꼴 파일도 PDF·HTML·EPUB·PNG에 포함한다. 재실행 후에는 이미 허용된 권한으로만 목록을 다시 읽는다. 브라우저 미지원/권한 거부 시 자동 임베딩은 사용할 수 없다.
- 학교안심 OTF 표시 이름 3개를 실제 WOFF2 번들 파일에 연결했다. 사용자 글꼴의 영문 스타일 정보로 굵기/기울임을 매핑하며 특수 글꼴 컬렉션과 비표준 스타일은 실제 결과 확인이 필요하다.
- DOCX는 글꼴 이름을 기록하며 수신 PC의 글꼴 설치 여부에 영향을 받는다. Word 글꼴 파일 임베딩은 이번 수정 범위에 포함되지 않는다.
- 최초 글꼴 다운로드에는 연결이 필요하다. 인터넷 단절 자체를 해결하는 변경은 아니다.
- 저장소 테스트는 통과했지만 배포 웹과 설치된 데스크톱의 새 결과물을 실제 렌더링하는 검증이 필요하다.
