# 그림책 서식 사용방법

## 시작하기

1. 새 문서작성에서 저장할 폴더와 파일 이름을 지정한다.
2. 서식관리에서 ‘+ 그림책 · 전체 표지’ 또는 ‘+ 그림책 · 오른쪽 표지’를 눌러 내 서식으로 추가한다.
3. 서식관리의 ‘그림책’ 분류에서 생성한 서식을 선택한다. ‘서식 복제’로 변형 서식을 만들 수 있다. 서식 편집기의 ‘문서 배치’에서 표지, 그림 영역 비율, 그림 맞춤, 영역 간격, 페이지 번호를 조정하고 ‘현재 문서에 이 서식 적용’을 누른다.
4. 기존 용지 설정에서 용지 크기와 방향을 선택한다.
5. 미리보기의 ‘그림책 장면 편집’을 펼쳐 장면을 추가하고 원고를 작성한다.

서식은 기존 리소스 폴더의 `profiles/userCssProfiles.json`에 저장된다. 문서는 기존 MD 저장·자동 저장 기능을 사용한다. 그림을 Base64로 원고에 넣지 않고 사진 넣기를 통해 저장한 파일의 참조를 사용한다.

## 장면 문법

```markdown
:::scene {cover}
![표지 그림](media/cover.png)

# 책 제목

저자 이름
:::

:::scene
![장면 그림](media/scene-01.png)

본문을 작성합니다. **강조**, 목록, 인용문 등 Markdown을 사용할 수 있습니다.
:::
```

- `{cover}`는 첫 번째 표지 장면에만 사용한다.
- 장면의 첫 번째 독립된 Markdown 이미지가 그림 영역에 표시된다.
- 이미지 참조 정의(`[image1]: ...`)는 장면 밖에 둘 수 있다.
- 나머지 본문은 모두 장면 안에 넣는다. 장면 밖의 본문은 경고하며 PDF 출력을 막는다.
- 기존 원문을 자동으로 분할하거나 덮어쓰지 않는다. 서식 적용 후 장면 경계를 지정한다.
- 장면 편집에서 본문 수정, 장면 추가·삭제·위로 이동을 할 수 있다. 삭제는 확인 후 진행한다.

## PDF 출력

그림책은 한 장면당 한 페이지로 표시한다. 성능 저하로 자동 이어쓰기 기능은 제거했다. 본문이 넘치면 경고하고 PDF·EPUB 내보내기를 차단하므로 글을 줄이거나 글자 크기·줄간격·여백을 조정하거나 장면을 수동으로 나눈다.

- 웹: 브라우저 인쇄 창에서 ‘PDF로 저장’을 선택한다. 브라우저 머리글·바닥글은 끄고, 배경 그래픽은 켠다.
- 데스크탑: 기존 Chromium PDF 생성 경로로 파일을 저장한다.
- 그림책 페이지가 내부 여백을 이미 가지므로 PDF의 외부 인쇄 여백은 0으로 출력한다.

## 현재 범위와 제한

- 두 표지 배치, 본문 좌측 그림·우측 글, 용지·방향 선택, 넘침 검사, PDF 출력을 제공한다.
- 그림책 서식도 기존 JSON 가져오기·내보내기로 공유할 수 있다. 배경 이미지 패키지는 제공하지 않는다.
- 문서 메타에는 `css_profile`과 `css_profile_name`만 선언한다. 사용자 서식은 리소스 폴더의 `profiles/userCssProfiles.json`에서 ID로 찾아 읽으며, 시스템 서식은 내장 목록에서 찾는다. 서식 변경은 해당 서식을 사용하는 문서의 미리보기와 내보내기에 반영된다. 기존 `onrivi_picturebook_profile`은 서식 파일 저장 성공 후 제거하며 본문은 유지한다. 다른 기기에서는 동일한 리소스 폴더를 연결하거나 서식 JSON을 가져와야 한다. 메타 자동 접기는 사용하지 않는다.
- OS 글꼴은 기기마다 다를 수 있으므로 다른 기기에서 다시 출력할 때 확인한다.
- 그림책 EPUB은 장면별 XHTML 페이지와 EPUB 3 고정 배치 설정으로 내보낸다. 그림과 글의 위치를 유지하며, 고정 배치를 지원하는 뷰어에서 확인해야 한다. DOCX·HWPX는 그림책 내보내기 목록에서 제외하고 실행도 차단한다. 상품 소개 책은 아직 구현하지 않았다.

- 숨김 Edge에서 두 표지·가로/세로 용지·본문 넘침 검사 검증.
- 실제 PDF 내보내기 함수의 HTML로 2장 PDF를 생성하여 페이지 수와 텍스트 추출 확인.
- 기존 문서·참조 자료 전송 검사 9개 통과.
- 실제 사용자 Google Drive 계정과 모든 OS 글꼴 조합은 별도 확인이 필요하다.
