# AI 친화적 보고서 작성 지원

기준 자료: 사용자가 제공한 2026.8.24. 행정안전부 보도자료 「복잡한 표·그림 대신 고품질 텍스트로 행안부, 인공지능(AI) 친화적 보고서 전면 도입」.

이 기능은 해당 보도자료의 두 원칙(표·그림 구조 명확화, 보고서 맥락 명확화)에 대한 선택적 작성 지원입니다. 법령 준수 인증, 공식 공문 양식, 문서관리 시스템이 아닙니다. 요지·키워드 입력을 의무화하지 않습니다.

## 사용 방법

1. 서식 관리에서 **AI 친화적 보고서**를 선택합니다. 기존 기본서식과 기존 문서는 변경하지 않습니다. 용지·여백·글자 크기는 제품 기본값이며 보도자료가 지정한 수치가 아닙니다.
2. 표 삽입에서 표 제목과 번호를 입력합니다. 제목이 있으면 `**표 1. 추진 일정**`처럼 표 위에 원문으로 저장합니다. 기존 번호 다음 값을 제안하며, 재배치 후 번호는 직접 수정합니다. 제목이 없으면 기존 방식으로 표만 삽입합니다.
3. 이미지 삽입의 그림 제목·설명에 `그림 1. 업무 흐름`처럼 입력합니다. 기존 Alt 저장 방식을 사용합니다. 이 서식에서는 화면과 PDF·EPUB에서 그림 위에 표시하며, 별도의 제목/Alt 필드를 새로 도입하지 않았습니다.
4. 프롬프트 스튜디오의 **AI 친화적 보고서** 도메인에서 작성·정리·점검을 선택합니다. 기존 사용자 템플릿을 지우지 않습니다. 작성·정리는 사실·수치 보존과 서술식 문장을 안내하며, 점검은 원문을 바꾸지 않고 위치·이유·제안을 보고하도록 요청합니다. AI 결과는 적용 전에 확인합니다.
5. **AI 친화적 보고서** 서식은 제목 1~5에 `Ⅰ. → 1. → 가. → 1) → 가)` 번호를 자동 표시합니다. 제목 6은 번호가 없습니다. 사용자 서식에서는 **서식 관리 → 제목 위계 스타일 → 제목 번호 형식**에서 단계별로 선택하거나 **보고서 번호 적용**을 누릅니다. 기본 제공 서식을 수정하려면 복제한 사용자 서식에서 변경합니다.

## 제목 자동 번호

제목 태그(`#`~`######`)로 단계를 지정하고 제목 내용만 입력합니다. 같은 단계는 순서대로 증가하고 상위 제목이 바뀌면 하위 번호는 처음부터 시작합니다. 제목을 추가·삭제·이동하면 화면과 개요 목차가 다시 계산됩니다. 기존 제목 앞 번호를 선택한 형식과 순서로 갱신하며, 번호를 중복해서 붙이지 않습니다.

번호 설정은 서식에 저장하며 실제 번호·글머리기호도 마크다운 제목에 기록합니다. 예를 들어 `# Ⅰ. 업무 개선 계획`으로 저장하므로 다른 마크다운 도구에서도 표시됩니다. 번호 설정을 해제하면 적용 중이던 제목 앞 표시를 제거합니다. PDF·EPUB·DOCX·HWPX에는 번호를 실제 텍스트로 넣으며 EPUB 목차에도 반영합니다. 숫자 목록 설정과는 독립적입니다.

## 사용자 지정 제목 번호

제목 번호 형식에서 **사용자 지정**을 선택합니다. 표시 종류(숫자·로마자·가나다·글머리기호), 앞 문구, 뒤 문구를 조합합니다. 예를 들어 앞 문구 `제` + 숫자 + 뒤 문구 `장`은 `제1장`, 앞 문구 `(` + 가나다 + 뒤 문구 `)`는 `(가)`로 표시합니다. 글머리기호를 선택하면 `•`, `○`, `□`, `◆`, `※` 등 원하는 기호를 직접 입력할 수 있고, 같은 단계의 제목마다 동일한 기호를 사용합니다. 입력 아래에서 첫 세 표시를 미리 볼 수 있습니다. 설정은 서식에 저장되고 화면·개요 목차·내보내기에 동일하게 반영됩니다.

## 보고서 숫자 목록 작성

기존 숫자 목록의 보고서 번호 옵션도 그대로 사용할 수 있습니다. **글머리 & 숫자 목록 설정 → 숫자 목록 마커 → 보고서**에서 별도로 선택합니다. 숫자 목록을 만든 뒤 **Enter**로 다음 항목을 작성합니다. **Tab**은 한 단계 아래로, **Shift+Tab**은 한 단계 위로 이동합니다. 단계에 맞는 번호가 자동으로 표시됩니다.

| 단계 | 표시 예시 |
| --- | --- |
| 1 | Ⅰ., Ⅱ., Ⅲ. |
| 2 | 1., 2., 3. |
| 3 | 가., 나., 다. |
| 4 | 1), 2), 3) |
| 5 | 가), 나), 다) |
| 6 이상 | 1., 2., 3. |

마크다운 원문에는 일반 숫자 목록과 들여쓰기 구조를 저장하고, 선택한 서식으로 위 번호를 표시합니다. 따라서 해당 서식을 지원하지 않는 다른 마크다운 도구에서는 일반 숫자로 보일 수 있습니다. PDF·EPUB·DOCX·HWPX 내보내기에는 화면의 보고서 번호를 실제 텍스트로 포함합니다.

## 저장·출력 원칙

표와 그림을 금지하지 않습니다. 복잡한 병합이나 표 안의 표는 사용자가 확인할 대상으로 안내하며 자동으로 풀거나 삭제하지 않습니다. 장식과 강제 요약·FAQ를 추가하지 않습니다.

표 제목은 실제 원문이므로 다른 마크다운 도구에서도 읽을 수 있습니다. 상단 그림 캡션은 내보내기 복사본의 DOM 순서도 위로 옮겨 읽기 순서를 보존합니다. 원문이나 현재 화면의 요소 순서를 내보내기가 변경하지 않습니다. EPUB은 읽기 장치에 따라 페이지 배치가 달라집니다.
