# 인쇄 미리보기 출력용 페이지 나누기 구현계획

- 작성일: 2026-10-24
- 상태: 소스 구현 및 브라우저/PDF 검증 완료. 배포·데스크톱 설치본 반영 전.
- 제외 범위: 표 합치기

## 1. 목표와 원칙

인쇄 미리보기에서 사용자가 출력 경계를 지정하고 해제할 수 있게 한다. 표·목록·코드블록·인용문의 본문 구조는 변경하지 않는다.

- 표는 원본 마크다운에서 하나의 표로 유지한다.
- 출력 경계는 문서별 출력 설정으로 저장한다. 본문에 페이지 나누기 주석을 추가하지 않는다.
- 미리보기와 PDF·인쇄는 동일한 페이지 계산 결과를 사용한다.
- 화면 좌표나 페이지 번호가 아니라 원본 문서의 위치에 경계를 연결한다.
- 모달을 열거나 닫는 행위로 본문·선택영역·기존 나누기 설정을 변경하지 않는다.

## 2. 사용자 흐름

1. 인쇄/PDF 화면에서 쪽 윤곽 미리보기를 연다.
2. ‘페이지 나누기 조정’을 켠다.
3. 나눌 수 있는 행·항목·문단·코드 줄 사이에 마우스를 올리거나 키보드로 이동한다.
4. 해당 위치를 선택하고 ‘여기부터 다음 페이지’를 실행한다.
5. 미리보기를 다시 계산해 결과를 표시한다.
6. 지정된 경계에서 ‘나누기 해제’를 실행하면 자동 배치로 돌아간다.
7. ‘적용’하면 문서별 출력 설정에 확정한다. ‘취소’ 또는 Esc는 이번 조정만 폐기한다.

추가 동작:

- 조정 중 실행취소·다시실행 지원
- ‘출력용 나누기 전체 해제’는 이 기능으로 지정한 경계만 제거
- 적용 전 인쇄/PDF 실행 시 현재 조정안을 사용하고, 문서에 저장할지 여부는 적용 상태와 명확히 구분
- 문서 저장 시 확정된 출력 설정을 함께 저장하고, 저장 실패 시 성공으로 표시하지 않음
- 자동 페이지 경계와 사용자 지정 경계를 색·문구로 구별하고 기존 경계 표시 켜기/끄기 설정 존중

## 3. 요소별 동작

| 요소 | 지정 위치 | 출력 처리 | 원본 유지 사항 |
| --- | --- | --- | --- |
| 표 | 본문 행 사이 | 선택 행부터 다음 페이지에 배치하고 머리행 반복 | 표를 둘로 저장하지 않음 |
| 숫자·글머리·할 일 목록 | 항목 사이 | 선택 항목부터 다음 페이지에 배치 | 번호·계층·체크 상태 유지 |
| 코드블록 | 코드 줄 사이 | 선택 줄부터 다음 페이지에 배치 | 언어·들여쓰기·빈 줄·문자 유지 |
| 인용문·알림 상자 | 내부 문단 사이 | 선택 문단부터 다음 페이지에 배치 | 인용 계층·알림 유형 유지 |
| 일반 문단·제목 | 블록 앞 | 해당 블록부터 다음 페이지에 배치 | 문장과 제목 단계 유지 |
| 이미지·수식 등 단일 요소 | 요소 앞 | 요소 전체를 다음 페이지에 배치 | 이미지·수식 자체를 분할하지 않음 |

제약 처리:

- 표 셀 내부 텍스트를 임의로 절단하지 않는다.
- 세로 병합 셀이 걸쳐 있는 행 경계는 비활성화하고 이유를 표시한다.
- 한 행·이미지·수식이 출력 영역보다 큰 경우 명시적으로 알린다. 임의 축소·내용 삭제로 처리하지 않는다.
- 중첩 목록과 중첩 인용문은 부모 구조를 유지하며 출력용 복제본에서만 분할한다.
- 첫 콘텐츠 앞, 연속 경계, 기존 수동 경계와 같은 위치의 중복 지정은 빈 페이지를 만들지 않도록 정규화한다.

## 4. 출력 설정 저장과 위치 추적

기존 `documentPrintSettings.ts`는 워터마크 중심이므로 페이지 나누기 데이터를 해당 타입에 혼합하지 않는다. 별도 `documentPaginationSettings.ts`에서 버전이 있는 출력 배치 설정을 관리한다.

저장 방식:

- 문서 frontmatter의 전용 키 `onrivi_pagination`에 읽을 수 있는 구조로 저장
- 메타데이터 영역만 변경하며 본문 영역은 그대로 유지
- 새 문서는 임시 문서 ID로 관리하고, 다른 이름으로 저장할 때 설정을 함께 이전
- localStorage만 사용하는 방식은 피하여 다른 PC에서도 문서와 함께 복원
- 다른 Markdown 도구는 이 설정을 무시할 수 있으며 같은 페이지 배치를 보장하지 않음

각 경계에 필요한 데이터:

- 경계 ID와 설정 버전
- 요소 유형 및 원본 블록 경로
- 표 행·목록 항목·코드 줄·인용문 문단의 상대 위치
- 대상 내용·주변 문맥·상위 제목·컨테이너 유형을 조합한 위치 지문

편집 후 복원:

1. 미리보기를 계산할 때 현재 문서에서 위치 지문을 다시 해석한다. 변하기 쉬운 문자 오프셋을 고정 저장하지 않는다.
2. 재열기 시 구조·위치·주변 내용을 함께 비교한다.
3. 위치가 이동했어도 하나의 대상이 확실하면 연결을 유지한다.
4. 삭제되었거나 같은 내용이 반복되어 대상이 모호하면 ‘위치 확인 필요’로 표시하고 출력에 자동 적용하지 않는다.

고정 페이지 번호, 화면 픽셀, 전체 문서 내용 해시 하나만으로 위치를 저장하지 않는다.

## 5. 렌더링 구조

```text
원본 마크다운 + 확정/조정 중 출력 배치 설정
  → 원본 위치가 연결된 출력용 DOM 복제본
  → 사용자 지정 경계 반영
  → 동일한 용지·여백·서식으로 페이지 계산
  → 인쇄 미리보기 / PDF / 인쇄
```

- 본문 에디터의 ProseMirror 문서에는 분할 트랜잭션을 보내지 않는다.
- 표·목록 등에서 CSS 경계만으로 정확히 나뉘지 않으면 출력용 DOM 복제본을 분할한다.
- 출력용 표에만 머리행을 복제하고, 목록은 시작 번호와 중첩 상태를 보정한다.
- 코드블록 출력 분할 시 문법 강조 요소와 줄 위치를 연결한다. 코드 문자를 수정하지 않는다.
- 인용문 복제 시 기존 클래스·속성을 유지하되 DOM ID 중복을 제거한다.
- 사용자가 지정한 경계를 먼저 적용하고 각 구간 안에서 자동 페이지 배치를 수행한다.
- 미리보기의 분할된 DOM 요소에도 원본 ID를 유지하여 경계를 다시 선택·해제할 수 있게 한다.
- 페이지 계산 캐시에 배치 설정을 포함한다. 이전 작업은 취소하고 최신 결과만 표시한다.
- 글꼴·이미지 준비 후 계산하며 용지·여백·서식 변경 시 재계산한다.

## 7. 기존 문서와 최근 구현의 처리

- 기존 페이지 나누기 주석은 계속 지원한다.
- 새 출력 설정과 기존 주석이 같은 위치를 가리키면 한 번만 나눈다.
- 에디터의 직접 나누기 명령·슬래시 메뉴·가위 버튼은 제거한다. 경계 지정·해제는 인쇄 미리보기에서 수행한다.
- 이미 둘로 저장된 표·목록은 자동으로 합치지 않는다. 이번 범위에 복구·합치기 기능은 포함하지 않는다.
- 문서를 열었다는 이유로 기존 본문이나 설정을 자동 변환하지 않는다.

## 8. 적용 범위

- 웹과 데스크톱에 같은 출력 배치 기능을 제공한다.
- 1차 대상은 PDF 및 인쇄, 해당 쪽 윤곽 미리보기이다.
- 일반 문서보기는 원본 구조를 유지한다. 실제 페이지 모양이 필요하면 쪽 윤곽 미리보기를 사용한다.
- 가변형 EPUB에는 고정 페이지 경계를 강제로 적용하지 않는다. 고정형 EPUB 연계는 출력 엔진 호환성을 검토한 뒤 별도 범위로 정한다.
- 그림책 전용 출력 경로는 기존 동작을 유지하고 이번 일반 문서 기능과 분리한다.

## 9. 구현 순서와 완료 기준

### 1단계 — 설정과 출력 위치 모델

- 버전형 설정 스키마와 frontmatter 읽기·쓰기 구현
- 원본 위치와 출력 DOM의 연결 구현
- 본문 불변, 설정 재열기, 위치 이동·모호성 처리 테스트 통과

### 2단계 — 출력 엔진

- 표 행·목록 항목·일반 블록 경계부터 구현
- 코드 줄·인용문·중첩 구조와 단일 요소 앞 경계로 확장
- 빈 페이지·중복 경계 방지, 표 머리행·목록 번호 보존 테스트 통과

### 3단계 — 미리보기 조정 UI

- 마우스·키보드 위치 선택, 지정·해제, 실행취소·다시실행 구현
- 적용·취소·Esc·탭 전환 시 조정 상태 처리
- 모달 재열기 및 문서 재실행 시 설정 복원 확인

### 4단계 — PDF·인쇄 및 회귀 검증

- 미리보기와 PDF의 페이지 수·경계·용지·여백 일치 확인
- 긴 표, 긴 코드, 중첩 목록·인용문, 이미지, 기존 수동 주석 혼합 문서 검증
- 실제 웹 실행과 패키징된 데스크톱 실행에서 확인

최종 수용 조건:

1. 지정·해제·취소 과정에서 원본 본문과 표 개수가 바뀌지 않는다.
2. 출력용 경계를 해제하면 원본을 기준으로 다시 자동 배치된다.
3. 조정한 위치와 출력 설정이 문서 저장·재열기 후 유지된다.
4. 행·항목·코드·인용 내용의 누락과 의도하지 않은 중복이 없다. 반복 머리행은 예외이다.
5. PDF와 미리보기의 경계가 일치하고 연속 경계로 빈 페이지가 추가되지 않는다.
6. 대상을 확정할 수 없는 경계는 사용자가 확인할 수 있으며 임의 위치에 적용되지 않는다.
7. 테스트 통과와 실제 배포·설치 반영 상태를 구분해 보고한다.

## 10. 구현 및 검증 기록

- 별도의 가위 버튼과 `/pagebreak` 명령은 제거하고, 인쇄 버튼의 쪽 윤곽 미리보기에서 출력 경계를 조정한다.
- 인쇄 미리보기의 `+`로 지정하고 `×` 또는 지정 목록의 해제로 제거한다.
- 미리보기를 열면 출력 형식·워터마크 설정을 기본으로 접는다. 필요한 경우 `출력 설정 펼치기`로 다시 연다.
- 전체 페이지 목록, 이전·다음·페이지 번호 이동, 페이지 전체 맞춤·너비 맞춤·배율 선택, 크게 보기로 전체 문서를 관리한다.
- 보기 배율은 미리보기 iframe에만 적용하며 출력 크기나 원본은 변경하지 않는다. 축소 상태에서도 조정 버튼 크기를 유지하고 인접 버튼의 겹침을 피한다.
- 미리보기 iframe에 독립적인 세로 스크롤 영역을 제공한다. 마우스 휠·스크롤바로 모든 페이지에 접근하며, 조정 모드 변경 시 보던 스크롤 위치를 유지한다.
- 문서에 적용한 설정은 frontmatter의 `onrivi_pagination`에 저장된다. 실제 파일에 보관하려면 문서를 저장한다.
- 적용하지 않은 조정은 현재 출력에 사용할 수 있으며 취소·Esc·모달 재열기 시 폐기된다.
- 위치를 복원할 수 없는 경계나 용지보다 높은 표 행·그림·수식이 있으면 안내하며, 확인 없이 출력 경계를 무시하고 PDF를 만들지 않는다.
- 가변형 EPUB·그림책 출력 및 기존에 직접 분리된 표의 합치기는 이번 변경에 포함하지 않는다.

검증 스크립트:
