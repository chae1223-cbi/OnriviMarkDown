# HELP-01 전체 붙여넣기 점검

기준일: 2026-10-12

## 비교 자료

- 기준 원고: `frontend/public/help/HELP-01_온리비_어서_소개와_시작하기.md`
- 비교 자료: 사용자가 첨부한 문서보기 테스트 결과. 메타데이터가 본문에 중복되고 제목·링크·인용문·목록·코드에 역슬래시 및 중복 강조가 추가되어 있었다.
- 도움말 원본의 내용은 수정하지 않았다.

## 원인과 조치

| 원인 | 조치 |
|---|---|
| `---`로 시작하는 원고가 Markdown 붙여넣기에서 제외됨 | 메타데이터가 있는 원고 전체도 Markdown으로 처리 |
| 클립보드의 문법 색상용 HTML을 본문 서식으로 해석 | Markdown으로 판별되는 원문 텍스트를 HTML보다 우선 |
| 붙여넣은 블록의 원래 문자열 연결이 사라져 전체를 재직렬화 | 새로 가져온 블록의 원문 연결도 보존 |
| 문서 바깥에 보관한 메타데이터는 실행 취소에서 제외됨 | 문서 모델의 속성에 보관해 붙여넣기·실행 취소와 함께 변경 |
| 알림의 `[!참고]`가 일반 글로 변환되면서 기호가 이스케이프됨 | 원문을 보존하고 읽기용 알림으로 표시 |
| 코드 예제의 `> [!팁]`을 실제 알림으로 오인할 가능성 | 파싱된 인용문 토큰에서만 알림을 판별 |

## 확인한 결과

- 빈 문서의 기본 서식 메타데이터가 있는 상태에서 원고 전체를 붙여넣으면 저장된 MD가 원본과 문자 단위로 일치한다.
- 전체 선택 후 같은 원고로 교체해도 메타데이터가 중복되지 않는다.
- 붙여넣기 실행 취소는 이전 본문과 메타데이터를 복원한다. 다시 실행은 가져온 원고 전체를 복원한다.
- 클립보드에 잘못된 제목 강조 HTML과 이미지가 함께 있어도 원본 Markdown을 사용한다.
- 제목, 목록, 한글 파일명 링크, 두 코드 예제, 표의 4개 데이터 행, 알림 블록을 브라우저에서 확인했다.
- 표·알림은 읽기용으로 표시하며, 원문 수정은 Markdown 보기에서 한다.
- 기존 제목·강조 경계, Ctrl+Space, 기존 아이콘 툴바·슬래시 메뉴 검사도 함께 통과했다.

검사 명령: `node scripts/check-visual-editor.cjs --visual`

이미 손상된 기존 결과에 역슬래시를 일괄 제거하면 코드 예제나 의도된 기호까지 바뀔 수 있다. 이 테스트 원고는 첨부된 정상 HELP-01 원본으로 다시 붙여넣어 확인한다.
