# 수원 1박 2일 도보 여행 — 오른쪽 그림 그림책 제작 프롬프트

당신은 여행 에세이 작가이자 그림책 편집자입니다. 수원 1박 2일 도보 여행을 성인 독자가 즐길 수 있는 감성 여행 그림책으로 각색해 주세요. 아래 규칙에 맞춰 완성 원고와 이미지 제작 지시서를 작성하세요.

## 1. 독자와 여행 동선

- 독자: 주말에 걷기 여행을 즐기는 성인, 처음 수원을 방문하는 여행자.
- 여행 형태: 수원 1박 2일 도보 여행.
- 1일 차: 화성행궁 → 행리단길 → 장안문 → 화홍문·방화수류정 → 창룡문 → 수원 통닭거리.
- 2일 차: 팔달문 → 못골 종합시장 → 팔달산 서장대 숲길.
- 도보로 만나는 빛, 바람, 골목의 향기와 역사적 풍경을 하나의 여정으로 연결하세요.
- 실제 방문한 체험담이나 현지인의 발언을 만들어 사실처럼 제시하지 마세요. 개장 시간, 요금, 출입 가능 여부 등 변동 정보는 확인하지 않았다면 단정하지 마세요.

## 2. 페이지 배치

- A4 가로, 한 페이지에 왼쪽 글·오른쪽 그림으로 구성합니다.
- 표지와 모든 본문 페이지에 동일한 좌우 배치를 적용합니다.
- 좌우 영역은 약 1:1이며, 용지 여백과 영역 사이 간격을 고려합니다.
- 페이지마다 핵심 장소 또는 순간을 하나만 다룹니다.
- 그림은 세로형 3:4를 기본 제작 비율로 제안합니다. 정확한 비율은 최종 그림 영역에 맞춰 조정할 수 있습니다.
- 중요한 피사체는 가장자리에서 떨어뜨리고, 그림 영역에 맞춰 잘라도 장소의 특징이 남도록 구성합니다.
- 그림에 제목, 캡션, 로고, 워터마크, 문자를 넣지 마세요. 제목과 설명은 왼쪽 글 영역에 배치합니다.

## 3. 원고 분량과 문체

- 각 본문 페이지: 짧은 제목 1개, 본문 2~3문단, 한 줄 여행 팁 1개.
- 본문은 한글 기준 공백 포함 약 250~400자로 작성합니다. 이는 초안 기준이며 실제 조판에서 넘치면 줄이거나 페이지를 나눕니다.
- 제목은 가급적 20자 안팎으로 간결하게 작성합니다.
- 부드럽고 다정한 ‘~합니다’, ‘~해보세요’ 문체를 사용합니다.
- 한 페이지에 감각적 묘사 1~2개와 장소를 이해하는 핵심 정보만 담습니다.
- 긴 역사 설명, 큰 표, 여러 항목의 목록, 큰 인용문 박스는 넣지 마세요.
- 기존 원고의 ‘이미지 삽입 권장 위치’ 블록은 본문에 넣지 않습니다. 이미지 제작 지시서는 원고와 분리합니다.
- 여행 팁은 짧고 실행 가능하게 작성하되, 확인되지 않은 출입이나 이용을 권하지 마세요.

## 4. 전체 구성: 13페이지

1. 표지: 책 제목, 짧은 부제, 저자 자리표시자. 오른쪽 그림은 수원 여행을 대표하는 풍경.
2. 프롤로그: 두 발로 수원을 만나는 이유.
3. 화성행궁: 회랑과 기둥 사이로 만나는 고궁의 빛.
4. 행리단길: 낮은 지붕과 작은 가게가 이어지는 골목.
5. 장안문: 성문과 옹성의 웅장함.
6. 화홍문·방화수류정: 수원천의 물길과 용연 주변의 휴식.
7. 창룡문: 잔디 언덕과 저녁빛.
8. 수원 통닭거리: 하루의 끝을 채우는 먹거리와 거리의 온기.
9. 팔달문: 도심 속에서 만나는 남쪽 성문.
10. 못골 종합시장: 시장 골목의 활기와 소박한 먹거리.
11. 서장대 숲길: 팔달산에서 바라보는 수원의 풍경.
12. 여정 정리: 이틀의 동선과 편한 신발, 가벼운 짐, 휴식에 관한 짧은 안내. 표 없이 간결한 문단으로 작성.
13. 에필로그: 여행을 마친 발걸음에 남는 여운.

## 5. 출력 A — 조판용 Markdown 원고

설명이나 이미지 제작 지시 없이 원고만 하나의 Markdown 코드 블록으로 출력하세요. 한 페이지는 반드시 하나의 `:::scene` 블록으로 작성합니다.

첫 이미지는 해당 페이지의 그림입니다. 이미지가 코드에서 먼저 나와도 화면의 오른쪽 배치는 서식이 결정합니다. `:::scene {cover}`는 표지에만 사용하세요. 지원 여부가 확인되지 않은 `image-right` 같은 장면 속성을 임의로 추가하지 마세요.

예시:

```markdown
:::scene {cover}
![수원 여행 표지](media/suwon-cover.png)

# 두 발로 만나는 수원

성곽과 골목을 잇는 1박 2일 여행

저자: [저자 이름]
:::

:::scene
![화성행궁 회랑](media/suwon-02-haenggung.png)

## 기둥 사이로 흐르는 빛

첫 번째 짧은 문단.

두 번째 짧은 문단.

**여행 팁:** 한 줄 안내.
:::
```

- 장면 밖에 설명이나 원고를 덧붙이지 마세요.
- `css_profile` ID는 사용자가 실제 서식을 선택할 때 앱에서 넣습니다. ID나 전체 서식 JSON을 만들어 넣지 마세요.
- 이미지 경로는 제작 예정 파일의 자리표시자입니다. 이미지를 생성하거나 저장했다고 주장하지 마세요. 실제 파일을 넣은 뒤 경로를 맞춰야 합니다.
- 표지 외 페이지의 그림도 오른쪽에 배치하도록 서식 설정이 준비되어 있다는 전제로 원고를 구성하세요.

## 6. 출력 B — 페이지별 이미지 제작 지시서

원고 코드 블록 밖에 별도 표로 작성하세요. 열은 ‘페이지’, ‘파일명’, ‘장소·장면’, ‘이미지 생성 프롬프트’로 구성합니다.

각 이미지 생성 프롬프트에 다음 내용을 포함하세요.

- 해당 페이지 본문과 정확히 연결되는 장면.
- 건물·성문·회랑·연못 등 장소의 식별 요소.
- 구도, 시점, 시간대, 빛, 색감, 분위기.
- 책 전체에 통일되는 따뜻한 여행 일러스트 스타일.
- 세로형 3:4, 주요 피사체 가장자리 여유, 문자·로고·워터마크 없음.
- 실제 장소를 과장하거나 다른 궁궐·성문과 혼동하지 않도록 하는 지시.

지금 위 규칙에 맞춰 13페이지 완성 원고와 13개 이미지 제작 지시서를 작성하세요.
