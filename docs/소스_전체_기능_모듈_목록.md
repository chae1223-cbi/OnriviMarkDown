# 온리비어서 소스 전체 기능·모듈 목록

- 기준: 2026-10-30 현재 작업 폴더의 소스. 실행·화면 검증 전이므로 **소스 존재**와 **기능 완료**를 구분한다.
- 목적: 기능별 분석 출발점과 GitHub 이슈 분류 기준을 제공한다. 세부 함수 목록은 분석할 기능을 정한 뒤 추가한다.
- 제외: `node_modules`, 빌드 산출물, 이미지·도움말 원본 등 비실행 자산.

## 3. 관리자 화면 세부 목록

`frontend/src/app/admin/components/` 기준: 사용자, 구독·기기, 요금제, 관리자 계정, 감사 로그, 시스템, 공통 코드, 콘텐츠, 도움말, 문의, FAQ, 프로모션, 블로그, OTP 초기화 및 각종 상세 모달. 각 화면의 서버 대응은 `frontend/src/app/api/admin/`과 `functions/api/admin/` 두 경로를 비교해야 한다. 같은 이름의 파일이 있다고 동작이 같다고 판단하지 않는다.

## 4. 현재 MCP 도구 목록

`plugins/onrivi-author/server/index.mjs`에 선언된 도구: `get_current_folders`, `list_workspace_files`, `search_workspace`, `read_markdown`, `create_markdown`, `replace_markdown`, `edit_markdown_section`, `list_style_profiles`, `create_style_profile`, `update_style_profile`. 실제 사용 가능 범위는 `context.mjs`, `authorization.mjs`, `workspace.mjs` 검사 결과에 따른다.

## 5. 분석 우선순위와 결과 기록

1. **P0 편집·저장**: M01–M07. 문서 손실과 선택/커서 오류를 먼저 확인한다.
2. **P1 외부 연동·권한**: M08, M12–M16. 인증, 라이선스, 경로·쓰기 권한을 확인한다.
3. **P1 입출력**: M09–M11. 대표 문서로 가져오기·내보내기 결과를 비교한다.
4. **P2 운영·배포**: M17–M18. 웹/데스크톱 API 차이와 빌드 검사를 확인한다.

분석 결과는 모듈 ID별로 `현재 동작 / 주요 파일 / 데이터 흐름 / 위험 / 재현 방법 / 이슈 링크 / 검증 상태`를 기록한다. 이 목록은 파일명과 경로를 기준으로 한 **탐색 지도**이며, 요구사항 충족이나 테스트 통과를 뜻하지 않는다.
