# Google Drive 작업장 선택 설정

연결 버튼은 마지막 작업장을 우선 복원한다. 폴더 변경은 파일 메뉴의 `작업장 폴더 열기`에서 진행한다. 선택창은 현재 폴더에서 시작하며 `OnriviAuthor/작업장`보다 위로 이동할 수 없다. 선택 취소 시 기존 작업장을 유지한다.

현재 작업장 선택은 앱 내부 선택창을 사용하며 아래 Picker 설정 없이 사용할 수 있다. 공식 Google Picker를 사용하는 별도 기능을 연결할 경우 다음 공개 환경변수가 필요하다. 정적 빌드는 설정 후 다시 빌드해야 한다.

```
NEXT_PUBLIC_GOOGLE_PICKER_API_KEY=<Google Cloud API 키>
NEXT_PUBLIC_GOOGLE_PROJECT_NUMBER=<OAuth 클라이언트와 같은 프로젝트의 숫자 프로젝트 번호>
```

해당 Google Cloud 프로젝트에서 Google Picker API 및 Google Drive API를 활성화한다. API 키는 실제 사이트의 HTTP 리퍼러와 필요한 API로 제한하고 OAuth 클라이언트에는 사이트 출처를 등록한다. 프로젝트 번호는 문자열 프로젝트 ID가 아니다.

`drive.file` 권한은 앱이 생성하거나 사용자가 앱에 접근을 허용한 파일에 한정된다. 폴더 선택이 폴더 안의 모든 기존 문서 접근을 자동으로 허용하는 것으로 가정하지 않는다. 기존 외부 문서를 여는 기능은 별도 파일 Picker로 권한을 부여하는 흐름이 필요하다.

리소스 폴더는 기존 `OnriviAuthor/참조파일`을 사용한다. 작업장 선택은 문서 저장 대상만 변경한다. 공유 폴더는 파일 생성 권한을 확인한 후 연결한다.

공식 참고: https://developers.google.com/workspace/drive/picker/guides/web-picker
# 마지막 작업 환경 복원 (2026-10-03)

- 로컬에서 `내 구글 드라이브 연결`을 누르면 마지막 드라이브 작업장을 검증한 뒤 바로 연결합니다.
- 첫 연결이거나 기존 작업장 경로가 삭제·변경되어 복원할 수 없으면 폴더 선택창을 표시합니다.
- `작업장 폴더 열기`는 현재 저장소의 폴더 선택창을 표시하여 작업장을 변경합니다.
- 드라이브 연결 해제 시 마지막 로컬 작업장, 저장소 종류, 참조파일 경로와 브라우저 폴더 접근 정보를 복원합니다.
- 같은 앱 사용 중에는 저장소별 문서 탭과 현재 문서도 복원합니다. 앱 재시작 후 별도 탭 복원은 기존 세션 복원 기능의 범위를 따릅니다.
- 미저장 드라이브 문서가 있으면 해제를 중단하고 저장 안내를 표시합니다. 브라우저 폴더 권한이 만료된 경우 접근 허용이 필요합니다.
- 연결 해제 후 인증 토큰은 제거하지만 마지막 작업장 정보는 유지합니다. 다른 계정의 폴더를 잘못 복원하지 않도록 현재 계정의 작업장 루트 내부 경로를 확인합니다.
