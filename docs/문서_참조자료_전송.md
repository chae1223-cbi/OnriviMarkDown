# MD와 참조 자료 복사

파일 → 다른 이름으로 저장의 하위 메뉴에서 로컬 또는 개인 Google Drive를 선택한다. 편집 중인 내용의 스냅샷을 저장하고 완료되면 열린 문서와 자동 저장 대상을 새 파일로 전환한다. 원본 파일은 유지한다.

## Google Drive에서 내 컴퓨터로

1. Drive의 MD 문서를 연다.
2. 파일 → 다른 이름으로 저장 → 내 컴퓨터(로컬)에 저장을 선택한다.
3. 파일 이름을 입력하고 MD를 저장할 로컬 폴더를 선택한다.
4. 이미지는 로컬 설정의 리소스 폴더 아래 media에, 다른 참조 자료는 해당 하위 폴더에 저장한다. 로컬 리소스 폴더가 없으면 선택을 요청한다.
5. 대상 MD의 참조 경로를 로컬 위치로 바꾼 뒤 선택한 폴더에 저장한다.

## 내 컴퓨터에서 Google Drive로

1. 로컬 MD 문서를 연다.
2. 파일 → 다른 이름으로 저장 → 개인 Google Drive에 저장을 선택하고 파일 이름을 입력한다.
3. 인증이 필요하면 Google 계정에 연결한다.
4. OnriviAuthor 또는 그 하위 폴더를 선택한다. 선택창에서 폴더를 만들 수도 있다.
5. 참조 자료를 Drive에 설정된 참조 폴더에 복사하고 대상 MD에 Drive 파일 ID를 반영한다.

## 동명 파일과 실패 처리

- 같은 이름과 내용의 MD는 재사용한다. 내용이 다르면 번호를 붙인다.
- 로컬 참조 파일은 내용이 같으면 재사용하고 다르면 번호를 붙인다. Drive 참조 파일은 내용 체크섬이 같으면 재사용한다.
- 참조 자료가 하나라도 실패하면 대상 MD 저장을 중단한다. 이미 복사된 참조 자료는 유지하며 메뉴를 다시 실행하면 재시도할 수 있다.
- 전송은 복사 기능이며 삭제나 자동 양방향 감시는 수행하지 않는다.
- 같은 저장소에 다른 이름으로 저장하면 현재 폴더를 기본 위치로 제시하고 참조 자료와 링크를 유지한다.
- 저장 중 원고가 변경되거나 탭이 바뀌면 새 파일은 저장하되 현재 편집 문서의 위치는 전환하지 않는다.

## 지원 범위와 확인

- 본문의 Markdown 링크·이미지, 참조 정의, HTML src/href를 확인한다. 코드 예제는 변경하지 않는다.
- 리소스 폴더의 media·profiles·prompt·bible·db 경로와 media://local/serve, driveId 링크를 처리한다.
- 외부 웹 링크는 그대로 유지한다. 내장 data/blob 이미지와 참조 폴더 밖의 파일은 안내 후 중단한다.
- 웹의 로컬 저장은 폴더 접근 기능을 제공하는 Chrome·Edge와 사용자 권한이 필요하다.
- 자동 검증: node --test scripts/check-document-transfer.cjs (9개 통과).
- 실제 계정 인증·Drive API·로컬 폴더 권한을 포함한 왕복 사용 확인은 별도로 필요하다.
