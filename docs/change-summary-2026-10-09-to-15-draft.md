# Onrivi Author 최근 일주일 변경사항 안내 — 초안

대상 기간: 2026년 10월 9일~10월 15일

안녕하세요.

최근 일주일 동안 Onrivi Author의 문서 편집과 그림책 제작 기능을 보완하고, Google Drive 연결 및 저장 안정성을 개선했습니다. 주요 변경사항을 안내드립니다.

## 1. 문서 직접 편집 개선

- 문서보기에서 본문을 직접 편집하는 기능과 기존 단축키·서식 도구 연결을 보완했습니다.
- 나란히 보기에서 문서보기와 마크다운 사이의 스크롤·커서 위치 동기화를 개선했습니다.
- 입력, 문서 열기 및 저장 과정의 화면 흔들림과 불필요한 화면 갱신을 줄였습니다.
- 한글 조합, 문장 끝 공백·줄바꿈, 환경설정에 따른 탭의 공백 입력을 보완했습니다.
- 제목, 번호 목록, 일반 목록, 체크리스트의 적용·해제와 여러 항목 선택 처리를 개선했습니다.
- 인용문 안에서는 Enter로 다음 줄을 입력하고, Ctrl+Enter로 인용문 밖으로 나가도록 조정했습니다.

## 2. 그림책 제작과 장면 편집

- 표지와 장면별로 이미지·본문을 구성하는 그림책 편집 기능을 추가·보완했습니다.
- 장면 추가, 복제, 순서 변경, 삭제 및 현재 장면 뒤에 새 장면을 추가하는 기능을 정비했습니다.
- 장면 목록에서 해당 장면으로 이동하고, 장면에서 목록으로 돌아갈 수 있도록 했습니다.
- ‘본문 편집’에서 오른쪽 서식 도구, /명령어, 단축키를 사용할 수 있도록 연결했습니다.
- 장면 원고 입력의 한글 조합 문제와 편집 시작 시 화면 위치가 바뀌는 현상을 보완했습니다.
- 장면 목록과 본문 편집을 오갈 때 명령이 이전 입력칸에 적용될 수 있는 문제를 보완했습니다.

## 3. 이미지·표·코드 사용성 개선

- 그림책에 이미지 파일을 붙여넣거나 끌어 놓으면 장면의 대표 이미지를 교체하도록 정비했습니다.
- 붙여넣은 새 이미지의 파일명과 실제 삽입 경로가 일치하도록 보완했습니다.
- 그림책 이미지 복사 시 주소 대신 이미지 데이터를 클립보드에 복사하도록 개선했습니다.
- Markdown 이미지 주소를 감싼 `< >`가 로컬 파일 경로에 남아 이미지를 찾지 못하는 오류를 수정했습니다.
- 코드 블록 간 여백과 긴 줄의 가로 스크롤을 개선하고, 코드와 표 복사를 지원하도록 보완했습니다.
- 새 표를 만들면 첫 번째 헤더 내용을 바로 바꿀 수 있도록 선택·포커스 처리를 개선했습니다.
- Mermaid 다이어그램 렌더링 오류와 수식 관련 편집·표시 동작을 보완했습니다.

## 4. 그림책 원고 점검 안내 개선

- 장면 밖에 있는 본문을 발견하면 어느 장면 앞·사이·뒤인지, 원문 행 번호와 본문 일부를 표시합니다.
- 문서 메타정보는 검사 대상에서 제외하고, 실제 장면 밖 본문은 계속 확인합니다.
- 문제 본문을 펼쳐 확인하고 복사·편집할 수 있으며, 관련 장면으로 이동할 수 있습니다.
- 문제 본문 표시의 글자 크기와 명암 대비를 높였습니다.
- 문제 본문을 수정·삭제할 때 문서 메타정보와 기존 장면이 보존되도록 했습니다.

## 5. Google Drive 연결과 작업 내용 보호

- 토큰 만료 전 미저장 문서를 저장하고, 인증 만료·저장 실패에 대비해 로컬 초안을 보존하는 처리를 보완했습니다.
- 같은 인증 만료 안내가 여러 번 표시되지 않도록 줄이고, 재연결 후 이전 경고를 제거하도록 했습니다.
- 웹과 데스크톱에서 사용할 서버 OAuth 콜백 및 갱신 토큰 기반 자동 연장 경로를 구현했습니다.
- 자동 연장은 만료 3분 전부터 1초 전까지, 화면이 보이고 최근 1분 안에 입력·클릭·스크롤 등의 활동이 있을 때 시도합니다.
- 갱신 전에 문서 저장 완료를 확인하고, 미사용 중에는 자동 연장을 하지 않습니다. 미사용 상태에서도 만료 전 저장은 시도합니다.
- 갱신 토큰은 서버에 암호화해 보관하고, 데스크톱의 연결 정보는 운영체제 암호화 저장소를 사용하도록 했습니다.

## 6. 문서 관리·도움말·운영 도구

- 새 문서 생성 시 폴더·파일명을 지정하는 화면, 탭의 새 문서 버튼과 이름 변경 기능을 보완했습니다.
- TXT 문서의 마크다운 변환, 출판용 특수문자 등 작성 보조 기능을 추가·정비했습니다.
- 탐색기 스크롤과 사이드바 크기 조절 등 화면 사용성을 개선했습니다.
- 도움말 내용과 문서 연결, 관리자에서 도움말을 관리·게시하는 흐름을 정비했습니다.
- 운영 로그와 관리자 화면의 조회·표시 및 가독성을 보완했습니다.
- 데스크톱 빌드 과정에서 웹 전용 경로가 누락되는 문제를 보완하고, 실행 중인 개발 서버와 빌드의 충돌을 막는 확인 절차를 추가했습니다.

## 7. 검증 및 적용 시 참고사항

- 주요 수정 사항에 대해 개별 동작 검사와 TypeScript 검사를 수행했습니다. 모든 기능의 전체 통합 테스트가 완료됐다는 의미는 아닙니다.
- 약 1시간 동안 실행할 수 있는 통합 테스트 시나리오, 예제 문서·이미지·영상 및 결과 기록 양식을 준비했습니다.
- Google Drive 자동 연장은 모의 인증 검사와 로컬 인증 시작 경로를 확인했습니다. 실제 Google 계정으로 운영 환경에서 장시간 사용하는 검증은 별도로 필요합니다.
- 자동 연장을 사용하려면 운영 서버 배포 및 데스크톱 업데이트 후 Google Drive를 최초 한 번 다시 인증해야 합니다.
- 네트워크 장애나 Google 권한 취소 시에는 저장·연장이 실패할 수 있으며, 이 경우 로컬 초안을 보존하고 재연결을 안내합니다.

이번 변경은 문서를 작성하고 그림책을 구성하는 과정에서 편집 흐름을 자연스럽게 만들고, 작업 내용이 안전하게 유지되도록 하는 데 중점을 두었습니다.

감사합니다.
