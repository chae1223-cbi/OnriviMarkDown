# 나의 이야기를 한 권의 책으로
이 책에는 내가 살아온 날들과 소중하게 간직한 기억을 담았습니다. 화려한 표현보다 내 말로 솔직하게 이야기를 적어 보려 합니다.
## 1장. 오래 기억하고 싶은 하루
### 그날의 풍경
아침 햇살이 창문으로 들어오던 날이었습니다. 따뜻한 차 한 잔을 앞에 두고, 오래된 사진첩을 펼쳤습니다.
사진 속에는 젊은 날의 나와 반가운 사람들이 있었습니다. 그때 나누었던 말과 웃음이 조금씩 떠올랐습니다.
### 기억을 적는 순서
1. 언제, 어디에서 있었던 일인지 적습니다.
2. 함께 있었던 사람을 떠올립니다.
3. 가장 기억에 남는 장면을 적습니다.
4. 지금의 마음을 한두 문장으로 덧붙입니다.
> 기억이 정확하지 않아도 괜찮습니다. 내가 느꼈던 마음부터 천천히 적어 보세요.
## 2장. 내가 좋아하는 것들
일상에서 즐거움을 주는 작은 습관을 소개합니다. **한 문단에는 하나의 이야기**를 담으면 내용을 따라가기 편합니다.
| 좋아하는 활동 | 나에게 주는 즐거움 |
|---|---|
| 동네 산책 | 계절이 바뀌는 모습을 볼 수 있습니다. |
| 사진 정리 | 소중한 사람과의 추억을 되새깁니다. |
| 간단한 요리 | 가족과 이야기를 나눌 수 있습니다. |
### 책을 마무리하기 전에
- [ ] 제목과 본문이 읽기 편한지 확인했습니다.
- [ ] 사진에 짧은 설명을 붙였습니다.
- [ ] 실명과 사진 공개 여부를 확인했습니다.
- [ ] 전자책으로 내보낸 뒤 글자와 표를 확인했습니다.
