# Onrivi Author 랜딩페이지 개선안

현재 랜딩의 가장 중요한 포지셔닝은 이걸로 잡는 게 좋다.

> **Markdown Editor를 파는 것이 아니라  
> AI 시대의 문서 작성 경험을 판다.**

따라서 첫 화면부터 Markdown, Local-First, Mermaid 같은 기술 용어를 전면에 세우지 않는다.

## 디자인 방향도 바꾸자

온리비는 AI 서비스라고 해서 **보라색 그라데이션 + 빛나는 구체 + 우주 배경** 같은 전형적인 AI 디자인으로 갈 필요가 없다.

오히려 **문서 도구다운 정갈함 + 개발 도구다운 전문성**이 맞는다.

전체 배경은 White/Off-white 중심. 다크모드는 별도로 제공하고, 강조색은 Onrivi 브랜드 컬러 하나만 사용한다. 여백은 크게 잡고 카드 남발은 줄인다. 제품 UI와 실제 출력 문서가 랜딩의 주인공이어야 한다.

그리고 애니메이션도 `fade-up`을 여기저기 붙이는 것보다 **Markdown 입력 → A4 변화**, **Before → After**, **문서 → PDF Export**처럼 제품의 원리를 설명하는 곳에만 쓴다.

### 가장 먼저 고칠 우선순위

**P0:** HERO 카피 + 실제 제품 화면 + CTA  
**P0:** Problem → Solution 설명  
**P0:** Markdown → A4 데모  
**P1:** Local-First  
**P1:** Before/After  
**P1:** 실제 결과 문서  
**P2:** Use Case / 세부 기능  
**P2:** FAQ  
**P3:** 화려한 애니메이션

특히 **HERO 하나만 제대로 바꿔도 랜딩의 인상이 크게 달라질 가능성이 있다.**

그리고 한 가지는 이전 답변에서 수정할게. 이번 개선안에서는 **“60초 둘러보기” 버튼은 영상이 준비되기 전까지 넣지 않는 편이 낫다.** 지금 당장 랜딩을 개선한다면 CTA를 `무료로 시작하기` + `기능 살펴보기` 정도로 두고, 나중에 실제 데모 영상이 완성됐을 때 교체하면 된다.
