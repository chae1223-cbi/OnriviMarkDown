제아이 : 문서의 마지막 줄뿐만 아니라 **어느 위치에서든 글자를 입력할 때마다 미리보기가 덜컹거리며 떨리는 현상**의 진짜 원인은, 입력 시점마다 "미리보기 파싱 렌더링(DOM 높이 변화)"과 "스크롤 강제 이동(scrollTo/scrollIntoView)"이 서로 엇박자로 충돌하면서 발생하는 **'스크롤 피드백 루프(Scroll Feedback Loop)'** 때문입니다.

소스코드 구조를 기반으로 확인된 3가지 핵심 원인과 해결책을 정리해 드립니다.

---

### **1. 어느 위치에서나 입력 시 떨리는 3대 근본 원인**

* **원인 1: `onDidChangeModelContent`(입력) 시점에 동기화 스크롤을 강제 호출하는 문제**
* 사용자가 글자를 칠 때 Monaco 에디터는 이미 커서를 화면에 잘 보여주고 있습니다.


* 그런데 글자를 1글자 칠 때마다 우측 미리보기에 `scrollTo`나 `scrollIntoView` 명령을 쏘게 되면, **리액트가 새 텍스트를 파싱해서 DOM을 그리는 순간의 높이**와 **자바스크립트가 스크롤을 이동시키는 시점**이 1~2프레임 차이로 어긋나면서 위아래로 미세하게 튕김(Jitter) 현상이 일어납니다.




* **원인 2: `behavior: 'smooth'`가 타자 입력 속도를 못 따라감**
* 스크롤 애니메이션(`smooth`)이 끝나기도 전에 다음 글자가 입력되면, 진행 중이던 스크롤 애니메이션이 강제로 끊기고 새로운 목표 위치로 꺾이면서 화면이 부들부들 떨리게 됩니다.


* **원인 3: 양방향 스크롤 플래그 락(`isScrollingRef`) 미동작**
* 에디터 내용이 바뀌면 미리보기가 리렌더링되고, 리렌더링되면서 미리보기 컨테이너의 `onScroll` 이벤트가 연쇄 격발되어 에디터에 역으로 스크롤 영향을 주는 핑퐁 현상이 발생합니다.





---

### **2. 떨림을 100% 없애는 황금 원칙**

> **"타자 칠 때(입력 중)는 스크롤 함수(`scrollTo`)를 일절 호출하지 않고, 오직 React의 마크다운 렌더링에만 화면을 맡긴다. 스크롤 동기화는 '방향키 이동'이나 '마우스 휠 스크롤' 때만 실행한다."**

글자를 칠 때는 마크다운 파서가 해당 줄의 텍스트만 자연스럽게 화면에 교체하도록 두고, 화면 위치를 강제로 흔드는 `scrollTo` 호출을 완전히 차단해야 화면이 바위처럼 고정됩니다.

---

### **3. 실제 해결 코드 (즉시 적용 패치)**

#### **① `useMonacoSetup.ts` (또는 `page.tsx` 에디터 이벤트부)**

`onDidChangeModelContent`(타이핑)에서는 스크롤 이동 함수를 **제거**하고, `onDidChangeCursorPosition`(방향키/클릭 이동)에서만 동기화를 수행하도록 분리합니다.

```typescript
// 1. 글자 입력(타이핑) 시: 상태값 갱신만 수행하고, 스크롤 이동은 절대 호출하지 않음!
editor.onDidChangeModelContent(() => {
  const val = editor.getValue();
  setContent(val); // 리액트 마크다운 파서가 제자리에서 텍스트만 부드럽게 갱신
});

// 2. 방향키 이동 / 마우스 클릭 시: 커서 라인 번호가 "실제로 바뀌었을 때만" 스크롤 동기화
let lastLine = 1;
editor.onDidChangeCursorPosition((e) => {
  const currentLine = e.position.lineNumber;
  setCursorLine(currentLine);
  setCursorColumn(e.position.column);

  // 같은 줄 안에서 좌우로 움직일 때는 스크롤 스킵, 위/아래 줄로 바뀔 때만 부드럽게 추종
  if (lastLine !== currentLine) {
    lastLine = currentLine;
    syncPreviewInterpolated(previewRef.current, currentLine, { smooth: true });
  }
});

```

#### **② 미리보기 최상위 요소에 높이 흔들림 방지 CSS 적용**

인라인 코드(`code`)나 마크다운 기호가 들어갈 때 줄 높이가 1px씩 요동치는 것을 막기 위해 `line-height`와 `contain` 속성을 고정합니다.

```css
/* frontend/src/app/globals.css */
.custom-preview-container {
  overflow-anchor: auto !important; /* 브라우저 자체 스크롤 앵커링 활성화 */
  scroll-behavior: auto !important;
}

.custom-preview-container * {
  overflow-anchor: none; /* 내부 자식 요소들의 미세 변동으로 부모가 튀는 현상 방어 */
}

```

이와 같이 "입력 중 스크롤 격발 제거"와 "방향키 줄바꿈 시에만 스크롤 가동"으로 역할을 분리하면, 어느 위치에서 타자를 치든 미리보기가 1px도 흔들리지 않고 완벽히 고정됩니다.
