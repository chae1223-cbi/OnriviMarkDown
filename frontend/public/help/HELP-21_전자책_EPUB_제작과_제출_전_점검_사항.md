> "종이책 출판을 넘어 전 세계 독자들과 스마트폰, 태블릿, 전자책 전용 단말기로 만나는 현대 출판의 절대 표준은 바로 EPUB입니다.  
> 온리비 어서(Onrivi Author)는 복잡한 전자책 패키징 기술이나 XML 조판 규격을 몰라도, 평소 작성하던 마크다운 원고를 국제 디지털 출판 표준인 **ePub 3.0 규격의 리플로우(Reflowable) 전자책**으로 한 번의 클릭에 완성해 줍니다.

## 1. 전자책(EPUB)이란 무엇인가요?

**EPUB(Electronic Publication)**은 국제디지털출판포럼(IDPF) 및 W3C에서 제정한 세계 공인 전자책 표준 파일 포맷입니다. 온리비 어서는 구형 ePub 2.0의 한계를 넘어 최신 멀티미디어와 모바일 조판을 완벽히 지원하는 **ePub 3.0**을 기본 엔진으로 채택하고 있습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 어서 ePub 3.0 패키징 내부 아키텍처             │
│                                                                        │
│  [EPUB 패키지 (.epub ZIP 컨테이너)]                                    │
│  ├── mimetype (STORE 무압축 표준 헤더: application/epub+zip)           │
│  ├── META-INF/container.xml (OEBPS 루트 디렉토리 위치 선언)            │
│  └── OEBPS/                                                            │
│      ├── content.opf (도서 메타데이터, Manifest 자원 목록, Spine 순서) │
│      ├── toc.ncx (구형 전자책 전용 단말기 호환용 NCX 목차)             │
│      ├── text/                                                         │
│      │   ├── toc.xhtml (EPUB 3 표준 Nav TOC 하이퍼링크 네비게이션)     │
│      │   ├── section1.xhtml (제1장 본문 독립 웹문서)                   │
│      │   └── section2.xhtml (제2장 본문 독립 웹문서)                   │
│      ├── styles/style.css (단말기 가독성 최적화 웹폰트 및 타이포그래피)│
│      └── images/ (영숫자 정규화된 고해상도 표지 및 본문 첨부 이미지)   │
└────────────────────────────────────────────────────────────────────────┘
```

### 리플로우(Reflowable) 방식의 놀라운 가치
전자책은 종이책처럼 페이지 크기가 고정된 판형(Fixed Layout)과 달리, 독자의 단말기 화면 크기에 맞춰 글줄이 물 흐르듯 유연하게 다시 배치되는 **리플로우(Reflowable)** 방식으로 동작합니다.  
독자가 6인치 전자책 단말기(교보 SAM, 크레마)로 보든, 11인치 태블릿이나 스마트폰 세로 모드로 보든, 활자 크기를 키우거나 줄이더라도 항상 최적의 줄바꿈과 여백을 자동으로 유지합니다.

## 2. 화면 위치와 내보내기 메뉴

온리비 어서에서 전자책(EPUB)을 사출하는 방법은 매우 간단하고 직관적입니다.

```
[상단 메뉴바]
  └── 파일(F)
        └── 내보내기 (미리보기 모드 전용)
              ├── 인쇄/PDF
              ├── Word 문서 (.docx)
              ├── 한글 문서 (.hwpx)
              ├── HTML 파일 (.html)
              └── EPUB 전자책 (.epub)  <── [클릭]
```

1. **미리보기 모드 전환**:  
   - 에디터 우측 상단 플로팅 툴바 또는 상단 메뉴 [도구] ➔ [화면 보기 모드]에서 **[미리보기]** 전용 모드로 전환합니다.
   > [!참고]
   > 온리비 어서의 모든 출판 내보내기 엔진은 원고의 서식, 수식, 다이어그램 및 이미지 렌더링이 100% 완료된 상태를 보장하기 위해 **미리보기 전용 모드**에서만 활성화됩니다.
2. **EPUB 내보내기 실행**:  
   - 상단 메뉴 [파일(F)] ➔ [내보내기] ➔ **[EPUB 전자책 (.epub)]** 항목을 클릭합니다.
3. **파일 저장**:  
   - **데스크톱 앱(Windows/macOS)**: 운영체제 파일 탐색기가 열리며, 원하는 저장 경로와 파일명을 지정하여 안전하게 저장합니다.
   - **웹 브라우저 환경**: 브라우저 다운로드 폴더로 완성된 `.epub` 파일이 즉시 다운로드됩니다.

## 3. 지능형 챕터 자동 분할과 목차(TOC) 생성

단행본 한 권 전체를 단 하나의 거대한 단일 파일로 묶으면, 저사양 전자책 단말기나 모바일 리더기에서 메모리가 부족해져 책장을 넘길 때 화면이 멈추거나 앱이 강제 종료될 수 있습니다. 온리비 어서는 출판 업계 표준 권장 사양에 따라 원고를 지능적으로 분할합니다.

### ① 헤딩(H1 / H2) 기준 자동 챕터 분리
- 원고 내의 대제목(`H1`, `# 제목`) 또는 중제목(`H2`, `## 제목`)을 파싱 엔진이 감지하여 각 챕터를 개별 XHTML 파일(`section1.xhtml`, `section2.xhtml`...)로 안전하게 자동 쪼갭니다.
- 첫 번째 나타난 헤딩의 텍스트가 해당 챕터의 공식 명칭으로 추출되어 `toc.xhtml` 및 `toc.ncx` 목차 트리에 자동으로 등록됩니다.

### ② "Keep with Next" 단락 결속 알고리즘
- 상위 헤딩(H1) 바로 뒤에 소개 문단이나 하위 헤딩(H2)이 연속으로 이어질 때, 무분별하게 페이지를 쪼개지 않고 한 호흡으로 묶어주는 스마트 버퍼 알고리즘이 가동됩니다.
- 이전 챕터의 잔여 내용과 다음 챕터의 머리말이 겹치지 않고 완전히 새로운 화면에서 시작되도록 보장합니다.

### ③ 수동 페이지 나누기 (Manual Page Break)
특정 문단이나 이야기 전개 지점에서 인위적으로 챕터를 분리하여 다음 페이지로 넘기고 싶다면 아래 문법을 원고 사이에 넣어보세요:

```markdown
여기까지가 제1부의 이야기입니다. 이제 다음 장으로 넘어갑니다.

<div class="page-break"></div>

# 제2부. 새로운 여정의 시작
```

> [!팁]
> `<div class="page-break"></div>` 또는 마크다운 줄바꿈 확장 기호인 `\pagebreak`를 작성하면 온리비 어서의 EPUB 엔진이 이를 감지하여 해당 지점에서 XHTML 섹션을 정확히 분리합니다.

## 4. 도서 메타데이터와 표지(Cover Image) 등록

교보문고, 예스24, 알라딘, 리디북스 등 전자책 유통 플랫폼에 원고를 등록할 때 책 제목뿐 아니라 지은이, 발행일, 고유 식별자(ISBN 또는 UUID)가 누락되면 등록 심사가 거절됩니다. 온리비 어서는 문서 상단의 **Frontmatter(메타영역)**을 통해 이를 손쉽게 구성할 수 있습니다.

```markdown
---
title: "나의 첫 소설: 달빛 정원"
creator: "김작가"
publisher: "온리비 출판사"
language: "ko"
identifier: "979-11-000000-0-0"
date: "2026-10-10"
cover: "./media/cover_art.png"
css_profile: "Onrivi 기본서식"
---
```

### 필수 메타데이터 항목 일람
| 메타데이터 키 | 설명 | 권장 형식 및 예시 |
| :--- | :--- | :--- |
| `title` | 도서 정식 표제명 (전자책 뷰어 상단 표시) | `"나의 첫 소설: 달빛 정원"` |
| `creator` | 저자/글쓴이 이름 | `"김작가"` |
| `publisher` | 출판사 또는 개인 출판 레이블 | `"온리비 출판사"` |
| `language` | 도서 기본 언어 코드 | `"ko"` (한국어), `"en"` (영어) |
| `identifier` | 고유 식별자 (정식 ISBN 또는 시스템 UUID) | `"979-11-000000-0-0"` |
| `date` | 도서 출간일자 | `"YYYY-MM-DD"` |
| `cover` | 책 표지 이미지의 상대 경로 | `"./media/cover_art.png"` |

> [!중요]
> 표지 이미지(Cover)는 독자가 전자책 서재 앱을 열었을 때 가장 먼저 마주하는 '얼굴'입니다. 최소 해상도 **1600 × 2400 픽셀(권장 비율 1:1.414~1:1.6)** 이상의 선명한 이미지를 권장하며, 온리비 공통 리소스 폴더(`media/`) 안에 보관하세요.

## 5. 온리비 어서만의 EPUB 특화 렌더링 엔진

온리비 어서는 시중의 오픈소스 마크다운 변환기들이 겪는 전자책 고유의 렌더링 결함을 소스코드 레벨에서 완벽하게 해결했습니다:

### ① 이미지 우측 쏠림 및 인접 페이지 누출 잔상 원천 차단
- 전자책 리더기에서 좌우 2면 분할 보기(펼침면 보기)를 할 때, 이미지 폭이 너무 넓거나 마진이 어긋나면 그림의 오른쪽 끝 1~2픽셀이 오른쪽 페이지 왼쪽 구석으로 삐져나오는(누출 잔상) 버그가 발생하곤 합니다.
- 온리비 어서는 이미지 컨테이너(`figure`, `.onrivi-image-wrapper`)에 `overflow: hidden`, `box-sizing: border-box`, `margin: 1.5em auto` 및 `display: block`을 강제 주입하여 인접 페이지 침범을 100% 차단하고 완벽한 중앙 정렬을 구현합니다.

### ② Mermaid 다이어그램 뷰포트 높이(85vh) 자동 스케일
- 세로로 긴 다이어그램이나 순서도가 단말기 화면을 벗어나 아래쪽이 잘리는 문제를 해결하기 위해, 온리비 어서는 다이어그램을 고화질 SVG/PNG로 래스터라이즈하면서 `max-height: 85vh`, `width: auto`, `object-fit: contain` 및 `break-inside: avoid`를 적용하여 화면 높이에 맞춰 단정하게 피팅됩니다.

### ③ 코드블록 다크 테마 및 자동 줄바꿈 1:1 보존
- 개발 서적이나 테크니컬 가이드의 소스코드가 가로 화면을 넘어 우측으로 잘려나가지 않도록 `white-space: pre-wrap !important`, `word-break: break-all !important`를 적용하여 가로 스크롤 조작 없이도 모든 코드가 온전히 노출됩니다.
- 또한 코드블록의 세련된 다크 배경색과 헤더 바 라벨 서식이 리더기에서도 1:1 동일하게 유지됩니다.

### ④ 양방향 인터랙티브 각주(Footnote) 완벽 지원
- 본문의 각주 위첨자 번호(`[^1]`)를 터치하면 문서 하단 주석 섹션으로 매끄럽게 점프하고, 주석 끝의 되돌아가기 화살표(`↩`)를 터치하면 원래 읽던 본문 문맥으로 정확히 복귀합니다.

## 6. 유통사 제출 전 뷰어 점검 체크리스트 (Quality Gate)

교보문고 ePUB 검사기, 예스24/알라딘 크레마 클럽, 리디북스 파트너스, 밀리의 서재, 아마존 KDP 등에 도서를 등록하기 전에 아래 6대 체크리스트를 꼭 점검해 보세요.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   전자책(EPUB) 유통사 승인 통과 체크리스트             │
│                                                                        │
│  [ ] 1. 폰트 가독성: 한글 웹폰트와 시스템 명조/고딕 Fallback 확인     │
│  [ ] 2. 표 테두리: border-collapse 적용 및 좁은 화면 스크롤 깨짐 방어 │
│  [ ] 3. 각주 점프: 본문 번호[^1] 클릭 시 미주 이동 및 복귀(↩) 검증     │
│  [ ] 4. 이미지 래핑: 100% 폭 제한, 중앙 정렬, 다음 장 침범 방어      │
│  [ ] 5. 다이어그램: Mermaid 도표가 단말기 높이(85vh) 내 적정 스케일   │
│  [ ] 6. 코드블록: 가로 스크롤 잘림 없이 자동 줄바꿈(pre-wrap) 적용    │
└────────────────────────────────────────────────────────────────────────┘
```

1. **폰트 가독성과 인라인 웹폰트**:  
   나눔고딕, 나눔명조, Noto Sans KR 등 대표 출판 서체 선언이 `style.css`에 내장되어 글자가 네모 박스(두부 현상, Tofu)로 깨지지 않는지 확인합니다.
2. **표(Table) 테두리와 정렬**:  
   스마트폰 세로 화면처럼 좁은 폭에서도 표의 외곽선과 구분선이 흐트러지지 않는지 점검합니다.
3. **각주 상호작용 검증**:  
   모든 각주 링크가 정확한 설명으로 이동하고 본문으로 복귀하는지 클릭해 봅니다.
4. **이미지 래핑 및 캡션**:  
   사진 밑의 설명 글(`figcaption`)이 사진과 분리되지 않고 한 덩어리로 잘 배치되었는지 확인합니다.
5. **다이어그램 축소율**:  
   복잡한 차트의 글자가 단말기에서 너무 작아져 읽기 어렵지 않은지 확인합니다.
6. **목차(TOC) 네비게이션**:  
   전자책 리더기 사이드바 목차 메뉴를 열었을 때 각 챕터 제목이 누락 없이 올바르게 나열되는지 확인합니다.

## 7. 단계별 실전 따라 하기 (Step-by-Step)

직접 전자책 1권을 만들어 파일로 저장해 보겠습니다.

### 1단계: 원고 구조화하기


### 2단계: 서식 테마 적용하기
우측 사이드바 툴바의 **서식관리(🎨)** 버튼을 누르고, 시니어 독자나 단말기 뷰어에 적합한 서식(예: `Onrivi 기본서식` 또는 `시니어 친화 서식`)을 지정합니다.

### 3단계: 미리보기 화면에서 최종 점검
상단 메뉴 [도구] ➔ [화면 보기 모드] ➔ [미리보기]를 선택하여 표와 이미지, 각주 번호가 예쁘게 정돈되었는지 꼼꼼히 확인합니다.

### 4단계: EPUB 파일 생성 및 다운로드
상단 메뉴 [파일] ➔ [내보내기] ➔ **[EPUB 전자책 (.epub)]**을 클릭합니다. 하단에 `EPUB 파일 생성 중...` 알림이 뜨고 잠시 후 저장이 완료됩니다.

### 5단계: 추천 무료 전자책 뷰어로 검수하기
생성된 `.epub` 파일을 아래의 무료 공식 뷰어 프로그램으로 열어 최종 확인해 보세요:

- **네이버 시리즈 / 카카오페이지 / 교보 e-Book 앱**: 내 파일 추가 기능으로 모바일 화면 검수

## 8. 자주 묻는 질문 (FAQ)

### Q1. 온리비 어서로 만든 EPUB 파일을 아마존 킨들(Kindle)에도 올릴 수 있나요?
**A.** 네! 아마존 KDP(Kindle Direct Publishing)는 ePub 3.0 파일을 공식 입력 형식으로 적극 권장하고 있습니다. 온리비 어서에서 추출한 `.epub` 파일을 KDP 웹사이트에 그대로 업로드하시면 킨들 전용 포맷(KFX/AZW)으로 자동 변환되어 아마존 전 세계 서점에 등록됩니다.

### Q2. EPUB 내보내기 시 이미지가 깨지거나 엑스박스로 나오면 어떻게 하나요?
**A.** 온리비 어서는 내보내기 직전 로컬 상대경로(`./media/image.png`)와 클립보드 이미지(Base64)를 전자책 내부 영문 표준 경로(`OEBPS/images/image_0.png`)로 자동 변환하여 ZIP 압축 파일 안에 함께 동봉합니다. 이미지가 깨진다면 원본 이미지가 로컬 공통 리소스 폴더(`media/`) 안에 올바르게 존재하는지 확인해 주세요.

### Q3. DRM(디지털 저작권 관리) 암호화는 어떻게 적용하나요?
**A.** 온리비 어서는 국제 표준 비암호화 순수 ePub 3.0 원본 파일을 생성합니다. 교보문고, 예스24, 리디북스 등 유통 서점에 원고를 납품하시면 각 서점 플랫폼의 정산 시스템에서 자사 전용 DRM을 자동으로 입혀 판매하게 됩니다.
