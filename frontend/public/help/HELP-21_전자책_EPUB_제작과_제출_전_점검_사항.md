# EPUB 전자책 내보내기

## 1. 내보내기 순서

1. 원고를 저장하고 제목 단계·이미지·표·링크를 확인합니다.
2. 파일의 내보내기에서 EPUB 전자책을 선택합니다.
3. 서식과 워터마크 등 표시된 설정을 확인합니다.
4. 파일을 저장하고 실제 전자책 리더에서 엽니다.
5. 목차 링크, 장 시작, 한글 글꼴, 이미지와 표를 점검합니다.

## 2. 페이지의 차이

일반 문서의 가변형 EPUB은 화면 크기와 독자 글자 설정에 따라 줄과 쪽이 달라집니다. PDF의 종이 크기·예상 페이지 점선과 동일한 페이지 수를 보장하지 않습니다. 수동 페이지 나누기는 구조적 구분에 활용되지만 실제 페이지 배치는 리더의 동작에도 영향을 받습니다.

제목 번호가 원문에 기록된 문서는 그 번호가 목차와 본문에 반영됩니다. 제목의 단계를 건너뛰거나 빈 제목을 만들면 목차가 어색해질 수 있습니다.

## 3. 그림책

그림책은 장면 단위의 고정 배치 내보내기 경로를 사용합니다. 일반 가변형 문서와 별도로 확인하세요. 원문에 장면 밖 내용이나 잘못된 표지가 있으면 해당 안내를 먼저 처리합니다.

## 4. 제출 전 점검

표가 화면 밖으로 나가지 않는지, 이미지 설명이 적절한지, 외부 동영상·지도가 리더에서도 동작하는지 확인합니다. 서점의 파일 크기·표지·메타데이터·검수 기준은 별도이며, 온리비에서 생성했다는 이유로 모든 서점의 접수를 보장하지 않습니다.
