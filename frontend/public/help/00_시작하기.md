# 온리비 어서 도움말 — 현재 기능 안내

온리비 어서(Onrivi Author)는 마크다운(Markdown) 기반의 전문 집필 환경과 상용 출판 수준의 실시간 조판 엔진, 그리고 안전한 AI 보조 기능을 하나로 결합한 차세대 문서 저작 시스템입니다.

사용자의 원고와 소중한 지식 자산이 서비스 제공자의 서버에 종속되지 않도록 **사용자 주권 데이터 보안 원칙(내 PC 로컬 디스크 및 개인 웹드라이브 연동)**을 엄격히 준수하며, 웹 브라우저뿐만 아니라 파일 반응 속도가 뛰어난 **Electron 데스크톱 전용 앱**에서도 동일하게 동작합니다.

![[그림 1] 온리비 어서 4단계 초기 시작 및 온보딩 흐름](./assets/fig1_setup_steps.png)

## 1. 처음 시작하는 4단계 빠른 흐름

1. **실행 환경 확인**: 웹 브라우저(Chrome, Edge 등)로 접속하거나 초고속 네이티브 파일 접근이 가능한 데스크톱 앱을 실행합니다.
2. **작업장과 리소스 폴더 연결**: 내 PC의 원고 폴더(작업장)와 이미지·서식·설정이 저장되는 공통 리소스 폴더를 각각 지정합니다.
3. **새 문서 작성 또는 불러오기**: 상단 메뉴의 [파일] ➔ [새 문서]를 누르거나 기존 원고를 열어 문서보기 또는 나란히 보기에서 편안하게 글을 작성합니다.
4. **서식 적용 및 내보내기**: 서식 관리 센터에서 대한민국 4대 공인 표준 서식(KS/ISO, 전략기획, KDI, 6-Pager)을 선택한 뒤, 인쇄용 PDF, 전자책(EPUB), 한글(HWPX), 워드(DOCX)로 내보냅니다.

---

## 2. 온리비 어서의 5대 핵심 가치와 차별점

- **무손실 실시간 출판 조판**: 마크다운을 타이핑하는 순간, 서식 설정에 정의된 인쇄 용지 규격(A4 등)에 맞추어 실제 인쇄물과 동일한 줄바꿈 폭과 실시간 쪽 나눔선(페이지 분할선)이 화면에 즉시 표시됩니다. (※ 머리글과 하단 페이지 번호는 인쇄 및 PDF 내보내기 시 자동으로 정밀 조판됩니다.)
- **사용자 주권 데이터 보안 (내 PC & 개인 웹드라이브)**: 온리비 어서 전용 서버에 원고를 강제 종속시키지 않고, 내 PC 로컬 디스크(`./media/`) 또는 개인 웹드라이브(구글 드라이브 등) 등 사용자가 원하는 안전한 저장소에 원고와 삽입 이미지를 온전히 보관합니다.
- **대한민국 4대 공인 표준 서식과 계층형 십진 분류**: 국가기술표준, 대기업 기획서, 공공 정책보고서 규격을 원클릭으로 적용하며, `1. ➔ 1.1 ➔ 1.1.1` 자동 번호 매김이 마크다운 원문과 완벽 동기화됩니다.
- **책임 분리형 안전한 멀티 AI 어시스턴트**: Google Gemini(4.0/3.8 Flash), OpenAI ChatGPT(GPT-4o), Anthropic Claude(3.7/3.5 Sonnet) 등 글로벌 3대 최신 플래그십 AI 모델을 자유롭게 연동할 수 있으며, 사용자가 직접 승인하지 않은 문서 전체가 외부로 임의 전송되지 않는 엄격한 프라이버시 보호 정책을 유지합니다.
- **모든 이해관계자를 위한 맞춤형 출판 서식 제공**: 기술 엔지니어, 비즈니스 기획자, 학술 연구원, 감수자 및 일반 독자까지 문서 생태계의 모든 이해관계자가 목적과 용도에 맞추어 즉시 활용할 수 있는 표준 출판 서식(공인 기술 표준, 전략 기획서, 정책 보고서, 학술 논문, 대독자 가독성 서식 등)을 원클릭으로 제공합니다.

## 4. 빠른 문제 해결 및 핵심 수칙

- **글씨가 흐릿하게 보일 때**: [환경설정(⚙️)] ➔ [일반 설정]에서 글꼴 굵기를 **'더 선명하게 (SemiBold 600)'**로 지정하고 필요 시 **'고대비 모드'**를 활성화하세요.
- **이미지가 화면에 나오지 않을 때**: 원고 본문에 기재된 경로가 `./media/파일명` 형태인지 확인하고, 해당 파일이 연결된 공통 리소스 폴더의 `media/` 디렉토리에 존재하는지 확인하세요.
- **작업 내용의 안전한 보관**: 세션 복구 창이 있더라도, 집필 중 수시로 `Ctrl + S`를 눌러 내 컴퓨터 파일에 영구 기록하는 습관을 권장합니다.

온리비 어서와 함께 즐겁고 전문적인 저작 활동을 경험해 보세요!
