> "내가 공들여 만든 서식을 다른 컴퓨터로 옮기거나 동료 작가와 나누고 싶으신가요?  
> '가을 고궁 산책 느낌의 따뜻한 서식을 만들어줘'처럼 말 한마디로 나만의 디자인을 완성하고 싶으신가요?  
> 온리비 어서의 서식 관리 센터(`StyleManagerModal`)가 원클릭 백업과 스마트한 생성형 AI 서식 제작을 완벽하게 지원합니다."

## 1. 서식 관리 센터(StyleManagerModal) 진입하기

서식의 백업, 가져오기, 공유, AI 생성 등 고급 서식 작업은 **서식 관리 센터**에서 이루어집니다:

```
[1단계] 우측 사이드바 툴바의 팔레트(🎨) 아이콘 클릭 (서식 정의 창 오픈)
[2단계] 서식 정의 창 상단 우측의 [⚙ 서식 관리] 버튼 클릭
```

![서식 관리 센터 화면](media/img_style_manager.png)

서식 관리 센터에 들어오면 좌측에 내가 만든 서식 목록이 표시되고, 우측에 **[서식 세부정보]**, **[서식 가져오기]**, **[✨ AI 서식 생성]** 3대 핵심 작업 탭이 시원하게 제공됩니다.

---

## 2. JSON 파일 단위 서식 백업 및 동료 공유

온리비 어서의 모든 서식은 가볍고 호환성이 뛰어난 **표준 JSON 규격**으로 관리됩니다.

```
┌────────────────────────────────────────────────────────┐
│  [1] JSON 파일 다운로드 (.json)                         │
│      ➔ 내 컴퓨터나 외장하드, 클라우드에 영구 백업         │
├────────────────────────────────────────────────────────┤
│  [2] 클립보드로 JSON 복사                              │
│      ➔ 카카오톡, 이메일, 슬랙으로 동료에게 즉시 텍스트 전송│
├────────────────────────────────────────────────────────┤
│  [3] 외부 JSON 파일 업로드 / 텍스트 붙여넣기           │
│      ➔ 다른 사람이 만든 서식을 내 서재에 원클릭 등록    │
└────────────────────────────────────────────────────────┘
```

### ① 서식 파일 다운로드 (내보내기)
1. 서식 관리 센터 좌측 목록에서 백업하고자 하는 서식을 선택합니다.
2. 우측 화면 상단의 **[📥 서식 다운로드 (JSON)]** 버튼을 누릅니다.
3. 브라우저/PC 다운로드 폴더에 `<서식명>_theme.json` 파일이 안전하게 저장됩니다.

### ② 클립보드로 초고속 복사 (메신저 전달)
- 복잡하게 파일을 주고받을 필요 없이 **[📋 클립보드로 JSON 복사]** 버튼을 누르세요.
- 클립보드에 복사된 서식 코드를 카카오톡 대화창이나 메일에 `Ctrl + V`로 붙여넣어 동료 작가에게 1초 만에 선물할 수 있습니다.

### ③ 외부 서식 가져오기 (가져오기 & 적용)
다른 사람이 공유해 준 서식을 등록하는 방법은 두 가지입니다:
- **파일 업로드 방식**: [서식 가져오기] 탭에서 **[파일 선택]**을 눌러 전달받은 `.json` 파일을 선택합니다.
- **텍스트 붙여넣기 방식**: [JSON 직접 붙여넣기] 영역에 복사한 코드를 붙여넣고 **[서식 적용하기]**를 누릅니다.

> [!참고]
> **온리비 지능형 살균 정규화 엔진 (`normalizeCssProfile`)**  
> 외부에서 가져온 JSON에 오탈자가 있거나, 구버전 서식이라 최신 표(Table)나 체크박스 규격이 누락되어 있어도 안심하세요! 온리비 어서의 관대한 파서가 잘못된 주석을 자동으로 정제하고, 빠진 필수 규격을 최신 기본 규격으로 100% 자동 채워 안전하게 등록해 줍니다.

## 3. 공통 리소스 폴더의 `userCssProfiles.json` 자동 저장 체계

온리비 어서에서 생성하거나 수정한 모든 사용자 서식은 어디에 보관될까요?

```
내 컴퓨터 (또는 Google Drive)
└── 온리비 공통 리소스 폴더 (Resource Folder)
    └── profiles/
        └── userCssProfiles.json   (★ 모든 사용자 서식이 통합 보관되는 핵심 파일)
```

1. **단일 파일 영구 보존**:
   - 내가 만든 수십 개의 커스텀 서식은 공통 리소스 폴더 하위의 `profiles/userCssProfiles.json` 단일 파일에 차곡차곡 누적 저장됩니다.
   - 컴퓨터를 포맷하거나 앱을 재설치하더라도, 환경설정에서 이 리소스 폴더만 다시 연결하면 내가 만든 모든 서식이 원래대로 100% 복원됩니다.
2. **Google Drive 클라우드 자동 동기화**:
   - 구글 드라이브 작업장을 사용하는 경우, 서식을 수정하는 즉시 내 구글 드라이브의 `OnriviAuthor/참조폴더/profiles/userCssProfiles.json`으로 무인 백그라운드 자동 업로드됩니다.
   - 집 컴퓨터에서 만든 서식이 회사 노트북의 구글 드라이브 서재에도 실시간으로 똑같이 반영됩니다!

## 4. Google Gemini AI 맞춤 서식 자동 생성 🌟

"색상 코드(#)나 픽셀(px) 계산은 잘 모르겠고, 그냥 가을 느낌이 나는 고풍스러운 서식이 필요한데..."  
이럴 때는 온리비 어서의 **`✨ AI 서식 생성`** 기능을 이용해 보세요!

```
┌────────────────────────────────────────────────────────┐
│  [사용자 프롬프트 입력]                                 │
│  "가을 고궁을 산책하는 느낌의 따뜻한 한지 서식을 만들어줘.  │
│   단풍잎을 닮은 버건디 포인트 컬러와 부드러운 명조체,   │
│   그리고 은은한 아이보리 배경이 어우러지면 좋겠어."     │
└──────────────────────────┬─────────────────────────────┘
                           │ Gemini 3.8 Flash 엔진 분석
┌──────────────────────────▼─────────────────────────────┐
│  AI 자동 설계 결과                                      │
│  - 배경색: #F9F6F0 (따뜻한 한지 미색)                   │
│  - 제목 H1: #800020 (버건디) + 2px 하단 장식선          │
│  - 본문: 17px + 1.85 행간 + KoPub 바탕 폰트 매칭        │
│  - 표: 브라운/버건디 가로선 강조형 조판                 │
└────────────────────────────────────────────────────────┘
```

### 🚀 AI 서식 생성 단계별 실전 가이드
1. 상단 메뉴 `도구 ➔ 환경 설정 ➔ AI 설정`에서 **Google Gemini API Key**가 등록되어 있는지 확인합니다. (무료 발급 가능)
2. 서식 관리 센터(`StyleManagerModal`)에서 **[✨ AI 서식 생성]** 탭을 클릭합니다.
3. **AI 모델 선택**: `Gemini 3.8 Flash` 또는 `Gemini 3.7 Flash` 등 원하는 최신 모델을 선택합니다.
4. **프롬프트 입력창**에 내가 원하는 분위기를 자유로운 일상 언어로 입력합니다:
   - *"스타트업 투자 유치용 IR 피칭 백서 스타일. 짙은 네이비와 오렌지 포인트, 표는 가로선 중심의 모던 테크 느낌으로 해줘."*
   - *"초등학교 아이들을 위한 동화책 서식. 큼직한 22px 글자와 알록달록한 파스텔 톤 인용구 상자를 넣어줘."*
   - *"논문 심사용 학술 서식. 격식 있는 흑백 톤과 1.6배 콤팩트 줄간격, 정밀한 괘선 표를 적용해줘."*
5. **[✨ AI 서식 생성 시작]** 버튼을 누릅니다.
6. 약 3~5초 후, AI가 완성한 고유한 서식이 서재에 자동으로 등록되며 우측 미리보기에 즉시 적용됩니다!

> [!팁]
> **AI 생성 서식도 100% 자유롭게 재수정 가능!**  
> AI가 만들어준 서식이 마음에 들지만 글자 크기만 조금 더 키우고 싶다면, 서식 정의 창(`CssStyleForm`)으로 돌아가 슬라이더를 살짝 움직여 내 취향대로 얼마든지 추가 다듬기를 할 수 있습니다.

## 5. 자주 묻는 질문 (FAQ)

### Q1. AI 서식 생성 시 "API Key가 필요합니다"라는 안내가 나와요.
**A.** 온리비 어서는 사용자의 개인정보와 보안을 위해 공유 서버를 거치지 않고, 사용자가 직접 발급받은 Google AI Studio의 무료 Gemini API 키를 로컬에서 안전하게 사용합니다. 상단 메뉴의 `도구 ➔ 환경 설정 ➔ AI 설정`에서 키를 한 번만 등록해 두시면 평생 무료로 무제한 AI 서식 생성을 이용하실 수 있습니다.

### Q2. 구글 드라이브와 내 PC 로컬 폴더의 서식이 다르게 보일 때는 어떻게 하나요?
**A.** 서식 관리 센터 상단 우측의 **[새로고침(🔄)]** 버튼을 누르면, 현재 작업장(로컬 디스크 또는 구글 드라이브)의 최신 `userCssProfiles.json` 파일을 즉시 다시 읽어와 목록을 동기화합니다.
