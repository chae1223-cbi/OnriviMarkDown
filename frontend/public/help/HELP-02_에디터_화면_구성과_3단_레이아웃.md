# 화면 구성과 보기 모드

온리비 어서는 집필자가 원고의 전체 구조를 한눈에 조망하고, 편안하게 입력하며, 인쇄될 최종 결과를 실시간으로 검토할 수 있도록 **3단 분할 레이아웃**과 **4가지 맞춤 보기 모드**를 제공합니다.

---

## 1. 에디터 3단 화면 구성

화면은 크게 좌측 LNB 사이드바, 중앙 에디터 편집창, 우측 실시간 조판 미리보기의 3개 구역으로 나뉩니다:

1. **좌측 LNB 사이드바 (Navigation Bar)**:
   - **파일 탐색기**: 내 로컬 작업장 폴더 내의 마크다운 문서 목록을 트리 구조로 확인하고 새 문서를 만듭니다.
   - **문서 개요 (TOC 목차)**: 현재 문서의 제목(H1~H6) 구조를 계층 목차로 자동 추출하여 원하는 챕터로 즉시 이동합니다.
   - **서식 관리 센터**: 현재 문서에 적용된 출판 CSS 프로필을 확인하고 다른 서식으로 즉시 전환합니다.
   - **AI 도우미**: 에디터 우측 하단 챗봇 버튼이나 사이드바를 통해 지능형 집필 어시스턴트를 호출합니다.
2. **중앙 편집 영역 (Editor Core)**:
   - 실제 원고를 집필하는 핵심 공간입니다. 워드프로세서처럼 스타일이 적용되어 보이는 **문서보기**와 마크다운 태그를 직접 제어하는 **원문 편집**을 상황에 맞추어 자유롭게 선택할 수 있습니다.
   - 빈 줄에서 `/`를 누르면 제목, 표, 체크리스트 등을 즉시 삽입하는 슬래시 명령어가 열립니다.
3. **우측 실시간 조판 미리보기 (Print Preview Engine)**:
   - 입력하는 내용이 실제 A4 용지에 어떻게 인쇄될지 오차 없이 실시간으로 계산하여 렌더링합니다.
   - 용지 여백, 행간, 표 스타일, 그림 캡션, 페이지 나눔선이 완벽히 조판된 상태로 표시됩니다.
   - 에디터 커서 이동 시 미리보기 화면이 자동으로 동기화 스크롤되어 교정·교열이 매우 편리합니다.

---

## 2. 목적에 맞춘 4대 보기 모드

화면 하단 상태바(Status Bar) 중앙의 보기 모드 아이콘을 클릭하여 원클릭으로 전환할 수 있습니다:

1. **문서보기 (Visual Document Mode)**:
   - 마크다운 문법 기호(`#`, `**` 등)를 숨기고 실제 책처럼 서식이 입혀진 화면에서 직접 타이핑하는 위지윅(WYSIWYG) 방식입니다. 마크다운이 익숙하지 않은 초보자나 일반 작가에게 가장 추천합니다.
2. **나란히 보기 (Split Mode - 기본값)**:
   - 좌측에는 마크다운 원문 에디터를, 우측에는 실시간 A4 미리보기를 나란히 배치합니다.
   - 원문 수정과 출력 결과를 동시에 대조하며 작업할 때 최적입니다.
3. **미리보기만 (Preview Only Mode)**:
   - 편집창을 숨기고 완성된 출판 레이아웃만 넓은 화면으로 집중 검토하고 교정·교열할 때 사용합니다.
4. **서식 편집 (CSS Style Mode)**:
   - 문서 본문 대신 CSS 프로필 및 스타일 코드를 직접 수정하며, 내 문서에 즉각 반영되는 디자인 변화를 실시간으로 확인할 때 사용합니다.

---

## 3. 상단 메뉴바와 하단 상태바의 편의 기능

- **상단 메뉴바 (Menu Bar)**:
  - [파일], [편집], [서식], [보기], [도구], [AI], [도움말] 메뉴를 통해 저장, 내보내기, 단축키 확인 등 모든 기능을 마우스로 손쉽게 실행할 수 있습니다.
- **하단 상태바 (Status Bar)**:
  - 현재 문서의 **전체 글자 수(공백 포함/제외)** 및 **단어 수**, 현재 커서가 위치한 줄(Line)과 열(Col) 번호가 실시간으로 집계됩니다.
  - 미리보기 배율 슬라이더(Zoom)를 통해 50% 축소부터 200% 확대까지 자유롭게 배율을 조정할 수 있습니다.
