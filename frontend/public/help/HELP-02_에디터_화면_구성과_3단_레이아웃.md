# 화면 구성과 보기 모드

온리비 어서는 집필자가 원고의 전체 구조를 한눈에 조망하고, 편안하게 입력하며, 인쇄될 최종 결과를 직관적으로 검토할 수 있도록 **2단 기본 레이아웃**과 **2대 맞춤 보기 모드(문서보기 / 나란히 보기)**를 제공합니다.

---

## 1. 에디터 기본 2단 화면 구성

![<그림 1> 에디터 기본 2단 화면 구성](./assets/img_c631f169f155.png?align=center&caption=top)

온리비 어서 실행 시 기본 화면은 **좌측 LNB 사이드바**와 **우측 본문 작업 영역(문서보기)**의 2단 구조로 시원하게 펼쳐집니다:

1. **좌측 LNB 사이드바 (Navigation Bar - 1단)**:
   - **파일 탐색기**: 내 로컬 작업장 폴더 내의 마크다운 문서 목록을 계층 트리 구조로 탐색하고 새 문서를 만듭니다.
   - **문서 개요 (TOC 목차)**: 현재 문서의 제목(H1~H6) 구조를 계층 목차로 자동 추출하여 원하는 챕터로 즉시 점프합니다.
   - **검색**: 작업장 내 모든 문서에서 특정 문자열이 포함된 문구를 빠르게 찾아내고 해당 줄로 바로 이동합니다.
   - *팁: 하단 상태바 우측의 사이드바 토글 버튼(`🗃️`)을 누르면 좌측 LNB를 접어 본문 영역을 전체 화면으로 넓게 활용할 수 있습니다.*
2. **우측 본문 작업 영역 (Main Workspace - 2단)**:
   - 실제 원고를 집필하고 서식을 입히는 핵심 공간입니다. 기본적으로 실제 출판 서식이 반영된 상태에서 직접 타이핑하는 **[문서보기]**로 시작됩니다.
   - 상단 메뉴의 [도구] ➔ [화면 보기 모드]나 하단 상태바 중앙 세그먼트 버튼을 통해 **[문서보기]**와 **[나란히 보기]**를 자유롭게 전환할 수 있습니다.

---

## 2. 목적에 맞춘 2대 보기 모드

![<그림 2> 목적에 맞춘 2대 보기 모드](./assets/img_a87bdb0e07f6.png?align=center&caption=top)

화면 하단 상태표시줄(Status Bar) 중앙의 세그먼트 버튼을 클릭하여 원클릭으로 손쉽게 전환할 수 있습니다:

1. **문서보기 (Visual Document Mode - 디폴트 기본값)**:
   - 마크다운 문법 기호(`#`, `**` 등)를 의식하지 않고 실제 책처럼 서식이 입혀진 완성형 조판 화면에서 직접 타이핑하는 위지윅(WYSIWYG) 방식입니다.
   - 좌측 LNB 사이드바와 우측 본문 뷰가 조화된 **2단 화면**으로 기본 제공되며, 워드프로세서에 익숙한 작가나 일반 사용자에게 가장 편안한 집필 경험을 선사합니다.
   - 빈 줄에서 슬래시(`/`)를 입력하거나 플로팅 툴바 단축키(`Ctrl + Space`)를 누르면 제목, 표, 체크리스트, 각주 등을 즉시 삽입하는 스마트 명령어가 열립니다. (*참고: `Ctrl + Enter`는 표나 미디어 블록 작성 후 다음 본문 행으로 빠르게 이동할 때 사용합니다.*)
2. **나란히 보기 (Split / 모두보기 Mode - 3단 분할 구성)**:
   - 본문 작업창이 **좌측의 문서보기(위지윅 편집 및 실시간 조판 미리보기)**와 **우측의 마크다운 원문 표시 영역**으로 나란히 분할됩니다.
   - 좌측 LNB 사이드바와 함께 중앙 문서보기, 우측 마크다운 뷰가 동시에 펼쳐지는 **3단 화면**으로 구성됩니다.
   - 원문 마크다운 태그가 적용되는 과정을 실시간으로 렌더링하여 인쇄 조판 결과물과 원본 마크다운 코드를 대조하며 정밀하게 교정·교열할 때 최적입니다.

## 3. 상단 메뉴바와 하단 상태바의 편의 기능

![<그림 3> 하단 상태바](./assets/img_1f9e2e64574f.png?align=center&caption=top)

- **상단 메뉴바 (Menu Bar)**:
  - [파일], [편집], [서식], [도구], [AI], [도움말] 메뉴를 통해 저장, 내보내기, 단축키 확인, 보기 모드 전환 등 모든 기능을 손쉽게 실행할 수 있습니다.
- **하단 상태바 (Status Bar)**:
  - **좌측 영역**: 조판 액션 도구(예상 페이지 경계 켜기/끄기 `📖`, 인쇄/쪽 윤곽 `🖨️`, 서식 선택 드롭다운, 문서 저장 상태)가 배치되어 있습니다.
  - **중앙 영역**: **문서보기**와 **나란히 보기**를 원클릭으로 전환하는 세그먼트 버튼, 조판 가드(Layout Guard) 토글, AI 지식 엔진 색인 진행률 배지가 표시됩니다.
  - **우측 영역**: 툴바 토글(`♻️`), AI 버튼 토글(`✨`), 사이드바 토글(`🗃️`), 전체 글자 수/단어 수, 커서 위치(Ln/Col)가 실시간으로 집계됩니다.
