## 1. 현재 화면 구성

| 위치 | 역할 |
| --- | --- |
| 왼쪽 탐색기 | 작업장 파일·폴더, 개요, 검색 |
| 가운데 문서 영역 | 직접 타이핑하는 문서보기, 표·코드·미디어 편집 |
| 나란히 보기의 오른쪽 | 생성된 마크다운 원문 확인 |
| 오른쪽 세로 툴바 | 이모지, 플로팅 서식 툴바, 슬래시 메뉴, 서식·환경설정 등 |
| 아래 상태바 | 저장 상태, 서식 이름, 문서 보기·나란히 보기 전환 |

앱 시작 시 왼쪽 탐색기가 열립니다. 탐색기는 표시/숨김 기능으로 작업 중 접을 수 있습니다.

## 2. 두 가지 보기

- **문서 보기:** 문서 결과 화면에 직접 입력합니다. 일반 문서의 기본 작업 화면입니다.
- **나란히 보기:** 왼쪽은 문서보기, 오른쪽은 마크다운입니다. 현재 오른쪽 원문은 읽기 전용이며 문서보기에서 한 편집이 반영됩니다.

독립된 **마크다운 보기** 탭은 없습니다. 예전 도움말의 중앙 마크다운·우측 미리보기 배치와 다르므로 하단 버튼을 기준으로 전환하세요.

## 3. 스크롤과 커서

나란히 보기에서는 왼쪽 문서의 세로 스크롤바와 마우스 휠을 사용합니다. 오른쪽 마크다운의 독립 세로 스크롤바는 숨겨져 있으며 문서 위치를 따라갑니다. 문서를 클릭하거나 커서를 이동하면 오른쪽에도 대응하는 원문 위치가 표시됩니다. 이미지·표의 높이가 다르므로 두 화면의 같은 픽셀 높이를 의미하지는 않습니다.

코드블록의 긴 행은 블록 내부 가로 스크롤바로 확인합니다. `Ctrl`+휠은 문서 배율 조정입니다.

## 4. 도구가 나타나는 위치

- **플로팅 서식 툴바:** `Ctrl+Space` 또는 오른쪽 툴바로 엽니다. 마우스 선택만으로 자동 표시되지 않습니다.
- **표 편집 도구:** 문서보기의 표 셀을 클릭하면 문서 영역 상단에 나타납니다. 행·열·정렬·복사 기능이 있습니다.
- **코드 복사:** 각 코드블록의 CODE/언어 입력줄 오른쪽입니다.
- **Mermaid 작업 버튼:** 다이어그램 카드 상단입니다.
