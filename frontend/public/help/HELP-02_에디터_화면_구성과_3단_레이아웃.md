# 화면 구성과 보기 모드

상단에는 파일·편집·도구·도움말 메뉴와 문서 탭이 있습니다. 왼쪽은 작업장 탐색·개요·검색, 가운데는 편집 영역, 오른쪽은 도구와 AI 패널, 아래는 상태바입니다. 사이드바와 툴바는 접어 작업 공간을 넓힐 수 있습니다.

## 1. 보기 선택

| 보기 | 용도 | 입력 위치 |
| --- | --- | --- |
| 문서보기·미리보기 | 서식이 적용된 문서를 읽고 직접 편집 | 편집이 켜진 일반 문서 본문 |
| 나란히 보기 | 마크다운과 문서 결과 비교 | 문서보기의 편집 가능한 영역을 확인 |
| 마크다운 편집 화면 | 태그·경로·메타데이터 확인과 원문 편집 | 읽기 전용이 아닌 원문 창 |

나란히 보기의 Monaco 원문 창에는 읽기 전용 조건이 적용됩니다. 글이 입력되지 않으면 커서만 보고 판단하지 말고 현재 보기와 편집 권한을 확인하세요. 그림책은 일반 본문 대신 장면별 편집을 사용합니다.

## 2. 위치 이동과 확대

왼쪽 개요의 제목을 누르면 해당 위치로 이동합니다. 문서 도구의 확대·축소는 화면 읽기 크기를 바꾸는 기능이며, 원고의 글자 크기나 출판 판형을 바꾸는 설정과 다릅니다.

줄 이동 시 보이는 노란 배경·주황 테두리는 위치 안내입니다. 일반 커서 동기화 강조는 잠시 뒤 사라지며, 이미지 자체의 배경색 설정이 아닙니다.

## 3. 편집이 안 될 때

문서를 열었는지, 도움말 문서인지, 제한 사용자 상태인지부터 확인합니다. 다른 패널에 포커스가 있으면 단축키 대상도 달라질 수 있습니다.
