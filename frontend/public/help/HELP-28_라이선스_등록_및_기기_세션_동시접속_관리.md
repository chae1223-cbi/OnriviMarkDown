> "온리비 어서(Onrivi Author)는 작가의 소중한 원고가 다중 기기나 중복 브라우저 창에서 동시에 편집되다가 덮어써져 유실되는 사고를 원천 방지하기 위해 정교한 **세션 락(Session Lock) 및 단일 인스턴스 보호 체계**를 운영하고 있습니다.  
> 복잡하고 번거로운 시리얼 키 입력 대신 웹 가입 계정으로 1초 만에 완료되는 **원클릭 정품 라이선스 연동**, 데스크톱 고유 기기 바인딩, 그리고 다른 PC나 탭에서 접속 시 원고를 안전하게 지키는 **제한사용자(읽기 전용) 모드 및 제어권 인수(Take Over)** 메커니즘을 상세히 안내해 드립니다."

## 1. 온리비 어서 라이선스 체계 및 요금제 개요

온리비 어서는 작가님의 작업 규모와 환경에 맞춰 4단계 라이선스 플랜을 제공합니다.

| 플랜명 | 주요 대상 및 특징 | 이용 가능 기능 | 기기 동시 접속 |
| :--- | :--- | :--- | :---: |
| **Reader 플랜** | 무료 읽기 전용 사용자 | 마크다운 문서 무제한 읽기 및 뷰어 | 1대 |
| **Apprentice 플랜** | 신규 가입자 (14일 무료 체험) | 14일간 모든 편집 기능 및 기본 조판 테마 | 1대 (14일 체험) |
| **Regular 플랜** | 전문 출판 작가 및 집필가 | AI 지능형 글쓰기, EPUB/PDF 출판 사출, 지식보관함 | 공식 등록 기기 |
| **Elite Pro 플랜** | 출판사, 대형 연구원, 파워 유저 | 오프라인 독립 설치형, 무제한 지식보관함 RAG | 1대 PC 전용 |

## 2. 정품 라이선스 활성화 방법 (LicenseModal)

온리비 어서는 과거의 복잡한 32자리 시리얼 키나 로컬 백엔드 티켓 발급 방식 대신, **웹 계정(이메일 + 비밀번호) 로그인 기반 직접 인증** 방식을 채택하고 있습니다.

```
[접근 경로]
에디터 좌측 하단 상태바 또는 환경설정 좌측 사이드바:
  └── [라이선스 상태 뱃지] 클릭 ➔ LicenseModal 호출
```

```
┌────────────────────────────────────────────────────────────────────────┐
│                        정품 라이선스 활성화 대화상자                    │
│                                                                        │
│  [기기 고유 식별자]  e7f8-9a01-bc23-45de (자동 감지)                  │
│                                                                        │
│  가입 이메일 (ID)    [ author@example.com                         ]   │
│  비밀번호            [ ••••••••••••••••                           ]   │
│                                                                        │
│                    [ 🔐 계정 확인 및 정품 인증하기 ]                  │
│                                                                        │
│  ※ 신규 구독 또는 플랜 변경이 필요하신가요?                           │
│     ➔ [🌐 공식 대시보드(onrivi.com/dashboard) 이동]                   │
└────────────────────────────────────────────────────────────────────────┘
```

### ① 단계별 인증 순서
1. **[라이선스 상태]** 뱃지를 클릭하여 라이선스 모달을 엽니다.
2. 온리비 공식 홈페이지(`onrivi.com`) 가입 시 사용한 **이메일**과 **비밀번호**를 입력합니다.
3. **[계정 확인 및 정품 인증하기]** 버튼을 클릭합니다.
4. Supabase 인증 원장과 데스크톱 라이선스 검증 API(`/api/license/verify-desktop`)가 실시간으로 구독 상태를 확인합니다.
5. 인증이 성공하면 `✅ 본 계정은 성공적으로 확인되었습니다. (PRO 플랜)` 토스트 알림과 함께 데스크톱 안전 저장소(`saveLicenseFull`)에 기기 UUID가 영구 바인딩되며 1초 후 에디터가 정품 모드로 재기동됩니다.

### ② 라이선스 상태 3대 뱃지 안내
- **`✅ 정품 인증됨` (Cobalt #1d4ed8)**: 활성화된 유효 플랜으로 전 기능 정상 이용 가능
- **`⚠️ 체험판 (인증 필요)` (Amber #f59e0b)**: 미인증 상태로 기본 기능만 체험 가능
- **`🔒 미리보기 전용` (Rose #e11d48)**: 구독 기간이 만료되어 편집이 잠금되고 문서 열람 및 내보내기만 가능한 상태

## 3. 다중 기기 및 브라우저 세션 제어 원리 (Single Tab Guard)

문서를 작업하다가 다른 브라우저 탭을 열거나, 사무실 PC와 노트북에서 동시에 같은 계정으로 로그인했을 때 두 곳에서 서로 다른 내용이 저장되어 **작업 원고가 덮어써지는 사고(Race Condition)**를 온리비 어서는 어떻게 방어할까요?

온리비 어서는 HTML5 표준 **`BroadcastChannel('onrivi_editor_single_instance')`** 통신 기반의 **단일 인스턴스 보호 가드(Single Tab Guard)**를 작동시킵니다:

```
[시나리오 1: 동일 PC에서 새 탭을 추가로 열었을 때]

  [기존 탭 A (편집 중)]                      [신규 탭 B (방금 열림)]
          │                                          │
          │ <──── 접속 알림 PING 발송 ───────────────│ (새 창 접속)
          │                                          │
          │ ───── "나 이미 활성 상태임(PONG)" ─────> │
          │                                          │
       [정상 편집]                           [⚠️ 제한사용자 모드]
                                             (읽기 전용으로 안전 진입)
```

1. **핑-퐁(PING-PONG) 감지**: 새 탭이 열리면 백그라운드 채널로 `PING`을 보냅니다. 기존 편집 탭이 즉시 `PONG`으로 응답합니다.
2. **부드러운 제한사용자 진입**: 화면 전체를 강제로 닫거나 튕겨내지 않고, 신규 탭을 **`isDuplicateInstance = true (제한사용자 / 읽기 전용)`** 상태로 부드럽게 전환합니다.
3. **자동 승격 (RELEASE_LOCK)**: 작업을 마친 기존 탭 A를 닫으면 `RELEASE_LOCK` 신호가 전파되어, 남아있던 탭 B가 **별도의 새로고침 없이 즉시 정상 편집 탭으로 자동 승격**됩니다.

## 4. 제어권 인수 (Take Over) 메커니즘

만약 기존 탭이나 다른 PC가 켜져 있는 상태에서 **"지금 열려 있는 이 화면에서 바로 글을 쓰고 싶다"**면 어떻게 해야 할까요?

```
┌────────────────────────────────────────────────────────────────────────┐
│               ⚠️ 다른 창에서 이미 온리비 어서가 열려 있습니다             │
│                                                                        │
│  문서 동시 쓰기 충돌을 방지하기 위해 현재 화면은 [읽기 전용] 모드입니다. │
│                                                                        │
│               [ 🚀 이 화면에서 편집 시작하기 (제어권 인수) ]             │
└────────────────────────────────────────────────────────────────────────┘
```

1. 화면 상단에 출현하는 **[이 화면에서 편집 시작하기]** 버튼을 클릭합니다.
2. 시스템이 `CLAIM_LOCK` 메시지를 브로드캐스트하여 제어권을 즉각 현재 화면으로 인수합니다.
3. **타 세션 보호**: 제어권을 넘겨준 기존 화면은 강제 로그아웃되지 않으며, **`isRestrictedUser` (제한사용자) 모드로 안전 전환**된 채 화면이 자동으로 **미리보기(Preview) 모드로 전환**됩니다.
4. 따라서 기존 화면에서도 보던 글이 사라지지 않고 문서를 끊김 없이 참조할 수 있습니다!

## 5. 제한사용자(읽기 전용) 모드에서 가능한 작업

제어권을 갖지 못한 제한사용자 화면에서도 원고 열람과 출판 작업에는 아무런 제약이 없습니다:

- **100% 정상 지원 기능**:
  - 원고 전체 내용 열람 및 스크롤, 실시간 미리보기 (Preview)
  - A4 종이 스타일 조판 테마 변경 및 서식 스타일 감상
  - **인쇄 / PDF 사출 (`Ctrl+P`)**
  - **Word 문서 (`.docx`) 및 EPUB 전자책 (`.epub`) 내보내기**
  - **블로그용 인라인 HTML 복사**
  - 환경설정 열람 및 글꼴 크기 변경
- **안전을 위해 잠기는 기능**:
  - 본문 Monaco 에디터 텍스트 수정 및 삭제
  - 물리 디스크 파일 저장 (`Ctrl+S`)
  - 문서 병합 (Merge) 및 각주 자동 재채번

## 6. 웹 대시보드(onrivi.com/dashboard) 기기 세션 관리

사무실 컴퓨터를 켜두고 퇴근하여 집 PC에서 동시접속 제한에 걸렸다면:

1. 환경설정의 **[대시보드 이동]**을 클릭하거나 웹 브라우저에서 `https://onrivi.com/dashboard`로 이동합니다.
2. [기기 접속 관리] 섹션에서 등록된 기기 목록을 확인합니다.
3. 원격으로 연결을 해제하고 싶은 기기 옆의 **[연결 해제]** 버튼을 클릭하면 세션이 즉시 반환되어 현재 PC에서 자유롭게 집필을 이어갈 수 있습니다.

## 7. 자주 묻는 질문 (FAQ)

### Q1. 브라우저 창을 여러 개 띄워놓고 서로 다른 문서를 동시에 볼 수 없나요?
**A.** 볼 수 있습니다! 기존 탭에서 제어권을 가진 채로 새 탭을 열면 새 탭은 '제한사용자(미리보기 모드)'로 열리므로, 한쪽 모니터에는 기존 문서를 크게 띄워 참고하면서 다른 쪽 창에서 자유롭게 원고를 작성할 수 있습니다.

### Q2. '이 화면에서 편집 시작하기'를 누르면 기존 창에 쓰던 글이 날아가나요?
**A.** 날아가지 않습니다. 온리비 어서의 5초 세션 자동 복구 캐시가 메모리에 온전히 보존되어 있으며, 제어권이 넘어간 기존 창은 단순히 '수정'만 잠길 뿐 열려 있던 원고 텍스트는 그대로 유지됩니다.

### Q3. 인터넷 연결이 끊겨도 데스크톱 앱 정품 인증이 유지되나요?
**A.** 네! Electron 데스크톱 앱은 최초 1회 인증 완료 시 로컬 보안 스토리지에 인증 토큰과 만료일을 암호화 저장하므로, 비행기나 지하철 등 인터넷이 연결되지 않는 오프라인 환경에서도 정품 권한으로 원고를 집필할 수 있습니다.
