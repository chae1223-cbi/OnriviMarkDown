> "코딩(CSS)을 전혀 몰라도 괜찮습니다. 마우스 슬라이더를 좌우로 움직이는 순간, 우측 미리보기 화면에서 글자와 표가 마법처럼 실시간으로 바뀝니다."  
> 온리비 어서의 서식 튜닝 패널은 복잡한 CSS 코드를 직관적인 슬라이더와 컬러 피커로 완전히 시각화하여 누구나 3분 만에 전문가급 출판 서식을 완성할 수 있게 돕습니다.

---

## 1. 커스텀 서식 시작하기 (새 서식 복제)

시스템 제공 서식은 원본 훼손을 방지하기 위해 편집이 잠겨 있습니다. 나만의 커스텀 서식을 만들려면 기존 서식을 바탕으로 **새 서식을 복제 생성**해야 합니다.

```
[1단계] 우측 사이드바 툴바의 팔레트(🎨) 아이콘 클릭
[2단계] 상단 우측의 [⚙ 서식 관리] 버튼 클릭
[3단계] 좌측 상단의 [+ 새 서식 추가] 버튼 클릭
[4단계] '새 서식 1'이 자동 생성되며 이름 입력창이 열립니다 ➔ 원하는 이름(예: '나만의 수필집') 입력 후 Enter!
```

이제 잠금이 해제된 나만의 커스텀 서식이 생성되었으므로, 모든 슬라이더와 색상을 자유롭게 조작할 수 있습니다.

---

## 2. 1:1 실시간 위지윅(WYSIWYG) 피드백 시스템

온리비 어서의 서식 관리 창(`CssStyleModal`)은 좌우 2단 화면으로 구성되어 있습니다:

```
┌─────────────────────────────────┬─────────────────────────────────┐
│  [좌측 설정 패널]               │  [우측 실시간 미리보기 쇼케이스] │
│                                 │                                 │
│  - 7대 아코디언 설정 섹션       │  [🎴 모아보기]  [📝 내 원고보기] │
│  - 슬라이더 및 컬러 피커 조작   │                                 │
│  - 0px 단위 정밀 조절           │  💡 변경된 요소에 실시간 펄스   │
│                                 │     하이라이트(.onrivi-sync-pulse)│
│                                 │  💡 상단 HUD 상태 배지 즉각 반응│
│                                 │  💡 해당 카드로 자동 스무스 스크롤│
└─────────────────────────────────┴─────────────────────────────────┘
```

- **상단 뷰 모드 스위처**:
  - **`🎴 서식별 모아보기(Modules)`**: 글꼴, 제목, 표, 인용구 등 각 디자인 요소가 가장 잘 드러나는 표준 쇼케이스 카드로 확인합니다.
  - **`📝 현재 편집 문서(Document)`**: 내가 지금 실제로 작성 중인 원고 전체에 서식이 어떻게 적용되는지 실시간으로 확인합니다.
- **실시간 반응**: 좌측 패널에서 슬라이더를 움직이거나 색상을 바꾸는 순간, 우측 화면의 해당 요소가 은은하게 반짝(Pulse 애니메이션)이며 즉시 새로운 스타일로 렌더링됩니다.

## 3. 핵심 조판 슬라이더 정복 가이드

### ① 기본 타이포그래피 (✍️ 기본 타이포그래피)
문서 전체의 뼈대를 이루는 기본 활자 환경을 설정합니다.
- **문서 전체 글꼴 (`fontFamily`)**: [변경] 버튼을 눌러 내 컴퓨터에 설치된 폰트나 Pretendard, KoPub바탕 등 출판용 서체를 선택합니다.
- **기본 글자 크기 (`fontSize`)**: `10px ~ 36px` 범위로 조절합니다. (일반 문서: 15~16px, 시니어 전자책: 18~20px)
- **기본 줄 간격 (`lineHeight`)**: `1.0배 ~ 3.0배` (0.1배 단위 정밀 조절). (권장: 1.75~1.85배)

### ② 용지 여백과 본문 문단 (⚙️ 고급 레이아웃 및 본문 문단)
출판물의 판형(A4, B5 등)과 용지 상하좌우 마진, 문단 간격을 결정합니다.
- **용지 크기 & 방향**: A4/B5/A5 선택 및 가로/세로 방향 원클릭 전환
- **용지 마진 여백 (mm)**:
  - `위 여백` / `아래 여백`: `5mm ~ 50mm` (온리비 표준 기본값: **18mm**)
  - `왼쪽 여백` / `오른쪽 여백`: `5mm ~ 50mm` (온리비 표준 기본값: **12mm**)
- **기본 본문 문단 (P) 세부 설정**:
  - `문단 위 여백` / `문단 아래 여백`: `0px ~ 48px` 슬라이더
  - **`문장 사이 간격 (sentence-gap)`**: 문단 내에서 `Shift + Enter`로 줄바꿈했을 때 줄과 줄 사이의 틈새를 `0px ~ 32px`로 1px 단위 조절
  - **`첫 줄 들여쓰기 (text-indent)`**: 소설이나 수필처럼 문단 첫 머리를 안쪽으로 밀어 넣는 기능 (`0px ~ 48px`)

### ③ 제목 위계 스타일 (👑 제목 위계 스타일 H1 ~ H6)
큰 제목부터 소제목까지 시각적 계층 구조를 완성합니다.
- **H1 마스터 설정**:
  - 기준 글자 크기 (`16px ~ 48px`), 정렬(왼쪽/가운데/오른쪽/양끝), 굵기/기울임/밑줄
  - **단계별 크기 감소폭 (`headingSizeOffset`)**: `0px ~ 10px` (기본 4px 지정 시 H1=32px, H2=28px, H3=24px로 자동 계산)
  - **왼쪽 여백 (`padding-left`)**: 제목 들여쓰기 조절 (`0px ~ 60px`)
  - **하단 밑줄 장식**: [선 없음], [실선 (1px solid)], [관보선 (3px double)] 버튼 지원. 색상 지정 시 글자색과 매칭되어 우아한 하단선 생성
- **H2 ~ H6 개별 탭**:
  - H2에는 하단 포인트 밑줄을 넣고, H3에는 좌측 세로 바(`border-left: 4.5px solid ...`)를 추가하여 세련된 챕터 구분을 연출할 수 있습니다.

## 4. 표(Table) 3대 선 두께 독립 제어

표는 보고서와 출판물에서 가장 중요한 시각적 도표입니다. 일반 에디터에서는 표 테두리 전체가 한 번에 바뀌어 투박하지만, 온리비 어서는 **외곽선, 가로선, 세로선 3대를 완벽히 독립 제어**합니다:

```
┌──────────────────────────────────────────────┐ ─── [1] 외곽 테두리 두께 (outerBorderWidth)
│  구분      │  내용            │  비고        │
├────────────┼──────────────────┼──────────────┤ ─── [2] 행(가로선) 두께 (rowBorderWidth)
│  항목 A    │  설명 1          │  완료        │
│  항목 B    │  설명 2          │  진행 중     │
└────────────┴──────────────────┴──────────────┘
             │                  │
             └── [3] 열(세로선) 두께 (colBorderWidth)
```

### ① 표 형태 프리셋 3종
- **모든 테두리 (Grid)**: 외곽 1px, 가로선 1px, 세로선 1px (격자형 완전 표)
- **가로선 강조 (Modern Tech)**: 외곽 2px, 행 가로선 1px, **세로선 0px (소거)**. 현대적인 기술 백서와 잡지에서 가장 선호하는 세련된 표 양식
- **미니멀 (Minimal)**: 외곽 0px, 가로 0px, 세로 0px (테두리 없이 은은한 헤더 배경색만으로 구분)

### ② 세부 커스텀 슬라이더
- `표 외곽 테두리 두께`: `0px ~ 8px`
- `표 행(가로선) 두께`: `0px ~ 8px`
- `표 열(세로선) 두께`: `0px ~ 8px` (0px로 설정하면 지저분한 세로 칸막이선이 완벽히 사라집니다!)
- `표 헤더(TH) 배경색` / `표 본문(TD) 배경색`: 부드러운 파스텔 톤이나 짙은 네이비로 지정
- `표 셀 내부 여백 (Padding)`: `0px ~ 24px` 슬라이더로 표 안쪽 숨통을 틔워줍니다.

## 5. 인용구와 코드블록 커스텀

### ① 인용구 (Blockquote)
- **형태 프리셋**:
  - `왼쪽 띠형`: 좌측에 4px 굵은 컬러 바만 노출 (뉴스, 칼럼 추천)
  - `전체 박스형`: 사방이 1px 은은한 테두리로 둘러싸인 안전한 카드 형태
  - `그림자 박스형`: 테두리 없이 부드러운 3D 드롭 섀도가 깔리는 모던 카드
- **세부 조절**: 테두리 두께, 모서리 둥글기(`border-radius`: 0~40px), 채우기 배경색, 상하 바깥 여백

### ② 코드 블록 (CodeBlock)
- **테마 프리셋**:
  - `기본 박스`: 부드러운 밝은 회색(`#F1F5F9`) 배경의 기본형
  - `Mac OS 테마`: 상단에 창 제어 버튼 감성의 타이틀 바와 세련된 다크 그레이(`#282C34`)
  - `다크 테마 고정`: 인쇄나 웹에서도 항상 어두운 밤하늘색(`#0F172A`) 고정
- **코드 블록 줄 간격 (행간)**: `1.0배 ~ 2.0배` 슬라이더 지원 (기본 1.35배). 본문 글의 1.8배 넓은 행간이 코드 블록에 번져 길게 늘어지는 현상을 방지합니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 슬라이더를 0px로 맞췄는데도 여백이 남아있나요?
**A.** 온리비 어서의 최신 서식 엔진은 마진 상쇄(Margin Collapse) 방어 알고리즘이 적용되어 있어, 슬라이더를 `0px`로 내리면 해당 요소가 인접 요소와 1픽셀의 오차도 없이 완전히 밀착됩니다. 만약 그래도 여백이 보인다면 이웃한 다른 태그(예: 제목의 `margin-bottom` 또는 본문의 `margin-top`)의 수치를 함께 확인해 보세요.

### Q2. 여러 서식을 만들어 두고 문서마다 다르게 적용할 수 있나요?
**A.** 네, 원하는 만큼 무제한으로 서식을 만들어 둘 수 있습니다! 문서 A에는 '시니어 자서전 서식'을, 문서 B에는 '가로선 강조 보고서 서식'을 지정하여 각 문서마다 개별 보관됩니다.
