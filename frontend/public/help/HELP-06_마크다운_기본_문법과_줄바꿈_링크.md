## 1. 기본 표현

| 표현 | 마크다운 | 문서보기에서 적용 |
| --- | --- | --- |
| 제목 3 | `### 제목` | 제목 도구, `Ctrl+3`, 새 줄에서 `###` 입력 |
| 굵게 | `**내용**` | 선택 후 `Ctrl+B` |
| 기울임 | `*내용*` | 선택 후 `Ctrl+I` |
| 취소선 | `~~내용~~` | 선택 후 `Ctrl+Shift+X` |
| 인라인 코드 | `` `내용` `` | 선택 후 `Ctrl+E` |
| 링크 | `[표시 글](https://주소)` | `Ctrl+K`로 글과 주소 입력 |
| 밑줄 | `<u>내용</u>` | 선택 후 `Ctrl+U` |

문서보기의 새 입력줄에서 `#`부터 `######`까지 입력하면 제목으로 전환합니다. 제목 맨 앞에서 Backspace를 누르면 일반 본문으로 바꿀 수 있습니다. 이미 있는 코드블록 안의 `#`는 코드이며 제목으로 바뀌지 않습니다.

## 2. 줄바꿈·공백·탭

일반 문서보기의 `Enter`는 바로 다음 줄로 이동합니다. 생성하는 일반 줄바꿈은 원문에 줄바꿈으로 기록하며, 끝에 역슬래시를 추가하지 않습니다. 제목·목록 등 다른 구조를 시작할 때는 구조에 필요한 빈 줄이 들어갈 수 있습니다.

연속 스페이스와 줄 끝 공백도 문서보기에서 유지합니다. 문장 중간 Tab은 환경설정의 **탭 간격** 수만큼 일반 스페이스를 삽입합니다. 기본은 4칸입니다. 목록·표에서는 Tab의 역할이 다릅니다.

다른 마크다운 뷰어는 연속 공백이나 일반 줄바꿈을 합칠 수 있습니다. 온리비 문서보기의 표시 규칙과 외부 뷰어의 표시 규칙은 동일하지 않을 수 있습니다.

## 3. HTML 태그가 남아 있는 이유

일반 제목·목록·본문·코드는 마크다운으로 저장합니다. 마크다운에 없는 밑줄, 표 셀 내부 줄바꿈(`<br>`), 동영상·지도 삽입 등에는 HTML 표현을 사용합니다. 이런 태그를 모두 지우면 해당 기능의 정보가 사라질 수 있습니다.

링크와 날짜·이모지 사용법은 HELP-32를 참고하세요.
