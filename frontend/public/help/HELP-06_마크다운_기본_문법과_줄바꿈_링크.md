# 마크다운 기본 문법과 줄바꿈 링크

온리비 어서는 국제 표준 마크다운(CommonMark / GitHub Flavored Markdown) 문법을 100% 지원하며, 전문 작가의 집필 속도와 편의를 위해 다양한 스마트 타이핑 자동 변환 기능과 혁신적인 **실시간 라이브 프리뷰(Live Preview) 인라인 서식 전개·접기**를 함께 제공합니다.

## 1. 제목 (Heading: H1 ~ H6) 입력하기

제목은 문서의 골격과 출판 목차(TOC)를 구성하는 가장 핵심적인 요소입니다. `#` 기호의 개수에 따라 총 6단계의 계층 구조를 만듭니다:

```markdown
# 대제목 1 (문서 제목 또는 장 제목)
## 중제목 2 (절 제목)
### 소제목 3 (항 제목)
#### 세부제목 4
##### 상세제목 5
###### 최소단위제목 6
```

- **스마트 제목 변환**: 줄 맨 앞에서 `#`을 1개부터 6개까지 입력하고 **스페이스(공백)**를 한 번 누르면, 해당 줄이 그 자리에서 즉시 큼직한 제목 스타일로 자동 변환됩니다.
- **십진 개요 번호 자동 연동**: 선택한 출판 서식 프로필에 십진 분류 번호(`decimal-outline`)가 설정된 경우, `# ` 뒤에 스페이스를 한 번 더 누르면 `1. `, `1.1 `, `1.1.1 ` 등의 계층형 번호가 자동으로 부여됩니다.
- **제목 탈출 및 엔터(Enter) 처리**: 제목 행의 끝에서 `Enter`를 누르면 제목 아래에 깔끔한 일반 본문 문단(paragraph)이 생성되어 다음 내용 집필로 매끄럽게 넘어갑니다. (내용이 빈 제목 행에서 `Enter`를 누르면 일반 문단으로 즉시 복귀합니다.)
- **고대비 선명화 뱃지**: 문서보기 에디터에서는 현재 제목의 레벨(H1~H6)이 우측 상단 뱃지로 선명하게 표시되며, 인쇄나 PDF 내보내기 시에는 뱃지가 100% 자동 숨김 처리되어 본문 무결성을 완벽히 유지합니다.

## 2. 줄바꿈과 문단 나눔의 규칙

마크다운은 일반 문서 작성 프로그램과 달리 **'문단(Paragraph)'**과 **'강제 줄바꿈(Soft Break)'**을 명확히 구분하여 처리합니다:

- **문단 나눔 (Paragraph Break - 기본 개행)**:
  - `Enter` 키를 누르면 독립된 새로운 문단이 생성됩니다.
  - 온리비 어서의 전자책·출판 조판 엔진은 문단과 문단 사이에 정갈한 문단 여백(Margin)을 자동으로 부여하므로, 불필요하게 엔터를 여러 번 누르지 않아도 가독성 높은 여백이 유지됩니다.
- **소프트 줄바꿈 (Soft Break - 문단 내 강제 개행)**:
  - 문단을 분리하지 않고 같은 문단 안에서 줄만 다음 줄로 내리고 싶을 때는 **`Shift + Enter`**를 누릅니다.
  - 마크다운 표준 방식인 **줄 끝에 공백 2칸을 입력하고 `Enter`**를 눌러도 동일하게 작동합니다. 마크다운 소스 코드에는 `<br>` 또는 줄 끝 공백 2개로 안전하게 기록됩니다.
- **빈 줄 최적화**:
  - 연속적인 빈 줄이 과도한 세로 공간을 차지하지 않도록 콤팩트한 행간이 적용되어 있어, 원고의 전체적인 균형과 리듬을 깔끔하게 유지할 수 있습니다.

## 3. 텍스트 강조와 스마트 인라인 서식

본문 중 중요한 단어나 문장을 돋보이게 하거나 보조적인 의미를 부여할 때 사용하는 문법입니다:

| 서식 종류 | 마크다운 원문 문법 | 추천 단축키 | 미리보기 결과 |
| :--- | :--- | :---: | :--- |
| **굵게 (Bold)** | `**중요한 내용**` | `Ctrl + B` | **중요한 내용** |
| *기울임 (Italic)* | `*강조 단어*` | `Ctrl + I` | *강조 단어* |
| ~~취소선 (Strikethrough)~~ | `~~삭제된 문구~~` | `Ctrl + Shift + X` | ~~삭제된 문구~~ |
| <u>밑줄 (Underline)</u> | `<u>밑줄 친 내용</u>` | `Ctrl + U` | <u>밑줄 친 내용</u> |
| `인라인 코드 (Code)` | `` `단축키 또는 변수명` `` | `Ctrl + E` | `단축키 또는 변수명` |

### 가. 🚀 스마트 서식 선언 및 Live Preview 전개/접기 (신규 기능)

온리비 어서는 텍스트를 미리 블록 지정하지 않고도 빠르게 서식을 작성할 수 있는 **스마트 서식 선언 워크플로우**를 지원합니다:

1. **템플릿 즉시 선언**:
   - 텍스트를 선택하지 않은 빈 커서 상태에서 `Ctrl + B`, `Ctrl + I`, `Ctrl + E` 등의 단축키를 누르면, `**텍스트**`, `` `코드` `` 등의 템플릿이 삽입되고 내부 단어('텍스트' 또는 '코드')가 자동으로 블록 선택됩니다.
2. **타이핑 즉시 대체**:
   - 키보드로 글자를 입력하는 즉시 선택된 안내 단어가 사용자가 입력한 내용으로 교체되며, 해당 서식이 그대로 유지됩니다.
3. **Enter 또는 Tab으로 서식 탈출 및 자동 렌더링 (Fold)**:
   - 타이핑을 마치고 `Enter` (또는 `Tab`)를 누르면, 줄바꿈으로 나뉘는 대신 서식 바깥으로 커서가 빠져나오며 문법 기호(`**` 등)가 감춰지고 깔끔한 서식으로 즉시 렌더링(Fold) 확정됩니다. 이후 바로 일반 텍스트를 연속해서 작성할 수 있습니다.
4. **커서 진입 시 문법 기호 실시간 표시 (Unfold)**:
   - 이미 작성된 굵은 글자나 코드 등의 내부로 방향키를 이동하거나 마우스로 클릭하면, 양쪽에 해당 문법 기호(`**`, `*`, `~~`, `<u>`, `` ` ``)가 블루 톤으로 동적 전개되어 현재 어떤 서식인지 직관적으로 확인하고 정밀하게 수정할 수 있습니다.
5. **좌우 방향키(← / →) 경계 이탈 시 자동 렌더링 복귀**:
   - 서식 단어의 시작 경계나 끝 경계를 좌/우 방향키로 벗어나면, 문법 기호가 자동으로 사라지고 본래의 정갈한 서식 문서로 깔끔하게 렌더링 복귀합니다.
   - 화면에 표시되는 기호는 가상 데코레이션이므로, 파일 저장 및 PDF 내보내기 시 기호가 중복 저장되거나 출력물에 노출되지 않습니다.

## 4. 구분선 (가로선: Horizontal Rule)

문맥의 큰 전환이나 챕터 내 섹션 구분을 시각적으로 명확히 나누고 싶을 때 사용합니다:

```markdown
---
또는
***
```

- **입력 방법**: 빈 줄에서 대시 3개(`---`) 또는 별표 3개(`***`)를 입력하고 `Enter`를 누르면 얇고 정갈한 수평선(가로 구분선)이 생성됩니다.
- **구분선 아래 새 문단 연속 생성**: 구분선이 선택된 상태에서 `Enter`를 누르면, 구분선 바로 아래에 새로운 빈 문단이 생성되어 멈춤 없이 곧바로 본문 타이핑을 이어갈 수 있습니다.

## 5. 하이퍼링크 (Hyperlink) 삽입과 문서 연결

외부 웹사이트나 내 컴퓨터 작업장 안의 다른 마크다운 문서를 연결하는 방법입니다:

```markdown
[온리비 공식 웹사이트](https://onrivi.com)
[작업 환경 연결 가이드](./HELP-04_작업_환경_연결.md)
```

- **단축키 활용 (`Ctrl + K`)**:
  - 링크를 걸고 싶은 텍스트를 드래그하여 선택한 뒤 `Ctrl + K`를 누르면 링크 설정 팝업이 나타납니다. 연결할 URL 또는 파일 경로를 입력하고 [적용]을 누르면 깔끔하게 링크가 완성됩니다.
- **작업장 내부 문서 상대경로 연결**:
  - 같은 작업장 폴더 내의 다른 마크다운 문서를 연결할 때는 `./파일명.md` 형태의 상대경로를 사용합니다. 문서보기 에디터나 도움말 모달에서 클릭 시 해당 문서로 즉시 전환됩니다.
- **문서 링크 피커 (`Ctrl + Shift + L` 또는 슬래시 커맨드)**:
  - 작업장 내 수십 개의 문서 중 원하는 문서를 검색하여 원클릭으로 상호 링크를 삽입할 수 있습니다.

## 6. 실전 집필 꿀팁 & 단축키 일람

- **플로팅 도구함 호출 (`Ctrl + Space`)**:
  - 집필 중 마우스를 잡지 않고 언제든지 `Ctrl + Space`를 누르면 커서 바로 옆에 굵게, 기울임, 밑줄, 링크, 취소선 등의 서식 도구함이 열립니다.
- **슬래시 빠른 명령어 (`/`)**:
  - 빈 줄에서 `/`를 입력하고 제목, 목록, 인용구, 표, 코드블록, 링크 등을 타이핑하면 방향키로 손쉽게 선택하여 삽입할 수 있습니다.
- **서식 일괄 제거 (`Ctrl + `)**:
  - 복사해 온 텍스트에 원치 않는 서식이 섞여 있을 때, 블록 지정 후 서식 지우기를 실행하면 깔끔한 일반 본문 텍스트로 초기화됩니다.
