> 마크다운(Markdown)은 복잡한 마우스 조작 없이 평범한 키보드 기호(`#`, `*`, `-`) 몇 개만으로 서식이 입혀진 아름다운 문서를 작성할 수 있는 가장 대중적인 글로벌 표준 서식 언어입니다. 온리비 어서와 함께 마크다운의 기초를 가장 쉽고 다정하게 시작해 보세요.

## 1. 제목 위계 (Heading 1 ~ Heading 6)

책이나 보고서를 쓸 때 가장 중요한 것은 목차와 제목의 위계(Hierarchy)입니다. 마크다운에서는 샵 기호(`#`)의 개수로 제목의 크기와 레벨을 정합니다.

```markdown
# 1단계 제목 (문서 대제목, H1)
## 2단계 제목 (장/섹션 제목, H2)
### 3단계 제목 (소주제/절 제목, H3)
#### 4단계 제목 (세부 항목, H4)
##### 5단계 제목 (소분류, H5)
###### 6단계 제목 (최하위 분류, H6)
```

### ① 제목 작성 규칙과 팁
1. **`#` 뒤에는 반드시 한 칸 띄어쓰기(스페이스바)**를 넣어야 제목으로 올바르게 인식됩니다.
2. **`# H1`은 한 문서당 1번만 사용하는 것을 권장**합니다. 책의 메인 제목이나 논문의 논제에 해당하기 때문입니다.
3. 본문의 장과 절은 주로 `## H2`와 `### H3`를 사용하여 계층을 구성합니다.
4. 본문의 내용에 따라 `## H4` ~ `## H6` 각 단계별로 분류할때 사용한다.

### ② 툴바의 제목 스핀 버튼 (HeadingSpinButton)
마크다운 기호를 직접 타이핑하지 않고도 서식 툴바의 제목 조절기를 통해 원클릭으로 제목을 적용할 수 있습니다:
- 상단 툴바 및 플로팅 툴바의 **`[▲ H3 ▼]`** 버튼을 확인하세요.
- `▲` 버튼을 누르면 제목 레벨이 커지고(H3 ➔ H2 ➔ H1), `▼` 버튼을 누르면 작아집니다.
- 가운데의 **`[H3]`** 버튼을 클릭하면 현재 커서가 놓인 줄에 즉시 해당 제목 태그가 적용됩니다.

> [!팁]
> **고대비 선명화로 눈이 편안한 에디터**  
> 온리비 어서 편집기에서는 `#` 접두사 태그가 선명한 코발트 블루(`#1d4ed8`)로, 제목 본문은 딥 틸/에메랄드 톤으로 눈에 띄게 하이라이트 처리되어 긴 원고 속에서도 각 챕터의 위치가 한눈에 식별됩니다.

## 2. 텍스트 강조 서식 4총사

중요한 단어나 핵심 문장을 강조할 때 사용하는 마크다운의 핵심 서식들입니다.

| 서식 종류 | 마크다운 문법 | 단축키 | 미리보기 결과 |
| :--- | :--- | :--- | :--- |
| **굵게 (Bold)** | `**중요한 내용**` | `Ctrl + B` | **중요한 내용** |
| *기울임 (Italic)* | `*강조할 단어*` | `Ctrl + I` | *강조할 단어* |
| <u>밑줄 (Underline)</u> | `<u>밑줄 긋기</u>` | `Ctrl + U` | <u>밑줄 긋기</u> |
| ~~취소선 (Strikethrough)~~ | `~~삭제된 내용~~` | `Ctrl + Shift + X` | ~~삭제된 내용~~ |
| `인라인 코드` | `` `myVariable` `` | `Ctrl + E` | `myVariable` |

### ① 굵게와 기울임 결합하기
기호들을 중첩하면 굵은 기울임체도 손쉽게 만들 수 있습니다:
```markdown
***굵으면서 기울어진 문장***
```
➔ ***굵으면서 기울어진 문장***

### ② 온리비 어서의 취소선 안전 규격
온리비 어서는 일상적인 물결표(예: `12월 1일 ~ 12월 5일`)가 취소선으로 오인되지 않도록, **정확히 물결표 2개(`~~`)로 감싼 경우에만 취소선으로 변환**하는 GitHub 표준 안전 파서를 채택하고 있습니다.

## 3. 문단과 줄바꿈 (가장 많이 묻는 핵심!)

초보 마크다운 사용자가 가장 혼란스러워하는 부분이 바로 "줄바꿈(Enter)"입니다. 온리비 어서의 줄바꿈 메커니즘을 정확히 알아두면 원고 조판이 훨씬 쉬워집니다.

### ① 단순 엔터 1번 vs 빈 줄(빈 행 1개)의 차이
마크다운 표준 문법에서는 원칙적으로 엔터를 1번만 치면 다음 줄로 넘어가지 않고 한 줄로 이어져 버립니다. 하지만 온리비 어서는 사용자의 편의를 위해 **한국인 친화적인 자동 줄바꿈 엔진(`remark-breaks`)**을 기본 탑재하고 있습니다:

```markdown
첫 번째 문장입니다. (엔터 1번)
두 번째 문장입니다.

세 번째 문장입니다. (엔터 2번으로 빈 줄 생성)
```

1. **단순 엔터 1번**: 같은 문단(`<p>`) 안에서 줄만 바뀌는 부드러운 개행(`<br>`)이 일어납니다.
2. **빈 행 1개 (엔터 2번)**: 새로운 문단(`<p>`)으로 완전히 분리되며, 서식 설정에서 지정한 문단 상하 여백이 적용됩니다.

### ② `<br>` 태그와 문장 간격 (`sentence-gap`)
문단 안에서 특정 문장들 사이의 간격만 살짝 넓히고 싶다면 `<br>` 태그를 사용할 수 있습니다.

```markdown
위쪽 문장입니다.<br>
아래쪽 문장입니다.
```

> [!중요]
> **출판 서식의 비밀: sentence-gap 슬라이더**  
> 온리비 어서의 `서식관리(CSS 프로필)`에는 문단 내 문장 사이 간격을 1px 단위로 미세 조절하는 **`sentence-gap`** 컨트롤이 탑재되어 있습니다. 종이책 조판이나 웹진 발행 시 줄간격을 아름답게 맞추는 데 활용해 보세요.

## 4. 링크 삽입의 모든 것 (Web, 문서, 폴더)

인터넷 웹사이트 링크부터 내 서재 안의 다른 문서, 심지어 특정 폴더로 이동하는 링크까지 마크다운으로 깔끔하게 연결할 수 있습니다.

### ① 표준 웹 하이퍼링크
- 문법: `[표시할 이름](웹사이트 주소)`
- 단축키: 문장을 드래그하고 `Ctrl + K`를 누르면 링크 템플릿이 즉시 생성됩니다.
```markdown
온리비 어서 공식 홈페이지는 [온리비 어서](https://onrivi.com)입니다.
```
미리보기: 온리비 어서 공식 홈페이지는 [온리비 어서](https://onrivi.com)입니다.

### ② URL 자동 링크
꺾쇠 괄호(`< >`)로 주소를 감싸면 주소 자체가 하이퍼링크로 자동 변환됩니다:
```markdown
<https://onrivi.com>
```

### ③ 내 서재 안의 다른 문서 연결 (상대 경로 링크)
같은 작업장에 있는 다른 챕터나 노트를 연결할 때는 상대 경로를 적어줍니다:
```markdown
이전 챕터는 [HELP-05: 3대 입력 방식](HELP-05_3대_본문_입력_방식.md)을 참조하세요.
```
> [!팁]
> 서식 툴바의 **`문서 연결(BookBookmark 아이콘)`** 버튼을 누르거나 슬래시 명령어 `/doclink`를 입력하면, 내 작업장의 마크다운 파일 목록 픽커가 나타나 원하는 문서를 검색해서 클릭 한 번으로 링크를 삽입할 수 있습니다.


### ④ 특정 제목(헤딩)으로 바로 점프하는 앵커 링크
문서 내부나 다른 문서의 특정 소제목으로 독자를 바로 이동시키고 싶다면 `#헤딩제목` 해시를 붙입니다:
```markdown
[텍스트 강조 문법으로 바로가기](#2-텍스트-강조-서식-4총사)
```

### ⑤ 작업장 폴더 링크 (`📁`)
탐색기 내 특정 폴더를 마크다운 본문에 링크할 수도 있습니다:
```markdown
관련 참고자료는 [자료실 폴더](./자료실/)에서 확인하세요.
```
- **미리보기 클릭 시 동작**: 좌측 탐색기(LeftSidebar)에서 해당 폴더가 자동으로 스르륵 펼쳐지며 부드러운 코발트 블루 펄스 하이라이트로 위치를 안내해 줍니다.

## 5. 자주 묻는 질문 (FAQ)

### Q1. 문서 안에 특수기호(`*`, `#`, `[`)를 마크다운 서식으로 바꾸지 않고 그대로 출력하려면 어떻게 하나요?
**A.** 기호 바로 앞에 역슬래시(`\`)를 붙여주시면 됩니다. 이를 '이스케이프(Escape)'라고 합니다.  
예: `\# 제목 아님`, `\*별표그대로\*`

### Q2. 밑줄 단축키(`Ctrl+U`)를 눌렀더니 마크다운 기호 대신 `<u></u>`가 들어갑니다. 정상인가요?
**A.** 네, 100% 정상입니다! 마크다운 표준(CommonMark)에는 밑줄 문법이 정의되어 있지 않으므로, 전 세계 모든 마크다운 편집기 및 온리비 어서는 웹 및 출판 표준인 HTML `<u>` 태그를 사용하여 완벽한 밑줄을 표현합니다.
