# 마크다운 기본 문법과 줄바꿈 링크

온리비 어서는 표준 마크다운(CommonMark / GFM) 문법을 100% 지원하며, 집필 편의를 위해 다양한 스마트 타이핑 자동 변환 기능을 함께 제공합니다.

---

## 1. 제목 (Heading: H1 ~ H6) 입력하기

제목은 문서의 뼈대를 이루는 가장 중요한 요소입니다. `#` 개수에 따라 6단계 계층 구조를 만듭니다:

```markdown
# 대제목 1 (문서 제목 또는 장 제목)
## 중제목 2 (절 제목)
### 소제목 3 (항 제목)
#### 세부제목 4
##### 상세제목 5
###### 최소단위제목 6
```

- **스마트 제목 변환**: 줄 맨 앞에서 `#`을 1개부터 6개까지 입력하고 **스페이스(공백)**를 한 번 누르면 해당 줄이 즉시 제목 스타일로 변환됩니다.
- **제목 자동 번호 연동**: 선택한 출판 서식에 십진 분류 번호(`decimal-outline`)가 설정되어 있는 경우, `# ` 뒤에 스페이스를 한 번 더 누르면 `1. `, `1.1 ` 등의 계층 번호가 자동으로 부여됩니다.

---

## 2. 줄바꿈과 문단 나눔의 규칙

마크다운에서 줄바꿈은 일반 텍스트 에디터와 조금 다르게 동작합니다:

- **문단 나눔 (Paragraph Break)**:
  - `Enter` 키를 눌러 빈 줄을 하나 만들면 새로운 문단이 형성됩니다. 출판 조판 엔진은 문단 사이에 적절한 문단 간격(Margin)을 자동으로 부여합니다.
- **소프트 줄바꿈 (Soft Break - 강제 줄바꿈)**:
  - 문단을 나누지 않고 같은 문단 안에서 다음 줄로만 내려가고 싶을 때는 **`Shift + Enter`**를 누르거나, 문장 끝에 **공백(스페이스) 2칸**을 입력하고 `Enter`를 누릅니다. 마크다운 원문에는 `<br>` 태그 또는 줄 끝 공백 2칸으로 기록됩니다.

## 4. 하이퍼링크 (Hyperlink) 삽입하기

웹사이트 주소나 다른 문서로 이동할 수 있는 링크를 만드는 방법입니다:

```markdown
[온리비 공식 웹사이트](https://onrivi.com)
[작업 환경 연결 가이드](./HELP-04_작업_환경_연결.md)
```

- **단축키 활용 (`Ctrl + K`)**:
  - 링크를 걸고 싶은 텍스트를 마우스로 드래그하여 선택한 뒤 `Ctrl + K`를 누르면 링크 입력 팝업이 나타납니다. 주소(URL)를 입력하고 [확인]을 누르면 깔끔하게 링크가 생성됩니다.
- **상대경로 링크**:
  - 같은 작업장 내의 다른 마크다운 파일을 연결할 때는 `./파일명.md` 형식의 상대경로를 사용하면, 도움말 모달이나 웹 뷰어에서 클릭 시 해당 문서로 즉시 이동합니다.
