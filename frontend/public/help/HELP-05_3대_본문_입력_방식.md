## 1. 문서보기에서 직접 입력

본문을 클릭하고 입력합니다. 제목·굵게·취소선·목록·인용문·표는 문서보기에서 적용할 수 있습니다. 복잡한 수식이나 지원 범위 밖의 원문 블록은 개별 편집창이 표시될 수 있습니다.

마크다운 전체 문서를 붙여넣으면 제목·목록 등 구조를 읽어 문서로 표시합니다. 메타영역이 포함된 원문도 처리합니다. 붙여넣기 결과를 확인하고 필요하면 `Ctrl+Z`로 취소하세요.

## 2. 플로팅 서식 툴바

1. 서식을 적용할 텍스트나 여러 목록 줄을 선택합니다.
2. `Ctrl+Space` 또는 오른쪽 툴바의 서식 도구로 툴바를 엽니다.
3. 굵게·제목·숫자 목록·일반 목록·체크리스트 등 원하는 버튼을 누릅니다.

마우스로 선택하는 것만으로는 자동 표시되지 않습니다. `Esc`로 닫을 수 있습니다.

## 3. 슬래시 명령어

새 줄이나 명령을 입력할 위치에 `/`를 입력하고 이름을 검색합니다. `/표`, `/코드블록`, `/팁`, `/날짜`처럼 한글로도 검색할 수 있습니다. 방향키로 선택하고 `Enter` 또는 `Tab`으로 실행합니다.

슬래시 메뉴가 열려 있을 때의 Tab은 명령 실행입니다. 메뉴를 닫은 본문에서의 Tab과 다릅니다.

## 4. 단축키

`Ctrl+B` 굵게, `Ctrl+K` 링크, `Ctrl+T` 표, `Ctrl+Shift+E` 코드블록 등 기본 단축키가 있습니다. 실제 지정값은 **환경설정 → 단축키 / 명령어**에서 확인하세요. 사용자 정의 설정은 문서보기 명령에도 반영됩니다.
