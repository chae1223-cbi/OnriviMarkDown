# 각주·인용과 참고문헌 관리

학술 논문, 전문 서적, 연구 보고서에서는 주장의 신뢰성을 뒷받침하기 위해 정확한 출처 표기와 각주(Footnote) 작성이 필수적입니다. 온리비 어서는 표준 마크다운 각주 문법과 함께 **참고문헌 관리 모달(Reference Manager)**을 제공합니다.

---

## 1. 마크다운 표준 각주(Footnote) 작성법

문장 속에 각주 번호를 달고, 문서 하단에 부연 설명을 배치하는 방법입니다:

```markdown
온리비 어서는 로컬 우선 아키텍처를 채택하고 있습니다[^1]. 이 방식은 사용자의 데이터 주권을 지켜줍니다[^2].

[^1]: 로컬 우선(Local-First)이란 데이터를 외부 클라우드가 아닌 사용자 PC에 우선 저장하는 소프트웨어 설계 패러다임입니다.
[^2]: 한국지능정보사회진흥원(NIA), 2026년 데이터 프라이버시 백서 42페이지 참조.
```

- **실시간 번호 자동 정렬**: 본문에서 각주를 `[^1]`, `[^2]` 형태로 작성하면, 조판 엔진이 본문 위치에 위첨자 번호(¹⁾, ²⁾)를 달아주고, 실제 페이지 하단이나 문서 끝에 각주 구분선과 함께 깔끔하게 정렬하여 렌더링합니다.
- **상호 점프 링크**: 웹 및 PDF 뷰어에서 본문의 각주 번호를 클릭하면 하단 설명으로 즉시 이동하고, 설명 옆의 리턴 화살표(↩)를 누르면 원래 읽던 본문 위치로 돌아옵니다.

---

## 2. 참고문헌 관리 모달 (Reference Manager)

학술 연구자나 전문 작가를 위한 고급 참고문헌 도구입니다:

- **호출 방법**: 상단 메뉴의 [도구] ➔ [참고문헌 관리]를 선택합니다.
- **BibTeX 데이터 가져오기**: Google Scholar, RISS, DBpia, arXiv 등에서 복사한 BibTeX 텍스트를 붙여넣으면 저자, 논문명, 학술지, 출판년도, DOI가 자동으로 파싱되어 등록됩니다.
- **국제 표준 학술 인용 스타일 지원**:
  - **APA 스타일**: `(홍길동, 2026)` 형태의 인문·사회과학 표준
  - **IEEE 스타일**: `[1]` 형태의 공학·컴퓨터과학 표준

---

## 3. 인쇄 및 출판 시 조판 최적화

- PDF로 인쇄할 때 각주가 페이지 경계선에 걸려 잘리지 않도록, 조판 엔진이 해당 페이지의 하단 여백 공간을 계산하여 각주를 최적의 위치에 자동 배치합니다.
- 전자책(EPUB) 내보내기 시에는 팝업 각주(Popup Footnote) 표준 규격으로 자동 변환되어 전자책 단말기(리디페이퍼, 크레마 등)에서 화면 전환 없이 가볍게 팝업으로 각주를 열람할 수 있습니다.
