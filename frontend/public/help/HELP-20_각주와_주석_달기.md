> "전문 서적이나 학술 논문, 심층 기획 기사를 집필할 때 생소한 전문 용어의 어원이나 보충 설명, 인용 논문의 출처를 본문 한가운데 장황하게 늘어놓으면 독자의 몰입도가 크게 떨어집니다.  
> 온리비 어서(Onrivi Author)는 세계 표준 마크다운 각주(Footnote)와 출판 조판 엔진을 결합하여, 본문에는 작고 단정한 위첨자 번호만 남기고 모든 부연 설명을 문서 최하단에 기품 있게 격리 배치합니다. 또한 클릭 한 번으로 설명과 본문을 오가는 강력한 양방향 인터랙티브 점프를 지원합니다."

## 1. 학술 서적·출판 논문의 필수 도구, 각주란?

각주(Footnote)는 본문의 가독성을 최우선으로 보호하면서도, 필요한 독자에게 심도 있는 추가 정보나 출처를 제공할 수 있도록 돕는 출판의 핵심 도구입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 어서 각주(Footnote) 조판 구조                  │
│                                                                        │
│  [본문 영역]                                                           │
│  온리비 어서는 개인형 RAG 기술[^1]을 탑재하여 거짓 없는 사실만을...       │
│                                                                        │
│  ───────────────────────────────────────────────────────────────────  │
│  [문서 최하단 각주 영역 (Footnote Section)]                            │
│  [^1]: RAG(Retrieval-Augmented Generation)는 대규모 언어 모델이         │
│        자체 지식에만 의존하지 않고 외부 지식을 검색해 답변하는 기술입니다. ↩ │
└────────────────────────────────────────────────────────────────────────┘
```

온리비 어서의 각주는 일반적인 텍스트 괄호 설명과 달리, 화면 뷰어 및 PDF 전자책에서 서로 상호작용하는 스마트 하이퍼링크로 동작합니다.

## 2. 마크다운 표준 각주 문법

온리비 어서는 GitHub Flavored Markdown(GFM)의 표준 각주 문법을 100% 충실하게 따릅니다.

### ① 본문 참조 마커 (`[^번호]`)
부연 설명이 필요한 단어나 문장의 바로 뒤에 대괄호와 캐럿(`^`), 그리고 식별 번호를 붙여줍니다:

```markdown
인공지능의 환각 현상[^1]을 방지하기 위해서는 철저한 팩트체크가 필수적입니다.
```

### ② 하단 설명 정의 (`[^번호]: 내용`)
문서의 하단(또는 문단 아래)에 동일한 번호를 기입하고 콜론(`:`) 뒤에 설명할 내용을 작성합니다:

```markdown
[^1]: 환각(Hallucination)이란 AI가 주어진 질문에 대해 사실이 아닌 그럴싸한 거짓말을 지어내는 현상을 뜻합니다.
```

### ③ 여러 문단으로 이루어진 장문 각주
각주의 설명이 길어져 여러 문단이나 목록을 포함해야 할 때는, 둘째 줄부터 **스페이스 4칸(또는 탭 1번)** 들여쓰기하여 작성하면 동일한 각주에 귀속됩니다:

```markdown
[^2]: 이 이론은 20세기 중반 정보이론의 창시자인 클로드 섀넌에 의해 제안되었습니다.

    이후 현대 디지털 통신 및 데이터 압축 알고리즘의 기초가 되었습니다.
```

> [!참고]
> **단어형 각주 이름 지원**  
> 식별자에는 숫자뿐만 아니라 영문 단어나 한글도 사용할 수 있습니다(예: `[^용어해설]`, `[^ref_ai]`). 화면에 렌더링될 때는 독자가 읽기 편하도록 시스템이 자동으로 1, 2, 3 순서의 단정한 숫자로 변환해줍니다.

## 3. 양방향 인터랙티브 점프 (Interactive Two-Way Jump)

온리비 어서의 각주는 독서 몰입감을 극대화하는 **양방향 점프 메커니즘**을 내장하고 있습니다.

### ① 본문 ➔ 각주 설명 점프
미리보기 화면에서 본문 속 파란색 위첨자 각주 번호(`[1]`)를 마우스로 클릭하면, 화면이 부드럽게 스크롤되며 문서 최하단의 해당 각주 설명으로 즉시 점프합니다.

### ② 각주 설명 ➔ 본문 원래 위치 복귀 (↩)
각주 설명을 모두 읽은 독자가 방금 읽던 본문 위치를 찾느라 스크롤을 위아래로 헤맬 필요가 없습니다!  
각주 설명 끝에 자동으로 생성되는 **되돌아가기 화살표(↩)**를 클릭하면, 0.01초 만에 방금 읽던 본문 문맥 위치로 정확하게 복귀합니다.

이 스마트 네비게이션 기능은 웹 브라우저는 물론, 온리비 어서로 제작된 독립형 HTML 문서와 EPUB 전자책에서도 완벽하게 동작합니다.

## 4. 온리비만의 원클릭 각주 생산성 도구

문서를 작성하다가 각주 번호를 일일이 세고, 문서 맨 아래로 스크롤을 내려 정의를 적은 뒤 다시 올라오는 작업은 매우 번거롭습니다. 온리비 어서는 이를 1초 만에 해결하는 전용 자동화 기능을 제공합니다:

### ① 서식 툴바 `fn` 원클릭 자동 채번
- **상단 서식 툴바**: 툴바 중앙의 **[fn]** 각주 버튼 클릭
- **키보드 단축키**: `Ctrl + Alt + F` (macOS: `Cmd + Option + F`)

단추를 누르는 순간 에디터 내부에서 다음과 같은 작업이 한 번에 일어납니다:
1. **최대 번호 자동 계산**: 문서 전체를 스캔하여 기존 각주 번호 중 가장 큰 번호를 추적하고 다음 번호(`[^N]`)를 본문 커서 위치에 자동 삽입합니다.
2. **문서 최하단 정의 라인 생성**: 문서 맨 아래로 자동 이동하여 `[^N]: ` 라인을 추가합니다.
3. **입력 커서 자동 안착**: 커서가 방금 생성된 `[^N]: ` 직후로 자동 이동하여 대기하므로, 손을 멈출 필요 없이 곧바로 각주 설명을 타이핑할 수 있습니다.

### ② 각주 일괄 재정렬 (`ORGANIZE_FOOTNOTES`)
원고를 수정하다 보면 중간에 각주를 삭제하거나 새로운 각주를 끼워 넣어 번호 순서가 뒤죽박죽(`[^1]`, `[^5]`, `[^2]`)이 되는 경우가 있습니다.  
온리비 어서의 각주 정리 엔진은 문서 내에 흩어진 모든 각주를 파싱하여, 본문 인용 순서에 맞추어 번호를 1부터 오름차순으로 완벽히 재정렬하고 문서 맨 아래로 깔끔하게 정리해줍니다.

## 5. 출판 조판 테마와 각주 스타일링

온리비 어서의 출판 조판 엔진(`CSS Profile Engine`)은 각주 영역을 일반 본문과 시각적으로 명확히 분리하여 전문 출판 서적의 품격을 부여합니다:

- **활자 크기 및 행간**: 본문 폰트보다 15% 아담한 전용 크기(`0.85em`)와 정갈한 행간을 적용하여 부가 정보로서의 위계를 분명히 합니다.
- **상단 은은한 구분선**: 본문과 각주 영역 사이에 부드러운 가로 실선(`<hr class="footnote-sep">`)을 자동으로 사출하여 단락 간의 경계를 우아하게 나눕니다.
- **A4 PDF 출판 최적화**: PDF 내보내기 시 각 페이지 하단 여백 내에 단정하게 안착되어 인쇄소 납본 기준을 완벽하게 충족합니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 동일한 각주 설명을 본문 여러 곳에서 반복 인용할 수 있나요?
**A.** 네! 본문의 서로 다른 문장에서 동일한 각주 번호(예: `[^1]`)를 여러 번 사용하면, 하단의 단 하나의 설명 정의(`[^1]: ...`)에 복수의 되돌아가기 앵커(↩, ↩2)가 생성되어 중복 설명 없이 경제적으로 출처를 밝힐 수 있습니다.

### Q2. 지식보관함(RAG) 출처 앵커와 일반 각주의 차이는 무엇인가요?
**A.**
- **일반 각주(`[^1]`)**: 현재 작성 중인 문서의 최하단으로 연결되어 본문 용어 설명이나 보충 주석을 제공합니다.
- **지식보관함 출처 앵커(`[출처 1: ...](file:///...)`)**: 내 컴퓨터에 저장된 다른 외부 원본 마크다운 파일의 실제 줄 번호(L45)로 화면을 스크롤하여 커서를 이동시키는 온리비만의 데스크톱 전용 지식 링크 시스템입니다.

### Q3. 인쇄할 때 각주가 다음 페이지로 밀려나지 않나요?
**A.** 온리비 어서의 Chromium 기반 고정밀 A4 인쇄 엔진(`printHTMLToPDF`)은 각주 블록의 높이를 사전에 계산하여 페이지 브레이크(`page-break-inside: avoid`)를 방어하므로, 각주가 흉하게 잘리는 현상을 사전에 방지합니다.
