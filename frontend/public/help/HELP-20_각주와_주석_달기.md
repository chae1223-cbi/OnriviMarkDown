# 각주·인용과 참고문헌 관리

## 1. 각주

```markdown
이 문장에는 보충 설명이 있습니다.[^note1]

[^note1]: 독자가 확인할 추가 설명입니다.
```

본문의 참조와 각주 정의에 같은 키를 사용합니다. 각주 도구를 사용할 수 있으며 도구 메뉴의 각주 정리는 참조 순서와 정의를 정리하는 작업입니다. 원고에 없는 출처를 자동으로 만들어 주는 기능은 아닙니다.

## 2. 참고문헌 파일

참조관리에서 BibTeX 파일을 선택·작성·저장합니다. 입력 폼과 샘플을 이용해 인용키·제목·저자·연도·출판사·URL·DOI 등을 기록할 수 있습니다. 인용키에는 공백을 넣지 말고 문헌 사이에 중복되지 않도록 합니다.

```bibtex
@book{kim2026,
  title = {자료를 읽는 방법},
  author = {김연구},
  year = {2026},
  publisher = {예시출판사}
}
```

예시 문헌은 실제 출처가 아닙니다. 실제 사용 자료로 교체하세요. 본문 인용은 `[@kim2026]` 같은 키를 사용합니다. 표기와 목록의 실제 표시를 확인하고 파일을 저장합니다.

## 3. 관리 시 주의

사용 중인 참고문헌 파일을 삭제하면 해당 인용을 찾지 못할 수 있습니다. 삭제 안내를 읽고, 다른 PC로 원고를 옮길 때 참고문헌 파일도 함께 전달합니다. 각주와 참고문헌은 역할이 다르며, 출판사별 인용 규칙을 자동 인증하는 기능은 아닙니다. 내보낸 결과에서 인용과 목록이 연결되는지 확인하세요.
