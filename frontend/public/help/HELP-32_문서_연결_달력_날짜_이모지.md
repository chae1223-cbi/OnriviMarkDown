# 문서 연결·날짜·이모지·서명과 문서 병합

## 문서 연결

문서 연결 도구에서 연결할 파일과 필요한 제목 위치를 선택합니다. 상대 경로와 공백이 있는 경로를 확인하세요. 대상 문서를 옮기거나 이름을 바꾸면 링크도 확인해야 합니다. 링크에 보이는 제목이 파일 경로 자체와 같은 것은 아닙니다.

## 날짜·달력·이모지

날짜/시간 도구와 달력에서 날짜 또는 형식을 선택해 입력할 수 있습니다. 현재 날짜는 컴퓨터의 시간·지역 설정에 영향을 받습니다. 날짜를 넣는 작업과 자동으로 계속 갱신되는 필드는 구분하세요.

이모지 도구에서 문자를 고르고 본문에 삽입합니다. 팝업이 열려 있을 때 Escape와 Enter는 팝업의 동작에 쓰일 수 있습니다. 이모지 모양은 글꼴·운영체제·출력 형식에 따라 달라집니다.

## 서명/발신인

서명 도구 또는 Ctrl+Alt+R을 사용합니다. 선택한 글을 감싸거나 기본 서명 문구를 삽입하는 동작이 있습니다. 예시 이름·날짜·인 표시는 실제 정보로 바꾸세요. 붉은 인 표시는 시각적 표현이며 법적 전자서명이나 인증된 직인이 아닙니다.

## 문서 병합

도구 메뉴의 문서 병합은 현재 보기에서 활성화되는 조건을 확인한 뒤 사용합니다. 병합 전 원본을 저장하고 순서·중복 제목·이미지 경로·각주 키·참고문헌 키를 점검합니다. 병합 결과에도 선택한 제목 번호 설정이 적용될 수 있으므로 원문과 목차를 함께 확인하세요.
