# 문서 연결·날짜·이모지·서명과 문서 병합

## 1. 문서 연결과 위키링크 (`[[문서명]]`)

문서 연결 도구에서 연결할 파일과 필요한 제목 위치를 선택해 표준 마크다운 링크를 생성할 수 있습니다:
- **링크명 직접 수정 지원**: 문서 연결 창(DocLinkPicker) 상단의 `링크명 (앞의 표시할 텍스트)` 입력창에서 기본 문서명 대신 원하는 텍스트로 자유롭게 변경할 수 있습니다. 에디터나 문서보기에서 본문 텍스트를 미리 드래그하여 선택한 후 문서 연결을 실행하면 해당 텍스트가 링크명으로 자동 채워집니다.
- **ESC 키 및 닫기 버튼 연동**: 문서 연결 창이 열린 상태에서 키보드의 `Esc` 키를 누르거나 상단 우측의 `✕` 버튼을 누르면 검색 및 연결 작업을 취소하고 창이 즉시 닫힙니다.
- **빠른 위키링크 자동완성**: 에디터에서 `[[`를 입력하면 작업장 내 마크다운 문서 목록이 자동완성 추천창으로 나타납니다.
- **표준 상대경로 링크**: 문서를 선택하면 `[링크명](<상대경로.md#헤딩>)` 형태의 표준 마크다운 상대 링크로 자동 변환되어 다른 컴퓨터나 웹에서도 링크가 깨지지 않습니다.
- 대상 문서를 다른 폴더로 옮기거나 이름을 바꾸면 링크 경로도 확인해야 합니다.

## 2. 날짜·달력·이모지

날짜/시간 도구와 달력에서 날짜 또는 형식을 선택해 입력할 수 있습니다. 현재 날짜는 컴퓨터의 시간·지역 설정에 영향을 받습니다. 날짜를 넣는 작업과 자동으로 계속 갱신되는 필드는 구분하세요.

데스크톱의 이모지 도구는 운영체제 기본 이모지 창을 엽니다. 브라우저에서는 입력 위치에 커서를 놓고 Windows의 `Win + .` (마침표), macOS의 `Control + Command + Space`를 사용하세요. 자체 이모지 보관함 패널은 사용하지 않습니다. 선택한 이모지는 현재 입력 위치에 들어가며 모양은 글꼴·운영체제·출력 형식에 따라 달라집니다.

## 3. 서명/발신인

서명 도구 또는 `Ctrl+Alt+R`을 사용합니다. 선택한 글을 감싸거나 기본 서명 문구를 삽입하는 동작이 있습니다. 예시 이름·날짜·인 표시는 실제 정보로 바꾸세요. 붉은 인 표시는 시각적 조판 표현이며 법적 전자서명이나 인증된 직인이 아닙니다.

## 4. 문서 병합

도구 메뉴의 문서 병합은 여러 마크다운 문서를 하나의 완성된 출판 원고로 순서대로 합치는 기능입니다. 병합 전 각 원본을 저장하고 순서, 중복 제목, 이미지 경로, 각주 키, 참고문헌 키를 점검합니다. 병합 결과물에도 선택한 서식의 제목 번호 설정이 일괄 적용될 수 있으므로 원문과 목차를 함께 확인하세요.
