# 문서 연결·날짜·이모지·서명과 문서 병합

온리비 어서는 작가의 상상력과 지식의 조각들을 하나로 엮어 거대한 한 권의 책이나 종합 보고서로 완성할 수 있도록 돕는 다채로운 **문서 연결 및 집필 부가 도구**를 갖추고 있습니다.

---

## 1. 위키링크(Wiki-Link)를 통한 문서 간 상호 연결

하나의 프로젝트 안에서 서로 다른 문서를 하이퍼링크로 긴밀하게 연결하는 기능입니다:

```markdown
이 설정에 대한 자세한 안내는 [[HELP-04_작업_환경_연결]] 문서를 참고하세요.
```

- **입력 방법**: 본문에서 대괄호 두 개(`[[`)를 입력하면 작업장 내의 마크다운 파일 목록이 자동 완성 팝업으로 나타납니다.
- **클릭 이동**: 도움말 센터나 에디터에서 해당 링크를 클릭하면 즉시 연결된 문서가 새 탭이나 현재 화면에 열려 유기적인 지식 네트워크를 구축할 수 있습니다.

---

## 2. 달력 날짜와 현재 시간 빠른 삽입

기안서, 일기, 업무 일지, 회의록을 작성할 때 오늘 날짜를 일일이 손으로 치지 않고 원클릭으로 삽입합니다:

- **슬래시 명령어**: 빈 줄에서 `/date`를 치면 `2026-10-24` 형식의 오늘 날짜가 즉시 삽입됩니다.
- **날짜 피커 모달**: 상단 메뉴의 [도구] ➔ [날짜 삽입]을 열어 달력에서 원하는 특정 날짜와 시간 형식(예: `2026년 10월 24일 토요일 오전 10:00`)을 선택할 수 있습니다.

---

## 3. 이모지(Emoji) 피커 및 전자 서명 삽입

- **이모지 피커**:
  - 단축키 `Win + .` (Mac은 `Cmd + Ctrl + Space`)를 누르거나 툴바의 스마일(😊) 아이콘을 클릭하여 다채로운 감정 표현 및 기호 이모지를 즉시 삽입할 수 있습니다.
- **전자 서명(Signature) 패드**:
  - 계약서, 확인서, 서약서 작성 시 마우스나 태블릿 펜으로 직접 서명할 수 있는 캔버스 서명 패드를 제공합니다.
  - 서명한 필적은 고화질 투명 PNG 이미지로 자동 변환되어 본문 하단 서명란에 단정하게 배치됩니다.

---

## 4. 다중 문서 하나로 묶기: [문서 병합] 기능

단편 원고나 챕터별로 나뉘어 있는 여러 개의 마크다운 파일(`01장.md`, `02장.md`, `03장.md`)을 하나의 완성된 단행본으로 묶어 출판하고 싶을 때 사용합니다:

1. 상단 메뉴의 [도구] ➔ [문서 병합]을 클릭합니다.
2. 병합할 마크다운 파일들을 순서대로 선택하고 상하 드래그로 장/절 순서를 정렬합니다.
3. [병합 실행]을 누르면 각 챕터 사이에 적절한 페이지 분할(`page-break`) 태그가 삽입된 종합본 문서가 하나로 생성됩니다.
4. 이 병합본을 통해 한 번에 전체 PDF 인쇄나 ePub 전자책 패키징을 완성할 수 있습니다.
