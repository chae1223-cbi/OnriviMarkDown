## 1. 작업장과 리소스 폴더

- **작업장:** 작성하는 마크다운 파일과 폴더를 탐색하는 위치입니다.
- **리소스 폴더:** 이미지·서식·AI 프롬프트·참고문헌·지식 자료를 관리하는 공통 위치입니다.

두 폴더는 역할이 다릅니다. 환경설정에는 현재 로컬 또는 클라우드 위치에 해당하는 리소스 폴더가 표시됩니다.

## 2. 로컬 연결

파일 메뉴에서 작업장 폴더를 열고 환경설정의 자원 관리에서 리소스 폴더를 지정합니다. 데스크톱은 OS 폴더 선택창을 사용합니다. 브라우저는 파일 시스템 접근 권한이 필요하며 브라우저 지원에 따라 연결 방식이 달라집니다.

브라우저의 접근 권한이 만료되면 같은 폴더를 다시 연결하고 읽기·쓰기 권한을 허용하세요.

## 3. Google Drive 연결

파일 메뉴에서 Google Drive 연결을 실행하고 사용할 계정의 접근을 허용합니다. 작업장과 리소스 폴더 정보가 설정되었는지 확인합니다. 초기화에서는 필요한 하위 폴더를 생성합니다.

토큰 갱신과 만료 전 저장 처리가 있지만, 네트워크·인증 오류가 있으면 재연결이 필요합니다. 연결 해제는 Drive 파일을 삭제하는 동작이 아닙니다.

![리소스 폴더 안내](/help/assets/fig4_resource_folder.png)

## 4. 리소스 폴더에서 사용하는 자료

| 하위 폴더 | 자료와 기능 |
| --- | --- |
| `media` | 사진·로컬 동영상, 그림책 이미지, 렌더링·내보내기 |
| `profiles` | `userCssProfiles.json`, 사용자 서식 |
| `prompt` | `ai_prompts.json`, `ai_presets.json`, `promptTemplates.json` |
| `bible` | `references.bib`, 참고문헌·인용 |
| `db` | `onrivi_knowledge.db`, 데스크톱 지식 색인 |

Mermaid와 코드 원문, 외부 지도·동영상 URL, 이모지는 마크다운 본문에 저장됩니다. 문서 이동 시에도 참조 자료가 함께 이동했는지 확인하세요.
