> 온리비 어서(Onrivi Author)는 사용자의 소중한 원고와 지식 자산을 본인의 동의 없이 외부 서버에 임의로 저장하지 않는 **로컬 우선(Local-First)** 철학을 고수합니다. 내 컴퓨터의 안전한 하드디스크 폴더(로컬 서재)와 언제 어디서나 접속할 수 있는 Google Drive(클라우드 서재)를 연결하여 완벽한 집필 작업실을 구축해 보세요.

---

## 1. 온리비 어서의 작업 공간 구조 2대 축

온리비 어서의 작업 공간은 서로 역할을 분담하는 두 가지 핵심 폴더로 구성됩니다.

```
┌───────────────────────────────────────────────┐
│              [1] 작업장 (Workspace)           │
│   • 내가 집필하는 마크다운 문서들 (.md)       │
│   • 책의 챕터, 폴더별 문서 분류 및 원고 보관   │
└───────────────────────┬───────────────────────┘
                        │ 상호 연결
┌───────────────────────▼───────────────────────┐
│        [2] 공통 리소스 폴더 (Resource Folder)  │
│   • profiles/ : 나만의 CSS 출판 서식          │
│   • media/    : 캡처 및 붙여넣은 이미지·미디어 │
│   • prompt/   : 맞춤형 Gemini AI 프롬프트/프리셋│
│   • bible/    : 학술·출판 참고문헌 (BibTeX)   │
│   • db/       : 로컬 지식 베이스 SQLite DB     │
└───────────────────────────────────────────────┘
```

1. **작업장 (Workspace / 서재)**:  
   내가 집필하는 실제 마크다운 문서(`.md`)들이 모여 있는 책장입니다. 소설 집필 폴더, 기술 명세서 폴더, 블로그 원고 폴더 등 프로젝트 단위로 폴더를 자유롭게 열고 전환할 수 있습니다.
2. **공통 리소스 폴더 (Resource Folder)**:  
   문서들이 공통으로 사용하는 **서식(CSS 프로필), 이미지 미디어, AI 프롬프트, 참고문헌(BibTeX)**을 한곳에 안전하게 모아두는 '중앙 자원 창고'입니다.

## 2. 왜 공통 리소스 폴더(Resource Folder)를 지정해야 할까요?

일반적인 마크다운 편집기에서는 글을 쓸 때마다 이미지가 어디 저장되는지 몰라 헤매거나, 문서를 다른 컴퓨터로 옮겼을 때 이미지가 모조리 엑박(Broken Image)으로 깨지는 문제를 겪습니다.

온리비 어서는 이를 해결하기 위해 **공통 리소스 폴더** 시스템을 기본 탑재했습니다:

| 리소스 하위 폴더 | 관리 대상 자원 | 주요 역할 및 이점 |
| :--- | :--- | :--- |
| **`profiles/`** | `userCssProfiles.json` | 내가 직접 튜닝한 폰트, 색상, 여백 등 출판 CSS 서식 영구 보존 |
| **`media/`** | `img_xxxxxxxx.png` 등 | 에디터에 붙여넣거나 끌어다 놓은 이미지가 해시 기반 고유 파일명으로 자동 저장 |
| **`prompt/`** | `ai_prompts.json` 등 | 나만의 AI 글쓰기 프롬프트 및 프리셋 템플릿 보관 |
| **`bible/`** | `references.bib` | 학술 논문, 도서 인용을 위한 표준 BibTeX 서지 데이터베이스 |
| **`db/`** | `onrivi_knowledge.db` | 데스크톱 로컬 지식 보관함의 고속 SQLite 데이터베이스 |

> [!중요]
> **전체사용자 필수 항목!**  
> 공통 리소스 폴더를 지정하지 않으면 이미지를 클립보드에서 붙여넣거나 나만의 서식을 저장할 때 안내 경고가 표시됩니다. 최초 시작 시 꼭 한 번 지정해 두세요.

## 3. 로컬 작업장 연결 (내 컴퓨터 폴더 열기)

내 컴퓨터의 하드디스크를 작업장으로 사용할 때 가장 빠르고 완벽한 오프라인 작업 환경이 마련됩니다.

![내 PC 공통 자원 폴더 지정과 로컬 서재](/media/스크린샷_2026-10-10_084410.png?align=center)

### ① 내 PC 작업장 폴더 열기
1. 상단 메뉴바의 `파일(F) ➔ 작업장 폴더 열기`를 누르거나, 단축키 `Ctrl + Shift + O`를 누릅니다.
2. (또는 좌측 사이드바 상단의 `작업장 실폴더` 바를 클릭합니다.)
3. 내 컴퓨터 탐색기 창이 나타나면 글을 보관할 폴더(예: `D:\MyNovels` 또는 `내 문서\온리비원고`)를 선택하고 확인을 누릅니다.
4. 좌측 사이드바 탐색기에 해당 폴더의 모든 마크다운 파일 트리와 하위 폴더가 즉시 로드됩니다.

### ② 로컬 공통 리소스 폴더 지정하기
1. 상단 메뉴바 우측 끝에 깜빡이는 **`[⚠️ 리소스 폴더 미설정]`** 칩을 클릭하거나, `도구(T) ➔ 환경 설정 ➔ 일반 설정 ➔ 자원 관리`로 이동합니다.
2. `[폴더 선택 (필수)]` 버튼을 클릭합니다.
3. 내 PC의 전용 자원 보관 폴더(예: `D:\Onrivi_Asset` 권장)를 선택합니다.
4. 온리비 어서가 선택된 폴더 안에 5대 필수 서브폴더(`profiles`, `media`, `prompt`, `bible`, `db`)를 1초 만에 자동으로 깔끔하게 구성해 줍니다.

## 4. Google Drive 클라우드 서재 무설정(Zero-Config) 연결법

컴퓨터를 포맷해도, 집과 회사를 오가며 다른 PC에서 작업해도 Google Drive를 연결해 두면 언제든 동일한 집필실이 열립니다.

### ① 클릭 한 번으로 자동 연결하기 (Zero-Config)
1. **연결 시작**:  
   좌측 사이드바 탐색기에서 파란색 **`[☁️ 내 구글 드라이브 연결]`** 버튼을 클릭하거나, 상단 메뉴바의 `파일(F) ➔ 내 구글 드라이브 연결`을 선택합니다.
2. **구글 로그인 및 권한 승인**:  
   구글 계정 로그인 창이 열립니다. 온리비 어서의 구글 드라이브 액세스 권한 체크박스를 확인하고 `[계속]`을 누릅니다. (데스크톱 앱에서는 보안을 위해 시스템 기본 웹 브라우저 브리지를 통해 안전하게 인증됩니다.)
3. **무인 자동 세팅 (Zero-Config)**:  
   복잡한 폴더 ID나 설정을 입력할 필요가 없습니다! 온리비 어서가 사용자의 구글 드라이브 최상단에 아래 구조를 **100% 자동으로 즉시 생성하고 바인딩**합니다:
   ```
   Google Drive (내 드라이브)
   └── OnriviAuthor/
       ├── 작업장/      ➔ [클라우드 작업장]: 내가 쓰는 모든 마크다운 문서 (.md)
       └── 참조파일/    ➔ [클라우드 리소스 폴더]: profiles/, media/, prompt/, bible/, db/
   ```
4. 좌측 탐색기 상단에 내 구글 계정 이름과 함께 구글 드라이브 파일 트리가 펼쳐지며 즉시 클라우드 집필이 시작됩니다.

### ② 백그라운드 무중단 토큰 자동 갱신 (Auto-Refresh)
일반적인 클라우드 연동 프로그램은 1시간이 지나면 인증 토큰이 만료되어 글을 쓰다 저장이 튕기곤 합니다. 온리비 어서는 **토큰 만료 5분 전에 백그라운드에서 조용히 토큰을 자동 갱신**하는 무중단 스케줄러가 탑재되어 있어, 온종일 창을 띄워두고 글을 써도 연결이 끊어지지 않습니다.

### ③ 구글 드라이브 연결 해제
클라우드 서재 작업을 마치고 로컬 작업장으로 돌아가고 싶다면, 탐색기 상단의 빨간색 **`[🔌 해제]`** 버튼이나 상단 메뉴의 `파일(F) ➔ 구글 드라이브 연결 해제`를 누르면 언제든 안전하게 연결이 해제됩니다.

## 5. 로컬-클라우드 간 안전한 파일 관리 노하우

### 1) 환경 간 완벽한 자원 격리 (Cross-contamination 방지)
온리비 어서는 로컬 모드와 구글 드라이브 클라우드 모드의 설정을 완전히 격리하여 관리합니다. 로컬 작업장을 사용할 때는 로컬 리소스 폴더(`D:\Onrivi_Asset` 등)만 참조하고, 구글 드라이브 작업장을 사용할 때는 구글 드라이브 안의 `참조파일` 폴더만 참조하므로 서식이나 이미지가 엉뚱한 곳에 뒤섞이지 않습니다.

### 2) 이미지 상대 경로 표준화
문서에 이미지를 복사하여 붙여넣으면(`Ctrl + V`), 이미지는 리소스 폴더 안의 `media/` 디렉터리에 암호학적 해시 파일명(`img_a1b2c3d4e5f6.png`)으로 저장되며 본문에는 상대 경로로 삽입됩니다:
```markdown
![](media/img_a1b2c3d4e5f6.png)
```
따라서 나중에 폴더 전체를 압축하여 다른 사람에게 전달하거나 출판사에 투고하더라도 링크가 깨지지 않고 이미지가 완벽하게 함께 보존됩니다.

### 3) 자유로운 멀티 디바이스 연속 집필
* **이동 중 / 카페**: 웹 브라우저에서 `onrivi.com`에 접속하여 Google Drive를 연결해 가볍게 메모 및 초안을 작성합니다.
* **작업실 / 서재 PC**: 데스크톱 전용 앱을 열어 로컬 하드디스크의 고용량 대작 원고를 오프라인 상태에서 안정적으로 집필하고 고품질 조판 PDF로 인쇄합니다.

> **구글 드라이브에 저장된 파일도 일반 마크다운 파일입니다!**  
> 온리비 어서가 구글 드라이브에 생성한 문서들도 구글 드라이브 웹사이트나 모바일 구글 드라이브 앱의 `OnriviAuthor/작업장` 폴더에서 일반 파일 형태로 언제든 다운로드하거나 확인할 수 있습니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 구글 드라이브 연결 시 온리비 개발팀이 제 문서를 볼 수 있나요?
**A.** 전혀 볼 수 없습니다! 온리비 어서는 Google의 공식 OAuth 표준을 준수하며, 통신은 사용자의 브라우저와 Google 서버 간의 다이렉트 암호화 통신으로만 이루어집니다. 어떤 원고 데이터도 온리비 서버를 경유하지 않으므로 보안과 프라이버시가 100% 보장됩니다.

### Q2. 로컬 리소스 폴더를 외장 하드디스크나 USB 메모리로 지정해도 되나요?
**A.** 네, 가능합니다. 외장 드라이브(예: `E:\Onrivi_Asset`)로 지정해 두시면, 외장 하드를 다른 컴퓨터에 꽂아 작업할 때도 나만의 출판 서식과 이미지 라이브러리를 그대로 이어 사용할 수 있어 매우 편리합니다.

### Q3. 다른 마크다운 에디터(Typora, Obsidian 등)에서 쓰던 폴더를 그대로 열어도 되나요?
**A.** 네, 완벽하게 호환됩니다! 온리비 어서는 100% 표준 GitHub Flavored Markdown(GFM) 규격을 따르므로, 기존에 사용하시던 폴더를 `작업장 폴더 열기`(`Ctrl+Shift+O`)로 열면 기존 폴더 구조와 마크다운 문서들을 손상 없이 그대로 열람하고 집필을 이어갈 수 있습니다.
