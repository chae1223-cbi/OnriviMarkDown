## 1. 사진·동영상 넣기

플로팅 툴바, `/사진`·`/이미지`·`/동영상` 또는 빠른 작업의 사진 넣기를 사용합니다. 오른쪽 세로 툴바에 별도 이미지 삽입 버튼은 없습니다.

찾아보기는 현재 작업 환경을 따릅니다. Google Drive 작업에서는 Drive 파일 선택을, 데스크톱 로컬 작업에서는 OS 파일 선택을 사용하며 현재 리소스 폴더에서 찾기를 시작합니다. 브라우저 로컬 작업은 폴더 접근 권한이 필요합니다.

## 2. 파일 복사와 같은 이름 처리

선택한 로컬 또는 Drive 사진·동영상 파일은 현재 환경의 리소스 `media` 폴더에 복사합니다. 같은 이름의 대상 파일이 있으면 이번에 선택한 파일 내용으로 덮어씁니다. 수정 날짜를 비교해 오래된 파일을 자동 제외하는 방식은 아닙니다.

웹 이미지·외부 영상 주소는 링크를 유지할 수 있습니다. Drive의 비공개 파일 주소는 인증과 파일 접근 권한이 필요합니다. Drive 찾아보기의 동영상 크기 제한은 100MB입니다.

## 3. 편집과 복사

문서의 이미지·동영상·지도에 표시되는 **편집** 버튼으로 주소·자료와 삽입 옵션을 변경합니다. **복사**는 다른 문서에 붙여넣을 수 있는 미디어 참조를 복사합니다. 파일 바이너리나 사진 픽셀 자체를 복사하는 버튼과는 다릅니다.

이미지는 클립보드 붙여넣기와 파일 드래그도 지원합니다. 파일 저장에 실패하면 경로·권한·연결을 확인하세요.

## 4. 지도와 외부 영상

`/지도`에서 위치·지도 설정을 입력하고 `/동영상`에서 지원하는 영상 주소 또는 파일을 선택합니다. 웹 지도나 외부 영상은 인터넷과 서비스의 삽입 허용 정책에 영향을 받습니다. 인쇄물에서는 대화형 재생이 유지되지 않을 수 있습니다.

## 5. 다른 환경으로 옮기기

마크다운만 복사하면 상대경로 사진이 사라질 수 있습니다. 문서 이동 기능과 리소스 폴더를 확인하고 참조하는 `media` 자료도 함께 옮기세요. 도움말의 `/help/assets/` 그림은 앱에 포함된 도움말 자산으로 사용자 리소스 폴더와 다릅니다.
