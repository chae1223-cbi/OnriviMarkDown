# 수학 수식 작성과 편집

수식 도구는 LaTeX (KaTeX) 문법으로 고품질 수학 수식을 작성하고 문서에 미려하게 조판하는 기능입니다. 계산기의 연산 결과를 검증하는 기능은 아닙니다.

## 1. 입력 방법과 수식 마법사

수식 도구(상단 툴바의 시그마 $\sum$ 버튼) 또는 `Ctrl+Shift+T`를 누르면 수식 마법사 모달이 열립니다:
- 분수(`\frac{a}{b}`), 제곱근(`\sqrt{x}`), 첨자, 합계/적분(`\sum`, `\int`), 그리스 문자(`\alpha`, `\beta`, `\pi`), 행렬(`\begin{pmatrix}`) 기호 버튼을 클릭해 TeX 문법을 조합할 수 있습니다.
- 하단의 실시간 렌더링 미리보기를 확인한 뒤 문서에 원클릭으로 삽입합니다.

```markdown
삼각형의 넓이는 $S=\frac{1}{2}bh$입니다.

$$
E = mc^2
$$
```

문장 안 인라인 수식은 `$수식$`, 독립된 중앙 정렬 블록 수식은 `$$수식$$`으로 작성합니다. 수식의 달러 기호는 일반 텍스트 입력과 구분되며, 원문에서 닫는 기호가 빠지면 뒤 문장까지 수식으로 해석될 수 있습니다.

## 2. 수정과 다음 문단

기존 수식을 편집할 때는 수식을 더블클릭하거나 원문 마크다운에서 직접 수정합니다. 블록 아래로 빠져나가려면 `Ctrl+Enter`로 다음 본문 문단을 생성합니다. 코드 블록 안의 수식 기호는 수식으로 렌더링되지 않습니다.

## 3. 출력 호환성

KaTeX 수식은 PDF 및 인쇄 출력 시 무손실 벡터 글꼴로 선명하게 사출됩니다. 화면에서 보이더라도 외부 DOCX·HWPX·EPUB 변환기마다 수식 렌더링 방식(MathML 또는 고해상도 이미지)에 차이가 있을 수 있으므로 내보낸 최종 결과 파일을 열어 확인하세요.
