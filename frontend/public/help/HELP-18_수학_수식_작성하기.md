# 수학 수식 작성과 편집

수식 도구는 LaTeX 계열 문법으로 수식을 작성하고 문서에 표시하는 기능입니다. 계산기의 계산 결과를 검증하는 기능은 아닙니다.

## 입력 방법

수식 도구 또는 `Ctrl+M`을 누르고 수식과 미리보기를 확인한 뒤 삽입합니다. 문장 안에서는 인라인 수식, 독립된 식은 블록 수식으로 구분합니다.

```markdown
삼각형의 넓이는 $S=\frac{1}{2}bh$입니다.

$$
E = mc^2
$$
```

수식의 달러 기호는 일반 문자 입력과 구분됩니다. 원문에서 닫는 기호가 빠지면 뒤 문장이 수식으로 해석되거나 표시가 깨질 수 있습니다.

## 수정과 다음 문단

기존 수식을 편집할 때는 수식의 편집 동작이나 원문을 사용합니다. 블록 아래로 이동하기 어려우면 `Ctrl+Enter`로 다음 본문을 만드는 방법을 확인합니다. 코드 블록 안의 수식 문법은 수식으로 렌더링되지 않습니다.

## 오류 확인

괄호·중괄호 짝, 지원하지 않는 명령, 역슬래시와 닫는 달러 기호를 확인합니다. 화면에서 보이더라도 DOCX·HWPX·EPUB에서는 처리 방식이 달라질 수 있으므로 실제 결과를 열어 확인하세요. 수식이 이미지로 변환된 경우에는 원문 수식 편집과 같은 방식으로 수정되지 않을 수 있습니다.
