## 1. 코드블록 만들기

`/코드블록`, `/code`, 코드 도구 또는 기본 `Ctrl+Shift+E`로 삽입합니다. 상단 **CODE** 옆 언어 입력칸에 `text`, `javascript`, `python`, `markdown` 등을 입력합니다.

````markdown
```javascript
const message = '안녕하세요';
console.log(message);
```
````

언어는 마크다운 코드 울타리 뒤에 기록됩니다. 언어 이름을 지정하는 것과 모든 언어의 구문 강조를 보장하는 것은 다릅니다.

## 2. 편집과 가로 스크롤

코드 내용을 직접 클릭해 입력합니다. Enter는 코드 안의 다음 줄입니다. 긴 행은 자동으로 잘라 감추지 않고 **블록 내부 가로 스크롤**로 끝까지 볼 수 있습니다. 연속된 코드블록 위에는 24px 간격을 둡니다.

Tab은 설정된 수의 스페이스를 입력합니다. 코드·로그의 줄바꿈과 공백은 그대로 유지합니다.

## 3. 복사와 아래 본문으로 이동

상단 오른쪽의 **복사** 버튼은 코드 내용만 복사합니다. 언어 이름과 코드 울타리는 제외하며 공백·줄바꿈은 유지합니다. 완료되면 잠시 **복사됨**이 표시됩니다. 실패 표시가 나오면 클립보드 권한을 확인하세요.

**Ctrl+Enter**로 코드블록 아래 본문으로 이동합니다. 코드의 마지막 위치에서 아래 방향키로 이동하는 처리도 있습니다. 일반 Tab이 언어 입력창으로 포커스를 옮기는 용도로 사용되지는 않습니다.

## 4. Mermaid와 구분

언어를 `mermaid`로 지정하면 자동 다이어그램 미리보기가 추가됩니다. 코드 편집을 펼치고 편집 완료로 접습니다. 상세한 이미지 복사·저장은 HELP-19를 참고하세요.
