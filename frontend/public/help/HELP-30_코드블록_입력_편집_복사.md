# 코드 블록 입력·편집·복사

## 1. 코드 블록 만들기

코드 도구, `/code`, `Ctrl+Shift+E`를 사용하거나 코드 울타리(` ``` `)를 입력합니다. 언어 이름을 지정하면 문법 강조(Syntax Highlighting)를 사용할 수 있습니다.

````markdown
```python
def greet(name):
    print(f"안녕하세요, {name}")
```
````

예시를 원고에 직접 코드로 넣으려면 안쪽의 백틱 세 개짜리 블록을 사용합니다. 바깥 네 개짜리 울타리는 도움말에서 문법을 보여주기 위한 것입니다.

## 2. 편집과 안전 토크나이저 (Safe Monarch Tokenizer)

온리비 어서는 임의의 한글 언어명(예: ` ```아자아자 `) 또는 언어명을 지정하지 않은 무명 코드블록(` ``` `)을 입력하더라도 블록 닫힘 울타리를 정확히 매칭하는 **안전 토크나이저(Safe Monarch Tokenizer)**를 탑재하고 있습니다. 코드블록 상태가 닫힘 이후의 일반 본문으로 유출되어 글씨가 보라색으로 변색되는 결함이 원천 차단됩니다.

문서보기 및 미리보기에서 코드블록 우측 상단의 **'복사' 버튼**을 클릭하면 순수 코드 내용만 깔끔하게 클립보드로 복사됩니다.

## 3. 문법 보존과 블록 나가기

Enter는 코드 줄바꿈입니다. 긴 줄은 코드 영역의 가로 스크롤로 처리됩니다. 아래 본문으로 빠져나가려면 `Ctrl+Enter` 등 블록 나가기 동작을 사용합니다.

코드 안의 `#`, `1.`, `-`는 문서 제목이나 목록으로 자동 변환되지 않으며, 제목 번호 계산과 문서 서식 일괄 정리에서도 코드 영역은 안전하게 원문 그대로 보존됩니다.

Mermaid·수식처럼 특별한 언어 이름은 렌더링 도구로 해석될 수 있습니다. 일반 텍스트 코드로 보여주려면 목적에 맞는 일반 언어명(예: `text`, `python`)을 선택하세요.
