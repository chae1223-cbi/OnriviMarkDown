# 코드 블록 입력·편집·복사

## 코드 블록 만들기

코드 도구, `/code`, `Ctrl+Shift+E`를 사용하거나 코드 울타리를 입력합니다. 언어 이름을 지정하면 해당 언어의 표시를 사용할 수 있습니다.

````markdown
```python
def greet(name):
    print(f"안녕하세요, {name}")
```
````

예시를 원고에 직접 코드로 넣으려면 안쪽의 백틱 세 개짜리 블록을 사용합니다. 바깥 네 개짜리 울타리는 도움말에서 문법을 보여주기 위한 것입니다.

## 편집과 복사

문서보기에서 코드 내용을 편집합니다. 언어 입력 도구와 복사 버튼은 코드 본문과 별도입니다. 코드 복사는 코드 내용용이며 문서 전체나 이미지 복사와 다릅니다.

Enter는 코드 줄바꿈입니다. 긴 줄은 코드 영역의 가로 이동을 확인하세요. 아래 본문으로 나가려면 Ctrl+Enter 등 블록 나가기 동작을 사용합니다. 빈 코드 블록에서 삭제 키는 일반 문단 전환 동작을 할 수 있습니다.

## 문법 보존

코드 안의 `#`, `1.`, `-`는 문서 제목이나 목록으로 자동 변환하지 않습니다. 제목 번호 계산과 문서 서식 일괄 정리도 코드 영역을 보존하는 경로를 사용합니다. 코드 울타리의 열고 닫는 개수가 맞지 않으면 뒤 본문까지 코드로 보일 수 있습니다.

Mermaid·수식처럼 특별한 언어 이름은 렌더링 도구로 해석될 수 있습니다. 일반 코드로 보여주려면 목적에 맞는 언어를 선택하세요.
