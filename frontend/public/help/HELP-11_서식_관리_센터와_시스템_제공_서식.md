# 서식 관리와 제공 서식 선택

서식 관리는 원고의 글꼴·제목·문단·표·미디어·용지 설정을 함께 관리하는 기능입니다. 화면 확대와 원문 편집기의 글자 크기는 문서 출력용 서식 설정과 다릅니다.

## 적용 순서

1. 서식 관리 또는 상태바의 현재 서식 이름을 누릅니다.
2. 제공 서식과 사용자 서식을 살펴봅니다.
3. 사용할 서식을 선택하고 현재 문서의 제목·본문·표를 확인합니다.
4. 필요한 경우 사용자 서식으로 복제해 조절합니다.
5. 마크다운을 저장하고 내보내기 결과를 확인합니다.

기본 제공 서식은 직접 수정이 제한됩니다. 사용자 서식을 만들어 관리하세요. 문서의 메타데이터에는 적용할 서식 식별 정보가 들어갈 수 있으며, 사용자 서식 파일까지 원고 안에 모두 포함되는 것은 아닙니다.

## 목적에 맞춰 선택

일반 문서, 기술 문서, 보고서, 그림책 등 목적에 따라 구성 요소가 달라집니다. AI 친화적 보고서 서식은 제목 계층과 단순한 표·설명을 돕는 선택 기능입니다. 정부 공식 인증이나 모든 책의 공통 출판 규격을 의미하지 않습니다.

## 도움말 전용 서식

기본 제공 서식의 **온리비 도움말**은 설명서에 맞춘 파란 제목, 읽기 편한 본문, 표·코드 예제 서식입니다. 도움말 문서와 도움말 창에는 이 서식을 사용합니다. 제목 자동 번호는 사용하지 않습니다. 다른 용도로 조절하려면 사용자 서식으로 복제하세요.

## 확인할 항목

제목 번호를 켠 서식은 마크다운 제목 앞 번호도 갱신합니다. 미디어 설명의 위·아래 위치와 형식도 확인하세요. 서식을 바꾸기 전 중요한 원고는 저장하고, 사용자 지정 CSS를 사용했다면 기본 설정보다 우선되는 규칙이 있는지 확인합니다.
