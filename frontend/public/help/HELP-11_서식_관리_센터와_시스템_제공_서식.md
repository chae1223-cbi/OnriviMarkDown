## 1. 대한민국 4대 공인 표준 서식 프로필

온리비 어서는 국가 기관, 대기업, 연구원, 글로벌 테크 기업의 실제 출판 표준 규격을 철저히 분석하여 구축한 **4대 공인 표준 서식**을 기본 제공합니다:

| 프로필 ID | 서식 명칭 | 핵심 디자인 특징 | 최적 활용 분야 |
| :--- | :--- | :--- | :--- |
| **`ks-iso-standard`** | KS/ISO 기술표준 문서 규격 | 정밀한 십진 분류 번호, 표준 글꼴, 격자형 기술 표 서식 | 국가기술표준, 감리보고서, 기술사양서, 제품 설명서 |
| **`corporate-strategy`** | 대기업 경영기획·전략보고서 | 코발트 블루(#1d4ed8) 헤드라인, 간결한 표, 명확한 요약 박스 | 사업계획서, 경영전략 보고, 임원 보고, 투자 제안서 |
| **`academic-kdi`** | KDI 학술·정책연구 보고서 | 중후하고 신뢰감 높은 세리프/산세리프 조화, 각주 및 인용구 강조 | 공공 정책보고서, 연구 논문, 학술 저널, 싱크탱크 분석 보고서 |
| **`tech-six-pager`** | 글로벌 테크 6-Pager 기획서 | 아마존 스타일의 내러티브 서술 구조, 군더더기 없는 미니멀 레이아웃 | 신제품 혁신 기획서, 기술 백서(Whitepaper), 스타트업 PRD |

## 2. 서식 선택 및 실시간 적용 방법

1. 에디터 우측 상단의 **[서식 관리]** 버튼을 클릭하거나, 메뉴바의 [서식] ➔ [서식 관리 센터]를 엽니다.
2. 서식 갤러리 목록에서 원하는 프로필 카드를 선택합니다.
3. 선택 즉시 우측의 **실시간 A4 조판 미리보기**에 해당 서식이 적용되어 글꼴, 제목 크기, 줄간격, 표 스타일, 테두리 색상이 단숨에 갱신됩니다.
4. **마크다운 원문의 완벽한 보존**: 서식을 아무리 바꾸더라도 사용자가 정성껏 작성한 마크다운 본문 원본 텍스트는 1글자도 손상되지 않습니다.

---

## 3. 3대 책임 영역 격리 (DESIGN.md 디자인 시스템 원칙)

온리비 어서는 시스템 UI와 사용자 문서가 서로 간섭하지 않도록 책임을 엄격히 격리합니다:

- **에디터 인터페이스 UI**: 메뉴바, 사이드바, 상태바, 모달 창은 현대적인 Modern Technical Editorial 토큰(코발트 `#1d4ed8`, 틸 `#0d9488`)으로 렌더링됩니다.
- **문서 본문 Scope (`.onrivi-content-root`)**: 책 본문, 표, 이미지, 제목 서식은 오직 선택된 CSS 프로필에 의해서만 통제됩니다. 에디터 화면을 어두운 다크 모드로 전환하더라도 책 인쇄 본문의 서식은 오염되지 않고 순수한 종이 출판 규격을 유지합니다.
