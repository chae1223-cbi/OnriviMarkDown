# AI 연결·첨부·프롬프트 템플릿

## 1. API 연결

환경설정의 제공사별 AI 연결 카드에서 Google Gemini/Gemma, OpenAI, Claude의 키와 연결 상태를 확인합니다. Google Drive 로그인용 OAuth 값은 Gemini API 키가 아닙니다. 제공사에 맞는 키를 등록하고 모델 목록 조회와 실제 요청을 각각 확인하세요.

연결 정보는 공통 리소스 폴더의 암호화된 자격정보로 관리하도록 구현되어 있습니다. 리소스 폴더·기기·계정을 바꾸면 연결 상태를 다시 확인합니다. 암호화 파일도 민감한 자료이므로 공개 저장소에 올리지 마세요. 화면에 키가 표시되지 않는 것과 제공사에서 사용 가능한 상태인 것은 다릅니다.

모델 목록에 보인다는 사실만으로 생성 권한·지원 기능·잔액을 보장하지 않습니다. ChatGPT 등 서비스 구독과 API 과금은 구분합니다. 요청이 결제·할당량 오류로 실패하면 해당 제공사의 API 계정을 확인하세요.

## 2. 파일 첨부

TXT·MD·CSV·JSON·PDF·DOCX와 PNG·JPG·WebP를 지원합니다. 최대 5개·합계 20MB, 파일당 10MB 제한이 있으며 PDF는 최대 100쪽과 추출 분량 제한이 있습니다. 스캔 PDF는 현재 첨부 추출만으로 OCR 처리되지 않습니다. 이미지는 모델의 이미지 입력 지원도 확인해야 합니다.

문서 정리에서 열린 문서는 자동 참고하므로 같은 원고를 다시 첨부하지 않아도 됩니다. 전송할 문서·첨부는 선택한 AI 제공사로 전달될 수 있습니다.

## 3. 템플릿 재사용과 4대 규격 템플릿

프롬프트 스튜디오에서 템플릿을 선택하고 입력사항을 채워 AI 입력창으로 보냅니다. 기본 탑재된 **'문서 표준 규정 (4대 규격)'** 템플릿을 활용하면 현재 문서를 다음과 같이 원클릭 정리할 수 있습니다:
- **KS / ISO 기술표준 보고서 정리**: 십진 분류, 객관적 기술식 서술, 표/그림 분리 캡션
- **대기업 전략기획서 (개조식) 정리**: 도형 기호 위계, 헤드라인 요약, 종결어(~추진함)
- **학술·정책 연구보고서 (KDI 표준) 정리**: 장절 체계, 학술 서술식, 각주/출처 표기
- **글로벌 테크 / 아마존 6-Pager 정리**: 6페이지 내러티브 줄글, FAQ 구조화

사용자 정의 템플릿을 저장·수정·복제하여 팀원과 공유하거나 재사용할 수도 있습니다.
