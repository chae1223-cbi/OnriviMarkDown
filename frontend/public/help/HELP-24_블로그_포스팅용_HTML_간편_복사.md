## 1. HTML 내보내기

문서보기에서 내용을 확인한 뒤 파일 메뉴의 내보내기에서 HTML을 선택합니다. 출력은 문서 화면을 복제하고 서식·이미지 처리를 적용하여 생성합니다. 로컬 이미지에는 HTML에 포함할 수 있도록 인라인 변환을 시도합니다.

원고의 마크다운 복사와 HTML 파일 내보내기는 다릅니다. CODE 복사는 코드 텍스트, 표 복사는 마크다운 표, 미디어 복사는 참조입니다.

## 2. 블로그에 활용하기

1. HTML 파일을 열어 결과를 확인합니다.
2. 대상 블로그가 HTML 입력을 제공하면 필요한 본문을 해당 방식으로 넣습니다.
3. 사진·표·인용구·수식·다이어그램을 발행 전 미리보기에서 확인합니다.
4. 이미지가 차단되면 해당 플랫폼에 직접 업로드합니다.

문서보기에서 일반 복사를 했다고 전체 서식을 인라인 HTML로 완전히 복사하는 것은 아닙니다. 외부 에디터는 CSS·HTML·Data URI를 제거할 수 있어 동일한 표시를 보장하지 않습니다.

## 3. 코드·다이어그램·동영상

코드의 긴 행과 표는 모바일 화면에서 확인하세요. Mermaid는 이미지 복사 또는 저장으로 그림을 첨부할 수 있습니다. 외부 영상·지도는 해당 플랫폼이 삽입을 허용해야 합니다. 수식 지원이 없으면 PNG 출력 등 이미지 전달 방법을 사용하세요.
