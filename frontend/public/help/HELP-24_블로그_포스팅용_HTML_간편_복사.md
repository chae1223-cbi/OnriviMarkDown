# HTML 내보내기와 서식 포함 복사

## 파일로 내보내기

내보내기에서 HTML 파일을 선택합니다. 브라우저로 결과를 열어 제목·본문·표·이미지와 링크를 확인합니다. 파일을 다른 위치로 옮기면 상대 이미지 경로와 외부 자료 접근도 확인해야 합니다.

## 복사해서 게시하기

문서의 복사 도구와 블록별 복사 도구는 대상이 다릅니다. 코드 복사는 코드 내용, 표 복사는 표의 마크다운, 미디어 복사는 참조나 이미지 등 해당 버튼이 안내하는 대상을 사용합니다. 문서 전체 복사인지 일부 블록 복사인지 확인하세요.

블로그나 게시판에 서식을 포함해 붙여넣을 때는 대상 편집기의 지원 범위에 따라 결과가 달라집니다. 해당 서비스가 CSS·iframe·외부 글꼴을 제거하면 온리비 화면과 동일하지 않을 수 있습니다. 게시 전에 미리보기에서 확인합니다.

## 안전한 공유

- 개인 PC 절대 경로로 연결된 파일은 다른 사람에게 보이지 않을 수 있습니다.
- 드라이브 비공개 자료는 받는 사람에게 접근 권한이 필요합니다.
- 동영상·지도는 인쇄용 그림과 웹 임베드의 동작이 다릅니다.
- API 키와 개인 설정 파일은 HTML이나 원고에 직접 적어 넣지 마세요.

HTML 내보내기는 사이트 호스팅이나 게시 완료를 의미하지 않습니다. 게시 서비스의 파일 업로드·이미지 저장·이용 조건은 별도로 따릅니다.
