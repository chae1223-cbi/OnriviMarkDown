# 그림책 장면 편집과 내보내기

그림책은 일반 문서를 임의로 페이지마다 잘라 만드는 방식이 아니라 명시적인 장면 단위를 사용합니다. 그림책 서식을 선택하고 장면 표시·이미지·본문을 함께 관리하세요.

## 1. 장면 원문

```markdown
:::scene {cover}
![표지 그림](media/cover.png)

# 작은 여행
:::

:::scene
![첫 장면](media/scene1.png)

첫 번째 장면의 이야기입니다.
:::
```

표지 장면은 첫 번째에 배치합니다. 실제 이미지 파일을 준비하고 예시 경로를 바꿉니다. 닫는 `:::`가 빠지거나 장면 밖에 글이 있으면 안내를 확인하세요. 장면 밖 내용을 임의로 삭제하기보다 원문 위치를 확인해 장면 안으로 옮기거나 새 장면으로 묶습니다.

## 2. 편집

장면의 본문 편집·편집 완료와 사진 편집을 사용합니다. 화면에 제공되는 다음 장면 추가 기능으로 장면을 확장할 수 있습니다. 대표 이미지와 본문 안 추가 이미지의 역할을 구분하세요. 비율과 맞춤 방식에 따라 사진 일부가 잘려 보일 수 있습니다.

## 3. AI와 출력

질문과 문서 정리는 그림책에서도 사용할 수 있습니다. 문서 정리는 원문 전체를 참고합니다. 장면 편집창의 문구 수정은 일반 문서 선택 편집과 동일하게 연결되어 있지 않으므로 마크다운 편집 경로를 확인합니다.

그림책은 인쇄/PDF·고정 배치 EPUB 등 화면에 제공되는 형식을 사용합니다. DOCX·HWPX 항목은 제외됩니다. 결과물에서 장면 순서·표지·사진 크기·넘치는 본문을 확인하세요.
