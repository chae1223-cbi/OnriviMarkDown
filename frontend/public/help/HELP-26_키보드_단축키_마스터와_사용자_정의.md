> "단축키는 단순한 편의 기능을 넘어, 작가의 머릿속에 떠오른 생각과 손끝 사이의 지연 시간을 0으로 만드는 강력한 무기입니다.  
> 온리비 어서(Onrivi Author)는 세계 최고 수준의 Monaco Editor 엔진을 바탕으로 설계된 **직관적인 전역 기본 단축키 시스템**을 탑재하고 있습니다.  
> 뿐만 아니라, 사용자의 손에 익은 타이핑 습관을 100% 존중하기 위해 환경설정에서 모든 단축키를 자유롭게 변경하고, 단축키 중복 충돌을 사전에 방지하며, 클릭 한 번으로 설정을 클립보드에 복사하거나 초기화할 수 있는 **[단축키 및 명령어 매핑 센터]**를 제공합니다."

## 1. 온리비 어서 단축키 시스템 개요

온리비 어서의 단축키 체계는 다음 3대 원칙에 따라 설계되었습니다:
1. **표준 오피스 친화성**: 전 세계 표준 워드프로세서(Word, 한글)의 공통 단축키(`Ctrl+B`, `Ctrl+I`, `Ctrl+S`, `Ctrl+Z` 등)를 그대로 계승하여 별도의 적응 기간이 필요 없습니다.
2. **출판 조판 특화 단축키**: 각주 삽입(`Ctrl+Alt+F`), 타문서 변환(`Ctrl+Alt+O`), 도장 서명(`Ctrl+Alt+R`), 인쇄/PDF(`Ctrl+P`) 등 전문 출판 기능을 손쉽게 제어할 수 있습니다.
3. **100% 사용자 정의(Customization)**: 내 손에 맞지 않는 키 조합은 언제든 환경설정에서 나만의 단축키로 재정의할 수 있습니다.

## 3. 환경설정 [단축키 / 명령어] 매핑 센터 활용법

기본 단축키가 익숙하지 않거나 다른 에디터의 키 바인딩에 익숙한 작가님들을 위해, 온리비 어서는 완벽한 커스텀 매핑 센터를 제공합니다.

```
[상단 메뉴바]
  └── 도구(T)
        └── 환경설정 (SettingsModal)
              ├── 일반 설정
              ├── 단축키 / 명령어  <── [클릭]
              └── 계정 관리
```

```
┌────────────────────────────────────────────────────────────────────────┐
│                   단축키 및 명령어 매핑 센터 화면 구조                  │
│                                                                        │
│  [구분]   [아이콘]   [기능명]         [단축키 조합]       [명령어 (/)] │
│  서식       B       굵게             [ Ctrl+B      ]     / [bold     ] │
│  서식       I       기울임           [ Ctrl+I      ]     / [italic   ] │
│  제목      H1       H1 (제목 1)      [ Ctrl+1      ]     / [h1       ] │
│  ...                                                                   │
│                                 [📋 복사하기]  [🔄 초기화]             │
└────────────────────────────────────────────────────────────────────────┘
```

### ① 나만의 단축키 변경 방법
1. 변경하고 싶은 기능의 **[단축키 조합]** 입력 상자를 마우스로 클릭합니다.
2. 키보드에서 원하는 조합(예: `Ctrl + Shift + B` 또는 `Alt + 1`)을 **실제로 누릅니다**.
   - `onKeyDown` 이벤트 감지기가 작동하여 `Ctrl`, `Shift`, `Alt` 키와 문자 키를 자동으로 조합하여 인식합니다.
3. 입력 즉시 브라우저 로컬 저장소(`localStorage.customHotkeys`)에 암호화되어 안전하게 보존되며, 에디터에 1ms 만에 즉각 반영됩니다.
4. 단축키를 완전히 해제(삭제)하고 싶다면 입력 상자에서 **`Backspace`** 또는 **`Delete`** 키를 누르면 비워집니다.

### ② 단축키 중복 충돌(Conflict) 자동 감지 가드
- 이미 다른 기능(예: `Ctrl+S` 저장)에 할당된 단축키를 다른 기능에 중복으로 등록하려고 시도하면:
  > **`⚠️ 이미 [저장] 기능에 할당된 단축키입니다.`**
  라는 경고 토스트 알림이 즉시 뜨며, 중복 입력이 안전하게 차단됩니다. 실수로 중요한 단축키가 덮어써지는 사고를 사전에 완벽히 방지합니다.

### ③ 슬래시 명령어 커스텀 지정
- 우측의 **[명령어 (/)]** 입력창에 평소 자주 쓰는 짧은 키워드를 입력할 수 있습니다.
- 예를 들어, `/codeblock` 대신 `/c`나 `/코드`로 수정해 두면 본문에서 `/c`만 입력해도 코드블록이 즉시 사출됩니다.

### ④ [복사하기] 및 [초기화] 편의 기능
- **[📋 복사하기] 버튼**: 현재 설정된 모든 기능의 단축키와 명령어 매핑 현황을 단정한 텍스트 목록으로 클립보드에 복사해 줍니다. 나만의 단축키 치트시트를 메모장에 보관하거나 동료와 공유할 때 유용합니다.
- **[🔄 초기화] 버튼**: 단축키를 복잡하게 변경하다가 원래대로 되돌리고 싶을 때 클릭하면, 0.1초 만에 온리비 공식 권장 기본값(`DEFAULT_HOTKEYS`)으로 깨끗하게 초기화됩니다.

## 4. macOS 사용자를 위한 키보드 매핑 가이드

Mac 환경에서 온리비 어서를 사용하실 때는 윈도우 키와 맥 키보드가 다음과 같이 1:1로 매핑됩니다:
- **`Ctrl`** ➔ **`Cmd (⌘)`** (Command 키)
- **`Alt`** ➔ **`Option (⌥)`** (Option 키)
- **`Shift`** ➔ **`Shift (⇧)`** (Shift 키)

예를 들어, 윈도우의 `Ctrl + Alt + F` (각주)는 맥북에서 **`Cmd + Option + F`**로 자연스럽게 작동합니다.

## 5. 자주 묻는 질문 (FAQ)

### Q1. 브라우저 기본 단축키(예: 새 탭 열기 Ctrl+T, 닫기 Ctrl+W)와 충돌하지 않나요?
**A.** 온리비 어서 데스크톱 앱(Electron)에서는 운영체제 키 입력을 완전히 독점 제어하므로 웹 브라우저 단축키와 일절 충돌하지 않습니다. 웹 브라우저 버전으로 접속하실 때도 에디터 내부 포커스 상태에서는 `e.preventDefault()` 및 Monaco Editor 가드가 동작하여 문서 작성에 필요한 키 조합을 최우선으로 가로채 처리합니다.

### Q2. 컴퓨터를 포맷하거나 다른 PC로 옮겨가면 단축키 설정이 사라지나요?
**A.** 단축키 매핑 정보는 브라우저 로컬 스토리지(`localStorage`)에 저장됩니다. 다른 PC로 설정을 옮기시려면 매핑 센터 상단의 **[복사하기]**를 눌러 단축키 목록을 메모장에 백업해 두시거나, 온리비 클라우드 프로필 동기화를 활용하시면 손쉽게 복원할 수 있습니다.

### Q3. 한 줄 전체를 빠르게 삭제하거나 위아래로 이동하는 단축키가 있나요?
**A.** 네! Monaco 에디터 고유의 강력한 편집 단축키가 모두 지원됩니다:
- **현재 줄 즉시 삭제**: `Ctrl + Shift + K` (또는 `Ctrl + D`)
- **현재 줄 위/아래 이동**: `Alt + ↑` / `Alt + ↓`
- **현재 줄 위/아래 복제**: `Shift + Alt + ↑` / `Shift + Alt + ↓`
- **단어 단위 이동**: `Ctrl + ←` / `Ctrl + →`
