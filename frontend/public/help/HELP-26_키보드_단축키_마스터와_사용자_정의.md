# 기본 단축키와 사용자 지정

아래는 기본 도구 설정에 정의된 단축키입니다. 환경설정에서 변경했거나 운영체제·브라우저가 가로채면 실제 동작이 달라질 수 있습니다.

| 단축키 | 기본 작업 |
| --- | --- |
| Ctrl+S / Ctrl+Shift+S | 저장 / 다른 이름으로 저장 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+B / Ctrl+I | 굵게 / 기울임 |
| Ctrl+1~6 | 제목 1~6 |
| Ctrl+Shift+7 / Ctrl+Shift+8 | 숫자 목록 / 글머리 목록 |
| Ctrl+Shift+C | 체크리스트 |
| Ctrl+K / Ctrl+T / Ctrl+M | 링크 / 표 / 수식 |
| Ctrl+Shift+E | 코드 블록 |
| Ctrl+Shift+L | 문서 서식 일괄 정리 |
| Ctrl+Alt+R | 서명/발신인 |
| Ctrl+Alt+C | 인용 |
| Ctrl+Shift+0 | 태그 취소 |
| Ctrl+F / Ctrl+H / Ctrl+Shift+F | 찾기 / 바꾸기 / 전체 검색 |
| Ctrl+Space | 플로팅 서식 툴바 |

## 1. 문맥별 키

목록 안의 Tab·Shift+Tab은 단계 조절에 사용합니다. AI 입력창의 Enter는 보내기, Shift+Enter는 줄바꿈입니다. 코드 블록 안 Enter는 코드 줄바꿈입니다. Ctrl+Enter는 여러 블록에서 아래 본문으로 나갈 때 사용합니다.

## 2. 사용자 지정

환경설정의 단축키 화면에서 도구별 단축키와 슬래시 명령을 확인·변경합니다. 중복 지정과 시스템 단축키 충돌을 피하세요. 원치 않는 동작이 나면 먼저 포커스와 현재 보기를 확인하고, 설정에서 실제 할당된 키를 기준으로 판단합니다.
