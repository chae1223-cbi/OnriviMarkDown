> "대한민국의 공공기관과 학교는 한글(`.hwp` / `.hwpx`)을 사용하고, 글로벌 기업과 일반 오피스는 마이크로소프트 워드(`.docx`)를 사용합니다.  
> 저작 도구가 특정 파일 형식에만 갇혀 있다면 동료들과 원활하게 문서를 주고받을 수 없습니다.  
> 온리비 어서(Onrivi Author)는 과거에 작성된 복잡한 바이너리 오피스 문서를 손실 없이 읽어와 경쾌한 마크다운으로 탈바꿈시키는 **[타문서 변환(가져오기)]** 엔진과, 완성된 원고를 정부·공공기관 제출 표준 규격인 **한글 문서(.hwpx)** 및 글로벌 표준 **Word 문서(.docx)**로 완벽하게 사출하는 양방향 오피스 호환 체계를 완벽히 갖추고 있습니다."

## 1. 양방향 오피스 문서 변환 아키텍처

온리비 어서는 마크다운을 중심 허브로 삼아 서로 다른 오피스 규격 사이를 자유롭게 오갈 수 있도록 설계되었습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 어서 오피스 문서 양방향 변환 구조              │
│                                                                        │
│  [가져오기 (Import)]                                                   │
│  ├── 한글 문서 (.hwp)       ──┐                                        │
│  ├── MS Word (.docx)       ──┼──► [지능형 마크다운 변환 파이프라인]     │
│  ├── 전자책 (.epub)         ──┤    (제목·본문·표·이미지·목록 자동 구조화)│
│  ├── 웹 문서 (.html)        ──┤                    │                   │
│  └── 텍스트/PDF (.txt/.pdf) ──┘                    ▼                   │
│                                           [온리비 어서 편집기]          │
│                                           (순수 마크다운 원고)          │
│                                                    │                   │
│  [내보내기 (Export)]                               ▼                   │
│  ├── 한글 표준 XML (.hwpx) ◄── [DOM 파싱 및 Office/OWPML XML 빌더]    │
│  └── MS Word (.docx)       ◄── (표 1:1 대응, 다이어그램/이미지 임베딩) │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. 외장 문서 가져오기 (타문서 변환)

오래된 한글 보고서나 외부 파트너가 보낸 워드 문서를 마크다운으로 옮겨 적느라 일일이 복사하고 서식을 고치던 고된 수작업은 이제 필요 없습니다.

### ① 메뉴 위치 및 바로가기 단축키
```
[상단 메뉴바]
  └── 파일(F)
        ├── 파일 열기 (Ctrl+O)
        ├── 작업장 폴더 열기 (Ctrl+Shift+O)
        └── 타문서 변환 (Ctrl+Alt+O)  <── [클릭]
```
- 상단 메뉴 [파일(F)] ➔ **[타문서 변환]**을 클릭하거나, 키보드 단축키 **`Ctrl+Alt+O`**를 누릅니다.
- 파일 선택 창에서 변환하고자 하는 외부 문서를 선택하면 즉시 변환 파이프라인이 가동됩니다.

### ② 지원 형식 및 변환 특장점
| 확장자 | 포맷 명칭 | 온리비 어서 변환 엔진 특장점 |
| :--- | :--- | :--- |
| **`.hwp`** | 아래아한글 바이너리 문서 | OLE 복합 스트림을 분석하여 텍스트, 표, 그림 컨트롤 추출. 복구 파서 내장으로 깨진 파일도 안전하게 복원 |
| **`.docx`** | Microsoft Word 문서 | `mammoth.js` 엔진 기반으로 제목 수준, 문단, 목록, 인라인 강조, 캡션(`figcaption`), 이미지 크기 완벽 보존 |
| **`.epub`** | 전자책 표준 파일 | 내부 XHTML 챕터를 순회하여 목차 구조와 본문을 단일 마크다운으로 일괄 통합 변환 |
| **`.html`** | 웹페이지 문서 | 복잡한 인라인 HTML 태그를 깔끔한 GFM 표준 마크다운 문법으로 자동 정제 |
| **`.pdf`** | PDF 전자 문서 | 텍스트 레이아웃을 보존하여 마크다운 본문으로 신속 변환 |
| **`.txt` / `.md`** | 텍스트 / 마크다운 문서 | 원본 텍스트를 손실 없이 그대로 에디터에 로드 |

### ③ 한글(HWP) 표와 이미지 자동 복원의 비밀
- **표(Table) 구조 완벽 복원**:  
  HWP 파일 내부의 복잡한 표 셀 데이터를 가로줄과 세로줄로 분석하여 마크다운 파이프 테이블(`| 헤더 | 내용 |`) 형태로 자동 변환합니다.
- **이미지 자동 추출 및 리소스 폴더 저장**:  
  HWP 내부에 바이너리로 묶여 있던 그림 파일(`BIN0001.png` 등)을 자동으로 분리 추출하여, 현재 연결된 공통 리소스 폴더(`media/`)에 저장하고 본문에 `![이미지](./media/...)` 상대경로 링크를 알맞게 삽입해 줍니다.

## 3. 공공기관 제출용 한글 문서 (.hwpx) 내보내기

대한민국 정부 부처, 지방자치단체, 공공기관 및 학교에 문서를 제출할 때는 구형 바이너리 `.hwp` 대신 **국가 표준 규격(KS X 6101)인 HWPX(개방형 워드프로세서 마크업 언어)**를 사용해야 합니다.

```
[상단 메뉴바]
  └── 파일(F)
        └── 내보내기 (미리보기 모드 전용)
              ├── 인쇄/PDF
              ├── Word 문서 (.docx)
              ├── 한글 문서 (.hwpx)  <── [클릭] (한컴오피스 완벽 호환)
              ├── HTML 파일 (.html)
              └── EPUB 전자책 (.epub)
```

1. **미리보기 모드 전환**:  
   - 에디터를 **미리보기 전용 모드**로 전환합니다.
2. **한글 문서 메뉴 클릭**:  
   - 상단 메뉴 [파일(F)] ➔ [내보내기] ➔ **[한글 문서 (.hwpx)]**를 클릭합니다.
3. **자동 빌드 및 저장**:  
   - 온리비 어서의 OWPML 생성 엔진이 마크다운 렌더링 트리를 분석하여 순수 XML 기반의 정식 `.hwpx` 압축 패키지를 빌드합니다.
   - 데스크톱 환경에서는 파일 저장 창이 열리며, 웹 환경에서는 브라우저 다운로드 폴더로 저장됩니다.
4. **한컴오피스에서 확인**:  
   - 다운로드된 파일을 '한글 2014', '한글 2020', '한글 2024' 또는 '한컴독스(Hancom Docs)'에서 열면 마크다운 원고 그대로 깔끔하게 열립니다.

> [!참고]
> **HWPX란?**  
> 과거의 HWP는 바이너리 형태여서 외부 프로그램이 내용을 읽기 어려웠지만, HWPX는 XML 표준 기반으로 제작되어 데이터의 투명성과 장기 보존성이 매우 뛰어납니다. 정부 공공 표준 규격으로 지정되어 있습니다.

## 4. 기업 보고서 & 오피스 협업용 Word 문서 (.docx) 내보내기

전 세계 기업과 대학, 연구소의 표준 워드프로세서인 MS Word 및 구글 문서(Google Docs)와 협업할 때는 DOCX 내보내기를 활용하세요.

1. **미리보기 모드 전환**:  
   - 에디터를 **미리보기 전용 모드**로 전환합니다.
2. **Word 문서 메뉴 클릭**:  
   - 상단 메뉴 [파일(F)] ➔ [내보내기] ➔ **[Word 문서 (.docx)]**를 클릭합니다.
3. **완벽한 레이아웃 보존**:  
   - Office Open XML 규격에 맞추어 제목 계층(Heading 1~6), 본문 글꼴, 볼드, 기울임, 목록 번호가 완벽하게 매핑된 `.docx` 파일이 생성됩니다.
   - MS Word, 구글 Docs, 애플 Pages, LibreOffice 등 어디서 열어도 원고의 레이아웃이 흐트러지지 않습니다.

## 5. 표와 스타일 서식의 보존 원리

온리비 어서의 오피스 내보내기 엔진(`exportHandlers.ts`, `docxGenerator`, `hwpxGenerator`)은 날 텍스트(Raw Markdown)를 단순 문자열로 치환하는 것이 아니라, **화면에 렌더링된 라이브 미리보기 DOM의 실제 치수와 스타일**을 참조하여 작동합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   서식 손실 0%를 위한 라이브 DOM 추출 기술             │
│                                                                        │
│  [마크다운 표]                    [Word / HWPX 네이티브 표]             │
│  | 과목 | 점수 |                  ┌────────┬────────┐                  │
│  |:---|:---:|    ──────────►     │  과목  │  점수  │ (배경색, 패딩,    │
│  | 국어 |  95  |                  ├────────┼────────┤  정렬 1:1 보존)  │
│                                   │  국어  │   95   │                  │
│                                   └────────┴────────┘                  │
│                                                                        │
│  [Mermaid 도표 / SVG]             [고해상도 DrawingML 이미지 임베딩]   │
│  ```mermaid                       ┌────────────────────────────────┐   │
│  graph TD; A-->B;  ──────────►    │ [Mermaid 3x 무손실 래스터라이즈]│   │
│  ```                              └────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

### ① 표(Table) 서식의 1:1 보존
- 마크다운의 정렬 지시자(`:---` 좌측, `:---:` 중앙, `---:` 우측)를 판별하여 워드/한글 표 셀 내부의 텍스트 정렬을 동일하게 맞춥니다.
- 서식 관리 센터(CSS 프로필)에서 설정한 표 외곽 테두리 두께, 가로선 색상, 헤더 배경색을 Word/HWPX 스타일 XML 속성으로 정밀 변환합니다.

### ② 이미지와 Mermaid 다이어그램 자동 임베딩
- 원고에 들어있는 로컬 이미지와 SVG 다이어그램은 `extractMediaFromElements` 파이프라인을 거쳐 Word/HWPX 문서 파일 내부에 바이너리로 직접 동봉(Embedding)됩니다.
- 문서를 외부 이메일이나 USB로 다른 사람에게 전달해도 이미지가 엑스박스로 깨지지 않고 온전히 표시됩니다.

### ③ 마크다운 특수기호 누출 원천 방어
- 일반 변환 도구에서 흔히 발생하는 `**굵게**`나 `### 제목` 같은 마크다운 특수기호가 완성된 Word/한글 문서 본문에 지저분하게 노출되는 현상을 100% 방어합니다.

## 6. 단계별 실전 따라 하기 (Step-by-Step)

기존 HWP 문서를 가져와 다듬은 뒤, 최신 HWPX와 Word 파일로 내보내는 전체 과정을 실습해 봅니다.

### 1단계: 외장 HWP 문서 가져오기
1. 상단 메뉴 [파일] ➔ **[타문서 변환]** (또는 단축키 `Ctrl+Alt+O`)을 누릅니다.
2. 내 컴퓨터에 있는 기존 한글 파일(예: `2025_사업계획서.hwp`)을 선택합니다.
3. 1~2초 만에 한글 문서의 본문과 표, 이미지가 깔끔한 마크다운 문법으로 변환되어 에디터에 열립니다.

### 2단계: 마크다운 에디터에서 원고 다듬기
필요 없는 문단을 지우고, 콜아웃 상자(`> [!중요]`)를 추가하거나 맞춤법을 점검합니다.

### 3단계: 공공기관 제출용 HWPX 파일 사출
1. 상단 메뉴 [도구] ➔ [화면 보기 모드] ➔ [미리보기]를 클릭합니다.
2. 상단 메뉴 [파일] ➔ [내보내기] ➔ **[한글 문서 (.hwpx)]**를 선택합니다.
3. 생성된 `.hwpx` 파일을 한컴오피스에서 열어 완벽한 표와 스타일을 확인합니다.

### 4단계: 기업 협업용 Word(.docx) 파일 사출
1. 동일한 미리보기 화면에서 상단 메뉴 [파일] ➔ [내보내기] ➔ **[Word 문서 (.docx)]**를 클릭합니다.
2. MS Word나 구글 드라이브(Google Docs)에 업로드하여 팀원들과 공유합니다.

## 7. 자주 묻는 질문 (FAQ)

### Q1. 암호가 걸려 있는 HWP 문서도 변환할 수 있나요?
**A.** 보안 암호가 걸린 한글 문서는 변환 엔진이 파일 스트림을 해독할 수 없습니다. 한컴오피스 프로그램에서 문서를 먼저 연 뒤, [파일] ➔ [다른 이름으로 저장]에서 보안 암호를 해제하고 온리비 어서로 가져와 주세요.

### Q2. 한글 문서 내보내기 시 글꼴이 깨지지 않나요?
**A.** 온리비 어서의 HWPX 생성기는 국내 윈도우 환경의 표준 서체(맑은 고딕, 본명조, 바탕, 돋움)와 사용자가 지정한 서식 글꼴을 기본 글꼴 패밀리로 지정하므로 한컴오피스에서 열었을 때 글꼴 충돌 없이 단정하게 열립니다.

### Q3. 워드(.docx) 문서 내보내기 시 각주(Footnote)도 워드 각주로 들어가나요?
**A.** 네! 마크다운 본문의 각주 번호(`[^1]`)와 문서 하단 주석 정의가 MS Word의 네이티브 각주(Footnote) 객체로 자동 치환되어, 워드 페이지 하단에 각주가 정식으로 배치됩니다.
