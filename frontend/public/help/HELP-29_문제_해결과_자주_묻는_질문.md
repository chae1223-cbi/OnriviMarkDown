## 1. 문서보기와 도구

| 증상 | 확인 방법 |
| --- | --- |
| 원문 입력이 되지 않음 | 나란히 보기 오른쪽은 현재 읽기 전용입니다. 왼쪽 문서에서 편집하세요. |
| 툴바가 안 뜸 | 선택 후 Ctrl+Space 또는 오른쪽 서식 도구로 엽니다. 마우스 선택만으로 자동 표시되지 않습니다. |
| 표 도구가 안 보임 | 문서보기 표 셀 안을 클릭하고 문서 영역 상단을 확인합니다. |
| 제목의 #를 지우기 어려움 | 제목 맨 앞에서 Backspace 또는 태그 취소를 사용합니다. |
| Tab이 다르게 동작 | 열린 슬래시 메뉴·표·목록 문맥이 Tab의 역할을 바꿉니다. |
| 코드가 잘림 | 코드블록 안쪽 아래 가로 스크롤을 사용합니다. |

## 2. 줄바꿈·목록·인용문

일반 문서보기 Enter는 다음 줄입니다. 인용문에서도 Enter는 안쪽 다음 줄을 유지하고 **Ctrl+Enter**로 나갑니다. 표는 Enter로 셀 안 줄바꿈, Ctrl+Enter로 표 밖 본문 이동입니다.

문장 중간 Tab은 환경설정의 탭 간격 수만큼 스페이스입니다. 목록 끝은 Tab·Shift+Tab으로 계층을 바꿉니다. 연속 공백을 외부 마크다운 뷰어에서 볼 때 합쳐지는 것은 해당 뷰어 표시 규칙일 수 있습니다.

## 3. 이미지·Drive

리소스 폴더와 읽기·쓰기 권한, Drive 로그인 상태를 확인합니다. 폴더가 초기화되어도 삭제된 사진 원본까지 복원되는 것은 아닙니다. 깨진 이미지의 실제 파일과 참조를 비교하세요.

Drive 인증 만료나 네트워크 오류 시 재연결하고 저장 완료 여부를 확인합니다. 도움말 그림은 앱의 `/help/assets/` 파일이므로 사용자 media 폴더에서 찾지 않습니다.

## 4. Mermaid·수식·AI

렌더링 실패는 문법뿐 아니라 엔진·자산 로드·브라우저 오류에서도 발생합니다. Mermaid 코드 언어가 `mermaid`인지 확인하고 새로고침합니다. 코드 원문과 콘솔 오류를 함께 확인하세요.

AI는 인증·모델·한도·네트워크 오류를 구분합니다. HELP-16의 오류표를 참고하세요. 키나 토큰을 제보에 포함하지 마세요.

## 5. 저장·복구

세션 복구가 파일 저장을 대신하지 않습니다. 복구된 내용이 맞는지 확인하고 Ctrl+S로 저장하세요. 자동 저장 간격은 설정값입니다. 브라우저 데이터를 지우기 전에 중요한 파일을 백업하세요.

오류 제보에는 사용 환경(웹/데스크톱, 로컬/Drive), 재현 순서, 개인정보를 가린 오류 메시지, 문제가 되는 짧은 원문을 포함하면 확인에 도움이 됩니다.
