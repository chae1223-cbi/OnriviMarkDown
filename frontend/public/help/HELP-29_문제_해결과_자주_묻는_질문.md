# 문제 해결과 자주 묻는 질문

## 1. 글이 입력되지 않습니다

현재 보기와 편집 가능 상태를 확인하세요.
- **나란히 보기**의 좌측 마크다운 창은 우측 위지윅 편집 결과를 깨뜨리지 않도록 읽기 전용으로 보호됩니다. 마크다운 원문을 직접 수정하려면 상단 또는 상태바에서 **'마크다운' 단독 보기**로 전환하세요.
- 도움말 문서 열람 모드, 라이선스 제한 상태, 문서 미열림 상태도 확인합니다.

## 2. 도움말 문서를 수정하고 저장하려는데 다른 이름으로 저장이 뜹니다

앱 설치 패키지(`app.asar`) 내부의 번들 도움말 파일이 훼손되지 않도록 보호하기 위한 정상적인 안전 동작입니다. `Ctrl+S` 입력 시 작업장 폴더로 새 문서를 저장할 수 있도록 자동으로 '다른 이름으로 저장' 대화상자가 연결됩니다.

## 3. 제목 번호가 자동으로 붙지 않거나 원문에도 생깁니다

- `# ` 뒤 스페이스 입력 시 제목 번호 자동 삽입은 **현재 적용된 서식 프로필의 제목 번호 설정(`headingNumbering`)이 켜져 있을 때만 동작**합니다. 서식 관리에서 제목 번호 형식이 '번호 없음'인지 확인하세요.
- 온리비 어서는 다른 편집기나 외부 내보내기 시에도 번호가 온전히 유지되도록 계산된 번호를 마크다운 원문에도 기록합니다.

## 4. AI가 모델 선택이나 키 등록을 요구합니다

공통 리소스 폴더와 제공사 연결, 선택 모델을 확인합니다. 키 등록·목록 조회·실제 생성은 서로 다른 단계입니다. 결제·할당량·모델 권한 오류는 제공사 계정에서 확인합니다.

## 5. 열린 문서를 AI에 다시 첨부해야 하나요?

문서 정리 탭은 현재 열린 문서 전체를 자동으로 전송합니다. 점검 규칙이나 질문만 입력하세요. 질문 탭의 일반 질문과 구분합니다.

## 6. 이미지가 작아지지 않거나 사라집니다

크기 단위와 적용 결과를 확인합니다. 가로 %는 본문 너비 기준입니다. 파일 경로·공통 리소스 폴더(`Onrivi_Asset/media`)·드라이브 인증도 확인하세요. 노란 배경과 주황 테두리는 위치 강조일 수 있으며 일반 동기화 강조는 잠시 후 사라집니다.

## 7. PDF가 화면 페이지와 다릅니다

예상선·수동 구분·실제 출력을 구분합니다. Enter로 빈 줄을 반복하는 대신 수동 나누기(`<!-- onrivi:page-break -->`)를 사용하고, 인쇄 화면의 용지·배율·여백을 확인합니다. 표나 이미지가 큰 경우 결과 PDF에서 추가 확인합니다.

## 8. 가져오기·그림책 오류

스캔 PDF는 OCR이 필요합니다. HWPX 가져오기는 현재 목록에 없습니다. 그림책은 장면 표시(`:::scene`)와 장면 밖 내용 안내를 확인합니다.

문의할 때는 현재 보기, 작업 순서, 파일 형식, 오류 문구를 함께 알려 주세요. API 키·개인정보는 가리고, 원고의 최소 재현 예제를 사용하세요.
