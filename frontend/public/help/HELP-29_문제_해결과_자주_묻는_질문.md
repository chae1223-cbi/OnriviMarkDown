> "원고를 작성하다가 한글 입력이 꼬이거나, 단축키가 반응하지 않거나, 갑작스러운 정전으로 PC가 꺼졌을 때 당황하지 마세요.  
> 온리비 어서(Onrivi Author)는 한국어 입력의 특성을 완벽히 방어하는 **한글 IME 조합 보호 엔진**, 긴 줄 글자 잘림을 방지하는 **32px 안전 여백 및 고정폭 D2Coding 폰트**, 그리고 예기치 못한 종료 시에도 글자를 100% 살려내는 **5초 세션 자동 복구 아키텍처**를 탑재하고 있습니다.  
> 집필 중 마주칠 수 있는 대표적인 증상별 원인과 원클릭 해결 방법을 상세히 정리해 드립니다."

## 1. 한글 IME 입력 및 슬래시(/) 명령어 트러블슈팅

### 증상 1: 슬래시(`/`)를 눌렀는데 자동완성 추천창이 안 떠요!
- **원인**: 한글은 자음과 모음이 결합되는 조합형 언어(IME)입니다. 한글 단어를 타이핑한 직후(글자 아래에 밑줄이 그어져 있는 조합 중 상태) 바로 `/`를 누르면 브라우저가 이를 조합 문자의 일부로 오인하여 명령어로 인식하지 못합니다.
- **해결 방법**:
  1. **방법 A**: 한글 단어를 입력한 후 `Space`(스페이스바) 또는 `Enter`를 가볍게 눌러 글자 조합을 완전히 끝낸 뒤 `/`를 입력하세요.
  2. **방법 B**: 조합 상태와 무관하게 즉시 슬래시 메뉴를 강제로 열고 싶다면 **`Ctrl + Space`**를 누르세요. 온리비 어서의 강제 제안 가드가 작동하여 100% 즉시 메뉴가 팝업됩니다.

### 증상 2: 한글 입력 중에 `Tab`을 누르거나 `Enter`를 칠 때 목록 들여쓰기가 이상해요!
- **원인**: 온리비 어서는 한글 글자 쪼개짐이나 자모 분리 현상을 막기 위해 `e.isComposing` 및 `__monaco_ime_composing` 플래그를 통한 **IME 조합 보호 가드**를 적용하고 있습니다.
- **원리**: 글자가 조합 중일 때는 들여쓰기나 복잡한 리스트 매크로를 차단하고 단순 공백/개행만을 수행하여 글자가 깨지는 사고를 원천 차단합니다. 글자 작성을 마친 후 키를 누르면 마크다운 목록 문법이 완벽하게 자동 연장됩니다.

### 증상 3: PDF나 이미지 내보내기를 했더니 마지막 한글 글자가 잘려요!
- **보호 조치**: 온리비 어서는 인쇄/PDF/PNG 사출 직전 IME 입력 버퍼를 강제로 디스크에 밀어 넣는 **강제 플러시(Force Flush Commit)** 기술을 적용하고 있습니다. 내보내기 버튼을 누르기 전에 본문 아무 곳이나 마우스로 한 번 클릭해 두시면 마지막 한 글자까지 100% 완벽하게 렌더링됩니다.

## 2. 에디터 텍스트 잘림 및 스크롤 문제 해결

### 증상 1: 긴 문장을 썼을 때 우측 끝 글자가 스크롤바에 가려져요!
- **원인**: 볼드체(`**굵게**`)나 가변폭 세리프 폰트를 사용할 경우 글자 폭이 모나코 에디터의 기본 가로폭 계산치를 초과하여 끝 글자가 숨겨지는 현상이 발생할 수 있습니다.
- **온리비 해결책**:
  1. 온리비 어서는 기본 에디터 글꼴로 가독성이 검증된 **고정폭 네이티브 폰트(D2Coding)**를 채택하여 글자 폭 계산 오차를 0으로 만들었습니다.
  2. 에디터 우측에 **32px 안전 여백(Safe Padding)**을 확보하여 줄 끝 글자(`r`, `;`, `l`, `y` 등)가 스크롤바와 절대 겹치지 않도록 보호합니다.
  3. 만약 화면 폭이 좁다면 환경설정(⚙️)에서 **[자동 줄 바꿈 (Word Wrap)]을 ON**으로 켜주세요.

### 증상 2: 에디터와 미리보기의 스크롤 위치가 맞지 않아요!
- **원인**: 에디터 본문에는 이미지나 표, 긴 수식 등 마크다운 텍스트로는 2~3줄이지만 미리보기에서는 수백 픽셀의 높이를 차지하는 요소들이 포함되어 있기 때문입니다.
- **해결 방법**:
  - 상단 툴바의 **[동기화 스크롤]** 버튼을 토글하여 켜짐 상태를 확인하세요.
  - 마우스 휠을 굴릴 때 커서가 위치한 문단의 헤딩(`H1`, `H2`) 위치를 기준으로 양방향 스크롤 매핑 엔진이 작동하여 항상 동일한 문맥을 바라보도록 정렬해 줍니다.

### 증상 3: 에디터 글씨가 너무 작거나 미리보기가 비정상적으로 확대되었어요!
- **원인**: `Ctrl` 키를 누른 채 마우스 휠을 조작하다가 배율이 틀어진 경우입니다.
- **원클릭 리셋 단축키**:
  - 에디터 글씨 크기 기본값(16px) 복원: 에디터 클릭 후 **`Ctrl + 0`**
  - 미리보기 배율 기본값(100%) 복원: 미리보기 화면 클릭 후 **`Ctrl + Alt + 0`**

## 3. 공통 자원 폴더 및 구글 드라이브 연결 트러블슈팅

### 증상 1: 이미지를 붙여넣었는데 `media/` 경로 엑스박스(깨짐)가 떠요!
- **원인**: 환경설정에서 **공통 자원 폴더(Resource Folder)**가 지정되지 않았거나, 브라우저의 로컬 파일 접근 권한이 만료된 경우입니다.
- **해결 방법**:
  1. 상단 메뉴 [도구] ➔ [환경설정] ➔ **[자원 관리]** 섹션으로 이동합니다.
  2. **[폴더 선택 (필수)]** 버튼을 클릭하여 내 PC의 작업 폴더를 다시 지정합니다.
  3. 브라우저 상단에 "파일 수정 권한을 허용하시겠습니까?" 팝업이 뜨면 반드시 **[수정 권한 허용]**을 눌러주세요.
  4. 구글 드라이브 작업 환경에서는 온리비 어서가 `OnriviAuthor/참조폴더/media`를 자동으로 생성하므로 아무런 추가 설정이 필요 없습니다.

### 증상 2: 구글 드라이브에서 "토큰이 만료되었습니다(401)" 알림이 떠요!
- **원인**: Google OAuth 인증 토큰의 유효 시간(1시간)이 경과했을 때 발생합니다.
- **온리비 자동 복구 시스템**:
  - 온리비 어서는 백그라운드에서 토큰을 무중단 갱신하는 **`initDriveTokenAutoRefresh`** 타이머를 가동하고 있습니다.
  - 만약 네트워크 단절 등으로 토큰이 갱신되지 못했다면, 상단 메뉴 [파일] ➔ **[내 구글 드라이브 연결]**을 다시 한 번 클릭해 주시면 작성 중인 원고 탭을 그대로 유지한 채 2초 만에 보안 세션이 재연결됩니다.

### 증상 3: 공통 자원 폴더의 5대 필수 폴더가 지워졌어요!
- **자동 자가 치유(Self-Healing)**:
  - 온리비 어서는 구글 드라이브 또는 로컬 리소스 폴더에 연결할 때 **5대 필수 하위 폴더**(`bible/`, `db/`, `media/`, `profiles/`, `prompt/`)와 기본 출판 서식 파일(`userCssProfiles.json`)의 존재 여부를 전수 검사합니다.
  - 실수로 폴더가 삭제되었더라도 앱을 새로고침하거나 폴더를 재선택하는 즉시 누락된 폴더와 기본 템플릿을 **무인 자동 복구(Auto Re-create)**합니다.

## 4. 정전 및 비정상 종료 시 세션 자동 복구 탭 관리법

### Q. 컴퓨터가 갑자기 재부팅되었는데 작성 중이던 글이 사라졌나요?
**A. 절대 안심하세요! 온리비 어서의 5초 세션 자동 복구 캐시가 안전하게 보호하고 있습니다.**

1. 브라우저를 다시 열고 온리비 어서에 접속하거나, 데스크톱 앱을 실행합니다.
2. 온리비 어서의 **`useEditorTabs` 자동 세션 복구 엔진**이 작동하여, 마지막 작업 시 열려 있던 모든 탭과 편집 중이던 텍스트 내용을 100% 동일하게 복원합니다.
3. 탭 제목 옆에 주황색 점(동기화 대기)이 표시되어 있다면, 즉시 **`Ctrl + S`** (저장)를 눌러 로컬 디스크 파일에 영구 반영해 주세요.

## 5. 자주 묻는 질문 (FAQ) 종합 정리

### Q1. 온리비 어서 데스크톱 앱(Electron)과 웹 브라우저 버전의 차이점은 무엇인가요?
**A.** 두 환경 모두 100% 동일한 Monaco 에디터 조판 엔진과 출판 서식을 공유합니다. 다만 데스크톱 앱(Electron)은 **내 PC 전체 로컬 파일 시스템 직접 읽기/쓰기**, **OS 단축키 독점 제어**, **오프라인 라이선스 영구 인증**을 지원하여 보안이 중요한 전문 집필가와 출판사에 더욱 최적화되어 있습니다.

### Q2. 수식(KaTeX)이나 다이어그램(Mermaid) 렌더링이 빨간 에러 상자로 떠요!
**A.** 수식 기호나 다이어그램 문법에 오타가 있는 경우입니다:
- 수식: `$` 기호 앞뒤 공백을 확인하시거나 `Ctrl + M` 수식 마법사 모달을 열어 기호를 직접 클릭해 보세요.
- Mermaid: 들여쓰기 공백이나 화살표 기호(`-->`) 문법 오류를 점검해 보세요.

### Q3. 온리비 어서 고객 지원 및 버그 제보는 어디로 하나요?
**A.** 공식 웹사이트 **`https://onrivi.com`**의 고객 센터 및 공식 이메일(`support@onrivi.com`)로 문의해 주시면, 온리비 전담 엔지니어 팀이 신속하게 답변해 드립니다.
