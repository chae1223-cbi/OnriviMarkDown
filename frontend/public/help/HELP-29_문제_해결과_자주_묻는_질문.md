# 문제 해결과 자주 묻는 질문

온리비 어서를 사용하시면서 발생할 수 있는 주요 궁금증과 현장 문제에 대한 **명쾌한 해결 가이드(FAQ)**입니다.

---

## 자주 묻는 질문 TOP 10

### Q1. 에디터 글씨가 흐릿하게 보이고 눈이 피로합니다.
**A1.** [환경설정(⚙️)] ➔ [일반 설정]에서 글꼴 크기를 16px 이상으로 키우시고, 글꼴 굵기를 **'더 선명하게 (SemiBold 600)'**로 선택해 보세요. 난반사가 심하거나 D2Coding 폰트를 사용할 때 글씨의 획이 두꺼워져 뛰어난 가독성을 경험하실 수 있습니다.

### Q2. 본문에 넣은 이미지가 엑스박스(깨짐)로 나옵니다.
**A2.** 두 가지를 점검해 주세요:
1. [환경설정] ➔ [공통 자원 관리]에서 공통 리소스 폴더가 올바르게 연결되어 있는지 확인합니다.
2. 본문에 기재된 이미지 경로가 `./media/파일명.png` 형태인지 확인하세요. 외부 웹 주소(`https://...`)는 원본 서버가 닫히면 깨질 수 있으므로, 이미지를 로컬 리소스 폴더에 다운로드하여 사용하시는 것을 권장합니다.

### Q3. AI 연동 테스트 시 오류가 발생합니다.
**A3.** Google AI Studio(`aistudio.google.com`)에서 발급받은 개인 API 키가 올바른지 확인해 주세요. 또한 모델 선택창에서 지원이 중단된 구형 모델 대신 공식 권장 모델인 **`Gemini 3.8 Flash`**를 선택하고 [연동 테스트]를 누르시면 정상 연결됩니다.

### Q4. PDF 인쇄 시 특정 제목이나 표가 페이지 중간에 어색하게 잘립니다.
**A4.** 인쇄 버튼에서 쪽 윤곽 미리보기를 열고 **페이지 나누기 조정**을 선택하세요. 원하는 위치의 `+`로 지정하고 `×`로 해제할 수 있습니다. 원본 표나 본문은 분리하지 않습니다.

### Q5. 다른 컴퓨터로 문서를 옮기려면 어떻게 해야 하나요?
**A5.** 원고가 보관된 **작업장 폴더(Workspace)**와 이미지가 보관된 **공통 리소스 폴더(Resource Folder)** 두 폴더를 함께 복사하여 새 PC로 옮기신 뒤, 새 PC의 온리비 어서에서 작업장과 리소스 폴더 경로를 지정해 주시면 모든 링크가 완벽하게 유지됩니다.

### Q6. 저장이 되지 않거나 '읽기 전용'이라는 경고가 뜹니다.
**A6.** 비회원(게스트) 상태에서는 문서 보호를 위해 에디터가 읽기 전용으로 잠깁니다. 로그인 후 대시보드에서 **무료(Apprentice) 플랜**을 활성화하시면 즉시 편집과 저장이 가능합니다.

### Q7. 단축키가 작동하지 않습니다.
**A7.** [환경설정] ➔ [단축키 & 슬래시 명령어] 탭에서 해당 기능에 할당된 단축키를 확인하세요. 혹시 다른 프로그램(화면 캡처, 메신저 등)의 전역 단축키와 겹치지 않는지 점검하고, 필요 시 원하는 키로 재정의하거나 [기본값 복원]을 누르세요.

### Q8. 블로그에 붙여넣을 때 서식이 다 깨집니다.
**A8.** 에디터 우측 상단의 **[HTML 복사]** 버튼(단축키 `Ctrl + Shift + C`)을 누른 후 블로그에 붙여넣으세요. 일반 텍스트가 아닌 인라인 CSS 스타일이 포함된 HTML로 복사되므로 제목 색상과 표 테두리가 그대로 살아납니다.

### Q9. 공통 리소스 폴더를 꼭 지정해야 하나요?
**A9.** 리소스 폴더를 지정하지 않으면 이미지를 클립보드로 붙여넣을 때 저장할 로컬 디렉토리를 찾지 못합니다. 안전한 로컬 보관과 원고 유실 방지를 위해 프로그램 최초 실행 시 로컬 폴더를 꼭 연결해 주세요.

### Q10. 세션 복구 알림창이 떴는데 어떻게 해야 하나요?
**A10.** 컴퓨터 강제 종료나 정전 직전까지 작성 중이던 임시 캐시 데이터가 남아 있다는 뜻입니다. **[복구하기]**를 누르시면 마지막 입력 상태가 그대로 복원됩니다. 복원 후 즉시 `Ctrl + S`를 눌러 영구 저장해 주세요.
