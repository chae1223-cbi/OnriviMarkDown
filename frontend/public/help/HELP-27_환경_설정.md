> "집필 환경은 작가의 시력과 집중력, 그리고 원고의 안전을 좌우하는 기초 토대입니다.  
> 온리비 어서(Onrivi Author)는 장시간 원고 작업에도 눈의 피로를 최소화할 수 있도록 **13px~22px의 유연한 글꼴 크기**, D2Coding 전용 **SemiBold(600) 획 굵기**, 난반사를 방지하는 **고대비 흑백 모드**, 5초 단위 **안심 디바운스 자동 저장**을 제공합니다.  
> 또한 나만의 지식 자산을 로컬에 안전하게 보존하는 **공통 자원 폴더 지정**과 최신 **Google Gemini 3.8 Flash AI 연동**까지, 온리비 환경설정(SettingsModal)의 모든 강력한 옵션을 한눈에 살펴보겠습니다."

## 1. 환경설정 창 접근 및 레이아웃 구성

온리비 어서의 환경설정 센터는 언제 어디서나 손쉽게 호출할 수 있습니다.

```
[접근 방법]
1. 상단 메뉴바: [도구(T)] ➔ [환경설정] 클릭
2. 상단 툴바: 우측 톱니바퀴 아이콘 (⚙️) 클릭
```

```
┌────────────────────────────────────────────────────────────────────────┐
│                        온리비 어서 환경설정 센터                       │
│                                                                        │
│  [좌측 사이드바]               [우측 메인 설정 패널]                   │
│  ┌────────────────────┐       ┌─────────────────────────────────────┐  │
│  │ ⚙️ 일반 설정       │       │ 1. 에디터 동작 (줄바꿈/괄호/자동저장)│  │
│  │ ⌨️ 단축키 / 명령어  │       │ 2. 글꼴 & 가독성 (크기/굵기/고대비) │  │
│  │ 👤 계정 관리       │       │ 3. 자원 관리 (공통 자원 폴더)       │  │
│  │                    │       │ 4. AI 어시스턴트 (Gemini API 키)    │  │
│  │ [라이선스 상태뱃지]│       └─────────────────────────────────────┘  │
│  │ [💾 저장 버튼]     │                                                │
│  └────────────────────┘                                                │
└────────────────────────────────────────────────────────────────────────┘
```

- **일반 설정 (`general`)**: 에디터 편집 동작, 타이포그래피 가독성, 공통 자원 폴더, Gemini AI 연동
- **단축키 / 명령어 (`hotkeys`)**: 30여 개 전역 기능 단축키 및 슬래시(`/`) 명령어 사용자 커스텀
- **계정 관리 (`account`)**: 가입 계정 이메일, 유저 UUID, 활동명/별명 수정, 구독 플랜 및 대시보드 연결

## 2. 에디터 동작 및 자동 저장 옵션

에디터 본문의 타이핑 편의성과 원고 안전을 지키는 3대 필수 옵션입니다.

### ① 자동 줄 바꿈 (Word Wrap)
- **기능**: 에디터 창 너비에 맞춰 긴 문장을 자동으로 다음 줄로 개행하여 보여줍니다.
- **설정값**: `ON (켜기)` / `OFF (끄기)`
- **권장**: 창 크기가 좁은 노트북이나 3단 분할 레이아웃 작업 시에는 `ON`을 권장합니다.

### ② 괄호 자동 완성 (Auto Closing Brackets)
- **기능**: 여는 괄호(`(`, `[`, `{`, `"`, `'`)를 입력하는 순간 닫는 괄호를 즉시 짝지어 기입해 줍니다.
- **설정값**: `ON (켜기)` / `OFF (끄기)`

### ③ 자동 저장 (Auto Save)
- **기능**: 편집 중인 원고를 주기적으로 로컬 세션 스토리지 및 캐시에 안전하게 백업합니다.
- **주기 선택**: `사용 안함` | `5초` | `10초` | `30초` | `1분` (기본 권장: **5초**)

> [!중요]
> 자동 저장은 갑작스러운 브라우저 새로고침이나 PC 재부팅 시 탭 상태를 복원해 주는 **세션 자동 복구 백업**입니다.  
> 원고의 물리적 디스크 파일에 영구 반영하려면 수시로 **`Ctrl + S`** (저장)를 눌러주셔야 합니다.

## 3. 글꼴 및 디스플레이 가독성 극대화 설정

온리비 어서는 개발자와 전문 출판 작가의 눈 피로도를 0으로 만들기 위해 Monaco Editor 기반 정밀 타이포그래피 조절 시스템을 내장하고 있습니다.

### ① 에디터 글꼴 크기 (Font Size)
에디터 코드/마크다운 텍스트의 폰트 크기를 1px 단위로 조절할 수 있습니다:
- **선택 단계**: `13px (작게)` ➔ `14px (보통)` ➔ `15px (약간 크게)` ➔ **`16px (크게) ★ 공식 권장`** ➔ `17px` ➔ `18px` ➔ `20px (특대)` ➔ `22px (최대)`
- **시니어 작가 추천**: 작은 글씨로 인해 눈이 침침하신 작가님께는 `18px` 또는 `20px`를 추천합니다.

### ② 에디터 글꼴 굵기 (Font Weight)
에디터 표준 고정폭 글꼴(D2Coding)의 획 굵기를 조절하여 고해상도 모니터나 난반사 환경에서 글자가 흐릿하게 보이는 현상을 완벽히 방지합니다:
- **`보통 (400 - Regular)`**: 얇고 슬림한 표준 개발 폰트
- **`선명하게 (500 - Medium)`**: 또렷한 가독성
- **`더 선명하게 (600 - SemiBold) ★ 공식 권장`**: 볼드체(`**텍스트**`)와의 시각적 구분을 유지하면서도 본문 획을 가장 진하고 선명하게 렌더링하는 황금 굵기
- **`굵게 (700 - Bold)`**: 굵고 단단한 헤비 획

### ③ 고대비 텍스트 (High Contrast)
- **기능**: 에디터 글씨 색상을 순수 흑백(최대 명암비)으로 또렷하게 표시하여 창가나 야외 조명, 빛 반사 환경에서도 텍스트가 번지지 않도록 보호합니다.
- **설정값**: 토글 스위치 `ON` / `OFF`

### ④ 테마 전환 (라이트 / 다크 모드)
- 상단 툴바의 해/달 아이콘(☀️/🌙) 또는 메뉴바에서 라이트 모드(종이 질감 Onrivi 테마)와 다크 모드(Zinc-900 다크 테마)를 원클릭으로 전환할 수 있습니다.

## 4. 자원 관리 (공통 자원 폴더) 설정

> [!NOTE]
> 공통 자원 폴더(Resource Folder)는 온리비 어서 사용 시 **[전체사용자 필수 항목]**입니다.

- **역할**: 현재 작업 환경에서 나만의 출판 서식(`profiles/`), 첨부 이미지·영상(`media/`), AI 프롬프트(`prompt/`), 사전(`bible/`), 로컬 색인 데이터베이스(`db/`)를 읽고 저장하는 중심 기지입니다.
- **폴더 선택 방법**:
  1. 환경설정 [자원 관리] 섹션으로 이동합니다.
  2. **[폴더 선택 (필수)]** 또는 **[폴더 변경]** 버튼을 클릭합니다.
  3. 내 PC의 작업 폴더(예: `C:\MyWorkspace\참조폴더`)를 선택합니다.
  4. 브라우저에서 폴더 읽기/쓰기 권한 요청 팝업이 뜨면 **[수정 권한 허용]**을 클릭합니다.
- **폴더 해제**: 연결된 공통 자원 폴더를 초기화하고 싶을 때는 붉은색 **[폴더 해제]** 버튼을 클릭합니다.

## 5. AI 어시스턴트 설정 (Google Gemini)

에디터 내에서 `/ai` 초안 생성, 문체 변환, 3줄 요약, 교정 기능을 사용하기 위한 연동 설정입니다.

### ① Gemini API 키 등록 및 보안
1. Google AI Studio(aistudio.google.com)에서 무료 발급받은 API 키를 입력창에 붙여넣습니다.
2. **[연동 테스트]** 버튼을 클릭하여 `✅ 구글 Gemini AI와 성공적으로 통신했습니다.` 확인 메시지를 받습니다.
3. 입력된 API 키는 온리비 로컬 보안 스토리지(`saveSecureData`)에 **AES 암호화**되어 안전하게 보관되며, 클라우드 외부로 절대 유출되지 않습니다.
4. 연동을 중단하고 싶다면 붉은색 **[연동 해제]** 버튼을 클릭하여 PC 로컬에 저장된 키를 1초 만에 영구 소거할 수 있습니다.

### ② 공식 지원 AI 모델 라인업
- 온리비 어서는 구버전(Gemini 3.1 이하 및 구형 모델)을 전면 배제하고, 최신 공인 플래그십 모델만을 지원합니다:
  - **`gemini-3.8-flash` (기본 권장 플래그십)**: 초고속 응답 속도와 탁월한 문장 조판 윤문 능력
  - **`gemini-3.7-flash`**: 안정적인 균형 잡힌 글쓰기
  - **`gemini-3.5-flash`**: 경량 빠른 요약
  - **`gemma-4-31b-it` / `gemma-4-26b-it`**: 오픈소스 고성능 추론

## 6. 계정 관리 및 닉네임(활동명) 연동

환경설정 좌측 사이드바의 **[계정 관리]** 탭에서는 다음 정보를 관리할 수 있습니다:

1. **회원 기본 원장 (DB users)**:
   - 계정 이메일 확인
   - 가입/로그인 제공자 (EMAIL, GOOGLE 등)
   - 회원 고유식별자 (User UUID) 클립보드 원클릭 복사
   - 회원 가입 일시 확인
2. **활동명 / 별명 관리 (AI 챗봇 호칭 연동)**:
   - 작가님의 필명이나 별명(예: `탕수육`, `마크다운작가`)을 입력하고 **[별명 저장]**을 누르면 DB에 즉시 영구 저장됩니다.
   - 설정하신 별명은 에디터 우측 하단 플로팅 버튼(예: **탕수육 AI**)에 1ms 만에 실시간 반영되어 다정한 맞춤형 AI 호칭을 제공합니다.
3. **구독 플랜 및 기기 접속 관리**:
   - [대시보드 이동] 버튼을 클릭하면 `onrivi.com/dashboard`로 안전하게 이동하여 라이선스 관리 및 동시접속 기기 제어를 수행할 수 있습니다.

## 7. 자주 묻는 질문 (FAQ)

### Q1. 설정을 바꾼 후 반드시 [저장] 버튼을 눌러야 하나요?
**A.** 네! 좌측 사이드바 하단의 푸른색 **[저장]** 버튼을 클릭해야 브라우저 로컬 저장소와 데스크톱 앱(Electron) 엔진에 영구적으로 기록되며, 변경된 글꼴 크기, 굵기, AI 모델명이 에디터에 즉시 적용됩니다.

### Q2. 글꼴 크기를 20px로 키우면 인쇄나 PDF로 내보낼 때도 글씨가 크게 출력되나요?
**A.** 아닙니다! 환경설정의 [에디터 글꼴 크기]는 작가님이 화면에서 원고를 집필하실 때의 **편집기 시각 가독성**만을 조절합니다. 인쇄나 PDF 사출 규격은 우측 패널의 **[서식 관리(🎨)]**에 정의된 출판 조판 CSS 프로필에 따라 독립적으로 완벽하게 렌더링됩니다.

### Q3. 다른 컴퓨터에서 로그인하면 환경설정이 그대로 유지되나요?
**A.** 계정 이메일과 별명, 라이선스는 클라우드 원장에 보존되어 새 기기에서도 동일하게 유지됩니다. 다만 글꼴 크기, 굵기, 로컬 공통 자원 폴더 경로는 사용자의 PC 하드웨어 환경(모니터 해상도, 드라이브 경로)에 따라 다를 수 있으므로 PC별 로컬 저장소에 안전하게 독립 보관됩니다.
