# 환경설정과 문서 서식의 차이

온리비 어서를 처음 접하시는 분들이 가장 흔히 헷갈리는 부분 중 하나가 **환경설정(Settings)**과 **문서 서식(CSS Profile)**의 차이점입니다.

두 설정의 영역과 역할을 명확히 이해하시면 훨씬 쾌적하고 일관된 저작 환경을 유지하실 수 있습니다.

![[그림 2] 통합 환경설정 모달 및 3대 전용 탭](./assets/fig2_settings_modal.png)

---

## 1. 환경설정과 문서 서식의 핵심 차이

- **환경설정 (⚙️ Application Settings)**:
  - **작가 본인이 일하는 작업실의 환경**을 조절하는 설정입니다.
  - 에디터 글꼴 크기, 에디터 글꼴 굵기, 자동 저장 주기, 단축키 매핑, 공통 리소스 폴더 연결, Google Gemini API 키 연동, 라이선스 계정 관리 등이 포함됩니다.
  - 이곳에서 글자 크기를 키운다고 해서 인쇄될 책의 글자 크기가 커지는 것은 아닙니다 (에디터 화면만 커짐).
- **문서 서식 (🎨 CSS Document Profile)**:
  - **독자가 읽게 될 최종 출판물의 디자인**을 정의하는 설정입니다.
  - 본문 글꼴, 책 본문 글자 크기(pt), 여백, 줄간격, 십진 분류 자동 번호, 표/그림 캡션 위치 등이 포함됩니다.

---

## 2. 통합 환경설정 모달의 3대 전용 탭 상세 안내

1. **일반 설정 (`general`) 탭**:
   - **모든 사용자를 위한 시각적 가독성 최적화 (글꼴 크기·선명도·고대비)**:
     - **원문 글꼴 크기**: 13px부터 22px까지 시원하게 조절
     - **원문 글꼴 굵기**: 4단계 선택을 제공하며, 특히 코딩 폰트나 난반사 모니터에서 글자가 흐려 보이는 현상을 완벽히 방어하는 **'더 선명하게 (SemiBold 600)'** 옵션 탑재
     - **고대비 모드 (High Contrast)**: 저시력 사용자를 위해 텍스트와 배경의 명도 대비를 극대화
   - **자동 줄바꿈(Word Wrap)**: 창 너비에 맞추어 긴 문장을 화면 안에서 줄바꿈 (원문 훼손 없음)
   - **자동 저장 주기(Auto-Save)**: 10초, 30초, 60초 주기 자동 저장
   - **공통 자원 관리 (Resource Folder)**: 내 PC의 미디어/서식 로컬 폴더 지정 및 해제
   - **기본 워터마크 조판 컨트롤 (2026-10-19 신설)**: PDF 출력 시 적용할 텍스트/이미지 워터마크 설정
   - **AI 연동 설정 (`AIConnectionSettings`)**: 글로벌 3대 AI(Gemini, ChatGPT, Claude) 최신 모델 연동 및 AES-256 암호화 보관
2. **단축키 & 슬래시 명령어 (`hotkeys`) 탭**:
   - 키보드 단축키 및 슬래시 명령어를 내 손맛에 맞게 커스텀 매핑
3. **계정 & 라이선스 (`account`) 탭**:
   - 내 로그인 계정 정보, 별명(활동명 - 변경 즉시 에디터 AI 챗봇 및 DB에 실시간 영구 반영), 라이선스 유효 기간 확인
