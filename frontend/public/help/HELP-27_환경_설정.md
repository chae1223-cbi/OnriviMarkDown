## 1. 환경설정 열기

오른쪽 설정 도구 또는 도구 메뉴의 환경설정을 엽니다. 편집 설정, 자원 관리, AI, 단축키 / 명령어, 계정 관련 설정을 확인합니다.

![환경설정 예시](/help/assets/fig2_settings_modal.png)

## 2. 편집 설정

| 설정 | 적용 범위 |
| --- | --- |
| 글자 크기·굵기·테마 | 편집 화면의 가독성 |
| 자동 줄 바꿈 | 마크다운 편집기 표시 옵션 |
| 괄호 자동 완성 | 마크다운 편집기 입력 옵션 |
| 자동 저장 | 선택한 초 단위 간격 뒤 파일 저장 |
| 탭 간격 | 문서의 Tab 공백 수와 원문 편집기 탭 크기 |

탭 간격은 1·2·3·4·6·8·12·16칸 중 선택합니다. 기본은 4칸입니다. 문장 중간 Tab은 탭 문자 대신 해당 수의 스페이스를 입력합니다. 표·목록은 셀 이동·계층 편집을 우선합니다.

문서보기에서 코드블록은 원래 행을 유지하고 긴 줄을 가로 스크롤로 보여줍니다. 일반 자동 줄 바꿈 옵션과 구분하세요.

## 3. 리소스·AI·단축키

- **리소스:** 현재 로컬·클라우드 환경의 폴더를 지정합니다. HELP-04와 HELP-10을 참고하세요.
- **AI:** API 키·모델과 연결을 확인합니다. HELP-16을 참고하세요.
- **단축키 / 명령어:** 플로팅 도구와 슬래시 기능의 사용자 지정값을 관리합니다. HELP-26을 참고하세요.
- **계정:** 라이선스와 사용자 정보를 확인합니다. HELP-28을 참고하세요.

문서의 용지·본문 글꼴·표 여백은 환경설정보다 **서식관리**에서 조정합니다. 설정 저장 결과와 현재 작업 환경을 확인하세요. 다른 기기에 모든 설정이 자동으로 동일하게 전달된다고 가정하지 마세요.
