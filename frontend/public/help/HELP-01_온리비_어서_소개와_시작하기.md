# 온리비 어서 소개와 시작하기

> **<u>온리비 어서는 마크다운 원고를 작성하고, 서식을 적용하여 인쇄·PDF·EPUB 등으로 내보내는 저작 도구입니다.</u>** 문서보기에서 직접 쓰거나 마크다운 원문을 편집할 수 있습니다. 일반 문서와 장면 단위 그림책은 편집 방식이 다릅니다.

## 1. 첫 문서 작성

1. 작업장 폴더를 연결하거나 파일 메뉴에서 새 문서를 만듭니다.
2. 파일명을 정하고 저장 위치를 확인합니다. 새 문서는 나란히 보기로 열리는 경우가 있으므로 상태바에서 원하는 보기로 전환합니다.
3. 문서보기에서 본문을 입력합니다. 줄 앞에 `#`와 스페이스를 입력하면 제목 1이 됩니다.
4. 서식 관리에서 문서에 사용할 서식을 선택합니다.
5. `Ctrl+S`로 저장하고, 수정 표시와 저장 결과를 확인합니다.
6. 파일의 내보내기에서 원하는 형식을 선택하고 결과물을 열어 확인합니다.

## 2. 파일과 설정의 위치

작업장에는 원고를, 공통 리소스 폴더에는 이미지·서식·프롬프트·AI 연결 정보 등 공유 자료를 관리합니다. 폴더를 바꾸면 보이는 자료와 연결 상태도 달라질 수 있습니다. 문서 파일 하나만 복사하면 이미지와 사용자 서식이 함께 이동하지 않을 수 있습니다.

## 3. 먼저 알아둘 점

- 저장, 자동 저장, 세션 복구는 서로 다른 기능입니다. 복구 화면이 있다는 이유로 파일 저장을 생략하지 마세요.
- AI는 API 연결이 필요한 별도 기능입니다. 요청한 내용은 선택한 제공사에 전달될 수 있습니다.
- 웹·데스크톱, 브라우저 권한, 라이선스 상태에 따라 사용 가능한 작업이 다릅니다.
- 화면 보기와 실제 출력 결과는 구분합니다. 특히 가변형 EPUB은 읽기 기기에 따라 페이지가 달라집니다.
