> "일상의 기록이 출판이 되고 가치가 되는 순간"  
> 온리비 어서(Onrivi Author)는 단순한 메모장이나 텍스트 편집기가 아닙니다. 누구나 손쉽게 전문가 수준의 전자책, 단행본, 기술 문서, 블로그 아티클을 기획하고 조판하여 완성도 높은 출판물로 펴낼 수 있도록 설계된 차세대 **마크다운 기반 전자책·출판 조판 저작 도구**입니다.

---

## 1. 온리비 어서(Onrivi Author)란 무엇인가요?

컴퓨터로 글을 쓸 때, 우리는 늘 두 가지 불편함 사이에서 방황하곤 했습니다.

* **일반 워드프로세서(한글, Word 등)**: 본문을 쓰는 도중에 글꼴, 줄간격, 여백, 문단 정렬 같은 복잡한 서식 설정에 끊임없이 신경을 빼앗깁니다. 문단을 조금 수정하면 다음 페이지의 사진과 표가 엉망으로 밀려나기 일쑤입니다.
* **단순 메모장이나 일반 마크다운 에디터**: 글쓰기는 가볍고 빠르지만, 정작 책이나 정식 보고서 형태로 인쇄하거나 전자책(EPUB)으로 내보내려면 디자인이 투박하고 별도의 조판 프로그램을 다시 배워야 합니다.

**온리비 어서**는 이 두 세계의 장점만을 결합하여 탄생했습니다.

1. **전 세계 개발자들이 검증한 Monaco Editor 코어**: VS Code의 심장인 Monaco Editor를 탑재하여 키보드만으로 매끄럽고 빠른 텍스트 입력과 완벽한 한글 입력을 지원합니다.
2. **출판 조판 엔진과 1:1 실시간 렌더링**: 내가 작성한 글이 실제 책이나 A4 규격으로 인쇄되었을 때 어떻게 보일지, 줄바꿈과 여백(Safe-zone)을 실시간으로 우측 화면에서 눈으로 확인하며 쓸 수 있습니다.
3. **독립된 서식 프로필(CSS Profile) 엔진**: 글의 내용과 시각적 디자인을 완벽히 분리하여, 글을 다 쓴 뒤 클릭 한 번으로 '단행본 소설', '학술 보고서', '네이버 블로그 감성 서식' 등 원하는 출판 디자인을 즉시 갈아입힐 수 있습니다.

## 2. 온리비 어서의 3단계 워크플로우: "글쓰기 ➔ 스타일링 ➔ 출판"

온리비 어서의 작업 흐름은 직관적이고 군더더기가 없습니다. 생각의 흐름을 방해하지 않는 3단계 파이프라인을 따라가 보세요.

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  1단계: 글쓰기   │  ──▶  │ 2단계: 스타일링  │  ──▶  │  3단계: 출판    │
│ (Pure Markdown) │       │  (CSS Profile)  │       │  (Multi-Export) │
└─────────────────┘       └─────────────────┘       └─────────────────┘
 • 마크다운 표준 문법      • 원클릭 서식 갤러리      • 인쇄 및 출판 PDF
 • AI 글쓰기 어시스턴트     • A4/출판 규격 여백       • Word (.docx)
 • 슬래시(/) 빠른 명령어    • 타이포그래피 자동화      • EPUB 전자책 / HTML
```

### ① 1단계: 온전한 집중 — 글쓰기 (Writing)
서식 단추를 누르거나 마우스를 쥐지 마세요. 우물 정 자(`#`)로 제목을 나누고, 별표(`**`)로 단어를 강조하며 키보드만으로 글의 뼈대를 세웁니다. 필요할 때는 슬래시(`/`) 명령어나 Google Gemini AI 어시스턴트의 도움을 받아 초안을 막힘없이 써 내려갈 수 있습니다.

### ② 2단계: 품격 있는 변신 — 스타일링 (Styling)
글 작성을 마쳤다면, 온리비 어서의 **서식 정의(CSS 프로필)**를 선택합니다. 문서 상단에 서식 이름 하나만 지정하면, 본문 글자 크기, 행간, 문단 간격, 인용구 박스 디자인, 표 테두리, 각주 형태까지 전문 북디자이너가 만진 것처럼 한 번에 세련되게 정돈됩니다.

### ③ 3단계: 세상과의 만남 — 출판 (Publishing)
완성된 문서는 단 한 번의 클릭으로 출판 품질의 **PDF/인쇄 문서**, 아마존/교보문고에 등록 가능한 **EPUB 전자책**, 웹에 바로 올릴 수 있는 **HTML 파일**, 오피스 편집을 위한 **Word(.docx) 문서**, 또는 SNS 카드뉴스용 **고해상도 PNG 이미지**로 사출됩니다.

## 3. 왜 마크다운(Markdown)과 온리비 어서인가요?

온리비 어서가 특정 회사의 독점 파일 형식이 아닌 **순수 마크다운(Markdown, `.md`)**을 고집하는 이유는 사용자 여러분의 소중한 지식 자산을 영구히 지키기 위함입니다.

| 비교 항목 | 전통적 워드프로세서 (.hwp, .docx) | 온리비 어서 & 마크다운 (.md) |
| :--- | :--- | :--- |
| **데이터 독립성** | 전용 프로그램이 없으면 열 수 없음 | 50년 후 메모장에서도 그대로 열람 가능 |
| **파일 무게** | 수십~수백 MB의 무거운 바이너리 | 불과 수십 KB의 가볍고 순수한 텍스트 |
| **서식과 내용** | 글과 서식이 뒤엉켜 수정 시 레이아웃 파손 | 내용과 서식이 완벽히 분리되어 안전 |
| **보안 및 저장** | 특정 클라우드 서버에 강제 종속 | 내 컴퓨터 로컬 폴더 또는 내 구글 드라이브 보관 |

> [!참고]
> **마크다운(Markdown)이란?**
> 2004년 존 그루버와 아론 슈워츠가 창안한 텍스트 기반 경량 마크업 언어입니다. 복잡한 HTML 태그 없이도 사람이 읽기 편한 기호(`#`, `*`, `-`)만으로 문서의 구조를 완벽하게 표현할 수 있어 전 세계 테크 기업과 작가들의 표준 형식으로 자리 잡았습니다.

## 4. 온리비 어서만의 4대 핵심 차별점

### 1) 로컬 우선(Local-First) 데이터 주권
온리비 어서는 사용자의 원고를 임의의 상업용 데이터베이스에 저장하지 않습니다. 모든 문서는 사용자의 로컬 PC 디스크나 사용자의 개인 Google Drive에만 저장됩니다. 인터넷 연결이 끊겨도 오프라인 데스크톱 앱을 통해 언제든 자유롭게 글을 쓸 수 있습니다.

### 2) A4 및 출판 안전구역(Safe-Zone) 시각화
기존 웹 에디터들은 모니터 너비에 따라 줄바꿈이 제멋대로 늘어납니다. 온리비 어서의 우측 미리보기는 실제 인쇄 용지(A4 규격) 여백과 비례를 1:1로 시뮬레이션하여, 페이지 경계를 넘어가는 글자나 이미지를 사전에 완벽히 방지합니다.

### 3) 공통 리소스 폴더(Onrivi_Asset / 참조폴더) 통합 관리
이미지를 문서에 넣을 때마다 어디 저장할지 고민하셨나요? 온리비 어서는 전용 리소스 폴더를 자동으로 구성하여, 이미지, CSS 서식, 참고문헌(BibTeX), AI 프롬프트를 한곳에서 일목요연하게 관리합니다.

### 4) 최신 Google Gemini AI 모델과의 유기적 결합
단순한 텍스트 완성을 넘어, 환경설정에서 등록한 개인 Gemini API 키를 바탕으로 최신 플래그십 AI 모델과 연동됩니다. 원클릭 교정, 목차 생성, 초안 확장, 맞춤법 검사를 에디터 안에서 즉시 수행할 수 있습니다.

## 5. 단계별 실전 따라 하기: 3분 만에 첫 문서 완성하기

지금 바로 온리비 어서의 마법 같은 저작 환경을 경험해 보세요!

1. **상단 메뉴에서 새 문서 시작하기**:  
   상단 메뉴바의 `파일(F) ➔ 새문서`를 클릭하거나, 좌측 탐색기 빈 곳에서 마우스 우클릭 후 `새 파일`(`Alt + N`)을 선택합니다.
2. **간단한 마크다운 문장 입력하기**:  
   중앙 편집기에 아래 예시 텍스트를 그대로 복사하여 붙여넣어 보세요.
   ```markdown
   # 나의 첫 번째 온리비 어서 원고
   
   온리비 어서로 **멋진 책**을 쓰기 시작했습니다.
   
   * 가볍고 빠릅니다.
   * 출판 품질의 PDF로 즉시 인쇄할 수 있습니다.
   
   > [!팁]
   > 키보드 단축키 `Ctrl + S`를 눌러 문서를 안전하게 저장하세요!
   ```
3. **우측 실시간 미리보기 확인하기**:  
   타이핑하는 즉시 우측 미리보기 화면에 깔끔한 글씨체와 서식이 렌더링되는 것을 확인합니다.
4. **문서 저장하기**:  
   단축키 `Ctrl + S`를 누르고 원하는 파일명(예: `첫문서.md`)을 입력하여 내 컴퓨터 또는 구글 드라이브에 안전하게 보관합니다.

---

> [!팁]
> **마크다운 기호가 낯설다면 서식 툴바를 활용하세요!**  
> 모든 마크다운 기호를 외울 필요는 없습니다. Ctrl + SpaceBar를 클릭해서 **플로팅 서식 툴바** 나 **/(슬래시) 명령어**로 해당 마크다운 명령을 선택해서 사용하면 해당 문장이나 단어 그리고 문단의 형태를 자동으로 표준 마크다운 문법을 삽입하고 적용할 수 있습니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 마크다운을 전혀 모르는 초보자도 쓸 수 있나요?
**A.** 네, 전혀 걱정하지 않으셔도 됩니다! 일반 메모장처럼 글을 쓰시다가 굵게 하고 싶은 부분만 마우스로 긁어 상단 툴바의 `B` 버튼을 누르거나 단축키 `Ctrl + B`를 누르면 됩니다. 온리비 어서의 친절한 툴바와 슬래시(`/`) 명령어가 자연스럽게 마크다운 문법을 안내해 드립니다.

### Q2. 작성한 문서는 어디에 저장되나요?
**A.** 온리비 어서는 사용자의 허락 없이 문서를 외부 서버로 전송하지 않습니다. 여러분의 컴퓨터 폴더(로컬 서재)나 여러분이 직접 연결한 Google Drive의 `OnriviAuthor/작업장` 폴더에 표준 `.md` 텍스트 파일로 안전하게 기록됩니다.

### Q3. 한글과 영문의 줄바꿈이나 폰트가 깨지지 않나요?
**A.** 온리비 어서는 한국어 저작 환경에 최적화된 **Pretendard** 및 **D2Coding** 폰트를 기본 채택하고 있으며, 한글 IME 조합 보호 엔진과 영문 단어 쪼개짐 방지 알고리즘이 내장되어 있어 타이포그래피가 언제나 단정하게 유지됩니다.
