# AI 질문·문서 정리·문구 수정

AI 버튼의 위쪽을 누르면 오른쪽 패널을 열거나 숨기고, 아래 모델 이름을 누르면 모델 목록을 엽니다. API 연결과 사용할 모델을 확인한 뒤 실행하세요.

## 세 가지 탭

| 탭 | 참고하는 내용 | 사용 예 |
| --- | --- | --- |
| 질문 | 질문·첨부, 명시적으로 선택한 참고 글 | 일반 질문, 선택한 문장 설명 |
| 문서 정리 | 현재 열린 문서 전체 | 문서에 대한 질문, 점검, 요약, 구성 정리 |
| 문구 수정 | 선택한 글 또는 지원되는 문서 편집 범위 | 문장 표현 교정 후 적용 |

문서 정리에서는 원고를 다시 첨부할 필요가 없습니다. 보내기 시점의 문서 내용을 읽습니다. 작성 규칙만 입력하고 “현재 문서를 위치·이유·제안으로 점검해 줘”라고 요청할 수 있습니다. 요약은 요청했을 때 수행하도록 안내하며 결과만으로 원문을 자동 교체하지 않습니다.

## 문구 수정의 복수 작업

정중한 문체·쉽게 설명하기·중복 표현 없애기 등을 함께 체크합니다. 선택한 조건에 맞춰 아래 입력창에 프롬프트가 생성됩니다. 독자·목적 같은 추가 요청을 직접 적을 수 있습니다. 작업을 해제하면 자동 생성 부분을 갱신하고 직접 덧붙인 요청은 유지합니다. 직접 요청은 작업 선택을 해제합니다.

추가 작업은 문장 흐름 개선하기·핵심을 먼저 쓰기·모호한 표현 명확히 하기·용어·말투 통일하기입니다. 여러 작업은 한 요청에 함께 전달하며, 충돌하는 조건은 추가 요청으로 우선순위를 설명하세요.

## 실행과 적용

Enter는 보내기, Shift+Enter는 줄바꿈입니다. 선택 글 수정에는 5,000자 제한이 적용되는 경로가 있습니다. 결과의 원문·수정안을 확인한 뒤 적용합니다. 요청 중 원문이 바뀌면 대상을 다시 지정해야 할 수 있습니다.

문서 전체 수정은 구조별 결과가 나올 수 있으며, 문서 정리의 전체 점검과 다른 기능입니다. 그림책은 질문·문서 정리를 사용할 수 있지만 장면 편집창의 문구 수정은 아직 별도 연결이 필요합니다. 마크다운 편집창에서의 선택 수정 가능 여부를 확인하세요.
