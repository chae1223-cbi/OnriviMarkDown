> "글을 쓰다 막막할 때, 문장이 매끄럽지 않거나 오탈자가 걱정될 때, 내 PC 안에 24시간 상주하는 전담 편집장(Editor-in-Chief)이 있다면 얼마나 든든할까요?  
> 온리비 어서의 **AI 글쓰기 어시스턴트(`AIDraftModal`)**는 마크다운 구조를 완벽히 이해하는 지능형 집필 파트너로서 원고 초안 생성부터 정밀 윤문, 문체 변환, 핵심 요약까지 원스톱으로 지원합니다."

---

## 1. AI 글쓰기 어시스턴트 진입 방법 3가지

온리비 어서에서는 집필 흐름을 끊지 않고 언제든 즉시 AI 도우미를 호출할 수 있도록 3가지 진입 경로를 제공합니다:

```
┌────────────────────────────────────────────────────────────────────────┐
│  [방법 1] 키보드 단축키 (가장 빠름)                                     │
│          ➔ Ctrl + Shift + A (Mac: Cmd + Shift + A)                     │
├────────────────────────────────────────────────────────────────────────┤
│  [방법 2] 상단 메뉴바 및 툴바                                           │
│          ➔ 상단 메뉴 [도구] ➔ [AI 글쓰기]                               │
│          ➔ 또는 에디터 플로팅 서식 툴바의 반짝이(✨) 아이콘 클릭        │
├────────────────────────────────────────────────────────────────────────┤
│  [방법 3] 에디터 우측 하단 2줄 플로팅 AI 버튼                           │
│          ➔ [1행: {내 별명} AI] 버튼 클릭 (예: '홍길동 AI')              │
└────────────────────────────────────────────────────────────────────────┘
```

> [!팁]
> **에디터 우측 하단의 모델 전환기**  
> 에디터 본문 우측 하단 스크롤 옆에는 항상 내 별명이 적힌 2줄 캡슐 버튼이 배치되어 있습니다. 1행을 누르면 AI 글쓰기 창이 열리고, 2행을 누르면 창을 열지 않고도 원하는 AI 모델(`Gemini 3.8 Flash`, `Gemini 3.7 Flash` 등)을 즉시 교체할 수 있습니다.

## 2. 작업 대상 범위(Scope)의 지능형 3단계 선택

AI 글쓰기 모달이 열리면 상단에서 가장 먼저 **[작업 대상 범위]**를 지정합니다. 에디터에서의 작업 상황에 따라 온리비 어서가 최적의 범위를 자동으로 추천해 드립니다:

| 작업 범위 라디오 | 추천 상황 | AI의 동작 메커니즘 |
| :--- | :--- | :--- |
| **선택 영역 (Selection)** | 본문에서 마우스로 드래그한 문장이 있을 때 | 드래그된 특정 단락만 정밀 수정·교정하며 앞뒤 문맥을 그대로 유지합니다. |
| **문서 전체 (Document)** | 현재 열려 있는 챕터 원고 전체를 손볼 때 | 문서 원본 전체의 맥락을 파악하여 종합 요약, FAQ 추출, 전체 오탈자 검수를 수행합니다. |
| **새 글 작성 (None)** | 백지상태에서 새로운 주제로 원고를 집필할 때 | 기존 본문 간섭 없이 오직 사용자가 입력한 프롬프트 지시에 따라 독립된 마크다운을 창작합니다. |

## 3. 핵심 기능 ① 원고 초안 생성 (Draft Mode)

새로운 책의 한 챕터나 블로그 기고글, 업무 기획서를 작성할 때 주제와 목차만 제시하면 완성도 높은 마크다운 본문을 사출해 냅니다.

### 📝 실전 작성 예시
1. 범위를 **[새 글 작성]**으로 선택합니다.
2. 어시스턴트 지시창(프롬프트)에 아래와 같이 입력합니다:
   ```markdown
   주제: 60대 은퇴자를 위한 스마트폰 모바일 뱅킹 안전 사용법
   타깃 독자: 시니어 독자 (친절한 경어체, 글자 크기와 대비를 고려한 쉬운 단어 사용)
   원고 분량: A4 2장 내외
   포함할 내용:
   1. 피싱·스미싱 문자 구별법 (의심스러운 링크 누르지 않기)
   2. 생체 인증(지문/얼굴) 등록의 편리함
   3. 자주 묻는 질문 3가지 (Q&A 표 포함)
   ```
3. `Ctrl + Enter`를 누르거나 우측 하단의 **[✨ AI 생성 실행]** 버튼을 클릭합니다.
4. AI가 실시간 스트리밍으로 제목(#), 소제목(##), 알림 상자(`> [!주의]`), 표(Table)가 완벽히 구성된 마크다운 코드를 작성해 줍니다.

## 4. 핵심 기능 ② 선택 영역 문맥 윤문 및 교정 (Editorial & Polish)

이미 작성한 문장이 어색하거나 비문(문법 오류), 오탈자가 있을 때 마우스로 쓱 긁어 지정한 뒤 AI에게 다듬기를 요청해 보세요.

```
[교정 전 원문]
이 시스템은 매우 좋아가지고 누구나 쉽게 쓸수있으며 에러도 거이 없습니다.

       ⇩ (선택 영역 모드 + "출판 서적에 어울리는 단정한 문체로 교정해줘")

[교정 후 결과]
본 시스템은 직관적인 인터페이스를 갖추어 누구나 손쉽게 활용할 수 있으며, 오류 발생률이 극히 낮아 높은 안정성을 자랑합니다.
```

- **맥락 인식 보장**: 드래그한 문장 주변의 문맥을 함께 전달받으므로, 뜬금없는 단어로 교체되지 않고 전체 글의 흐름에 자연스럽게 녹아듭니다.
- **원클릭 본문 교체**: 생성된 결과창 하단의 **[에디터에 반영]**을 누르면 선택했던 영역이 다듬어진 새 문장으로 깨끗하게 치환됩니다.

## 5. 핵심 기능 ③ 4대 문체 변환 (Tone & Style)

동일한 내용이라도 독자와 매체에 따라 어투가 달라져야 합니다. 온리비 AI 어시스턴트는 한 번 작성된 원고를 자유자재로 변환해 줍니다:

1. **정중한 경어체 ('~합니다', '~해보세요')**
   - 사용자 매뉴얼, 고객 안내문, 대중 교양서에 적합한 신뢰감 있고 부드러운 어조
2. **친근한 대화체 ('~했지요?', '~해볼까요?')**
   - 시니어 독자용 생활 에세이, 어린이·청소년 교육용 도서에 최적화
3. **학술·보고서체 ('~함', '~임', 개조식)**
   - 대학 논문, 기업 실무 기획서, IR 투자 제안서용 단단하고 논리적인 문체
4. **블로그·SNS 친화체 (이모지 포함)**
   - 네이버 블로그, 브런치, 뉴스레터용 가독성 높은 호흡과 시각적 강조

## 6. 핵심 기능 ④ 원고 3줄 요약 및 핵심 추출

긴 챕터나 연구 자료를 다 읽지 않고도 핵심을 파악할 수 있도록 요약 도구를 제공합니다:

- **TL;DR 3줄 요약**: 바쁜 독자를 위해 서두에 배치할 핵심 요약문 사출
- **Key Points (핵심 요점)**: 글머리 기호(-)로 5대 핵심 시사점 추출
- **해시태그 & 키워드**: SNS 및 SEO 검색 최적화를 위한 핵심 태그 자동 도출
- **인용구(Quote) 발췌**: 독자의 마음을 울리는 문장 1~2개를 엄선하여 인용구 서식(`> `)으로 추출

## 7. AI 프롬프트 템플릿 라이브러리 연동

자주 사용하는 나만의 프롬프트 지시사항이 있다면 매번 길게 타이핑할 필요가 없습니다:

```
[1단계] 모달 상단의 [📚 프롬프트 라이브러리] 버튼 클릭
[2단계] 비즈니스 보고서, SEO 블로그, 동화책, 논문 등 준비된 프리셋 선택
[3단계] 내가 자주 쓰는 명령은 [현재 명령을 라이브러리에 저장]을 눌러 폴더별 영구 보관
```

저장된 모든 라이브러리는 내 PC의 리소스 폴더(`ai_presets.json`)에 저장되므로, 앱을 껐다 켜도 평생 유지됩니다.

## 8. 자주 묻는 질문 (FAQ)

### Q1. AI가 생성한 결과물이 에디터 본문 어디에 들어가나요?
**A.** 모달 우측 하단의 [에디터에 반영] 버튼을 누를 때 3가지 방식을 선택할 수 있습니다:
- **선택 영역 대체**: 드래그했던 문장을 새 결과물로 교체합니다.
- **커서 위치에 삽입**: 현재 에디터 커서가 깜빡이는 자리에 바로 밀어 넣습니다.
- **문서 맨 끝에 추가**: 현재 문서의 가장 마지막 행에 덧붙입니다.

### Q2. AI 생성 도중 오류가 발생하거나 인터넷이 끊기면 어떻게 되나요?
**A.** 온리비 어서는 **원트랜잭션(All-or-Nothing) 클린 롤백 시스템**을 갖추고 있습니다. 생성이 비정상 종료되면 찌꺼기 텍스트가 남지 않도록 깨끗이 정리하고, 붉은색 안내 배너로 한글 원인(예: 인터넷 연결 끊김, Google API 할당량 초과)과 해결책을 안내합니다.
