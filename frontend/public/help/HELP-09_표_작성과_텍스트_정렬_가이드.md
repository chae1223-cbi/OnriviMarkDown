> 데이터와 수치, 비교 분석 내용을 전달할 때 표(Table)는 글의 신뢰도를 결정짓는 핵심 요소입니다. 온리비 어서는 표준 마크다운 표 문법은 물론, 마우스로 슥 긁어 표를 생성하는 **10×10 비주얼 표 마법사**와 출판 수준의 정밀한 열 정렬 기능을 지원합니다.

---

## 1. GFM 표준 표 문법 기초

온리비 어서는 전 세계 표준인 GitHub Flavored Markdown(GFM) 표 규격을 따릅니다. 파이프 기호(`|`)로 칸을 나누고, 하이픈(`-`)으로 헤더(제목 행)와 본문을 구분합니다.

```markdown
| 제품명 | 카테고리 | 가격 | 상태 |
| --- | --- | --- | --- |
| 온리비 어서 Pro | 소프트웨어 | ₩99,000 | 판매중 |
| 전용 조판 폰트팩 | 애드온 | ₩29,000 | 출시예정 |
```

### ① 기본 작성 규칙
1. **첫 번째 줄 (헤더)**: 각 열(Column)의 제목을 적습니다.
2. **두 번째 줄 (구분선)**: 헤더와 본문을 분리하는 줄이며, 각 칸마다 최소 3개 이상의 하이픈(`---`)을 적습니다.
3. **세 번째 줄 이후 (본문)**: 실제 데이터 행을 원하는 만큼 작성합니다.

> [!팁]
> **파이프(|) 간격을 억지로 맞출 필요가 없습니다!**  
> 에디터에서 글자 수가 달라 파이프 줄이 비뚤비뚤하게 어긋나 보여도 걱정하지 마세요. 온리비 어서 조판 엔진이 우측 미리보기 창에 완벽한 사각형 그리드로 정렬하여 렌더링해 줍니다.

## 2. 열(Column) 텍스트 정렬 문법 3가지

표를 깔끔하게 보이게 만드는 가장 중요한 디테일은 **열 정렬(Alignment)**입니다. 두 번째 줄의 구분선에 콜론(`:`)의 위치로 정렬을 지정합니다.

```markdown
| 좌측 정렬 (기본) | 중앙 정렬 | 우측 정렬 (숫자/금액) |
| :--- | :---: | ---: |
| 텍스트 설명 | 2026-10-10 | 1,250,000 원 |
| 한국어 원고 | 완료 | 45,000 개 |
```

### 1) 좌측 정렬 (`:---`)
- **콜론 위치**: 왼쪽 끝
- **추천 용도**: 제품명, 설명 문장, 긴 텍스트 등 일반 글귀에 가장 자연스럽습니다.

### 2) 중앙 정렬 (`:---:`)
- **콜론 위치**: 양쪽 끝
- **추천 용도**: 날짜, 연번, 진행 상태(완료/대기), 짧은 배지, 성별 등 고정 폭 데이터에 적합합니다.

### 3) 우측 정렬 (`---:`)
- **콜론 위치**: 오른쪽 끝
- **추천 용도**: 금액, 수량, 퍼센트(%), 통계 수치 등 자릿수를 맞추어야 하는 숫자에 필수적입니다.

## 3. 툴바 표 생성 마법사 모달 (`Ctrl + T`) 🌟

파이프와 하이픈을 하나하나 손으로 칠 필요가 전혀 없습니다! 온리비 어서의 비주얼 표 마법사를 이용해 보세요.

```
┌──────────────────────────────────────────────┐
│                  [표 삽입 마법사]             │
│                                      4 × 3   │
├──────────────────────────────────────────────┤
│  ┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐             │
│  │■ │■ │■ │■ │  │  │  │  │  │  │ (10×10     │
│  ├──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤  인터랙티브 │
│  │■ │■ │■ │■ │  │  │  │  │  │  │  그리드)   │
│  ├──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤             │
│  │■ │■ │■ │■ │  │  │  │  │  │  │ 원하는 행/열│
│  └──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘ 마우스 드래그│
├──────────────────────────────────────────────┤
│  [정렬 프리셋 선택]                          │
│  ( ) 기본 좌측    (•) 전체 중앙              │
│  ( ) 회계형       ( ) 요약형                 │
├──────────────────────────────────────────────┤
│              [ 표 코드 본문 삽입 ]           │
└──────────────────────────────────────────────┘
```

### ① 표 마법사 실행 방법
1. 상단 서식 툴바의 **`표 생성(Table 아이콘)`**을 클릭하거나 단축키 **`Ctrl + T`**를 누릅니다 (슬래시 `/table`도 가능).
2. 화면 중앙에 세련된 10×10 그리드 팝업창이 나타납니다.
3. 마우스 커서를 그리드 위로 움직여 원하는 **열(가로) × 행(세로)** 크기를 선택합니다 (예: `4 × 3`).
4. **4대 열 정렬 프리셋** 중 하나를 선택합니다:
   - **기본 좌측**: 모든 열을 좌측 정렬(`:---`)로 구성
   - **전체 중앙**: 모든 열을 중앙 정렬(`:---:`)로 구성
   - **회계형**: 첫 번째 열은 항목명 좌측 정렬, 나머지 수치 열은 우측 정렬(`---:`)로 자동 구성
   - **요약형**: 첫 열과 마지막 합계 열은 중앙 정렬, 본문은 좌측 정렬로 구성
5. 마우스를 클릭하면 마크다운 표 템플릿이 커서 위치에 한 번에 쏙 삽입됩니다!

## 4. 온리비 출판 서식 프로필(CSS)과의 시너지

온리비 어서는 일반 웹페이지 스타일의 둥글고 흐릿한 표가 아닌, **출판물에 걸맞은 격조 높은 표 조판**을 제공합니다.

### ① 테두리(Border)의 독립 제어
온리비 서식 프로필(`CSS Style Profile`)에서는 표의 세부 선 두께를 각각 독립 제어할 수 있습니다:
- **외곽 테두리 (Outer Border)**: 표 전체를 감싸는 바깥 테두리 두께 및 색상
- **가로 구분선 (Row Border)**: 행과 행 사이를 가르는 가로선
- **세로 구분선 (Column Border)**: 열과 열 사이를 가르는 세로선 (단정하게 0px로 숨기거나 선명하게 노출 가능)

### ② 헤더 배경색 및 줄무늬(Zebra) 음영
- 헤더 행(`<th>`)에 서식 테마의 고유 포인트 컬러와 볼드 글꼴이 적용되어 제목이 돋보입니다.
- 인쇄 및 PDF 사출 시 표가 페이지 경계선에서 쪼개지지 않도록 자동 페이지 넘김(Page-break) 방어 기능이 적용됩니다.

## 5. 본문 문단 우측 정렬과 서명/발신인 도구

표의 특정 열뿐만 아니라, 일반 본문 문단 전체를 우측이나 중앙으로 정렬하고 싶을 때가 있습니다. 온리비 어서는 이를 위한 전용 문법과 도구를 지원합니다.

### ① 문단 우측 및 중앙 정렬
```markdown
<div align="right">

이 문장은 오른쪽 끝에 정렬됩니다.  
공문서 작성일자나 발신인 명의에 적합합니다.

</div>
```

### ② 원클릭 서명/발신인 도구 (`Ctrl + Alt + R`) 🌟
공문서나 품의서, 편지글의 마지막에 들어가는 결재인 서명 블록을 단축키 **`Ctrl + Alt + R`** (또는 슬래시 `/sign`, `/사인`)로 1초 만에 삽입할 수 있습니다:

```markdown
<div align="right">

2026년 10월 10일  
**작성자: 대표이사 홍길동** <span style="color:#dc2626; border:1.5px solid #dc2626; border-radius:50%; padding:0 3px; font-size:0.85em; font-weight:bold;">인</span>

</div>
```
- **결과**: 화면 우측 끝에 작성일자와 작성자 성명, 그리고 선명한 붉은색 원형 인감도장 표식(`인`)이 정갈하게 인쇄 조판됩니다.

## 6. 자주 묻는 질문 (FAQ)

### Q1. 엑셀(Excel)이나 구글 스프레드시트에서 표를 복사해 붙여넣을 수 있나요?
**A.** 네, 완벽하게 지원됩니다! 엑셀이나 스프레드시트의 셀 영역을 복사(`Ctrl+C`)한 뒤 온리비 어서 편집기에 붙여넣기(`Ctrl+V`)하면, 온리비의 지능형 클립보드 파서가 탭 구분 텍스트(TSV)를 표준 마크다운 표(`|`, `-`)로 100% 자동 변환하여 깔끔하게 삽입해 줍니다.

### Q2. 표 셀 안에서 줄바꿈(Enter)을 하려면 어떻게 하나요?
**A.** 마크다운 표 셀 안에서 엔터를 치면 다음 행으로 넘어가 버립니다. 같은 셀 안에서 줄을 바꾸고 싶을 때는 `<br>` 태그를 입력해 주시면 됩니다.  
예: `| 서울시 중구<br>세종대로 110 |`
