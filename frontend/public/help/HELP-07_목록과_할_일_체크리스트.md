> 생각을 정리하고 작업 순서를 나열할 때 목록(List)만큼 명쾌한 도구는 없습니다. 온리비 어서는 일반 글머리 기호와 번호 목록은 물론, **미리보기 창에서 마우스 클릭 한 번으로 원본 에디터가 실시간 체크되는 혁신적인 양방향 인터랙티브 체크리스트**를 지원합니다.

---

## 1. 순서 없는 목록 (글머리 기호 / Unordered List)

항목의 순서가 중요하지 않은 나열형 내용을 작성할 때 사용합니다.

### ① 마크다운 문법
하이픈(`-`), 별표(`*`), 더하기(`+`) 기호 중 하나를 입력하고 **반드시 한 칸 띄어쓰기(스페이스)**를 누르면 됩니다:

```markdown
- 첫 번째 항목
- 두 번째 항목
  - 하위 보조 항목 (Tab 들여쓰기)
  - 또 다른 하위 항목
- 세 번째 항목
```

### ② 단축키 및 툴바
- **단축키**: `Ctrl + Shift + 8` (또는 슬래시 명령어 `/ul`, `/목록`)
- **서식 툴바**: 상단 툴바의 **`글머리 기호(ListBullets 아이콘)`** 버튼 클릭

### ③ 들여쓰기 깊이(Depth) 조절하기
- **하위 목록 만들기 (들여쓰기)**: 줄 시작이나 항목 앞에서 `Tab` 키를 누르면 오른쪽으로 쏙 들어가며 하위 계층 목록이 됩니다.
- **상위 목록으로 복귀 (내어쓰기)**: `Shift + Tab`을 누르면 다시 상위 목록 레벨로 빠져나옵니다.
- **목록 완전히 끝내기**: 항목 끝에서 `Enter`를 2번 연속 누르면 목록이 깔끔하게 종료되고 일반 본문 문단으로 돌아옵니다.

> [!팁]
> **온리비 어서의 미려한 불릿 디자인**  
> 온리비 어서 조판 엔진은 1단계에서는 꽉 찬 원형 불릿(`•`), 2단계 중첩 리스트에서는 비어 있는 원형 불릿(`◦`), 3단계에서는 사각형 불릿(`▪`)으로 계층에 따라 시각적 심볼을 우아하게 자동 전환해 줍니다.

## 2. 순서 있는 목록 (번호 목록 / Ordered List)

단계별 실행 매뉴얼, 조리법, 우선순위가 있는 계획을 작성할 때 적합합니다.

### ① 마크다운 문법
숫자와 마침표(`1.`, `2.`)를 적고 한 칸 띄어쓴 뒤 내용을 작성합니다:

```markdown
1. 작업장 폴더 열기
2. 새 문서 작성 시작하기
3. 조판 서식 선택하고 PDF로 내보내기
```

- **단축키**: `Ctrl + Shift + 7` (또는 슬래시 명령어 `/ol`, `/숫자`)
- **서식 툴바**: 상단 툴바의 **`숫자 목록(ListNumbers 아이콘)`** 버튼 클릭

### ② 온리비 어서만의 특장점: 에디터 원본 번호 1:1 일치 렌더링
일반적인 웹 브라우저나 타사 마크다운 뷰어는 에디터에 아무리 번호를 다르게 써도 브라우저가 강제로 `1, 2, 3`으로 다시 매겨버리는 문제가 있습니다.

온리비 어서는 **사용자가 에디터에 직접 적은 번호를 100% 존중**합니다:
```markdown
10. 열 번째 규칙
11. 열한 번째 규칙
12. 열두 번째 규칙
```
위와 같이 중간 번호부터 시작하거나 특정 번호를 건너뛰더라도, 미리보기 창에 에디터에 기입된 숫자 그대로 정확하게 1:1 일치하여 렌더링됩니다.

## 3. 인터랙티브 할 일 체크리스트 (Task List) 🌟

온리비 어서의 가장 매력적인 기능 중 하나인 실시간 양방향 체크리스트입니다.

### ① 체크리스트 마크다운 문법
하이픈 뒤에 대괄호와 공백(`- [ ]`), 또는 소문자 x(`- [x]`)를 입력합니다:

```markdown
- [ ] 미완료된 할 일 항목
- [x] 이미 완료된 항목
```

- **단축키**: `Ctrl + Shift + C` (또는 슬래시 명령어 `/check`, `/체크`)
- **서식 툴바**: 상단 툴바의 **`체크리스트(ListChecks 아이콘)`** 버튼 클릭

### ② 미리보기 화면 실시간 양방향 동기화 (Two-way Sync)
일반 마크다운 에디터에서는 미리보기 화면의 체크박스가 '그림'에 불과하여 클릭할 수 없거나, 클릭해도 원본 텍스트가 바뀌지 않습니다.

**온리비 어서는 다릅니다!**

```
┌─────────────────────────┐             ┌─────────────────────────┐
│     좌측 에디터 (Monaco) │             │    우측 실시간 미리보기   │
├─────────────────────────┤  클릭 즉시   ├─────────────────────────┤
│ - [ ] 출판 서식 검토하기  │  실시간 연동 │ ☑️ 출판 서식 검토하기   │
│           ▲             │ ◄─────────► │           ▲             │
│           │             │             │      (마우스 클릭!)     │
│ 원본 텍스트가 자동으로   │             │ 체크박스를 콕 누르면    │
│ '- [x]'로 0초 만에 치환! │             │ 파란색 체크로 변경      │
└─────────────────────────┘             └─────────────────────────┘
```

1. 우측 미리보기 패널에서 체크박스를 **마우스로 콕 클릭**해 보세요.
2. 에디터 원본의 `- [ ]`가 즉각 `- [x]`로 자동 치환되며 체크 표시가 켜집니다!
3. 다시 클릭하면 `- [ ]`로 해제됩니다.
4. **완벽한 실행 취소 지원**: 실수로 잘못 클릭하더라도 `Ctrl + Z`를 누르면 방금 전 체크 동작이 안전하게 취소(Undo)됩니다.

> [!중요]
> **서식 프로필과의 완벽한 조화**  
> 온리비 어서의 체크박스는 본문 폰트 및 테마 색상(라이트 모드 코발트 블루 / 다크 모드 스카이 블루)과 완벽하게 어우러지며, 불필요한 마커 점이 중복 표시되지 않도록 말끔하게 조판됩니다.

## 4. 목록 작성 생산성 꿀팁

### ① 목록 서식 한 번에 벗겨내기 (태그 취소)
작성해 둔 목록을 다시 일반 문단으로 되돌리고 싶다면:
- 목록 줄에 커서를 두고 단축키 **`Ctrl + Shift + 0`** (또는 서식 툴바의 지우개 아이콘 `Eraser`)을 누르세요.
- `- `, `1. `, `- [ ] ` 접두사가 깔끔하게 제거되고 순수 텍스트만 남습니다.

### ② 문서 서식 일괄 정리 (`🧹`)
복사해 온 글의 들여쓰기나 목록 기호가 어지럽게 엉켜 있다면:
- 단축키 **`Ctrl + Shift + L`** (또는 툴바의 마술봉/빗자루 `MagicWand` 아이콘)을 누르세요.
- 온리비 어서의 스마트 포맷터가 문서 전체의 불필요한 공백을 정돈하고 목록 기호를 표준 규격으로 일괄 정리해 줍니다.

## 5. 자주 묻는 질문 (FAQ)

### Q1. 목록 항목 안에서 줄을 바꾸고 싶은데 엔터를 치면 다음 번호가 생겨요!
**A.** 같은 항목 안에서 줄만 바꾸려면 `Shift + Enter`를 누르시면 됩니다. 다음 번호가 생기지 않고 해당 항목 아래로 줄바꿈됩니다.

### Q2. 체크리스트를 인쇄하거나 PDF로 내보내면 체크박스도 그대로 나오나요?
**A.** 네, 그렇습니다! 온리비 어서의 출판 엔진은 체크박스 상태(`[ ]`, `[x]`)를 고해상도 벡터 그래픽으로 인쇄 페이지에 선명하게 사출하므로, 체크리스트 보고서나 업무 점검표를 실물 종이로 인쇄하기에 최적입니다.
