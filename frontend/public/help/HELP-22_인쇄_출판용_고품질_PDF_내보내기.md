> "원고를 모니터 화면에서 읽을 때와 실제 종이에 인쇄하거나 인쇄소에 제작 납품용 PDF로 넘길 때는 요구되는 품질 기준이 완전히 다릅니다.  
> 화면에서는 보기 좋았던 글이 인쇄할 때 다음 페이지 첫 줄에 제목만 덩그러니 남는 '고아 제목'이 되거나, 수학 수식과 도표가 흐릿한 비트맵 이미지로 뭉개져 인쇄 사고로 이어지기도 합니다.  
> 온리비 어서(Onrivi Author)는 상용 출판사 수준의 정밀한 조판 엔진과 Chromium 네이티브 무손실 벡터 사출 기술을 결합하여, 모니터에서 보던 우아한 레이아웃 그대로 1200 DPI 초고화질 출판용 PDF를 완성합니다."

## 1. 온리비 어서 고품질 PDF 엔진의 특별함

온리비 어서의 PDF 출력 엔진은 시중 웹 에디터들의 조잡한 화면 캡처 방식(html2canvas 등)과 근본적으로 다릅니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   온리비 어서 고정밀 출판 인쇄 조판 아키텍처            │
│                                                                        │
│  [마크다운 원고 및 활성 서식 프로필]                                   │
│            │                                                           │
│            ▼                                                           │
│  [조판 전처리 파이프라인 (exportHandlers.ts)]                          │
│  ├── A4/B5/A5 판형 및 인쇄 안전구역 마진 적용 (상하 18mm, 좌우 12mm)   │
│  ├── 제목 고아 방지 결속 (H1~H6 break-after: avoid)                    │
│  ├── 다이어그램·표 원자적 묶음 보존 (break-inside: avoid)              │
│  └── 페이지 번호 & 러닝 헤더 자동 각인 (counter(page))                 │
│            │                                                           │
│            ▼                                                           │
│  [Chromium 백엔드 네이티브 인쇄 엔진 (printHTMLToPDF IPC)]             │
│  ├── KaTeX 수학 수식: 비트맵 변환 없는 순수 벡터 폰트 렌더링          │
│  ├── Mermaid 다이어그램 & SVG 아이콘: 무손실 벡터 사출                 │
│  └── 한글 서체: Pretendard, 본명조, 나눔글꼴 100% 임베딩               │
│            │                                                           │
│            ▼                                                           │
│  [최종 사출물: 1200 DPI 인쇄소 납품용 초고화질 PDF 파일]               │
└────────────────────────────────────────────────────────────────────────┘
```

1. **무손실 벡터(Vector) 렌더링**:  
   글꼴 활자, KaTeX 수학 공식, Mermaid 다이어그램, 구분선이 픽셀 깨짐 없이 종이에 칼날처럼 선명하게 인쇄됩니다. 300% 이상 확대해도 전혀 흐려지지 않습니다.
2. **출판 인쇄 표준 여백 규격 준수**:  
   국내 출판사 및 관공서 표준 조판인 상하 18mm, 좌우 12mm 인쇄 안전구역을 완벽 준수합니다.
3. **지능형 페이지 분할(Pagination)**:  
   문맥의 흐름을 분석하여 제목과 첫 문단이 서로 다른 페이지로 쪼개지는 것을 원천 방어합니다.

## 2. 화면 위치와 인쇄/PDF 사출 메뉴

PDF 내보내기는 에디터 어디서든 빠르게 실행할 수 있습니다.

```
[상단 메뉴바]
  └── 파일(F)
        └── 내보내기 (미리보기 모드 전용)
              ├── 인쇄/PDF  <── [클릭] (OS 인쇄 다이얼로그 및 PDF 저장)
              ├── Word 문서 (.docx)
              ├── 한글 문서 (.hwpx)
              ├── HTML 파일 (.html)
              ├── EPUB 전자책 (.epub)
              └── PNG 이미지 (.png)
```

1. **미리보기 모드 전환**:  
   - 에디터를 **미리보기 전용 모드**로 전환합니다. (상단 메뉴 [도구] ➔ [화면 보기 모드] ➔ [미리보기] 선택)
2. **인쇄/PDF 메뉴 클릭**:  
   - 상단 메뉴 [파일(F)] ➔ [내보내기] ➔ **[인쇄/PDF]** 항목을 클릭합니다.
   - 키보드 단축키: **`Ctrl+P`** (macOS: `Cmd+P`)
3. **환경별 동작 방식**:  
   - **데스크톱 앱 환경**: Electron IPC(`printHTMLToPDF`) 엔진이 가동되어 파일 저장 탐색기 창이 즉시 열리며, 원하는 폴더에 초고화질 `.pdf` 파일을 원클릭으로 직접 저장합니다.
   - **웹 브라우저 환경**: 시스템 인쇄 미리보기 창이 나타납니다. 대상 프린터에서 **[PDF로 저장]**을 선택하고 [저장]을 누르면 완성됩니다.

> [!중요]
> 웹 브라우저 인쇄 창에서 `Hancom PDF` 등 서드파티 가상 프린터를 선택하면 텍스트 검색 및 드래그 복사 정보가 손실될 수 있습니다. 반드시 브라우저 자체의 **"PDF로 저장"**을 선택해 주세요.

## 3. 출판 인쇄 표준 판형과 여백 조판

책을 만들거나 보고서를 제출할 때 규격에 맞는 종이 크기와 여백 설정은 문서의 품격과 신뢰도를 결정짓습니다.

### ① 지원 표준 판형 (Paper Sizes)
온리비 어서는 전 세계 및 국내 출판계 표준 판형을 완벽히 지원합니다:
- **A4 (210 × 297mm)**: 일반 기업 보고서, 공공기관 제출 공문, 학술 논문, 대형 매뉴얼 표준
- **B5 (182 × 257mm)**: 일반 단행본 서적, 대학 교재, 학습지, 전문 서적 표준
- **A5 (148 × 210mm)**: 시집, 에세이, 소형 핸드북, 독립출판 소설 표준
- **Letter (215.9 × 279.4mm)**: 북미 및 글로벌 오피스 규격

### ② 인쇄 안전구역과 기본 여백
- **온리비 표준 여백**: 상하 **18mm**, 좌우 **12mm**
- **시니어 친화/고급 도서 여백**: 상하 **22mm**, 좌 **19mm**, 우 **20mm**
- 우측 사이드바 툴바의 **서식관리(🎨)** 메뉴에서 [용지 여백] 슬라이더를 통해 밀리미터(mm) 단위로 자유롭게 여백을 조정할 수 있으며, 이 수치는 PDF 사출 시 `@page { margin: ... }` 속성에 1:1로 정확하게 반영됩니다.

## 4. 페이지 나누기(Page Break) 완벽 제어

단원이 끝나고 다음 장을 새로운 종이 첫머리에서 시작하고 싶을 때 온리비 어서가 제공하는 페이지 제어 수칙입니다.

### ① 수동 페이지 나누기 문법
원고 본문에서 페이지를 넘기고 싶은 위치에 아래 태그 중 하나를 삽입하세요:

```markdown
여기까지 1장 서론의 내용이 마무리되었습니다.

<div class="page-break"></div>

# 제2장. 본론 및 실증 분석
```

또는 간결한 마크다운 확장 표기를 사용할 수도 있습니다:
```markdown
\pagebreak
```

> [!팁]
> 온리비 어서의 인쇄 엔진은 `.page-break` 클래스를 감지하면 인쇄 시 `break-before: page !important;` 및 `page-break-before: always !important;`를 발동하여 이전 페이지를 즉시 마감하고 다음 장 맨 윗줄로 커서를 넘깁니다. 화면 미리보기에서는 눈에 거슬리지 않는 슬림한 점선 인디케이터로 표시됩니다.

### ② 고아 제목(Orphan Heading) 자동 방지
일반 워드프로세서에서는 페이지 맨 아래쪽에 제목만 덩그러니 찍히고 본문은 다음 장으로 넘어가는 흉한 인쇄 사고가 빈번합니다.  
온리비 어서는 모든 제목 태그(`H1` ~ `H6`)에 **`break-after: avoid !important;`** 규칙을 결속하여, 제목 바로 뒤의 첫 문단 또는 핵심 이미지와 원자적(Atomic)으로 결합합니다. 남은 페이지 공간이 부족하면 제목 스스로 다음 페이지 첫머리로 넘어가서 본문과 함께 시작됩니다.

### ③ 표(Table)와 다이어그램의 잘림 방지
- **표 행 분할 방지**: 표가 여러 페이지에 걸쳐 인쇄될 때, 표 전체는 자연스럽게 넘어가되 단일 행(`tr`)의 글자가 위아래로 잘리지 않도록 `tr { break-inside: avoid; }`를 적용합니다.
- **헤더 반복 출력**: 다음 페이지로 표가 넘어가도 표 머리글(`thead`)이 새 페이지 최상단에 자동으로 반복 출력되어 독자가 열의 의미를 잃지 않습니다.
- **다이어그램 일체화**: Mermaid 도표와 설명 박스가 한 덩어리로 유지되도록 `break-inside: avoid`를 강제하고, A4 1페이지 내에 쏙 들어가도록 `max-height: 230mm`를 적용하여 이전 페이지에 흉한 빈 사각형만 남는 잔상 버그를 원천 차단합니다.

## 5. 머리말/꼬리말과 실시간 페이지 번호 자동 각인

출판용 문서에는 페이지 상단에 도서 제목이, 하단에는 현재 페이지 번호가 단정하게 찍혀야 합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ [상단 머리말] 온리비 어서 공식 집필 가이드                          A4 │
│                                                                        │
│   본문 내용이 유려하게 조판되는 영역...                                 │
│   ...                                                                  │
│                                                                        │
│ [하단 꼬리말]                         - 5 -                            │
└────────────────────────────────────────────────────────────────────────┘
```

1. **`counter(page)` 기반 실시간 번호 계산**:  
   본문 페이지가 늘어남에 따라 브라우저 인쇄 엔진이 자동으로 실시간 쪽 번호를 계산하여 각인합니다.
2. **다양한 표기 스타일 지원**:  
   - 하이픈 번호형: `- 1 -`, `- 2 -`
   - 전체 쪽수 병기형: `1 / 15`, `2 / 15`
3. **표지 페이지(첫 페이지) 자동 숨김 가드**:  
   책 표지나 첫 표제지에는 페이지 번호가 찍히지 않도록 영리한 조건부 CSS 가드가 내장되어 있습니다.

## 6. 선명한 무손실 벡터 사출 (KaTeX & Mermaid)

일반 마크다운 에디터는 PDF를 만들 때 화면을 캡처한 비트맵 이미지를 삽입하므로 수식이나 도표가 흐릿하게 번집니다. 온리비 어서는 출판 인쇄 공정에 적합한 순수 벡터 데이터를 보존합니다.

```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```

- **KaTeX 수식 무손실 벡터화**: 위 가우스 적분 수식은 300% 이상 확대해도 글자가 절대 깨지지 않는 순수 수학 벡터 폰트(KaTeX Typeface)로 PDF에 내장됩니다.
- **Mermaid 다이어그램 SVG 보존**: 복잡한 순서도나 클래스 다이어그램도 확대 시 선이 뭉개지지 않고 벡터 패스 그대로 인쇄됩니다.

## 7. 단계별 실전 따라 하기 (Step-by-Step)

인쇄소에 넘길 수 있는 완벽한 A4 PDF를 직접 사출해 보겠습니다.

### 1단계: 원고 여백과 서식 확인
우측 사이드바 툴바에서 **서식관리(🎨)**를 클릭합니다. 기본 출판 서식을 선택하고, 용지 여백이 `상하 18mm, 좌우 12mm`로 잡혀 있는지 확인합니다.

### 2단계: 챕터 구분선 점검
큰 장이 바뀌는 곳마다 `<div class="page-break"></div>` 또는 `\pagebreak`를 넣어 새 페이지에서 시작되도록 배치합니다.

### 3단계: 미리보기 화면에서 최종 교정
상단 메뉴 [도구] ➔ [화면 보기 모드] ➔ [미리보기]를 선택합니다. 하단 각주와 표의 선 두께가 원하는 대로 표현되는지 눈으로 점검합니다.

### 4단계: PDF 내보내기 실행
상단 메뉴 [파일(F)] ➔ [내보내기] ➔ **[인쇄/PDF]**를 누릅니다.
- 데스크톱 앱: 파일명을 입력하고 [저장]을 누르면 1~2초 만에 무손실 PDF가 디스크에 생성됩니다.
- 브라우저: 인쇄 창 대상에서 `PDF로 저장`을 선택하고 [저장]을 누릅니다.

## 8. 자주 묻는 질문 (FAQ)

### Q1. 용지 가장자리(여백)에 흰색 테두리가 생기지 않고 배경색이 끝까지 차게 하려면 어떻게 하나요?
**A.** 온리비 어서는 `@page { margin: ...; background-color: ...; }` 및 `print-color-adjust: exact !important;` 지시자를 자동 주입합니다. 만약 브라우저 인쇄 창에서 여백이 하얗게 나온다면, 인쇄 설정의 **[배경 그래픽 인쇄]** 옵션에 체크가 되어 있는지 확인해 주세요.

### Q2. 인쇄용 PDF의 색상 모드는 CMYK인가요, RGB인가요?
**A.** 웹 및 전자문서 표준인 디지털 sRGB를 기본으로 생성합니다. 전문 상업 인쇄소(충무로, 을지로 등)의 옵셋 인쇄 장비에 접수하실 때는 인쇄소 RIP 소프트웨어에서 최신 자동 프로파일(Coated FOGRA39 등)로 CMYK 변환 처리를 진행하므로 안심하고 제출하셔도 좋습니다.

### Q3. 워터마크(대외비, 초안)를 PDF 배경에 흐리게 넣을 수 있나요?
**A.** 네! 환경설정 및 인쇄 옵션에서 배경 워터마크 텍스트(`대외비`, `DRAFT`)와 불투명도(Opacity 10%~20%)를 지정하면, 전 페이지 본문 뒤편에 대각선 반투명 워터마크가 기품 있게 자동 각인됩니다.
