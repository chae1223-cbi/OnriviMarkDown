# 지식보관함 등록·색인·검색·근거 확인

지식보관함은 여러 문서를 등록하고 검색·참조하기 위한 개인형 지식 베이스(RAG) 기능입니다. 열린 문서 한 편을 점검하는 AI 문서 정리와 구분하세요. 지식 화면은 도구 메뉴나 상태바의 지식 관리 진입점에서 엽니다.

## 1. 등록과 원트랜잭션(All-or-Nothing) 색인

1. 가져오기 마법사에서 대상 폴더나 문서를 선택합니다.
2. 스캔 결과와 제외 대상을 확인합니다.
3. 가져오기 설정을 정하고 색인 작업을 시작합니다.
4. 진행 상태·완료·실패 목록을 확인합니다.

색인은 문서의 의미 단위(헤딩, 단락, 표)로 청크를 지능 분할하여 전문 검색 인덱스를 구축하는 과정입니다:
- **데스크톱**: 네이티브 SQLite FTS5 전문 색인(`onrivi_knowledge.db`)에 원트랜잭션(`BEGIN TRANSACTION ... COMMIT`)으로 안전하게 적재되어 0.01초 초고속 검색을 지원합니다.
- 오류 발생 시 즉시 롤백되어 불완전하거나 고아 청크(Orphan Chunks)가 남지 않는 데이터 무결성을 보장합니다.
- **웹(SaaS)**: 브라우저 환경에서는 WASM SQLite(`sql.js`) 엔진을 통해 동일한 검색 기능을 제공합니다.

## 2. 검색과 인용 근거

문서 제목과 내용을 검색하고 결과의 원문·제목 경로·줄 범위를 확인합니다. 근거 뷰어에서 원본으로 즉시 이동할 수 있습니다. AI 원고 작성 시 지식보관함 참조 옵션을 켜면 인덱싱된 원고들을 바탕으로 정확한 근거와 각주를 바탕으로 답변을 생성합니다.

## 3. 유지 관리

환경설정에서 동시 작업 수와 저장 시 자동 재색인 옵션을 확인합니다. 자동 재색인은 등록된 대상과 설정 조건에 따라 수행됩니다. 실패한 문서는 원인과 연결 상태를 확인한 뒤 다시 처리합니다.

지식 DB의 백업·복원·초기화는 원고 파일 저장과 다릅니다. 중요한 작업 전 백업 목록을 확인하고, 복원이 원고 파일까지 되돌리는 기능이라고 오해하지 마세요.
