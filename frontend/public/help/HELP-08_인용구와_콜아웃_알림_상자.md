# 인용구와 콜아웃 알림 상자

## 1. 기본 인용구

문단 앞에서 `> `를 입력하거나 인용구 도구를 사용합니다. 원문 인용, 참고 설명처럼 본문과 구분할 내용에 사용하세요.

```markdown
> 인용한 문장입니다.
> 필요한 출처를 함께 적습니다.
```

## 2. 콜아웃

```markdown
> [!NOTE]
> 참고할 내용입니다.

> [!WARNING]
> 확인이 필요한 내용입니다.
```

NOTE·TIP·IMPORTANT·WARNING·CAUTION에 대응하는 인용 도구가 있습니다. 문서보기에서 태그를 입력하면 알림 상자로 전환할 수 있습니다. 영문 태그의 대소문자는 정규화되는 경로가 있습니다.

## 3. 상자 아래에 본문 쓰기

도구로 인용구를 만들면 아래 빈 문단을 사용할 수 있습니다. 상자 안에서 빠져나가기 어렵다면 `Ctrl+Enter`로 블록 아래 문단을 만드는 방법을 사용합니다. Enter만 반복해 불필요한 빈 인용문을 만들지 마세요.

## 4. 내보내기 확인

상자의 색과 제목은 화면 서식에 따라 달라질 수 있습니다. 외부 마크다운 도구는 콜아웃 확장 문법을 지원하지 않을 수 있습니다. PDF·EPUB·워드로 내보낸 뒤 상자 내용과 읽기 순서를 확인합니다. 콜아웃 배경은 커서 이동 시 잠시 보이는 노란 강조 표시와 다릅니다.
