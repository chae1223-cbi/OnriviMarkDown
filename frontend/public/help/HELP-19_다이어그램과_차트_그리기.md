# Mermaid 다이어그램과 도식

Mermaid는 텍스트로 관계와 흐름을 작성해 도식으로 표시하는 기능입니다. 지원되는 차트 종류는 포함된 렌더러 버전과 문법에 따라 달라집니다. 모든 데이터 차트나 외부 프로그램 파일을 자동 변환하는 기능은 아닙니다.

## 1. 작성 예시

````markdown
```mermaid
flowchart LR
    A[자료 수집] --> B[초안 작성]
    B --> C[검토]
    C --> D[출판]
```
````

코드 블록 언어를 `mermaid`로 지정합니다. 그래프 방향, 노드 이름과 연결선을 작성한 뒤 문서보기 결과를 확인합니다. 문법 오류가 나면 원문을 고쳐 다시 확인하세요.

## 2. 원문과 출력

도식이 복잡하면 작은 글자와 교차선 때문에 읽기 어려워집니다. 긴 문장은 본문으로 옮기고 도식에는 핵심 관계만 남기는 것이 좋습니다. 단순한 본문 표와 관계도를 구분해 사용하세요.

복사나 내보내기 기능은 화면에 표시되는 작업을 따릅니다. PDF·EPUB·워드에서 Mermaid 스크립트가 그대로 실행되는 것은 아니며 출력용 표현으로 변환되는 경로가 있습니다. 결과 파일에서 그림 누락·크기·잘림을 확인합니다.

외부 사이트 예시를 복사할 때는 Mermaid 코드만 코드 블록 안에 넣으세요. 예시를 감싸는 바깥 코드 울타리까지 중복으로 붙이면 일반 코드로 표시될 수 있습니다.
