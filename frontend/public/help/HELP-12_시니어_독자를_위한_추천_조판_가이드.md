> "나이가 들수록 활자는 더 넉넉해야 하고, 배경은 더 포근해야 합니다."  
> 온리비 어서는 은퇴 후 자서전을 집필하시는 시니어 작가님들과, 긴 글을 읽을 때 눈이 쉽게 침침해지는 중장년 독자분들을 위해 과학적인 **눈 건강 맞춤 조판 규격**을 연구하여 제공합니다.

## 1. 왜 시니어 조판이 별도로 필요한가요?

컴퓨터 모니터나 스마트폰, 태블릿 화면은 종이책과 달리 **빛을 정면으로 쏘아내는 발광체**입니다. 나이가 들면서 수정체의 조절력이 감소하고 안구 건조감이 잦아지면, 작고 빽빽한 글씨는 금세 두통과 눈의 피로를 유발합니다:

- **작은 글씨(13~15px)**: 미간을 찌푸리게 만들고 고개를 앞으로 빼게 만듭니다.
- **좁은 줄 간격(1.3~1.5배)**: 한 줄을 다 읽고 다음 줄로 시선이 내려갈 때 읽던 줄을 놓쳐 길을 잃기 쉽습니다.
- **차가운 순백색 배경(`#FFFFFF`)**: 형광등을 눈에 직접 비추는 것과 같은 강한 눈부심(Glare)을 발생시킵니다.

온리비 어서는 이 세 가지 피로 유발 요소를 완전히 해소할 수 있는 **시니어 활자 조판 4대 원칙**을 제안합니다.

## 2. 눈이 편안한 활자 조판 4대 원칙

```
┌────────────────────────────────────────────────────────┐
│  [원칙 1] 본문 글자 크기 : 18px ~ 20px                  │
│           (돋보기 없이도 한눈에 또렷하게 들어오는 크기)   │
├────────────────────────────────────────────────────────┤
│  [원칙 2] 줄 간격 (행간) : 1.85배 ~ 2.0배              │
│           (다음 줄을 찾을 때 시선이 길을 잃지 않는 여유)  │
├────────────────────────────────────────────────────────┤
│  [원칙 3] 소프트 미색 배경 : #FCFBF7 (소프트 아이보리)   │
│           + 다크 차콜 본문색 #222222 (고대비 명암)      │
├────────────────────────────────────────────────────────┤
│  [원칙 4] 대형 20px 체크박스 & 굵직한 인용구 테두리     │
│           (손가락 터치가 편하고 시각 구분이 확실한 요소)│
└────────────────────────────────────────────────────────┘
```

### ① 본문 글자 크기: 18px ~ 20px (가독성과 피로도 방어)
- 일반 웹사이트나 문서의 14~15px 글자는 시니어 독자에게 너무 작습니다.
- 온리비 어서가 추천하는 최적의 본문 활자 크기는 **`18px ~ 20px`**입니다.
- 글자 크기가 20px로 커지면 화면과 독자 사이의 거리가 50cm 이상 멀어져도 자연스럽게 글이 읽히므로, 허리와 목을 꼿꼿이 세운 편안한 자세로 집필할 수 있습니다.

### ② 줄 간격: 1.85 ~ 2.0 (줄 바꿈 길 잃음 방지)
- 긴 문장을 읽을 때 줄 끝에서 다음 줄 첫머리로 눈동자가 이동하는 과정을 '도약(Saccade)'이라고 부릅니다.
- 줄 간격이 좁으면 바로 아랫줄이 아닌 엉뚱한 줄을 읽게 되는 **줄 바꿈 길 잃음 현상**이 일어납니다.
- 줄 간격을 **`1.85배`**로 넉넉하게 띄우고, 문단 내 줄바꿈(Shift+Enter) 문장 사이 간격을 **`6px`**로 설정하면 한 줄 한 줄이 레일 위를 달리듯 매끄럽게 읽힙니다.

### ③ 아이보리/미색 배경: 순백색 눈부심을 막는 `#FCFBF7`
- A4 복사지 같은 100% 순백색(`#FFFFFF`)은 모니터의 청색광(블루라이트)과 함께 강한 눈부심을 줍니다.
- 전통 한지나 고급 서적의 내지처럼 따뜻한 온기가 감도는 **소프트 아이보리 미색(`#FCFBF7` 또는 `#F8F6F0`)**을 배경으로 적용하세요.
- 여기에 본문 글씨를 완전한 검정색이 아닌 부드러운 **다크 차콜(`#222222`)**, 큰 제목은 **딥 네이비/차콜(`#1A202C`)**로 매치하면 눈부심은 사라지고 글자의 윤곽은 또렷하게 살아납니다.

### ④ 대형 20px 체크박스와 굵직한 인용구
- 마우스 조작이 서툰 어르신이나 스마트폰 터치 시 작은 14px 체크박스는 누르기 어렵습니다.
- 체크박스 물리 크기를 **`20px`**로 대형화하고 글자와의 간격도 **`12px`**로 넓혀 오클릭을 방지합니다.
- 인용구 역시 얇은 1px 실선 대신 **`5px 두께의 선명한 블루 인디케이터 바`**와 은은한 배경색(`#EDF2F7`)을 적용하여 중요한 메모나 시 구절이 한눈에 띕니다.

## 3. 전자책·자서전·수필 출판 시 추천 글꼴 (Fonts)

온리비 어서의 서식 관리 센터(`CssStyleForm`)에서 [문서 전체 글꼴]을 선택할 때, 집필하고자 하는 책의 장르에 맞춰 아래 3대 추천 글꼴을 활용해 보세요.

```
┌────────────────────────────────────────────────────────┐
│  [1] KoPub 바탕 (한국출판인회의 전자책 표준 서체)       │
│      ➔ 전통적인 품격, 자서전·수필·시집·소설에 강력 추천│
├────────────────────────────────────────────────────────┤
│  [2] 나눔명조 / 본명조 (부드럽고 유려한 명조체)          │
│      ➔ 서정적인 문장, 가족에게 남기는 회고록에 이상적  │
├────────────────────────────────────────────────────────┤
│  [3] Pretendard (현대적이고 가장 선명한 고딕체)        │
│      ➔ 원문자(①, ②)와 숫자가 깨지지 않는 최고의 가독성 │
└────────────────────────────────────────────────────────┘
```

1. **KoPub 바탕 / KoPub 돋움**:
   - 한국출판인회의에서 전자책 보급을 위해 제작한 공인 출판용 글꼴입니다.
   - 글자마다 획의 끝이 부드럽게 맺혀 있어 장시간 독서에도 눈이 피로하지 않으며, 단행본 출판 인쇄 시에도 인쇄소에서 가장 선호하는 서체입니다.
2. **나눔명조**:
   - 한글의 붓글씨 질감을 현대적으로 살려낸 서체로, 살아온 삶의 발자취를 진솔하게 기록하는 자서전이나 인생 회고록에 깊은 울림을 더해줍니다.
3. **Pretendard (프리텐다드)**:
   - 온리비 어서가 시스템 전반에 적극 채택한 무설치 고품질 고딕 웹폰트입니다.
   - 윈도우, 맥북, 스마트폰 어디서 열어도 원번호(①, ②, ③)나 특수기호가 찌그러지지 않고 100% 동일한 선명도로 표시됩니다.

> [!팁]
> **글꼴 변경 방법**  
> 우측 사이드바 툴바의 팔레트(🎨) 아이콘 ➔ `✍️ 기본 타이포그래피` 아코디언 ➔ [문서 전체 글꼴] 옆의 **[변경]** 버튼을 누르면 설치된 폰트를 손쉽게 선택할 수 있습니다.

## 4. 원클릭으로 바로 쓰는 '편안한 전자책 서식'

일일이 글자 크기와 줄 간격을 슬라이더로 조절하기 번거로우시다면, 온리비 어서가 기본 제공하는 **`편안한 전자책 서식`**을 바로 불러오세요!

```markdown
---
title: "나의 인생 회고록"
css_profile: "profile-1791514218283"
css_profile_name: "편안한 전자책 서식"
---
```

### 🚀 적용 순서 (3단계)
1. 온리비 어서 화면 우측 사이드바 툴바에서 **팔레트 아이콘(🎨)**을 누릅니다.
2. 상단 서식 이름 카드를 누르고, 서식 목록에서 **`편안한 전자책 서식 (🏛️)`**을 클릭합니다.
3. 클릭하는 즉시 내 원고의 본문 글자가 20px로 커지고, 배경이 따뜻한 미색(`#FCFBF7`)으로 바뀌며 최적의 조판이 자동 완성됩니다!

```
┌──────────────────────────────────────────────────────────────┐
│  [미리보기 화면 변화]                                        │
│                                                              │
│  H2 큰제목 ➔ 26px 굵은 볼드체 + 하단 2.5px 블루 포인트 라인   │
│  H3 소제목 ➔ 22px + 좌측 4.5px 블루 세로 인디케이터 바      │
│  본문 문단 ➔ 20px 큰 활자 + 1.85 여유로운 행간 + 다크 차콜     │
│  인용구    ➔ 5px 블루 좌측바 + #EDF2F7 부드러운 박스 배경     │
│  체크박스  ➔ 20px 큼직한 네모 상자 (누르기 쉬움)              │
│  전체 배경 ➔ 순백색 눈부심을 없앤 #FCFBF7 소프트 미색         │
└──────────────────────────────────────────────────────────────┘
```

## 5. 자주 묻는 질문 (FAQ)

### Q1. 글자 크기를 20px로 키우면 나중에 A4 인쇄할 때 페이지가 너무 많이 늘어나지 않나요?
**A.** 일반 14px 글자에 비해 페이지 수는 약 20~30% 정도 늘어날 수 있습니다. 하지만 책을 실제로 받아보실 부모님, 어르신, 지인분들이 돋보기안경을 찾지 않고도 편안하게 완독하실 수 있는 가치를 생각한다면 18~20px 조판이 훨씬 만족도가 높습니다. 만약 페이지 수를 줄여야 하는 보고서 형태라면 언제든 `Onrivi 기본서식(system-1)`으로 클릭 한 번에 전환하실 수 있습니다.

### Q2. 다크 모드(검은 화면)를 쓰는 것보다 미색 배경이 더 좋은가요?
**A.** 어두운 방에서 잠깐 스마트폰을 볼 때는 다크 모드가 눈부심을 줄여주지만, 긴 글을 집중해서 읽을 때는 검은 배경에 흰 글씨가 잔상(난시 환자의 글자 번짐 현상)을 유발하기 쉽습니다. 서적 출판과 장시간 독서에는 소프트 미색(`#FCFBF7`)에 다크 차콜(`#222222`) 글씨를 배치하는 것이 의학적으로 눈의 피로도가 가장 낮습니다.
