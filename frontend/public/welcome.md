# 🚀 온리비 어서(Onrivi Author) 5분 완성 집필 체험 가이드 🌟

온리비 어서 즉시 체험판에 오신 것을 환영합니다! 아래의 **5단계 실습 과정**을 차례대로 진행하시며 온리비만의 정밀한 문서 통제와 독보적인 조판 기술을 직접 경험해 보세요.

---

### 📂 1단계 : 작업장 폴더 설정
내 PC에 원고를 보관하고 안전하게 관리할 작업 폴더를 지정하는 과정입니다.
1. 내 PC의 탐색기(Window 탐색기)를 열고, 원하는 공간에 **`my_writing`** 폴더를 생성합니다.
2. 온리비 어서 상단의 **메뉴바 -> 파일(F) -> 작업장 폴더 열기**를 클릭합니다.
3. 1번에서 생성한 **`my_writing`** 폴더를 선택하여 폴더 연동을 완료합니다.

---

### ⚙️ 2단계 : 공통 자원폴더 (Resource Folder) 지정
모든 서식 프로필과 이미지, 영상 등의 미디어가 저장될 공통 리소스 저장소를 지정합니다. 이 폴더는 사용 중인 데스크탑당 한 번만 설정되며, 모든 데이터는 개인 PC의 관리자만 접근 가능하여 외부로 유출될 염려가 전혀 없습니다.
1. 내 PC의 탐색기에서 자원을 통합 관리할 새로운 폴더를 생성합니다.
2. 온리비 어서 상단의 **메뉴바 -> 도구(T) -> 환경설정**을 클릭합니다.
3. 환경설정 모달 창의 왼쪽 사이드바에서 **일반설정 -> 자원관리 (서식&미디어)** 섹션을 찾습니다.
4. **폴더 선택** 버튼을 눌러 방금 생성한 리소스 공통 폴더를 지정합니다.

---

### ✍️ 3단계 : 간단한 문서 만들기
실제 마크다운 문서를 작성하고 실시간 서적 스타일 렌더링을 체험하는 단계입니다.
1. 아래 링크를 클릭하여 실습용 예제 문서를 다운로드합니다.
   * **[📥 실습용 onrivi_author.md 파일 다운로드하기](/onrivi_author.md)**
2. 다운로드받은 `onrivi_author.md` 파일을 메모장이나 텍스트 편집기로 열어 마크다운 원본 문서를 확인합니다.
3. 온리비 어서 왼쪽 파일 탐색기 영역의 빈 공간을 마우스 우클릭하여 **새 파일 생성**을 클릭합니다.
4. 파일명에 **`Onrivi_Author`**를 입력하고 더블클릭하여 에디터 화면에 띄웁니다.
5. 에디터 하단 상태바의 **`분할모드`** 버튼을 클릭하여 녹색(활성화)으로 켭니다.
6. 에디터 왼쪽 입력창에 아까 메모장으로 열어둔 원본 내용을 복사(Ctrl+C)하여 붙여넣습니다(Ctrl+V).
7. 오른쪽 화면에서 아름답게 조판되는 실시간 문서 결과물을 확인합니다.

---

### 🖨️ 4단계 : 내보내기 및 인쇄 (출력하기)
원하는 책 디자인 서식을 선택하고, 완성된 문서를 PDF나 종이책으로 출력하여 품질을 최종 확인하는 단계입니다.
1. 온리비 어서 오른쪽 사이드바에 위치한 **서식설정(프로필)** 탭을 클릭하여 엽니다.
2. 리스트 중 마음에 드는 디자인 테마(예: 페이스북 스토리 서식 등)를 선택하여 실시간 미리보기 화면이 우아하게 바뀌는 것을 확인합니다.
3. 상단의 **메뉴바 -> 파일(F) -> 내보내기 -> 인쇄/PDF**를 선택합니다.
4. 출력 옵션 화면에서 인쇄를 가동하여 완벽한 실물 조판 품질을 PDF나 프린터로 출력해 확인합니다.

---

### 🍀 5단계 : 새로운 글쓰기 여정의 시작
1단계부터 4단계까지의 기본 실습 과정을 모두 마쳤습니다. 이제 이 튜토리얼을 닫고, 온리비 어서(Onrivi Author) 공간에서 작가님만의 멋진 원고와 작품을 자유롭게 지어보시기 바랍니다!
