# 🚀 온리비 어서 5분 마법의 글쓰기 챌린지! 🎉

Onrivi Author 즉시 체험판에 오신 것을 환영합니다! 아래의 **4가지 간단한 단계**를 순서대로 따라 하시면, 5분 이내에 온리비만의 독보적인 가치를 100% 체험하실 수 있습니다.

---

### 📂 [1단계] 나만의 가상 작업 폴더와 문서 만들기
1. 왼쪽 **파일 탐색기** 빈 공간을 마우스 우클릭하거나, 탐색기 상단의 **새폴더 생성 아이콘**을 클릭해 보세요.
2. 폴더 이름으로 \`나의_첫_원고\`를 입력하고 만듭니다.
3. 생성된 \`나의_첫_원고\` 폴더를 우클릭하여 **[새 파일 생성]**을 누르고, \`아이디어.md\` 문서를 생성해 보세요.
4. 생성된 \`아이디어.md\` 파일을 더블클릭하여 에디터 화면에 띄웁니다!

---

### ✍️ [2단계] 타이핑과 실시간 조판의 감동 느끼기
1. 새로 생성하여 연 `아이디어.md` 파일에 아래의 예시 글을 복사해서 붙여넣거나 자유롭게 타이핑해 보세요.
2. 글을 적는 즉시 **우측 미리보기 화면에 실제 서적 스타일의 아름다운 조판으로 0.1초 만에 조판**되어 실시간 반영되는 쾌감을 확인해 보세요.

> **💡 복사하여 테스트해 볼 예시 본고:**
> 
> **글 쓰는 사람의 마음에 온기를 더하는 공간, 온리비 어서(Onrivi Author)입니다. 🍀**
> 
> 온리비 어서는 마크다운의 강력한 생산성과 종이책이 주는 편안한 시각적 감성을 조화롭게 빚어낸 집필 공간입니다. 작가님의 소중한 아이디어가 정갈한 조판을 통해 한 권의 온기 어린 책으로 피어나는 감동을 선물하고자 탄생했습니다.
> 
> 바쁜 일상 속에서 온리비 어서를 기꺼이 방문하여 체험해 주신 것에 깊이 감사드립니다. 작가님의 펜 끝에서 탄생할 모든 문장이 누군가의 마음에 가닿기를 바라며, 집필하시는 원고뿐만 아니라 일상에서 마주하시는 모든 일과 앞날에 늘 따뜻한 행운이 깃들고 하시는 일마다 막힘없이 순조롭게 잘되시기를 온리비 팀이 진심을 담아 기원하고 응원하겠습니다. 🌟

---

### 📊 [3단계] 표(Table)와 특수 하이라이트 무결성 검증하기
1. 아래 표 안의 단어 중 하나를 마우스로 **더블클릭**하여 선택해 보셔요.

| 기능 구분 | 일반 에디터 | 온리비 어서 |
| :--- | :---: | :---: |
| 단어 더블클릭 시 | 표 서식이 깨지거나 글자 위치 뒤틀림 | **텍스트 유실 없이 반투명 하이라이트만 정갈하게 표출** |
| 렌더링 신뢰성 | 깨짐이 다발하여 가독성 저하 | **특허받은 무결점 실시간 보정** |

2. 표나 인용구 내의 단어를 더블클릭하여 선택 영역을 지정해도, 렌더링이 깜빡거리거나 기호가 어긋나지 않는 온리비만의 압도적인 안정감을 느껴보세요.

---

### 💾 [4단계] 새로고침으로 데이터 보존 확인 및 가입하기
1. 키보드의 **F5(새로고침)**를 누르거나 브라우저를 껐다 켜보세요.
2. 5분의 제한 시간이 새롭게 충전되며, 방금 만드신 \`나의_첫_원고\` 폴더와 \`아이디어.md\` 파일이 **단 1글자의 유실도 없이 고스란히 복원**되는 것을 확인하세요.
3. **⚠️ 주의**: 본 체험판은 동일 브라우저당 **최대 5회 접속**만 가능합니다. 5회 접속을 모두 사용해 영구 잠금이 걸리기 전에, 아래 버튼이나 에디터 상단에서 무료로 회원가입을 하여 무제한 클라우드 백업을 활성화해 보셔요!
